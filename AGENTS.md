# Capy Canvas website agent guide

- Everything an artist reads must follow [site/WRITING.md](site/WRITING.md):
  the manual, website pages, release notes and store listings. Before you show a
  draft to anyone or commit it, check it against the cadence patterns in section
  6, and for release notes and store copy against section 12. Rewrite a failing
  passage's structure; trimming words doesn't fix it.
- Keep the owner's own wording where it is accurate, and change only what they
  name.
- Release-note images work on the light and dark site themes. Look at each one
  at display size on both backgrounds before committing it.
- [README.md](README.md) covers building and testing, and
  [DEPLOYMENT.md](DEPLOYMENT.md) covers deploying.
