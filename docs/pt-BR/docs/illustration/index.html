Tutorial de ilustração

Este tutorial percorre uma pequena pintura do início ao fim. Ele usa formas abstratas simples, para que você possa se concentrar na forma como o trabalho é dividido em etapas e camadas. Como cada estágio adiciona suas próprias camadas, você pode voltar e alterar uma parte sem refazer o resto.

O que você aprenderá

  • Sketch e experimente as cores.
  • Desenhe uma arte de linha limpa acima do esboço.
  • Dê a cada forma sua própria camada de cor mascarada.
  • Sombreie dentro de cada forma e exporte o resultado.

Configurar

Se você ainda não verificou sua caneta, comece com o Quickstart. Em seguida, escolha Paint, para que seus pincéis, cores e camadas fiquem todos na tela. Crie um novo desenho sobre pixels 1200 × 1200 para acompanhar o exemplo ou use seu próprio tema, se preferir.

O exemplo é composto por três formas sobrepostas: uma fita curva, um disco e um bloco inclinado, com alguns rabiscos soltos ao redor. Utiliza azul-petróleo, sálvia, ocre e terracota, com linhas azuis escuras e reflexos creme. Cada forma recebe suas próprias camadas nomeadas, o que facilita ver o que pertence a onde.

As quatro etapas

O tutorial possui quatro etapas, todas no mesmo desenho: Sketching, Line art, Masking e Rendering. Cada estágio adiciona novas camadas sobre as anteriores, em vez de substituí-las. É uma boa ideia manter o esboço e o estudo de cores mesmo depois de ocultá-los, caso queira revisá-los mais tarde.

Use os arquivos de exemplo

Para começar de uma etapa específica, abra o esboço, a arte-final, as cores base ou o desenho finalizado com File → Open…. Você também pode usar o PNG da imagem finalizada para praticar a edição de fotos.

Os arquivos de exemplo contêm as mesmas camadas e máscaras que você vê nas capturas de tela. Salve sua própria cópia antes de alterar uma, para que o original permaneça disponível.
