Kebijakan Privasi

Tanggal efektif: 10 September 2026

Kebijakan ini mencakup Capy Canvas dan situs web capycanvas.art dan editor.capycanvas.art. Capy Canvas dioperasikan oleh Zachary Drach dengan nama proyek Capy Atelier.

Untuk pertanyaan atau permintaan privasi, kirim email ke zackdrach@gmail.com.

Data aplikasi

Capy Canvas memproses gambar di perangkat Anda dan mengakses file yang Anda pilih untuk dibuka atau disimpan. Aplikasi tidak mengirimkan gambar Anda atau gambar yang diimpor kepada kami. Kami menerima file jika Anda mengirimkannya dengan permintaan dukungan.

Pengaturan dan preferensi situs web disimpan di perangkat Anda. Aplikasi web juga menyimpan file aplikasi untuk penggunaan offline. Capy Canvas tidak memerlukan akun.

Kami tidak menggunakan periklanan atau analisis penggunaan, menjual informasi pribadi, atau menyematkan pelacak yang mengikuti Anda di seluruh situs web.

Hosting dan diagnostik

GitHub menghosting situs web dan aplikasi web serta mencatat alamat IP pengunjung untuk keamanan. Cloudflare menyediakan DNS.

Untuk versi yang didistribusikan di toko, kami mungkin menerima laporan kerusakan dan diagnostik teknis dari Apple, Google, atau Microsoft. Laporan dapat mencakup informasi perangkat, versi aplikasi dan sistem operasi, serta detail kegagalan. Kami menggunakan laporan yang disediakan platform ini untuk menyelidiki masalah dan meningkatkan stabilitas. Pengumpulan dan pembagian bergantung pada kebijakan platform dan pengaturan berbagi diagnostik.

Dukungan dan kontak

Jika Anda menghubungi kami, kami menerima nama pengguna atau alamat email, pesan, dan lampiran yang Anda berikan. Kami menggunakannya untuk merespons dan menyelidiki masalah yang dilaporkan.

Dukungan melalui masalah GitHub bersifat publik. Korespondensi email ditangani melalui Gmail berdasarkan Kebijakan Privasi Google.

Retensi, keamanan, dan pilihan Anda

File dan pengaturan lokal disimpan di perangkat Anda dan dapat dihapus melalui aplikasi, browser, atau kontrol perangkat yang tersedia. Masalah GitHub publik tetap menjadi bagian dari riwayat dukungan proyek kecuali jika dihapus. Kami menyimpan korespondensi pribadi sesuai kebutuhan untuk menangani permintaan, mendokumentasikan tanggapan, atau memenuhi kewajiban hukum. Log hosting dan diagnostik platform disimpan sesuai dengan praktik penyimpanan penyedianya.

Situs web dan aplikasi web menggunakan HTTPS. Korespondensi non-publik dan laporan diagnostik diakses melalui kontrol akun penyedia.

Anda dapat meminta akses, koreksi, atau penghapusan informasi pribadi yang kami simpan dengan mengirim email ke kontak di atas. Permintaan ditangani berdasarkan hukum yang berlaku. Kami tidak dapat mengakses atau menghapus gambar yang hanya disimpan di perangkat Anda. Anda dapat mengelola berbagi diagnostik platform melalui kontrol privasi perangkat atau platform yang relevan jika tersedia.
