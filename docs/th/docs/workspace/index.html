เอกสารประกอบ

พื้นที่ทำงานและผืนผ้าใบ

Capy Canvas มาพร้อมกับเค้าโครงที่คุ้นเคยสำหรับการสเก็ตช์ภาพ ลงสี และแก้ไขภาพถ่าย เรียกว่า Sketch, Paint และ Photo พวกเขาแชร์เครื่องมือและภาพวาดเดียวกัน ดังนั้นคุณจึงสามารถสลับได้ทุกเมื่อที่งานของคุณเปลี่ยนแปลง หน้านี้ยังแสดงวิธีการเลื่อนไปรอบๆ ผืนผ้าใบและวิธีซ่อนทุกอย่างยกเว้นภาพวาดของคุณ

สิ่งที่คุณจะได้เรียนรู้

  • เลือกพื้นที่ทำงานที่เหมาะกับงานของคุณ
  • แพน ซูม และหมุนมุมมอง
  • ซ่อนอินเทอร์เฟซด้วยโหมด Zen

เลือกพื้นที่ทำงาน

Sketch ให้ภาพวาดของคุณมีพื้นที่หน้าจอมากที่สุดเท่าที่จะเป็นไปได้ ปุ่มสองสามปุ่มที่คุณต้องการอยู่ในแถบชื่อเรื่อง และแผงต่างๆ เช่น เลเยอร์และสี จะเปิดเป็นลิ้นชักในขณะที่คุณใช้งานเท่านั้น แถบเล็กๆ ที่ขอบของหน้าจอจะมีขนาดแปรง ความทึบ ตัวเลือกสี ตลอดจนเลิกทำและทำซ้ำ เพื่อให้อยู่ในระยะเอื้อมมือของคุณ

Paint ช่วยให้ทุกอย่างเปิดโล่งรอบผืนผ้าใบ เครื่องมือ แปรง และสีของคุณจะอยู่ทางด้านซ้าย และ Navigator คุณสมบัติ และเลเยอร์จะอยู่ทางด้านขวา เป็นสถานที่ที่ดีที่สุดในการเรียนรู้โปรแกรมแก้ไข และคำแนะนำเหล่านี้ส่วนใหญ่ใช้งาน

Photo มีไว้สำหรับการแก้ไขภาพ เครื่องมือการเลือกอยู่ใกล้แค่เอื้อม แถบด้านบนแสดงตัวเลือกสำหรับเครื่องมือปัจจุบัน และสี ฟิลเตอร์ และเลเยอร์จะยังคงเปิดอยู่ทางด้านขวา

การสลับพื้นที่ทำงานจะไม่เปลี่ยนรูปวาดของคุณ และภาพวาดที่เปิดอยู่ทั้งหมดของคุณจะยังคงเปิดอยู่เมื่อคุณสลับ

เคลื่อนไปรอบๆ ผืนผ้าใบ

บนหน้าจอสัมผัส ให้ใช้สองนิ้วเพื่อย้าย ซูม และหมุนมุมมองทั้งหมดในครั้งเดียว นิ้วของคุณไม่เคยทาสี ดังนั้นคุณจึงสามารถวางมือบนหน้าจอได้ในขณะที่คุณวาดด้วยปากกา ใช้เมาส์เลื่อนเพื่อเคลื่อนที่ กด Ctrl ค้างไว้แล้วเลื่อนเพื่อซูม หรือลากด้วยปุ่มกลางหรือขวาของเมาส์ คุณยังสามารถกด Space ค้างไว้แล้วลาก และบีบนิ้วเพื่อซูมบนแทร็กแพด กด Ctrl+0 เพื่อให้พอดีกับภาพวาดทั้งหมดบนหน้าจอ

แผง Navigator แสดงตัวอย่างภาพวาดขนาดเล็ก พร้อมปุ่มสำหรับซูม หมุน และพลิกมุมมอง การพลิกมุมมองเป็นวิธีคลาสสิกในการตรวจสอบสัดส่วนของคุณ เนื่องจากข้อผิดพลาดจะเกิดขึ้นเมื่อคุณเห็นภาพวาดสะท้อน การหมุนหรือการพลิกจะเปลี่ยนเฉพาะวิธีที่คุณเห็นภาพวาดเท่านั้น ไม่ใช่ภาพที่บันทึกไว้ หากต้องการเปลี่ยนงานศิลปะ ให้ใช้ การเคลื่อนย้ายและการแปลง

ซ่อนทุกอย่างด้วยโหมด Zen

กด Tab หรือคลิก capybara ที่มุมซ้ายบน เพื่อเข้าสู่ Zen mode แผงและแถบเครื่องมือหายไป เหลือเพียงรูปวาดของคุณ กด Tab หรือคลิก capybara อีกครั้งเพื่อนำกลับมา

หากคุณต้องการจัดเรียงพื้นที่ทำงานใหม่แทนที่จะซ่อน โปรดดูที่ แผง แถบเครื่องมือ และแถบหัวเรื่อง
