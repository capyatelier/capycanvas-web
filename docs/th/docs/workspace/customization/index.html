เอกสารประกอบ

แผง แถบเครื่องมือ และแถบชื่อเรื่อง

คุณสามารถย้ายแผงและแถบเครื่องมือทั้งหมดไปยังตำแหน่งที่คุณคาดหวังได้ ซึ่งจะเป็นประโยชน์อย่างยิ่งหากคุณคุ้นเคยกับแอปอื่น การเปลี่ยนแปลงเค้าโครงจะมีการเลิกทำในตัวเอง ดังนั้นการจัดเรียงอินเทอร์เฟซใหม่จะไม่เลิกทำภาพวาดใดๆ ของคุณ

สิ่งที่คุณจะได้เรียนรู้

  • ย้าย จัดกลุ่ม และยุบแผง
  • เลือกสิ่งที่แถบเครื่องมือและแถบชื่อเรื่องของคุณมี
  • เปลี่ยนรูปลักษณ์ของอินเทอร์เฟซ และเลิกทำการเปลี่ยนแปลงเค้าโครง

จัดเรียงแผง

ลากแผงข้างแท็บหรือที่จับเพื่อย้าย ขณะที่คุณลาก เครื่องหมายจะแสดงตำแหน่งที่สามารถเทียบท่าได้ ปล่อยไปที่อื่นแล้วแผงลอยได้อย่างอิสระ วางแผงลงบนแท็บของแผงอื่นเพื่อจัดกลุ่มเข้าด้วยกัน และลากขอบระหว่างแผงเพื่อทำให้แท็บใหญ่ขึ้น คอลัมน์สามารถยุบเป็นแถบไอคอนได้ ดังนั้นแต่ละแผงจะเปิดเป็นลิ้นชักเมื่อคุณต้องการเท่านั้น

แผงจะเคลื่อนที่ทันทีที่คุณเริ่มลาก ปุ่มต่างๆ ภายในแถบเครื่องมือจะแตกต่างออกไป โดยกดปุ่มค้างไว้ครู่หนึ่งก่อนที่จะลาก เพื่อไม่ให้เข้าใจผิดว่าแตะอย่างรวดเร็ว

เลือกแถบเครื่องมือของคุณ

คลิกขวาที่แถบเครื่องมือ หรือกดค้างไว้เพื่อเลือกเครื่องมือและคำสั่งที่จะแสดง แถบเครื่องมือสามารถรองรับได้มากกว่าปุ่ม: คุณสามารถเพิ่มขนาดแปรงและแถบเลื่อนความทึบ หรือแถบ Tool Options ที่แสดงการตั้งค่าของเครื่องมือปัจจุบันเสมอ ลากแถบเครื่องมือโดยใช้ที่จับเพื่อเคลื่อนย้าย และวางไว้ใกล้กับจุดเริ่มต้น ตรงกลาง หรือจุดสิ้นสุดของขอบหน้าจอเพื่อติดไว้ตรงนั้น Window → Quick Access Toolbars สร้างและจัดการแถบเครื่องมือเพิ่มเติม

Window → Customize Title Bar… ให้คุณจัดเรียงปุ่มต่างๆ ที่ด้านบนของหน้าต่าง รวมถึงตัวสลับพื้นที่ทำงานด้วย ลากรายการเข้าที่ จากนั้นเสร็จสิ้นเพื่อเก็บการจัดเรียงใหม่

เปลี่ยนรูปลักษณ์หรือเลิกทำการเปลี่ยนแปลง

Preferences → Appearance เก็บการตั้งค่าสำหรับรูปลักษณ์ของอินเทอร์เฟซ คุณสามารถเลือกธีมสว่างหรือมืด เลือกสีเฉพาะจุด และตั้งค่าการมองทะลุของแผง เพื่อให้งานศิลปะของคุณสามารถแสดงผ่านแผงเหล่านั้นได้อย่างนุ่มนวล

ใช้ Window → Undo Layout Change และ Redo Layout Change เพื่อย้อนกลับผ่านการเปลี่ยนแปลงเค้าโครง การเลิกทำแบบธรรมดามีไว้สำหรับรูปวาดของคุณเท่านั้น หากต้องการย้อนกลับไปยังวิธีการเริ่มต้นพื้นที่ทำงาน ให้เลือก Restore Starting Layout… หากคุณต้องการเก็บการจัดเรียงไว้มากกว่าหนึ่งรายการ ให้บันทึกการจัดเรียงแต่ละรายการเป็น workspace.
