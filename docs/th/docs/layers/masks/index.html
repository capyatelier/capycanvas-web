เอกสารประกอบ

หน้ากากและการตัด

มาสก์จะซ่อนส่วนหนึ่งของเลเยอร์โดยไม่ต้องลบสีใดๆ ดังนั้นคุณจึงสามารถเปลี่ยนใจได้ว่าขอบควรอยู่ที่ใด การตัดจะทำให้เลเยอร์หนึ่งอยู่ในรูปร่างของเลเยอร์ด้านล่าง ซึ่งเป็นวิธีที่ง่ายที่สุดในการเพิ่มการแรเงาที่ไม่หลุดออกนอกเส้น

สิ่งที่คุณจะได้เรียนรู้

  • ทำหน้ากากจากส่วนที่เลือก
  • Paint บนหน้ากากเพื่อแสดงหรือซ่อนสี
  • คลิปแรเงาไปที่เลเยอร์ด้านล่าง

ทำหน้ากากจากส่วนที่เลือก

ขั้นแรก เลือก พื้นที่ที่คุณต้องการให้มองเห็นได้ จากนั้นเปิดเมนูของเลเยอร์แล้วเลือก Mask → Mask: reveal selection ทุกอย่างที่อยู่นอกส่วนที่เลือกจะถูกซ่อนไว้ แต่ไม่มีสิ่งใดที่ถูกลบ คุณยังสามารถเลือก Mask: hide selection เพื่อซ่อนพื้นที่ที่เลือกแทนได้ อย่าลืมยกเลิกการเลือกหลังจากนั้น เพื่อให้จังหวะถัดไปของคุณไม่ได้จำกัดอยู่เพียงการเลือกเท่านั้น

มาสก์สามารถแสดงเฉพาะสีที่อยู่บนเลเยอร์จริงเท่านั้น หากคุณคิดว่าคุณอาจต้องการขยายรูปร่างให้กว้างขึ้นในภายหลัง ให้เติมสีให้เต็มเลเยอร์ก่อนทำการมาสก์ ดังที่ masking stage ของบทช่วยสอนทำ

Paint บนหน้ากาก

คลิกภาพขนาดย่อของมาสก์ที่อยู่ติดกับเลเยอร์เพื่อแก้ไขมาสก์แทนการทาสี ตอนนี้แปรงใดๆ ก็ตามเผยให้เห็นเลเยอร์ได้มากขึ้นไม่ว่าคุณจะทาสีที่ไหน และ Eraser จะซ่อนมันไว้อีกครั้ง สีที่คุณวาดไม่สำคัญกับหน้ากาก เมื่อเสร็จแล้ว ให้คลิกภาพขนาดย่อของสีเพื่อกลับไปวาดภาพตามปกติ

เมนูของมาสก์สามารถปิดมาสก์ครู่หนึ่ง กลับด้าน หรือลบออกได้ การปิดสีเป็นวิธีที่สะดวกในการเปรียบเทียบผลลัพธ์กับสีที่อยู่ด้านล่าง

คลิปแรเงาให้เป็นรูปร่าง

เพิ่มเลเยอร์ใหม่เหนือเลเยอร์ฐานโดยตรง เปิดเมนู และเลือก Layer Settings → Clip to layer below สิ่งที่คุณวาดบนเลเยอร์ที่ถูกตัดออกจะแสดงเฉพาะตำแหน่งที่เลเยอร์ฐานมีการทาสี ดังนั้นคุณจึงสามารถแรเงาได้อย่างอิสระโดยไม่ต้องเกินขอบ คุณสามารถซ้อนเลเยอร์ที่ถูกตัดไว้หลายชั้นเหนือฐานเดียวกัน เลเยอร์หนึ่งสำหรับเงาและอีกเลเยอร์หนึ่งสำหรับไฮไลต์

Alpha lock เป็นทางเลือกที่ง่ายกว่าเมื่อคุณต้องการเปลี่ยนสีลายเส้นที่มีอยู่แล้ว เช่น ภาพลายเส้น โดยจะเก็บสีใหม่ไว้ในลายเส้นที่มีอยู่ในชั้นเดียวกัน การเรนเดอร์ stage ของบทช่วยสอนใช้ทั้งสองอย่าง
