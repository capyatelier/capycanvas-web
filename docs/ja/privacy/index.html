プライバシーポリシー

施行日: 2026年9月10日

本ポリシーは、Capy Canvas および capycanvas.art、editor.capycanvas.art のウェブサイトに適用されます。Capy Canvas は、Zachary Drach が Capy Atelier というプロジェクト名で運営しています。

プライバシーに関するご質問やご請求は、zackdrach@gmail.com までお送りください。

アプリのデータ

Capy Canvas は端末上で描画を処理し、利用者が開く、または保存するために選択したファイルにアクセスします。アプリから当方に作品や読み込んだ画像が送信されることはありません。サポートへのお問い合わせに添付されたファイルは当方が受け取ります。

設定やウェブサイトの表示設定は端末に保存されます。ウェブ版は、オフラインで使用するためのアプリケーションファイルもキャッシュします。Capy Canvas の利用にアカウントは必要ありません。

当方は、広告の配信、利用状況の分析、個人情報の販売を行わず、複数のウェブサイトにわたって利用者を追跡するトラッカーも組み込みません。

ホスティングと診断情報

ウェブサイトとウェブ版アプリは GitHub でホストされており、GitHub はセキュリティのために訪問者の IP アドレスを記録します。DNS は Cloudflare が提供しています。

ストアで配布されるバージョンについては、Apple、Google、Microsoft からクラッシュレポートや技術的な診断情報を受け取る場合があります。レポートには、端末情報、アプリや OS のバージョン、障害の詳細が含まれる場合があります。当方は、これらのプラットフォームが提供するレポートを、問題の調査と安定性の改善に使用します。情報の収集と共有は、各プラットフォームのポリシーと診断情報の共有設定に従います。

サポートとお問い合わせ

お問い合わせの際には、利用者が提供したユーザー名またはメールアドレス、メッセージ、添付ファイルを受け取ります。これらは返信と報告された問題の調査に使用します。

GitHub Issues でのサポートのやり取りは公開されます。メールでのやり取りには Gmail を使用し、Google のプライバシーポリシー が適用されます。

保存、セキュリティ、利用者の選択

ローカルのファイルや設定は端末に保存され、アプリ、ブラウザー、端末で利用できる機能から削除できます。公開された GitHub の Issue は、削除されない限りプロジェクトのサポート履歴として残ります。非公開のやり取りは、請求への対応、対応記録の保存、法的義務の履行に必要な期間保存します。ホスティングのログやプラットフォームの診断情報は、各提供元の保存方針に従って保存されます。

ウェブサイトとウェブ版アプリは HTTPS を使用します。非公開のやり取りや診断レポートへのアクセスには、各提供元のアカウントのアクセス制御を使用します。

当方が保有する個人情報の開示、訂正、削除は、上記のメールアドレスから請求できます。請求は適用される法律に従って処理します。端末のみに保存された作品に当方がアクセスしたり、削除したりすることはできません。診断情報の共有は、端末やプラットフォームに該当するプライバシー設定がある場合、その設定から管理できます。

変更
