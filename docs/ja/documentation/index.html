ドキュメント

Capy Canvas は開発初期の段階です。ドキュメントは準備中です。

実装済み

  • エディターの基本フレームワーク
  • MVP ブラシライブラリ（初期の最小構成）
  • ウェブ版と GTK 版

今後の予定

  • お絵かきアプリに必要な基本編集機能、ブラシ、各種ツールの拡充。
  • iOS/iPadOS と Android への移植。Wacom MovinkPad Pro 14 などの描画用タブレットにも対応予定。

開発方針

まずは漫画とイラスト向けの機能に重点を置き、将来的にはリアルな絵画表現にも対応する予定です。
