ガイドの概要

作業画面とキャンバス

キャンバスを操作し、周りのツールを使いやすく配置します。

ツールの場所を知る

キャンバス、ブラシ一覧、色の操作、レイヤーパネルを確認します。ツールの設定を開き、調整できる項目を見てみます。

キャンバスを見渡す

表示の移動、拡大縮小、回転、左右反転を扱います。作品自体を変えずに、画面に合わせて表示したり、表示をリセットしたりします。

描きやすい配置にする

ツールバーを移動し、パネルの表示を切り替えます。ツールバーの内容やツール設定を調整し、レイアウトを初期状態に戻す方法も扱います。
