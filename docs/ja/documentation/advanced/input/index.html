ドキュメント
ガイドの概要

ペン・ジェスチャー・ショートカット

ペン、キーボード、デバイスに合わせて操作を調整します。

ペンを調整する

筆圧と傾きを確認し、応答曲線を調整して弱い線と強い線を比較します。ペンのボタンとタブレットの割り当ても扱います。

操作を設定する

キーボードショートカットとタッチジェスチャーを変更します。ペンとタッチの役割を決め、取り消しや表示操作を使いやすく配置します。

入力の問題を調べる

筆圧が効かない、意図しないタッチ跡、カーソルのずれ、線の遅延を扱います。アプリ、ブラウザー、OS、ドライバーの設定を区別します。

デバイス別の内容

プラットフォームを選ぶと、掲載予定の内容を確認できます。

Windows

筆圧、タブレットドライバー、キーボードショートカット。

macOS

ペンタブレット、トラックパッドのジェスチャー、Commandキーのショートカット。

Linux

GTKの作業画面、タブレットの割り当て、ペン入力。

iOS / iPadOS

Apple Pencilの筆圧と傾き、タッチジェスチャー、外付けキーボード。

Android

スタイラスの筆圧、タッチジェスチャー、Wacom MovinkPad Pro 14などの描画用タブレット。
