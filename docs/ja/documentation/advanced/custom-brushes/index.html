ガイドの概要

カスタムブラシと読み込み

ブラシプリセットを作り、整理して共有します。

プリセットを作る

ブラシを複製し、少しずつ設定を変えて線を比較します。名前、プレビュー画像、変更のリセットを扱います。

自分の素材を使う

ブラシ先端とテクスチャを作成、読み込みします。サイズ、透明度、繰り返しと、ブラシの変化への影響を説明します。

読み込んで整理する

ブラシやセットを読み込み、書き出します。対応形式と引き継げない設定を明記し、フォルダー、お気に入り、重複の整理を扱います。
