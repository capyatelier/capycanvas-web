プログレッシブウェブアプリ

Capy Canvas のウェブ版は、インストールしてオフラインで使えます。

OSその他の OS

この端末では Chrome からインストールしてください。

この端末では Safari からインストールしてください。

  1. ウェブアプリを開く。
  2. アドレスバーのインストールアイコンを押し、「インストール」を選びます。
  1. ウェブアプリを開く。
  2. メニュー（⋮）→「インストールとショートカットの作成」→「インストール」。
  1. ウェブアプリを開く。
  2. 「共有」→「ホーム画面に追加」→「追加」。「ウェブアプリとして開く」が表示されたらオンにします。
  1. ウェブアプリを開く。
  2. 「共有」→「ホーム画面に追加」→「追加」。
  1. ウェブアプリを開く。
  2. 「ファイル」→「Dock に追加」→「追加」。

macOS 14 以降が必要です。旧バージョンでは Chrome を使ってください。

  1. ウェブアプリを開く。
  2. アドレスバーのウェブアプリボタンを押してインストールします。

ボタンがない場合は Firefox を更新するか、Chrome を使ってください。

  1. ウェブアプリを開く。
  2. メニュー（⋮）→「インストール」→「ホーム画面に追加」。
  1. ウェブアプリを開く。
  2. パソコンや Android では Chrome、iPhone/iPad では Safari を使い、ブラウザーから「インストール」または「ホーム画面に追加」を選びます。
