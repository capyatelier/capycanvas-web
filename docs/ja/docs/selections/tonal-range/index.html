明るさで選択する

写真では、シャドウを持ち上げたり、明るすぎる空を落ち着かせたりと、暗い部分や明るい部分だけを調整したいことがよくあります。Tonal rangeツールは明るさや暗さで範囲を選び、境界を柔らかくするので、調整が自然になじみます。

このページで学ぶこと

  • プリセットで階調の範囲を選びます。
  • 画像から自分で範囲を指定します。
  • 選択範囲を柔らかくし、調整に使います。

階調の範囲を選ぶ

選択ツールの中からTonal rangeを選びます。Toolパネルに、ShadowsからMidtones、Highlightsへと並ぶプリセットが表示されます。どれか1つを選ぶと、画像の該当する部分がすぐに選択されます。

自分で範囲を決めるにはCustomを選び、選びたい階調の部分を画像上でクリックまたはドラッグします。そのあと範囲の両端を調整して、目的の階調だけが選択されるようにします。

境界を柔らかくする

Softnessは、選んだ階調とその周りの階調とのあいだで、選択範囲がどれだけなだらかに薄れていくかを決めます。値を高くすると、なめらかで自然な移り変わりになり、写真にはたいていこれが最適です。Featherは、選択された部分の外側の境界をさらに柔らかくします。ほかの選択ツールと同じく、Toolパネル上部のボタンを使って、階調で選んだ選択範囲に追加したり、一部を除いたりできます。

選択範囲を使う

選択範囲があるうちに、フィルターと調整からCurvesやExposureなどの調整を追加します。調整は選択した階調にだけ適用されます。たとえば、シャドウを選択して明るくすればディテールが見えるようになり、ハイライトを選択して下げれば白く飛んだ空の色を取り戻せます。

選択範囲をあとで使えるように残すには、クイックマスクと選択レイヤーで説明しているように、選択レイヤーとして保存します。
