マスク作成

線画の輪郭ができたら、その内側を塗るためのレイヤーを用意します。髪、肌、服の下塗りを分け、それぞれにマスクを付けます。マスクは、塗りを消さずに隠す範囲を編集できる境界です。

このガイドは想定する制作手順を説明する草案で、開発中の機能も含みます。

このページで学ぶこと

  • 選択ツールで線画を読み取り、別のレイヤーに色を塗りつぶします。
  • 塗りを線の下まで少し広げて、明るい隙間をなくします。
  • レイヤーマスクを編集して、塗った領域の縁を修正します。

1. 髪の形を選択する

下描きと色ラフを非表示にし、線画を残します。自動選択ツールの参照先を線画に設定してから、髪の輪郭の内側を選択します。参照先は、どのレイヤーの輪郭を読み取るかを指定する設定です。

先に選択範囲を確認してください。隙間から外へ広がった場合は、選択を解除し、線画の隙間を閉じて選択し直します。輪郭が閉じていない部分は自由選択で囲みます。線の下に薄い隙間が残らないよう、選択範囲を少し広げて線画の下まで含めます。詳しくは選択範囲と塗りつぶしを参照してください。

2. マスク付きの下塗りレイヤーを作る

線画の下に髪レイヤーを追加します。髪の範囲を選択したまま、その選択範囲から髪レイヤーにマスクを作成し、選択を解除します。マスクは髪の形の内側を表示し、外側を隠します。

髪のレイヤー本体のサムネイルを選び、色ラフから下塗りの色を拾って、レイヤー全体を塗りつぶします。色を拾うときは、必要に応じて色ラフを一時的に表示してください。全体を塗っておくと、マスクで隠れた部分にも色が残るため、後からマスクだけを編集して髪の輪郭を広げられます。

3. マスクの縁を整える

等倍表示で境界を確認します。マスクのサムネイルを選び、余分な色は黒で隠し、線の下まで色を広げる部分は白で表示します。色自体を変更するときは、レイヤー本体のサムネイルに戻してください。

同じ手順で肌と服を別々のレイヤーに作ります。髪を修正しても、顔や服には影響しません。細かな色の違いは、同じレイヤーで扱えます。

塗り込みでは、下塗りの上に描く色をクリッピングで形の内側に収めます。マスクとの関係はレイヤーマスクとクリッピングで説明します。
