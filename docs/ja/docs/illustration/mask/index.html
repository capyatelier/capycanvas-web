マスク作成

下塗りを部位ごとに分け、輪郭を後から修正できるようにします。

このガイドは想定する制作手順を説明する草案で、開発中の機能も含みます。

最初の下塗りレイヤーを作る

下描きと色ラフを非表示にし、線画を表示したままにします。線画の下に髪レイヤーを追加してください。必要に応じて色ラフを一時的に表示し、髪の下塗りに使う色を選びます。

自動選択ツールで髪の輪郭の内側を選択します。参照先を線画に設定すると、空の髪レイヤーではなく、その輪郭を読み取れます。選択範囲は編集できる場所を決め、選択中のレイヤーは色を置く先を決めます。髪レイヤーを選んだ状態で、範囲内を下塗り色で塗りつぶしてください。

塗りの境界を修正する

等倍表示で縁を確認します。線の下に明るい隙間が残る場合は、選択範囲を少し拡張してもう一度塗りつぶします。輪郭の切れ目から選択が外に漏れる場合は、線画の隙間を閉じるか、自由選択で不足している境界を指定してください。設定の詳細は選択範囲と塗りつぶしにあります。

境界を編集できる状態にする

範囲を選択したまま、その選択範囲から髪レイヤーにマスクを作成し、選択を解除します。マスクは絵を消さずに表示範囲を制御します。マスクのサムネイルを選び、黒で塗ると縁を隠し、白で塗ると再び表示できます。色を加えるときは、レイヤー本体のサムネイルに戻してください。マスクに描くと、色ではなく表示範囲が変わります。

同じ方法で肌と服のレイヤーを作ります。部位を分けることで、顔や服に影響させずに髪を修正できます。細かな色の違いすべてを別レイヤーにする必要はありません。

塗り込みでは、この下塗りの上に描画用レイヤーを追加し、クリッピングで形の内側だけに表示します。マスクとの関係はレイヤーマスクとクリッピングで説明しています。
