入力設定

ペンの入力は、デバイスとOSを通ってからエディターやブラシに届きます。筆圧が使えない、カーソルがずれるといった場合は、まず問題の起きている場所を調べます。ペンが使えるようになったら、よく使う操作を描画中に扱いやすいキーやボタンに割り当てます。

このガイドは想定する制作手順を説明する草案で、開発中の機能も含みます。

このページで学ぶこと

  • 筆圧が届かない問題と、ブラシの反応を調整すべき状態を区別します。
  • タブレットと画面の対応を確認し、ペン入力とタッチによる表示操作を分けます。
  • 取り消し、ブラシサイズ、キャンバス操作を、使いやすいキーやペンのボタンに割り当てます。

ブラシを変更する前に筆圧を確認する

組み込みのPencilプリセットを初期設定で使います。強く押すほど線が太く濃くなることを確認してください。徐々に力を入れてから抜くように線を引き、変化がなければ、ほかの描画アプリでも筆圧が使えるか確認します。両方で問題があればデバイスやドライバーを、Capy Canvasだけで起きる場合は入力設定やプリセットを調べます。

筆圧は使えるものの強く押す必要がある場合は、筆圧への反応を調整します。プリセットの最大値に届かせるために強く押すのではなく、普段の持ち方で試してください。個々のプリセットの反応は、ブラシエンジンの設定で調整します。

ペンとタッチの入力範囲を確認する

板型ペンタブレットでは、入力範囲がCapy Canvasを表示している画面に対応しているか確認します。縦横比が合っていないと、手を円形に動かしても画面では楕円になることがあります。液晶ペンタブレットでペン先とカーソルがずれる場合は、中央と端の両方で位置を確認してください。

手を置くと線が描かれる場合は、パームリジェクションと、タッチが描画・キャンバス操作のどちらに割り当てられているかを確認します。筆圧と傾きにはペンとデバイスの両方の対応が必要です。タッチパネルやスタイラスなら必ず使えるわけではありません。

描画中に使う操作を割り当てる

ウェブ版では設定の歯車から、ネイティブ版ではアプリメニューのPreferencesから、Preferences → Keyboard Shortcutsを開きます。操作を選び、Addを押して希望のキーを入力します。ほかの操作との重複は、適用前に表示されます。ペンのボタンには、タブレットドライバーで同じキーを割り当ててください。

このチュートリアルで使う初期ショートカットは、取り消しがCtrl+Z（AppleのOSではCommand+Z）、表示移動がSpaceを押しながらドラッグ、画面に合わせる操作がF、ZenモードがTabです。よく使うブラシサイズもショートカット一覧から割り当てられます。

線がペンに遅れて付いてくる場合は、筆圧設定を変える前に手ぶれ補正を弱めます。ウェブ版では小さなブラシや小さなドキュメントとも比較し、描画負荷に関係する遅延かを絞り込みます。問題を報告するときは、デバイス、ブラウザー、プリセット、ドキュメントのサイズを添えてください。

プラットフォーム別の入力

現在のシステムに対応する説明を表示します。選択を切り替えると、ほかのデバイスについても確認できます。

Windows

複数のアプリで筆圧が使えない場合は、タブレットドライバーの設定で筆圧を確認します。複数画面を使う場合は、Capy Canvasを表示している画面にタブレットを割り当ててください。

macOS

ブラシを調整する前に、タブレット設定の画面への割り当てを確認します。ショートカットのCommandとControlは別のキーなので、Windowsの割り当てをそのまま使わずに確認してください。

Linux

ウェブ版では、デスクトップ設定のタブレットの割り当てを確認します。筆圧が届かない、カーソルがずれるといった問題の報告には、ブラウザー名と、デスクトップがWaylandかX11かを添えてください。

iOS / iPadOS

使っているApple Pencilのモデルが、必要な筆圧や傾きの入力に対応しているか確認します。手を置くと線が描かれる場合は、ブラシを変更する前にタッチ入力の割り当てを確認してください。

Android

ペンとデバイスが筆圧入力に対応しているか確認します。一般的なタッチ用スタイラスは、指と同じ入力になる場合があります。ペンは使えるのにタッチが妨げになる場合は、描画とキャンバス操作の割り当てを確認してください。
