ブラシ設定の保存とリセット

ブラシの設定を変えると、Capy Canvasはそれをワークスペースの一部として覚えます。手動で保存する必要はありません。気に入っている設定を失わずにいろいろ試したいときは、先にワークスペースのコピーを作りましょう。

この簡潔なガイドは現在のウェブ版に基づいています。移植作業中のネイティブ版では操作が異なる場合があります。

このページで学ぶこと

  • 変更を現在のワークスペースに残します。
  • ワークスペースのコピーで別の設定を試します。
  • レイアウトを変えずにブラシをリセットします。

変更は自動で残ります

ブラシを選び、Toolパネルで設定を変えます。別のブラシに切り替えて、あとで戻ってきても、変更はそのまま残っています。各ワークスペースは、ブラシごとの設定を個別に覚えているほか、最後に使ったツールやパネルの配置も記憶しています。

ブラシの設定はドキュメントではなく、ワークスペースに属します。ドキュメントを開いてもブラシは変わらず、ドキュメントを保存してもブラシの設定は保存されません。Sketchのサイズや不透明度のスライダーに追加したブックマークはブラシごとに別々に保持され、どのワークスペースでも使えます。

別の設定を試す

自由に試したいときは、Window → Workspaces → New Workspace…を選びます。現在のワークスペースが、ブラシとレイアウトごと新しい名前でコピーされます。変更はそのコピーで行います。元のワークスペースに切り替えれば、その設定が離れたときのまま戻ってきます。

ワークスペースの切り替え方と、タイトルバーに表示するワークスペースの選び方は、ワークスペースの管理で説明しています。

初期設定に戻す

Window → Workspaces → Reset All Brushes…は、現在のワークスペースにあるすべてのブラシを元の設定に戻します。今使っていないブラシも対象です。ドキュメント、パネルの配置、スライダーのブックマークには影響しません。

パネルを最初の位置に戻したい場合は、代わりにRestore Starting Layout…を使います。こちらはパネルを元に戻しますが、ブラシの設定は残します。そのため、2つのリセットがお互いの作業を打ち消すことはありません。
