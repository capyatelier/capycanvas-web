マスクとクリッピング

レイヤーマスクは表示範囲を変え、クリッピングは別レイヤーを下地の形に制限します。透明度ロックは同じレイヤーの新しい描画を制限します。

この簡潔なガイドは現在のウェブ版に基づいています。移植作業中のネイティブ版では操作が異なる場合があります。

このページで学ぶこと

  • 選択範囲からマスクを作ります。
  • 塗りとは別にマスクを編集・無効化します。
  • 下地の上に陰影をクリッピングします。

選択範囲から作る

対象レイヤーと表示したい画素範囲を選びます。コンテキストメニューのMask: reveal selectionは選択部分を表示し、Mask: hide selectionは隠します。既存マスクがある場合はReplace maskと表示されます。作成後のマスク境界は、その後の画素選択から独立しています。

操作後は選択範囲を解除します。後で表示範囲を広げたい場合は、隠れた部分にも塗りを残します。マスクで表示できるのは既存の塗りだけです。

サムネイルを選んで編集する

マスクのサムネイルを選び、黒で隠し、白で表示します。通常の色を変えるときは内容のサムネイルへ戻ります。マスクメニューでは無効化、反転、表示、削除などができます。無効化は境界を残したまま元の塗りを確認する方法です。

リンクされたマスクはレイヤーと一緒に動きます。境界だけを変形する前にリンク状態を確認してください。

陰影をクリッピングする

下地のすぐ上に陰影レイヤーを追加し、Clip to layer belowを有効にします。陰影は独立して保持され、表示範囲は下地に従います。連続するクリッピングレイヤーは下地の直上に並べます。

Alpha lockはLine artなど同じレイヤーの既存画素を塗り替えるための機能です。マスクや陰影レイヤーは作りません。塗り込みで使い分けを確認できます。
