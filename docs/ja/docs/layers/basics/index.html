レイヤー

レイヤーはドキュメントの一部分を保持します。内容のサムネイルを選んで描き、無関係な部分を別レイヤーに分けると、修正範囲を限定できます。

この簡潔なガイドは現在のウェブ版に基づいています。移植作業中のネイティブ版では操作が異なる場合があります。

このページで学ぶこと

  • 描画レイヤーを作成し名前を付けます。
  • 編集対象と行の選択を区別します。
  • 表示、順序、不透明度を変えます。

レイヤーを作る

Layers下部のNew layerで追加し、名前をダブルクリックして変更します。チュートリアルではSketch、Line art、各下塗りを分けます。色が線を隠さないよう、Line artを上に置きます。

内容のサムネイルをクリックすると編集対象になります。行の選択ボタンは描画先を変えずに複数レイヤーを操作対象にできます。同じレイヤーでも、マスクのサムネイルは別の編集対象です。

表示と順序を確認する

目のボタンで内容を消さずに非表示にできます。行をドラッグして重ね順を変えます。タッチとペンでは行を長押ししてから移動するか、グリップを直接ドラッグします。マウスでは行をそのままドラッグできます。

レイヤーメニューには複製や削除があります。大きな変形や別の仕上げを試す前に、重要な塗りを複製しておきます。

レイヤー全体を調整する

行の上の不透明度は、編集対象の塗り全体に作用します。合成モードは下の内容との組み合わせ方です。まずNormalで作業します。

Lock editingは編集を禁止します。Alpha lockは透明部分へ広げずに既存の画素を塗り替えます。独立して編集できる境界が必要なときはマスクとクリッピングを使います。
