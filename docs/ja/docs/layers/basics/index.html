レイヤー

レイヤーは、透明なフィルムを何枚も重ねたようなものです。下描き、線画、各部分の色をそれぞれ別のレイヤーにしておけば、ほかの部分を崩さずに1つだけ修正したり、色を変えたりできます。

このページで学ぶこと

  • レイヤーを追加し、名前を付け、選択します。
  • レイヤーを非表示にしたり、並べ替えたり、薄くしたりします。
  • うっかり変更しないようにレイヤーを保護します。

レイヤーを重ねていく

Layersパネル下部のNew layerを選択すると、現在のレイヤーの上にレイヤーが追加されます。名前をダブルクリックすると変更できます。SketchやLine artのように分かりやすい名前を付けておくと、レイヤーが多い絵でも目的のレイヤーをずっと見つけやすくなります。リストの上にあるレイヤーほど手前に表示されるので、線画は、その下に塗る色よりも上に置きます。

レイヤーのサムネイルをクリックすると、そのレイヤーを選択できます。選択中のレイヤーはブラシで描き込む先になり、リストで強調表示されます。マスクのあるレイヤーには2つ目のサムネイルが表示され、そちらをクリックすると塗りではなくマスクを編集できます。詳しくはマスクとクリッピングで説明しています。

非表示・並べ替え・不透明度

レイヤーの横にある目のアイコンをクリックすると、そのレイヤーを非表示にできます。非表示にしてもレイヤーの内容はすべて残るので、いつでも元に戻せます。レイヤーを上下にドラッグすると、重なり順を変えられます。マウスならすぐにドラッグできます。ペンや指の場合は、レイヤーを少し長押ししてからドラッグするか、グリップをつかんでドラッグします。タッチ画面では、レイヤーを左にスワイプすると削除できます。

リストの上にあるスライダーはレイヤー全体の不透明度を設定し、そのレイヤーにすでに描かれているものすべてを薄くします。隣のメニューでは合成モードを設定します。合成モードは、レイヤーの色を下のレイヤーとどう混ぜるかを変えるもので、ほとんどのレイヤーはNormalのままで問題ありません。役に立つ合成モードの例は、グループと合成モードで紹介しています。

保護と整理

レイヤーを右クリックするか長押しすると、メニューが開き、ほかの操作を選べます。OrganizeにはDuplicateがあり、大きな変更の前に複製しておくのはよい習慣です。Layer Settingsには、うっかり変更されるのを防ぐLock editingと、既存の線からはみ出さずに塗り直せるAlpha lock（透明度ロック）があります。

パネル下部のボタンからは、グループ、マスク、選択レイヤーを追加したり、ファイルから画像を読み込んだりもできます。選択レイヤーの用途は、クイックマスクと選択レイヤーで説明しています。
