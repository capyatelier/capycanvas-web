選択範囲と塗りつぶし

選択範囲が制限するのは、編集できる場所です。編集先のレイヤーを決めるものではありません。この違いを使うと、線画の輪郭から領域を選び、線を塗りつぶさずに別のレイヤーへ色を置けます。

このガイドは想定する制作手順を説明する草案で、開発中の機能も含みます。

このページで学ぶこと

  • 自分で境界を描く方法と、既存の輪郭や色から選ぶ方法を使い分けます。
  • 選択や塗りつぶしが境界を読み取るレイヤーを指定します。
  • 隙間や縁を修正し、操作が終わったら選択を解除します。

選択方法を決める

移動したい下描きの一部を囲むなど、自分で境界を指定する場合は自由選択を使います。既存の色の領域や閉じた輪郭を利用する場合は自動選択を使います。選択への追加や削除を使えば、最初から選び直さずに範囲を修正できます。

選択範囲が決めるのは操作できる場所であり、編集するレイヤーではありません。範囲を塗りつぶす場合も、範囲からマスクを作る場合も、先に対象の下塗りレイヤーを選びます。マスク作成では、境界を後から編集できるよう、マスクにする方法を使います。

輪郭の参照先と塗り先を分ける

参照設定は、自動選択や塗りつぶしが境界を調べるレイヤーを指定します。空の下塗りレイヤーには検出できる輪郭がないため、線の下を塗るときは線画を参照します。

許容値は、どの程度の色の違いを同じ領域とみなすかを調整します。わずかな色むらで範囲が細かく分かれる場合は、許容値を上げます。隣の領域に塗りが漏れる場合は、さらに上げる前に輪郭の切れ目を確認してください。隙間閉じや自由選択の方が適切な場合もあります。

縁を修正して選択を解除する

拡張は、選択範囲や塗りつぶしの境界を外側へ広げます。少し拡張すると、アンチエイリアスのかかった線の下に残る明るい隙間を埋められます。等倍で確認し、線の下まで届きつつ外にはみ出さないようにします。

境界のぼかしは、選択範囲の縁を意図的に柔らかくします。輪郭のはっきりした下塗りでは使いません。塗りつぶしや変形が終わったら選択を解除し、その後のストロークが途中で切れないようにしてください。
