ワークスペースとキャンバス

Capy Canvasには、スケッチ、ペイント、写真編集のための、なじみのあるレイアウトが用意されています。それぞれSketch、Paint、Photoと呼びます。どれも同じツールとドキュメントを共有しているので、作業が変わればいつでも切り替えられます。このページでは、キャンバスの表示の動かし方と、絵以外をすべて隠す方法も紹介します。

このページで学ぶこと

  • 作業に合ったワークスペースを選びます。
  • 表示の移動、拡大縮小、回転を行います。
  • Zenモードで画面の操作部を隠します。

ワークスペースを選ぶ

Sketchは、画面をできるだけ広く絵のために使います。必要最小限のボタンはタイトルバーにまとまり、LayersやColorなどのパネルは、使うあいだだけ引き出しとして開きます。画面の端にある小さなバーには、ブラシサイズ、不透明度、カラーピッカー、元に戻す・やり直すがまとまっているので、いつでも手の届く位置で操作できます。

Paintは、キャンバスの周りにすべてのパネルを開いておきます。ツール、ブラシ、色が左側に、Navigator、Properties、Layersが右側にあります。編集画面の操作を覚えるのに最適なワークスペースで、このガイドのほとんどもPaintを使っています。

Photoは、写真編集に合わせた配置です。選択ツールが手近にあり、上部のバーには現在のツールのオプションが表示され、Color、Filters、Layersが右側に開いたままになります。

ワークスペースを切り替えても絵が変わることはなく、開いているドキュメントもすべて開いたままです。

キャンバスの表示を動かす

タッチ画面では、2本指で表示の移動、拡大縮小、回転を一度に行えます。指で塗ることはないので、ペンで描きながら画面に手を置いておけます。マウスでは、スクロールで表示を移動し、Ctrlを押しながらスクロールすると拡大縮小できます。マウスの中ボタンか右ボタンでドラッグして動かすこともできます。Spaceを押しながらドラッグしても移動でき、トラックパッドではピンチで拡大縮小できます。Ctrl+0を押すと、絵全体が画面に収まります。

Navigatorパネルには絵の小さなプレビューが表示され、表示の拡大縮小、回転、反転のボタンもあります。表示の反転は、形のバランスを確かめる昔ながらの方法です。反転した絵を見ると、狂っているところがぱっと目に付くからです。回転や反転で変わるのは絵の見え方だけで、保存される画像は変わりません。作品そのものを回転させたいときは、移動と変形を使います。

Zenモードですべてを隠す

Tabを押すか、左上のカピバラをクリックすると、Zenモードに入ります。パネルとツールバーが消え、絵だけが残ります。もう一度Tabを押すか、カピバラをクリックすると元に戻ります。

隠すのではなくワークスペースの配置を変えたい場合は、パネル・ツールバー・タイトルバーを参照してください。
