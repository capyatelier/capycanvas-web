ブラシと描画

ツールは操作の種類を、Tool Setはその中のグループとプリセットを選びます。組み込みブラシから始め、次に描く線に必要な項目だけ調整します。

この簡潔なガイドは現在のウェブ版に基づいています。移植作業中のネイティブ版では操作が異なる場合があります。

このページで学ぶこと

  • ツール、グループ、プリセットを選びます。
  • サイズ、不透明度、流量を調整します。
  • 正しいレイヤーでEraser、Blend、Liquifyを使います。

プリセットを選ぶ

線にはPenやPencil、塗りにはBrush、柔らかな塗布にはAirbrushを使います。Tool Setは現在のツールに応じて変わります。BrushにはPaint、Watercolor、Oil paintのグループがあり、グループ内でWatercolor Washなどを選びます。

描く前にLayersで描画先を選びます。マスクが選ばれていると、通常の色ではなく表示範囲を編集するため、予想外の結果になったらサムネイルを確認します。

筆跡を調整する

Toolでサイズと不透明度を変えます。隣のBrush sizeタブには定型サイズがあります。筆圧の効果はプリセットと機器によって異なります。実際に使う太さで、弱い力から強い力へ変化する線を試します。

不透明度は新しい筆跡に作用し、既存の塗りを薄くしません。流量は1本の線の中での塗料の重なり方を変えます。ブラシ設定で比較方法を説明します。

消す・混ぜる・変形する

Eraserは選択した対象の塗りを消します。Blendは既存の色を混ぜ、Liquifyは既存の塗りを動かします。大きな変更は複製レイヤーで試してください。元に戻す操作で直前の編集を取り消せます。

色とスポイトで色を選び、気に入った調整を現在のワークスペースに保持します。
