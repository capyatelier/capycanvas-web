ブラシと描画

Capy Canvasのブラシは、PencilやPaint Brushといった描画ツールのどれかに属しています。ツールはどんな種類の線を描くかを決め、Tool Setではそのツールの中から具体的なブラシを選びます。まずは組み込みのブラシから始め、次の線に必要な設定だけを調整しましょう。

この簡潔なガイドは現在のウェブ版に基づいています。移植作業中のネイティブ版では操作が異なる場合があります。

このページで学ぶこと

  • ツール、グループ、ブラシを選びます。
  • サイズ、不透明度、流量を変えます。
  • 塗りを消したり、混ぜたり、動かしたりします。

ブラシを選ぶ

描画ツールは、Paintの左端にあるツールバーに並んでいます。線にはPenやPencil、絵の具の塗りにはPaint Brush、柔らかな陰影にはAirbrushを使います。ツールを選ぶと、そのツールに属するブラシがTool Setに表示されます。いくつかのグループを持つツールもあり、たとえばPaint BrushにはPaint、Watercolor、Oil paintがあります。まずグループを選び、次にWatercolor Washなどのブラシを選びます。

Sketchでは、タイトルバーのBrushボタンを押すと、同じ選択肢が引き出しに表示されます。引き出しにはあらゆる種類のブラシが1か所にまとまっており、最後に使ったブラシを覚えているので、1回タップするだけでそのブラシに戻れます。

描き始める前に、Layersでどのレイヤーが選択されているかを確認します。新しい塗りは、常に選択中のレイヤーに描かれます。

サイズと不透明度を設定する

Toolパネルには、現在のブラシの設定が表示されます。Brush sizeは線の太さを、Opacityは新しく塗る色の透け具合を決めます。隣のBrush sizeタブには、すばやく切り替えられるサイズが並んでいます。Sketchでは画面端のスライダーが同じ役割を持ち、ドラッグしているあいだはブラシ先端のプレビューが表示されます。

不透明度が影響するのは、これから描く線だけです。レイヤーにすでに描かれている塗りを薄くしたい場合は、Layersでレイヤーの不透明度を下げます。Flowは不透明度とは少し違い、1本の線の中で同じ場所を重ねて塗ったときに、どれだけ色が重なっていくかを決めます。詳しくはブラシ設定で説明しています。

消す・混ぜる・塗りを動かす

Eraserは、選択中のレイヤーから塗りを消します。Blendはキャンバス上にある色をなじませて混ぜ、Liquifyは濡れた絵の具のように塗りを押し動かします。Sketchでは、BlendとLiquifyはSculptボタンにまとめられています。これらのツールは既存の塗りを変えるので、元の状態を残したい場合はレイヤーを複製して試しましょう。

色の選び方は、色とスポイトで説明しています。
