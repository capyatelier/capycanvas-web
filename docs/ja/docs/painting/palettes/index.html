パレット

パレットは、繰り返し使いたい色をまとめたものです。Palettesパネルは最近塗った色も覚えているので、同じ色を作り直さなくてもすぐに戻れます。自分でパレットを作れるほか、ほかのお絵かきアプリで使っているパレットも読み込めます。

このページで学ぶこと

  • 最近使った色をもう一度使います。
  • パレットに色を追加します。
  • パレットを読み込み、書き出します。

最近使った色を使う

Colorの隣にあるPalettesタブを開きます。いちばん上の列には、最近塗った色が新しい順に並びます。色が追加されるのは実際に絵の中で使ったときだけなので、眺めただけの色で列が埋まることはありません。もっと前の履歴を見るには、列の端にある矢印を選択します。

スウォッチを選択すると、その色で塗れるようになります。Sketchでは、Colorの引き出しを開くと、カラーホイールの下に同じスウォッチが表示されます。

パレットを作る

最近使った色の下には、現在のパレットがあります。Capy Canvasには最初からいくつかのパレットが用意されており、パネル下部のパレットメニューで切り替えられます。現在の色を追加するには、パレットの末尾にある+タイルを選択します。スウォッチをドラッグすると、並び順を変えられます。

新しいパレットを作るには、パレットメニューを開いてNew Palette…を選びます。同じメニューで、パレットの名前の変更や削除もできます。パレットはドキュメントの中には保存されないので、どのドキュメントを開いても使えます。

パレットを読み込む・書き出す

ほかのアプリのパレットを取り込むには、パレットメニューでImport Palette…を選びます。Capy Canvasは、Procreate、CLIP STUDIO PAINT、Photoshop、Krita、GIMP、Affinityのパレットを読み込めます。Export Paletteを使うと、現在のパレットをいくつかの形式から選んで保存できるので、ほかのアプリに持ち込んだり、ほかの人と共有したりできます。
