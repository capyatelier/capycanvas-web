细化

阴影、反光、高光与表面细节。

光照与阴影

确定光源方向，绘制主要阴影形状。区分表面背离光线形成的形体阴影，以及物体遮挡光线形成的投影。将明暗绘制限制在蒙版阶段划定的区域内。

边缘与材质

细化阴影过渡、反光与高光。根据形体、光照与材质使用硬边或软边。由明暗替代线条的部分，可调整线稿颜色或覆盖绘制。

最终调整

分别在缩小视图和实际尺寸下检查明暗、色彩平衡与细节。修正边缘和多余痕迹。导出图片前保留分层文档。
