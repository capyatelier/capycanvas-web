慢慢认识 Capy Canvas。

应用正在成形，使用指南也在计划中。先来看看我们已经做了什么，以及接下来想做什么。

指南筹备中

已经初具模样

以下功能已在当前原型中运行，仍有许多值得打磨的细节。

顺手的画笔

由 GPU 画布驱动的压感笔触，以及不断丰富的绘图与绘画笔刷。

安心创作的空间

图层、撤销与重做、画布导航、可移动面板，以及让界面安静下来的 Zen 模式。

熟悉又自在的工作区

明暗主题、画笔输入偏好和可自定义的快捷键。网页版与 Linux 原型共用同一绘画核心。

接下来的小目标

一步一步，用心做好。随着探索深入，计划也可能调整。

让日常绘画更流畅

在真实绘画过程中，持续改善画笔手感、响应速度和稳定性。

把画布带到更多地方

准备可下载的版本，并将共用的核心带到 iPadOS、Android、Windows 和 macOS。

一本友好的使用指南

从入门、画笔与图层，到快捷键和遇到问题时的小提示，让每一步都更轻松。

从小小的开始，长成舒心的角落。

我们希望做出最快、最舒心的免费绘画应用。欢迎试用早期演示版，或前往 GitHub 查看源码、技术笔记和开发进展。
