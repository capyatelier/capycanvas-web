隐私政策

生效日期: 2026年9月10日

本政策适用于 Capy Canvas 以及 capycanvas.art 和 editor.capycanvas.art 网站。Capy Canvas 由 Zachary Drach 以 Capy Atelier 项目名称运营。

如有隐私问题或相关请求，请发送邮件至 zackdrach@gmail.com。

应用数据

Capy Canvas 在您的设备上处理绘画，并访问您选择打开或保存的文件。应用不会向我们发送您的作品或导入的图片。如果您在寻求支持时提交文件，我们会收到这些文件。

设置和网站偏好保存在您的设备上。网页版还会缓存应用文件，以供离线使用。使用 Capy Canvas 无需注册账户。

我们不投放广告、不进行使用情况分析、不出售个人信息，也不嵌入跨网站跟踪您的追踪器。

托管与诊断

网站和网页版应用由 GitHub 托管。GitHub 会出于安全目的记录访客的 IP 地址。Cloudflare 提供 DNS 服务。

对于通过应用商店分发的版本，我们可能会收到 Apple、Google 或 Microsoft 提供的崩溃报告和技术诊断信息。报告可能包含设备信息、应用及操作系统版本，以及故障详情。我们使用这些平台提供的报告来调查问题并改善稳定性。信息的收集与共享取决于平台的政策和诊断信息共享设置。

支持与联系

如果您联系我们，我们会收到您提供的用户名或电子邮件地址、消息及附件。我们使用这些信息来回复您并调查所报告的问题。

通过 GitHub Issues 进行的支持交流是公开的。电子邮件通过 Gmail 处理，适用 Google 隐私政策。

保留、安全与您的选择

本地文件和设置存储在您的设备上，您可以使用应用、浏览器或设备提供的功能将其删除。公开的 GitHub Issue 会作为项目支持历史的一部分保留，除非被删除。我们会根据处理请求、记录回复或履行法律义务的需要保留私人通信。托管日志和平台诊断信息按各提供方的保留规则保存。

网站和网页版应用使用 HTTPS。非公开通信和诊断报告通过提供方的账户访问控制进行访问。

您可以向上述邮箱发送邮件，请求访问、更正或删除我们持有的个人信息。我们会依据适用法律处理请求。我们无法访问或删除仅保存在您设备上的作品。如果设备或平台提供相关隐私设置，您可以通过这些设置管理诊断信息的共享。

变更

我们会在此页面公布本政策的重要变更，并更新生效日期。
