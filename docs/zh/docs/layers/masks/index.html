图层蒙版与剪贴

蒙版、剪贴和锁定透明像素用不同方式限制绘画。蒙版修改可见范围，剪贴把独立图层限制在底色形状内，锁定透明像素则用于给已有笔迹改色。选择哪种方法，取决于你想改变什么、保留什么。

这些指南草案描述了预期的制作流程，其中包含仍在开发的功能。

本页会学到什么

  • 需要继续修改轮廓时，使用蒙版。
  • 明暗需要与底色分开保存时，使用剪贴。
  • 直接改色时使用锁定透明像素，临时限制编辑范围时使用选区。

从选区创建蒙版属于计划中的制作流程；该操作开放后，这里会说明控件的位置。

用图层蒙版修改轮廓

图层蒙版控制图层哪些部分可见。选中蒙版缩略图后，黑色会隐藏内容，白色会显示内容，灰色会产生半透明效果。要修改颜色本身，请切回图层缩略图。

需要以后修改边界时可以使用蒙版，例如蒙版阶段中的头发。教程先填满整个绘画图层，再修整蒙版，所以向外扩展轮廓时，有被隐藏的底色可以显示。白色只能显示已有颜色，不能显示未画过的部分，也不能恢复从图层上擦掉的像素。

用剪贴保留独立的明暗

在底色上方添加新图层，并对新图层开启剪贴。它的绘画内容只会显示在底色形状内。如果底色形状改变，包括通过蒙版修改，剪贴后的显示结果也会改变。

细化教程使用的就是这种结构：头发存放底色，头发明暗存放上方的绘画内容。修改外轮廓时编辑底色或其蒙版，只修改明暗时编辑剪贴图层。多个剪贴图层都出现相同边缘问题时，应先检查底色，而不是逐层擦除。

用锁定透明像素或选区改色

锁定透明像素适合直接覆盖已有像素，而不扩大原有形状，例如修改线稿颜色。它会改动原来的绘画内容，与在单独的剪贴图层上修正不同。

选区可以临时限制编辑范围，也能与上述方法配合。操作结束后请取消选择。如果笔刷突然在看不见的边界处截断，应先检查是否仍有选区，再修改蒙版或笔刷。
