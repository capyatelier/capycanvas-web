草案

插画教程

用简单头像练习分开保存草稿、线稿、底色与阴影。每个阶段使用命名图层，修改某一部分时无需重做其他部分。

这些简明指南以当前网页版为准。原生版本仍在移植中，部分控件可能不同。

本页会学到什么

  • 分开绘制草稿与色稿。
  • 在淡化草稿上勾线。
  • 为头发、皮肤和衣服建立蒙版底色。
  • 添加剪贴阴影并导出。

准备文档

尚未检查笔时，先看快速入门。选择Paint让Tool Set、Color和Layers保持可见。示例使用1200 × 1200文档；自己的作品可用合适尺寸。

示例包含头发、脸、外套与围巾。图层名保留英文以便与示例文件对应，不必描摹同一个人物。

按四个阶段进行

从草稿开始，在同一文档中继续线稿、蒙版与细化。Sketch和Color rough隐藏后仍保留，后续阶段通过添加图层继续工作。

各阶段使用真实编辑器截图，编号对应图注中的操作区。打开原图可检查顺序与缩略图。

使用示例文件

通过File → Open…打开草稿、线稿、底色或完成项目。图像编辑指南也可使用完成PNG。

修改前另存自己的副本。项目包含截图中实际使用的图层和蒙版。
