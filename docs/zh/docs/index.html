文档

教程通过一幅人物插画介绍Capy Canvas的操作，参考页面则说明各个工具与设置。

这些指南草案描述了预期的制作流程，其中包含仍在开发的功能。

基本操作

快速上手

选择版本、检查数位笔，然后开始插画教程。

工作区与画布

调整控件的位置，并在不改变作品的前提下操作画布视图。

插画教程

按顺序在同一文档中完成各阶段，每一步都会沿用上一阶段建立的图层。

从教程介绍开始

  1. 01

    草稿

    用铅笔起稿，并把色稿放在单独的图层上。

  2. 02

    线稿

    在草稿上方描线，保留下方的原始草图。

  3. 03

    蒙版

    分开底色区域，并让轮廓能够在之后继续修改。

  4. 04

    细化

    在剪贴图层上绘制明暗和质感，再分别调整结果。

参考手册

这些页面解释教程用到的控件，以及如何按自己的工作方式调整相关设置。

图层

用图层、蒙版和图层组管理插画的不同部分。

工具与文件

调整选中内容、修正填充边缘，并保存或导出结果。

高级设置

根据需要的笔迹调整笔刷预设和输入设置。
