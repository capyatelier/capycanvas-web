笔刷引擎

笔刷预设决定笔迹如何构成，以及怎样响应数位笔。如果已有预设接近需要的效果，只是间距、颜色累积或压感响应不合适，就可以调整引擎。使用同样的测试笔触，才能判断每次改动。

这些指南草案描述了预期的制作流程，其中包含仍在开发的功能。

本页会学到什么

  • 在相同绘画条件下，对比预设副本与原版。
  • 改变笔尖间距和纹理，调整一笔之内的印迹。
  • 分别理解不透明度、流量和压感响应，再调整颜色累积。

使用可重复的测试笔触

先复制一个接近目标效果的预设，再保持大小、颜色和测试动作一致，比较改动。画一条缓慢的曲线，让压力逐渐增加再减小，比快速点一下更能看出响应特点。

测试图层的不透明度保持最大，混合模式保持正常，否则图层效果可能掩盖笔刷变化。修改后的预设如何保留，见自定义笔刷。

调整笔尖和间距

笔画由笔尖形状反复印出的笔刷印迹组成，间距控制这些印迹之间的距离。如果一条线看起来像一串分离的图案，就减小间距；如果希望保留每个笔尖形状，则增大间距。

笔尖旋转和散布会改变印迹的排列，纹理会改变笔迹内部的疏密效果。分别调整这些参数，才能判断不需要的图案来自笔尖、间距还是纹理。

分别理解不透明度、流量和笔压

笔刷不透明度控制整条笔画的透明程度，流量控制每个印迹沉积多少颜色，因此会改变同一笔内的颜色累积。对比连续的一笔和多次叠画的笔触，可以看出它们在当前预设中的区别。

压感曲线把输入压力映射到大小、不透明度等参数。如果变化范围合适，但响应过于突然，可以调整曲线。如果笔压完全不起作用，应先检查输入设置；笔刷曲线无法补出设备没有上报的压力数据。
