输入设置

笔的输入会经过设备和操作系统，才到达编辑器和笔刷。缺少压感或光标偏移时，应先找出问题发生在哪一环。笔正常工作后，再把常用命令分配到绘画时方便操作的键或按钮上。

这些指南草案描述了预期的制作流程，其中包含仍在开发的功能。

本页会学到什么

  • 区分压感数据缺失和笔刷响应需要调整这两种情况。
  • 检查数位板到屏幕的映射，并分开笔输入与触控画布操作。
  • 将撤销、笔刷大小和画布操作分配给容易触及的按键。

修改笔刷前先检查压感

使用默认设置的内置Pencil预设。加大笔压时，线条应变宽、变深。画一条力度逐渐增加、再减小的线；如果笔触始终一致，检查压感在另一款绘画应用中是否正常。两款应用都有问题时，优先检查设备或驱动；只在Capy Canvas中出现问题时，检查其输入设置和预设。

如果压感有效，但必须用很大力气才能画出预期效果，就调整压力响应。用平时的握笔方式测试，不要为了达到预设最大值而额外用力。单个预设的响应可以在笔刷引擎设置中调整。

检查笔和触控的映射

使用独立数位板时，确认有效区域映射到显示Capy Canvas的屏幕。宽高比不匹配可能让手部画圆的动作在屏幕上变成椭圆。数位屏的光标若偏离笔尖，应分别检查屏幕中央和边缘的对齐情况。

如果手掌落在屏幕上会产生笔迹，检查防误触，以及触控当前用于绘画还是画布操作。笔压和倾斜都需要笔与设备共同支持，并非任何触摸屏或触控笔都能提供。

安排绘画时常用的操作

网页版从设置齿轮打开Preferences → Keyboard Shortcuts；原生版从应用菜单的Preferences进入。选择命令，点击Add，再按下所需组合键。如果与其他操作冲突，编辑器会在应用前提示。笔上的按键需要在数位板驱动中分配为同样的组合键。

教程中会用到这些默认快捷键：Ctrl+Z撤销（Apple系统使用Command+Z）、按住Space拖动平移、F适应窗口、Tab切换Zen模式。常用笔刷大小也可在快捷键列表中分配按键。

如果笔迹落后于笔尖，先减小笔画稳定程度，再考虑压力设置。网页版中还可比较较小的笔刷和较小的文档，以判断延迟是否与渲染有关。报告问题时，请注明设备、浏览器、预设和文档大小。

各平台的输入设置

设备选择器会显示当前系统的说明，也可以切换到其他设备进行查看。

Windows

如果多个应用都无法使用压感，请在数位板驱动设置中检查笔压。使用多台显示器时，将数位板映射到显示Capy Canvas的屏幕。

macOS

修改笔刷前，先检查数位板设置中的屏幕映射。设置快捷键时要区分Command和Control，不要未经检查就照搬Windows的按键分配。

Linux

使用网页版时，在桌面设置中检查数位板映射。报告压感缺失或光标偏移时，请注明浏览器，以及桌面使用的是Wayland还是X11。

iOS / iPadOS

确认所用Apple Pencil型号支持需要的压感或倾斜输入。如果手掌接触屏幕会留下笔迹，请先检查触控的操作分配，再修改笔刷。

Android

确认笔和设备支持压力输入；普通电容触控笔可能与手指输入相同。如果笔能正常工作但触控干扰绘画，请检查绘画与画布操作各自的分配。
