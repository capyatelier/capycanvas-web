变换

变换用于改变已有绘画内容的位置或形状。它可以作用于整层，也可以只作用于选中的部分，例如草稿中的一只手。它会修改文档内容，与为了方便落笔而旋转画布视图不同。

这些指南草案描述了预期的制作流程，其中包含仍在开发的功能。

本页会学到什么

  • 选中需要改变的图层和区域。
  • 在一次调整中完成移动、缩放和旋转。
  • 如果只想换个角度查看作品，使用视图控件。

变换控件和快捷键仍在开发中。以下说明预期的编辑行为；控件名称确定后会补充到这里。

选择变换对象

选中需要编辑的图层。如果只修改其中一部分，先用选区圈住它，再开始变换。起稿时可以借此移动手的位置，而不移动身体其余部分或色稿。

确认操作的是目标绘画图层。如果选中的是蒙版缩略图，变换的可能是可见边界，而不是绘画内容。结果异常时，要同时检查当前图层和缩略图。

在一次变换中完成调整

移动、旋转或缩放选中的内容。需要保持形状时锁定宽高比；只有确实要改变形状时，才使用透视或扭曲控件。预览正确后再确认，继续绘画前取消选择。

反复确认细小变换会多次重采样像素，可能使栅格画面变软。尽量在一次变换中完成相关调整。如果预计会尝试多种较大的改动，先复制原图层。

区分画面内容与视图

如果只是想换个角度落笔，或镜像检查作品，使用工作区与画布中的视图旋转和镜像即可，它们不会改动文档。变换或翻转图层内容则会改变最终保存与导出的作品。
