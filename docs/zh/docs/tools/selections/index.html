选区与填充

选区限制可以编辑的位置，但不决定编辑落在哪个图层。利用这个区别，可以从墨线轮廓中选出区域，再填充到独立的颜色图层上，而不覆盖墨线。

这些指南草案描述了预期的制作流程，其中包含仍在开发的功能。

本页会学到什么

  • 根据需要，自己指定边界，或从已有轮廓和颜色建立选区。
  • 设置选择或填充读取哪个图层的边界。
  • 修正缺口与边缘，并在操作结束后取消选择。

选择合适的选区工具

自己指定边界时使用自由选区，例如圈住草稿中需要移动的一部分。已有色块或闭合轮廓可作为边界时，使用自动选择。通过增加或减去选区，可以修正范围，不必从头重选。

选区限制操作的位置，但不决定编辑哪个图层。填充区域或用它创建蒙版前，都要先选中目标底色图层。蒙版教程采用后一种方法，方便继续修改边界。

读取一个图层，填充另一个图层

参考设置决定自动选择或填充从哪些图层读取边界。空白底色层没有可检测的轮廓，因此在线稿下方填色时，应将线稿设为参考来源。

容差决定多大的颜色差异仍被视为同一区域。如果细微色差把区域分成了不需要的小块，可以提高容差。如果填充流入了相邻区域，应先检查轮廓是否有缺口，再考虑继续增加容差；闭合间隙或自由选区可能更适合这种情况。

修正边缘并取消选择

扩展会把选区或填充区域向外推。少量扩展可以覆盖抗锯齿线条下方的浅色缝隙。以实际大小检查结果，让颜色延伸到墨线下方，但不要明显超出轮廓。

羽化用于有意柔化选区边缘；制作清晰的底色边界时应保持关闭。填充或变换结束后，取消选择，避免后续笔触被意外截断。
