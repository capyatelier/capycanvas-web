渐变

渐变会从一种颜色平滑地过渡到另一种颜色，适合用于天空、背景和柔和的光照。在画布上拖动，就能设定渐变的方向和长度。

这些简明指南以当前网页版为准。原生版本仍在移植中，部分控件可能不同。

本页会学到什么

  • 选择线性渐变或径向渐变。
  • 在两种颜色之间过渡，或渐隐为透明。
  • 把渐变限制在选区内。

选择颜色和图层

渐变放在单独的图层上最便于日后修改，所以请先添加一个新图层。然后在Color面板中选择两种颜色：渐变从前景色开始，到背景色结束。

选择Gradient工具，然后在Tool Set中选择一种类型。Linear渐变沿直线过渡，Radial渐变从中心点向外呈圆形扩散。color to clear版本会让前景色逐渐变为透明，而不是过渡到背景色。

拖动画出渐变

画线性渐变时，从第一种颜色所在的位置拖到第二种颜色所在的位置。画径向渐变时，从中心开始向外拖动。拖动距离短，颜色之间的变化就快；拖动距离长，过渡就会铺满作品中更大的范围。

如果效果不太理想，撤销后重新拖动即可。通常要试几次，才能找到合适的角度和长度。

让渐变留在想要的位置

如果有激活的选区，渐变只会填充选中的区域。之后请取消选择，让接下来的笔画可以画到任何地方。如果边界以后可能还要调整，请使用蒙版而不是选区。由于渐变在单独的图层上，你之后还可以通过降低图层的不透明度来减弱它。
