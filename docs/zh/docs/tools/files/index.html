保存与导出

编辑时保留工作文档，分享时另外导出图片。文档需要保留图层和蒙版，方便继续修正；导出图片则记录当前可见的结果。将两者分别保存，可以保留教程中建立的编辑结构。

这些指南草案描述了预期的制作流程，其中包含仍在开发的功能。

本页会学到什么

  • 保存能够保留图层和蒙版的文档。
  • 不合并工作图层，直接导出可见的插画。
  • 删除原文件前，先在目标应用或设备上检查转移后的文件。

文档保存和导出控件仍在开发中。功能开放时，这里会列出支持的格式及其图层兼容情况。以下说明预期的使用流程。

保留可编辑的工作文件

使用能保留Capy Canvas图层和蒙版的文档格式保存工作文件。教程中的分层结构允许你修改底色或明暗，而不重画其他部分。拼合后的图片无法保留这些编辑关系。

在不同应用间转移作品前，先检查接收方是否支持所用功能。支持图层并不保证剪贴、蒙版和混合会完全一致。打开并检查转移后的文件之前，请保留原始文档。

导出分享用的副本

需要发布插画或将其放入其他文档时，导出一张图片。导出会合成当前可见的结果，不要求你合并作业图层。先隐藏草稿和色稿，并检查背景的可见状态。

需要透明背景时，选择支持透明度的格式。打开导出的文件，检查外观和图像尺寸；编辑器里的缩放比例并不决定导出图片的大小。

在设备之间转移文件

使用网页版时，请留意浏览器把文件保存在哪里。安装可离线使用的网页应用，不会自动让文档出现在另一台设备上。需要转移的是保存的文档本身；删除原副本前，先在目标设备上打开确认。

如果导出后发现边缘需要修正，可以回到细化。保留独立的底色蒙版和明暗图层，就不必重建已经完成的绘画内容。
