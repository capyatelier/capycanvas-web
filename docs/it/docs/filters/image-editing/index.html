Modifica una foto

Photo è l'area di lavoro per la regolazione delle immagini. Puoi aprire una foto direttamente dalla fotocamera o dal telefono, schiarirla o modificarne i colori con i livelli di regolazione ed esportare una copia finita, il tutto senza modificare il file originale.

Cosa imparerai

  • Apri una foto o aggiungine una a un disegno esistente.
  • Regolalo con un livello di filtro modificabile.
  • Salva le modifiche ed esporta una copia.

Apri la foto

Scegli Photo nel commutatore dell’area di lavoro, quindi scegli File → Open… e seleziona la tua immagine. Capy Canvas apre i file JPEG, PNG, TIFF, WebP, HEIC, AVIF e OpenEXR, quindi le foto della maggior parte delle fotocamere e dei telefoni si aprono direttamente. La foto si apre nella propria scheda a grandezza naturale, con i suoi colori originali.

Per aggiungere una foto a un disegno già aperto, scegli File → Import Image as Layer… o trascina il file sulla tela. La foto viene visualizzata con maniglie in modo da poterla spostare e ridimensionare; selezionare Apply quando è a posto oppure Original Size (100%) per utilizzarlo nelle sue dimensioni effettive.

Effettuare una modifica

Apri Filters e scegli una regolazione come Curves, Vibrance o Hue / Saturation. Viene aggiunto come nuovo livello sopra la foto e le sue impostazioni vengono visualizzate in Properties. Cambiali gradualmente e guarda la foto mentre procedi. Nascondi e mostra il livello di regolazione per confrontare il risultato con l’originale.

Poiché la regolazione risiede su un proprio livello, puoi tornare indietro e modificarla in qualsiasi momento o eliminarla senza lasciare traccia. Per regolare solo una parte della foto, selezionare prima l’area, ad esempio il cielo con Seleziona per luminosità. Filtri e regolazioni spiega altri modi per limitare una regolazione.

Salva ed esporta

Quando salvi una foto che hai modificato, Capy Canvas salva un file .capy con tutti i livelli di regolazione e la foto originale non viene mai sovrascritta. Per condividere il risultato, scegli File → Export… e salva un JPEG o PNG. Esporta un’immagine spiega le impostazioni di esportazione.
