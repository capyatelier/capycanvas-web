가이드 개요

선화

밑그림 위에 새 레이어를 만들고 선을 정리합니다.

밑그림 준비하기

밑그림 레이어의 불투명도를 낮추고 위에 선화 레이어를 만듭니다. 대략적인 색 덩어리는 참고용으로 남겨 둡니다.

선 그리기

펜선용 프리셋을 고릅니다. 크기, 필압 반응과 보정을 조정하고 캔버스를 편한 각도로 돌립니다. 선의 굵기로 형태의 겹침을 표현합니다.

정리하기

불필요한 선을 지우고 중요한 윤곽을 다듬습니다. 밑그림을 숨겨 선화를 확인합니다. 나중에 색을 바꾸거나 덧칠할 수 있도록 선화는 따로 유지합니다.
