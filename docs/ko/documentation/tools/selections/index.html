선택 영역과 채우기

선택 도구, 선택 영역 경계 및 채우기 설정.

선택 도구

사각형, 타원과 자유 올가미 선택은 기하학적 형태로 영역을 정의합니다. 자동 선택은 색상 유사도를 사용합니다. 선택 영역을 더하거나 빼고, 교차하거나 반전하고, 해제할 수 있습니다.

선택 영역 경계

확장과 축소는 경계를 바깥쪽이나 안쪽으로 이동합니다. 페더는 경계를 부드럽게 합니다. 안티앨리어싱은 경계의 전환을 매끄럽게 하여 계단 현상을 줄입니다.

채우기 설정

허용치는 비슷한 색으로 처리할 범위를 정합니다. 틈 닫기는 작은 틈을 통해 채우기가 인접 영역으로 퍼지는 것을 막습니다. 확장은 선화 아래까지 색을 넓히며, 참조 레이어 설정은 어떤 레이어를 샘플링할지 정합니다.
