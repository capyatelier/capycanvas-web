가이드 개요

펜·제스처·단축키

펜, 키보드와 기기에 맞게 입력을 조정합니다.

펜 조정하기

필압과 기울기를 확인하고 반응 곡선을 조정해 약한 획과 강한 획을 비교합니다. 펜 버튼과 태블릿 매핑도 다룹니다.

조작 설정하기

키보드 단축키와 터치 제스처를 바꿉니다. 펜과 터치의 역할을 정하고 실행 취소와 캔버스 탐색 등 자주 쓰는 작업을 가까이 배치합니다.

입력 문제 해결하기

필압 누락, 의도치 않은 터치 자국, 커서 어긋남과 획 지연을 다룹니다. 앱, 브라우저, 운영체제와 태블릿 드라이버 설정을 구분합니다.

기기별 안내

플랫폼을 선택하면 다룰 예정인 내용을 볼 수 있습니다.

Windows

필압, 태블릿 드라이버와 키보드 단축키.

macOS

펜 태블릿, 트랙패드 제스처와 Command 키 단축키.

Linux

GTK 작업 화면, 태블릿 매핑과 펜 입력.

iOS / iPadOS

Apple Pencil 필압과 기울기, 터치 제스처와 외장 키보드.

Android

스타일러스 필압, 터치 제스처와 Wacom MovinkPad Pro 14 등의 드로잉 태블릿.
