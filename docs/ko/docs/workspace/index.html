작업 화면과 캔버스

Capy Canvas의 패널과 도구 모음은 화면 크기와 펜을 쥔 손에 맞춰 옮길 수 있습니다. 캔버스 보기 조작으로는 그림 자체를 돌리지 않고 그리는 각도를 바꿀 수 있습니다. 이 페이지에서는 이러한 조정과 Zen 모드로 조작부를 숨기는 방법을 다룹니다.

이 가이드 초안은 예정된 작업 흐름을 설명하며, 아직 개발 중인 기능도 포함합니다.

이 페이지에서 배울 내용

  • 그림을 가리지 않고 사용할 수 있는 곳에 브러시 목록과 레이어 패널을 놓습니다.
  • 문서를 바꾸지 않고 보기를 이동하거나 확대·축소하고 회전합니다.
  • 키보드나 펜으로 실행 취소와 캔버스 조작을 할 수 있는 상태에서 Zen 모드를 사용합니다.

패널과 도구 모음 배치

튜토리얼에서는 브러시 목록과 레이어 패널을 표시해 둡니다. 패널은 탭을 끌어서 옮기고, 탭이 숨겨져 있으면 아래쪽 손잡이를 사용합니다. 도구 모음도 손잡이로 옮깁니다. 도킹 표시 위에서 놓으면 고정되고 캔버스 위에서 놓으면 떠 있는 상태가 됩니다. 탭이나 손잡이를 오른쪽 클릭하거나 길게 누른 뒤 Configure를 선택하면 표시할 조작부를 바꿀 수 있습니다.

도구 설정은 현재 선택한 도구에 적용됩니다. 브러시에서 선택 도구로 바꾸면 설정도 다시 확인하세요. 브러시의 불투명도와 선택 영역의 경계 설정은 서로 다른 작업에 영향을 줍니다. 브러시의 세부 조작은 브러시 엔진에서 설명합니다.

그림을 바꾸지 않고 보기 조정

터치 화면에서는 두 손가락을 돌려 긴 곡선을 그리기 편한 각도로 캔버스 보기를 회전합니다. F를 누르면 창에 맞추면서 회전도 초기화합니다. 현재 보기 회전은 터치 입력이 필요합니다. 마우스나 별도 펜 태블릿에서는 회전 없이 진행하세요. 보기 조정은 그림 자체를 바꾸지 않습니다. 실제 그림을 옮기거나 모양을 바꾸려면 변형을 사용합니다.

Space를 누른 채 끌면 보기를 이동합니다. Ctrl+마우스 휠 또는 두 손가락 핀치로 확대·축소하면서 표시된 비율을 확인하세요. 실제 크기는 100% 확대 비율을 뜻하며, 바로 100%로 맞추는 조작부는 아직 없습니다. 큰 문서를 창에 맞추면 작은 틈이 가려질 수 있으므로 가는 선과 채우기 가장자리는 확대해서 확인합니다.

Zen 모드 사용

브러시와 레이어를 고른 뒤 Tab을 누르거나 Zen 버튼을 사용해 주변 조작부를 숨깁니다. Tab을 다시 누르면 해제됩니다. 기본 설정에서는 패널이 있는 화면 가장자리로 포인터를 옮기면 해당 패널이 잠시 나타납니다. 조작부를 숨겨도 현재 도구나 레이어는 바뀌지 않습니다.

이 상태로 자주 그린다면 실행 취소와 캔버스 조작을 키보드나 펜 버튼으로 사용할 수 있게 해 두세요. 조작부를 숨기기 전에 입력 설정에서 할당을 확인합니다.
