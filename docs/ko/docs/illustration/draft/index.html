스케치

먼저 연필 스케치와 대략적인 컬러 러프를 만듭니다. 스케치는 형태를 기록하고, 그 아래의 컬러 러프는 주요 배색을 시험하는 데 사용합니다. 두 레이어를 분리하면 스케치 일부를 옮기거나 색을 바꿀 때 양쪽을 모두 다시 그리지 않아도 됩니다.

이 가이드 초안은 예정된 작업 흐름을 설명하며, 아직 개발 중인 기능도 포함합니다.

이 페이지에서 배울 내용

  • 연필 프리셋과 필압으로 스케치를 그립니다.
  • 그림 일부를 선택해 변형하고, 선택을 해제한 뒤 다른 곳을 계속 그립니다.
  • 연필선 아래의 레이어에 대략적인 색을 배치합니다.

1. 스케치 준비

일러스트를 위한 새 문서를 만들고 첫 번째 레이어의 이름을 스케치로 정합니다. 기본 Pencil 프리셋을 선택하고 브러시 크기와 필압으로 선을 조절합니다.

2. 그림의 일부 수정

손을 옮기거나 머리 크기를 바꾸려면 자유 선택으로 해당 부분을 둘러싼 뒤 선택 영역을 변형합니다. 현재 레이어에서 선택된 픽셀만 바뀝니다. 변형을 확정한 다음 선택을 해제하고 다시 그리세요. 선택이 남아 있으면 새 획도 그 영역 안으로 제한됩니다.

더 세밀한 조정이 필요하면 선택 영역과 채우기, 변형을 참고합니다.

3. 컬러 러프 추가

스케치 아래에 컬러 러프 레이어를 만들고 넓은 브러시로 인물의 주요 색을 배치합니다. 배경을 따로 수정할 예정이면 그 아래의 다른 레이어에 그리세요. 컬러 러프는 배색을 검토하는 단계이므로 스케치의 윤곽에 정확히 맞출 필요는 없습니다.

연필선은 스케치 레이어에 그대로 둡니다. 색 때문에 선이 잘 보이지 않으면 컬러 러프를 잠시 숨기세요. 나중에 본 채색에 사용할 밑색 레이어를 만들 때도 컬러 러프를 참고할 수 있습니다.

스케치와 컬러 러프를 분리한 상태로 선화로 진행합니다.
