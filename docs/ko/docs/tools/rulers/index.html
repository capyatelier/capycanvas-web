자와 스냅

자는 실제 종이 위에 자를 대는 것처럼 브러시 획을 안내합니다. 획에는 여전히 고른 브러시, 필압, 색이 그대로 쓰이고, 자는 획이 벗어나지 않도록 잡아 주기만 합니다. 곧은 가장자리, 해칭, 투시선을 그릴 때 큰 도움이 됩니다.

이 간단한 가이드는 현재 웹 편집기를 기준으로 합니다. 이식 중인 네이티브 버전에서는 일부 조작이 다를 수 있습니다.

이 페이지에서 배울 내용

  • 직선, 평행, 방사형 자를 놓습니다.
  • 스냅을 켜고 그립니다.
  • 자를 옮기거나 지웁니다.

자 놓기

Ruler 도구를 고른 다음 Tool Set에서 종류를 선택합니다. Straight 자는 한 직선을 따라 획을 안내합니다. Parallel 자는 어디에 그리든 모든 획이 같은 방향으로 가게 하고, Radial 자는 소실점으로 모이는 선처럼 획을 한 점으로 안내합니다. 캔버스 위를 드래그해서 자를 놓습니다.

자는 안내선일 뿐입니다. 화면에는 보이지만 내보낸 이미지에는 절대 포함되지 않습니다.

자를 따라 그리기

Snap to rulers가 켜져 있는지 확인한 다음, 펜이나 브러시로 돌아가 자 가까이에 그립니다. 획은 안내선을 따라가고, 브러시, 필압, 색은 평소와 똑같이 작동합니다. 다시 자유롭게 그려야 할 때는 스냅을 끄세요.

Show rulers로 자를 숨기거나 표시합니다. 숨긴 자는 획을 안내하지 않으므로, 스냅이 작동하지 않는 것 같다면 자가 표시되어 있는지 확인하세요.

자 조절하거나 지우기

자를 조절하려면 Ruler 도구를 다시 고릅니다. 자를 드래그하면 옮겨지고, 한쪽 끝을 드래그하면 각도가 바뀝니다. Delete ruler는 선택한 자를 지우며, 이미 그린 것은 그대로 남습니다.

깔끔한 선이나 도형 하나만 필요하다면 Figure 도구가 더 빠를 수 있습니다. 이미 그린 선을 옮기려면 이동과 변형을 참고하세요.
