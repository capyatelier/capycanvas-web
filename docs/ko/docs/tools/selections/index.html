선택 영역과 채우기

선택 영역은 편집할 수 있는 위치를 제한하지만, 편집을 받을 레이어는 정하지 않습니다. 이 차이를 이용하면 선화 윤곽으로 영역을 찾고 별도 색 레이어에 채워서 선을 보존할 수 있습니다.

이 가이드 초안은 예정된 작업 흐름을 설명하며, 아직 개발 중인 기능도 포함합니다.

이 페이지에서 배울 내용

  • 경계를 직접 그릴지, 기존 윤곽이나 색에서 선택할지 정합니다.
  • 선택이나 채우기가 어느 레이어에서 경계를 읽을지 설정합니다.
  • 틈과 가장자리를 수정하고 작업이 끝나면 선택을 해제합니다.

선택 방법 결정

옮길 스케치 부분을 둘러싸는 것처럼 경계를 직접 정할 때는 자유 선택을 사용합니다. 기존 색 영역이나 닫힌 윤곽을 경계로 삼을 때는 자동 선택을 사용합니다. 선택 영역을 더하거나 빼면 처음부터 다시 선택하지 않고 범위를 고칠 수 있습니다.

선택 영역은 작업할 수 있는 위치를 제한하지만, 편집할 레이어를 정하지는 않습니다. 영역을 채우거나 마스크로 만들기 전에 대상 밑색 레이어를 선택하세요. 마스킹에서는 경계를 나중에 수정할 수 있도록 마스크로 만드는 방법을 사용합니다.

읽을 레이어와 채울 레이어 구분

참조 설정은 자동 선택이나 채우기가 경계를 찾을 레이어를 지정합니다. 빈 밑색 레이어에는 감지할 윤곽이 없으므로 선 아래를 채울 때는 선화를 참조합니다.

허용치는 어느 정도의 색 차이를 같은 영역으로 볼지 조절합니다. 미세한 색 차이 때문에 영역이 불필요하게 나뉜다면 값을 높입니다. 채우기가 이웃 영역으로 퍼진다면 허용치를 더 높이기 전에 윤곽의 틈을 확인하세요. 틈 닫기나 자유 선택이 더 적절할 수 있습니다.

가장자리 수정과 선택 해제

확장은 선택이나 채우기 경계를 바깥으로 넓힙니다. 조금 확장하면 안티앨리어싱된 선 아래의 밝은 틈을 덮을 수 있습니다. 실제 크기로 확인하면서 색이 선 아래까지 닿되 눈에 띄게 밖으로 나오지는 않게 합니다.

페더링은 선택 가장자리를 의도적으로 부드럽게 만듭니다. 선명한 밑색 경계가 필요할 때는 끈 상태로 둡니다. 채우기나 변형이 끝나면 선택을 해제해 다음 획이 잘리지 않도록 하세요.
