변형

변형은 이미 그린 내용의 위치나 모양을 바꾸는 작업입니다. 레이어 전체에도, 스케치의 손처럼 선택한 일부에도 적용할 수 있습니다. 그리기 편한 각도로 캔버스 보기를 돌리는 것과 달리 문서 자체를 바꿉니다.

이 가이드 초안은 예정된 작업 흐름을 설명하며, 아직 개발 중인 기능도 포함합니다.

이 페이지에서 배울 내용

  • 바꿀 레이어와 영역을 선택합니다.
  • 이동, 크기 조절, 회전을 한 번의 조정으로 마칩니다.
  • 그림을 보는 방향만 바꾸려면 보기 조작을 사용합니다.

변형 조작부와 단축키는 개발 중입니다. 아래는 예정된 편집 동작이며, 조작부 이름은 확정된 뒤 추가합니다.

변형할 내용 선택

편집할 레이어를 선택합니다. 일부만 바꾸려면 변형을 시작하기 전에 그 부분을 선택 영역으로 둘러쌉니다. 스케치 단계에서는 이를 이용해 나머지 인물이나 컬러 러프를 옮기지 않고 손의 위치를 바꿀 수 있습니다.

원하는 그림 레이어를 편집하고 있는지 확인하세요. 마스크 썸네일이 선택되어 있으면 그림 대신 표시 경계를 바꾸고 있을 수 있습니다. 결과가 예상과 다르면 레이어와 썸네일을 모두 확인합니다.

한 번의 변형으로 조정

선택한 내용을 이동, 회전하거나 크기를 바꿉니다. 모양을 유지해야 한다면 가로세로 비율을 고정하고, 형태 자체를 바꿀 때만 원근이나 왜곡 조작을 사용하세요. 미리보기가 맞으면 확정한 뒤 선택을 해제하고 다시 그립니다.

작은 변형을 반복해서 적용하면 매번 픽셀이 재계산되어 래스터 그림이 흐려질 수 있습니다. 가능하면 하나의 변형 안에서 조정을 마무리하세요. 큰 변경을 여러 방식으로 시도할 예정이면 원본 레이어를 복제해 둡니다.

그림과 보기 구분

그리는 각도만 바꾸거나 반전해서 확인하려면 작업 화면과 캔버스의 보기 회전과 좌우 반전을 사용합니다. 이 조작은 문서를 바꾸지 않습니다. 레이어 내용을 변형하거나 뒤집으면 저장하고 내보낼 그림도 바뀝니다.
