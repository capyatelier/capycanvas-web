브러시 설정

Tool은 선택한 프리셋의 설정을 보여 줍니다. 한 항목씩 바꾸며 같은 획을 반복해 어떤 설정이 결과를 바꾸는지 확인합니다.

이 간단한 가이드는 현재 웹 편집기를 기준으로 합니다. 이식 중인 네이티브 버전에서는 일부 조작이 다를 수 있습니다.

이 페이지에서 배울 내용

  • 크기, 불투명도, 유량을 구분합니다.
  • 브러시 끝과 간격을 조절합니다.
  • 브러시를 바꾸기 전에 필압을 확인합니다.

같은 획으로 비교하기

원하는 효과에 가까운 프리셋을 고릅니다. 레이어는 불투명도 100%, Normal로 두고 같은 크기와 곡선을 그리며 한 항목씩 바꿉니다. Tool을 스크롤하면 추가 설정이 보입니다.

크기는 폭을, 불투명도는 비치는 정도를, 유량은 한 획에서 칠해지는 양을 바꿉니다. 이어 그은 한 획과 여러 번 겹친 획을 비교하세요. 레이어 불투명도는 기존 색 전체에 작용하므로 비교 중에는 고정합니다.

브러시 끝 조절하기

획은 브러시 끝의 자국이 이어져 만들어집니다. Spacing을 늘리면 각각의 자국이 잘 보입니다. 프리셋이 지원하면Hardness, 각도, 흩어짐도 조절할 수 있습니다.

매체마다 설정은 다릅니다. 수채화나 유화는 기존 색과 상호 작용할 수 있으므로 빈 곳과 다른 색 위에서 각각 시험합니다.

반응 보관하기

필압이 작동하지 않으면 먼저 연필로입력 설정을 확인합니다. 브러시 설정으로 기기가 보내지 않는 압력을 만들 수는 없습니다.

수정한 값은 현재 작업 공간에 속합니다. 브러시 설정 저장과 초기화에서 다른 설정을 보관하고 기본값으로 돌아가는 방법을 설명합니다.
