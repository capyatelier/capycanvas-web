브러시 설정 저장과 초기화

브러시 설정을 바꾸면 Capy Canvas가 이를 작업 공간의 일부로 기억합니다. 따로 저장할 필요가 없습니다. 마음에 드는 설정을 잃지 않고 이것저것 시험해 보고 싶다면, 먼저 작업 공간을 복사하세요.

이 간단한 가이드는 현재 웹 편집기를 기준으로 합니다. 이식 중인 네이티브 버전에서는 일부 조작이 다를 수 있습니다.

이 페이지에서 배울 내용

  • 변경 사항을 현재 작업 공간에 보관합니다.
  • 작업 공간 사본에서 다른 설정을 시험합니다.
  • 레이아웃은 그대로 두고 브러시를 초기화합니다.

변경 사항은 자동으로 보관됩니다

브러시를 고르고 Tool 패널에서 설정을 바꿉니다. 다른 브러시로 바꿨다가 나중에 돌아와도 바꾼 설정이 그대로 남아 있습니다. 각 작업 공간은 모든 브러시의 설정을 브러시마다 따로 기억하며, 마지막으로 사용한 도구와 패널 배치도 함께 기억합니다.

브러시 설정은 그림이 아니라 작업 공간에 속합니다. 그림을 열어도 브러시는 바뀌지 않고, 그림을 저장해도 브러시 설정은 저장되지 않습니다. Sketch의 크기 슬라이더와 불투명도 슬라이더에 추가한 북마크는 브러시마다 따로 보관되며, 모든 작업 공간에서 사용할 수 있습니다.

다른 설정 시험하기

자유롭게 실험하려면 Window → Workspaces → New Workspace…를 선택합니다. 현재 작업 공간이 브러시와 레이아웃까지 그대로 복사되어 새 이름으로 만들어집니다. 변경은 이 사본에서 하세요. 원래 작업 공간으로 돌아가면 그곳의 설정이 두고 온 그대로 돌아옵니다.

작업 공간 사이를 전환하는 방법과 제목 표시줄에 표시할 작업 공간을 고르는 방법은 작업 공간 관리에서 설명합니다.

처음부터 다시 시작하기

Window → Workspaces → Reset All Brushes…는 지금 쓰지 않는 브러시까지 포함해 현재 작업 공간의 모든 브러시를 원래 설정으로 되돌립니다. 그림, 패널 배치, 슬라이더 북마크는 영향을 받지 않습니다.

패널을 처음 위치로 되돌리고 싶다면 대신 Restore Starting Layout…을 사용합니다. 패널은 원래 자리로 돌아가지만 브러시 설정은 그대로 남으므로, 두 초기화가 서로의 결과를 되돌리는 일은 없습니다.
