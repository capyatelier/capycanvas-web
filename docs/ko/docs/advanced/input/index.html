초안

펜, 터치와 단축키

브러시를 바꾸기 전에 기기 입력을 확인합니다. 필압이 작동하면 환경 설정과 단축키로 반복 조작을 조절합니다.

이 간단한 가이드는 현재 웹 편집기를 기준으로 합니다. 이식 중인 네이티브 버전에서는 일부 조작이 다를 수 있습니다.

이 페이지에서 배울 내용

  • 연필로 필압을 시험합니다.
  • 압력 반응과 획 예측을 비교합니다.
  • 단축키를 지정하고 펜과 터치를 구분합니다.

펜 확인하기

내장 연필로 가볍게 시작해 힘을 주었다가 빼는 선을 그립니다. 일정하게 나오면 다른 그리기 앱에서도 시험합니다. 둘 다 실패하면 기기나 드라이버를, 여기서만 실패하면 편집기의 입력과 프리셋을 확인합니다.

별도 태블릿은 올바른 화면에 매핑하고 가로세로 비율을 유지합니다. 펜 디스플레이는 중앙과 가장자리에서 커서 정렬을 확인합니다. 필압과 기울기는 기기 지원이 필요합니다.

반응 조절하기

Preferences의 입력 설정을 엽니다. Pressure response는 들어온 압력의 대응을 바꿉니다. Enable stroke prediction은 다음 펜 위치를 추정합니다. Use browser stroke prediction은 브라우저의 추정을 사용합니다. 사용 가능한 경우 Prediction amount로 편집기 자체 예측량을 조절합니다. 예측을 높이면 보이는 지연이 줄지만 꺾이는 곳을 지나칠 수 있습니다. 한 항목씩 바꿔 같은 곡선으로 비교합니다.

터치로 이동, 핀치, 회전을 할 수 있습니다. 손을 놓았을 때 원치 않는 획이 생기면 터치 동작을 확인합니다. 프리셋별 변경은브러시 설정을 참조하세요.

단축키 지정하기

Keyboard Shortcuts에서 명령을 고르고 키를 추가합니다. 적용 전에 충돌을 해결합니다. 주요 기본값은Ctrl+Z실행 취소, Space 드래그이동, F전체 보기, TabZen입니다. Apple에서는 플랫폼 매핑이 지원하는 곳에 Command를 쓸 수 있습니다.

필요하면 태블릿 드라이버에서 펜 버튼에 해당 키를 지정합니다.

플랫폼별 입력 설정

현재 시스템에 맞는 설명을 표시합니다. 다른 기기를 선택해 해당 설명을 확인할 수도 있습니다.

Windows

여러 앱에서 필압이 작동하지 않으면 태블릿 드라이버 설정에서 압력을 확인합니다. 화면을 여러 개 쓴다면 Capy Canvas가 있는 화면에 태블릿을 매핑하세요.

macOS

브러시를 조정하기 전에 태블릿 설정의 화면 매핑을 확인합니다. 단축키를 지정할 때 Command와 Control은 다른 키이므로 Windows의 할당을 그대로 옮기지 말고 확인하세요.

Linux

웹 버전에서는 데스크톱 설정의 태블릿 매핑을 확인합니다. 필압이 없거나 커서가 어긋나는 문제를 보고할 때는 브라우저와 데스크톱의 Wayland 또는 X11 사용 여부를 적어 주세요.

iOS / iPadOS

사용하는 Apple Pencil 모델이 필요한 필압이나 기울기 입력을 지원하는지 확인합니다. 손을 올렸을 때 자국이 생기면 브러시를 바꾸기 전에 펜과 터치를 따로 시험합니다.

Android

펜과 기기가 필압 입력을 지원하는지 확인합니다. 일반 터치용 스타일러스는 손가락처럼 입력될 수 있습니다. 펜은 정상인데 터치가 방해된다면 펜만 쓰는 그리기와 터치 탐색을 비교하고 기기의 팜 리젝션을 확인합니다.
