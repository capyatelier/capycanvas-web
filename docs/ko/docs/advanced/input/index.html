입력 설정

펜 입력은 기기와 운영체제를 거쳐 편집기와 브러시에 도달합니다. 필압이 없거나 커서가 어긋나면 먼저 문제가 시작되는 곳을 찾습니다. 펜이 정상적으로 작동하면 자주 쓰는 명령을 그리면서 사용하기 편한 키나 버튼에 할당할 수 있습니다.

이 가이드 초안은 예정된 작업 흐름을 설명하며, 아직 개발 중인 기능도 포함합니다.

이 페이지에서 배울 내용

  • 필압이 전달되지 않는 문제와 브러시 반응을 조정할 상황을 구분합니다.
  • 태블릿과 화면의 매핑을 확인하고, 펜으로 그리는 동작과 터치로 캔버스를 이동하거나 확대·축소하는 동작을 구분합니다.
  • 실행 취소, 브러시 크기, 캔버스 조작을 손이 닿는 키나 펜 버튼에 할당합니다.

브러시를 바꾸기 전에 필압 확인

기본 Pencil 프리셋을 초기 설정으로 사용합니다. 힘을 줄수록 선이 굵고 진해지는지 확인하세요. 서서히 힘을 주었다가 빼면서 그렸는데도 획이 일정하다면 다른 드로잉 앱에서 필압을 확인합니다. 두 앱 모두 문제가 있다면 기기나 드라이버를 먼저 확인하고, Capy Canvas에서만 발생한다면 입력 설정과 프리셋을 살펴봅니다.

필압은 작동하지만 힘을 너무 많이 줘야 한다면 필압 반응을 조정합니다. 프리셋의 최댓값에 맞추려고 더 세게 누르지 말고 평소 잡는 방식으로 시험하세요. 개별 프리셋의 반응은 브러시 엔진 설정에서 조정합니다.

펜과 터치 매핑 확인

별도 펜 태블릿은 활성 영역이 Capy Canvas가 표시된 화면에 매핑되어 있는지 확인합니다. 가로세로 비율이 맞지 않으면 손으로 원을 그려도 화면에는 타원이 나올 수 있습니다. 액정 태블릿에서 커서가 펜 끝과 어긋난다면 화면 중앙과 가장자리에서 모두 정렬을 확인하세요.

손을 올렸을 때 자국이 생기면 팜 리젝션과 터치가 그리기 또는 캔버스 조작 중 어디에 할당되어 있는지 확인합니다. 필압과 기울기는 펜과 기기가 모두 지원해야 하며, 모든 터치스크린이나 스타일러스에서 사용할 수 있는 것은 아닙니다.

그리면서 쓸 조작 설정

웹 버전은 설정 톱니바퀴에서, 네이티브 앱은 앱 메뉴의 Preferences에서 Preferences → Keyboard Shortcuts를 엽니다. 명령을 선택하고 Add를 누른 뒤 원하는 키를 입력하세요. 다른 명령과 겹치면 적용 전에 충돌이 표시됩니다. 펜 버튼에는 태블릿 드라이버에서 같은 키를 할당합니다.

튜토리얼에서 쓰는 기본 단축키는 실행 취소 Ctrl+Z(Apple 시스템에서는 Command+Z), 보기 이동 Space를 누른 채 끌기, 창에 맞추기 F, Zen 모드 Tab입니다. 자주 쓰는 브러시 크기도 단축키 목록에서 할당할 수 있습니다.

획이 펜보다 늦게 따라오면 필압 설정을 바꾸기 전에 선 보정을 낮춥니다. 웹 버전에서는 작은 브러시와 작은 문서로도 비교해 지연이 렌더링과 관련 있는지 좁혀 볼 수 있습니다. 문제를 보고할 때는 기기, 브라우저, 프리셋, 문서 크기를 함께 적어 주세요.

플랫폼별 입력 설정

현재 시스템에 맞는 설명을 표시합니다. 다른 기기를 선택해 해당 설명을 확인할 수도 있습니다.

Windows

여러 앱에서 필압이 작동하지 않으면 태블릿 드라이버 설정에서 압력을 확인합니다. 화면을 여러 개 쓴다면 Capy Canvas가 있는 화면에 태블릿을 매핑하세요.

macOS

브러시를 조정하기 전에 태블릿 설정의 화면 매핑을 확인합니다. 단축키를 지정할 때 Command와 Control은 다른 키이므로 Windows의 할당을 그대로 옮기지 말고 확인하세요.

Linux

웹 버전에서는 데스크톱 설정의 태블릿 매핑을 확인합니다. 필압이 없거나 커서가 어긋나는 문제를 보고할 때는 브라우저와 데스크톱의 Wayland 또는 X11 사용 여부를 적어 주세요.

iOS / iPadOS

사용하는 Apple Pencil 모델이 필요한 필압이나 기울기 입력을 지원하는지 확인합니다. 손을 올렸을 때 자국이 생기면 브러시를 바꾸기 전에 터치 할당부터 확인하세요.

Android

펜과 기기가 필압 입력을 지원하는지 확인합니다. 일반 터치용 스타일러스는 손가락처럼 입력될 수 있습니다. 펜은 정상인데 터치가 방해된다면 그리기와 캔버스 조작의 할당을 확인하세요.
