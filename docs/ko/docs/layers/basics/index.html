레이어 기초

레이어는 그림의 각 부분을 따로 보관합니다. 손을 옮기거나 스케치를 숨기거나 색을 바꿀 때 나머지 그림에 영향을 주지 않도록 하는 구조입니다. 이 페이지에서는 편집할 대상을 고르는 방법과 어떤 내용을 분리해 둘지 설명합니다.

이 가이드 초안은 예정된 작업 흐름을 설명하며, 아직 개발 중인 기능도 포함합니다.

이 페이지에서 배울 내용

  • 그리기, 채우기, 지우기 전에 현재 레이어를 확인합니다.
  • 레이어 순서, 표시 상태, 불투명도로 그림에 보이는 내용을 조절합니다.
  • 따로 편집할 부분은 분리하고, 그럴 필요가 없어졌을 때만 합칩니다.

획이 들어갈 레이어 확인

그리기, 채우기, 지우기는 현재 선택한 레이어에 적용됩니다. 표시 상태와 선택 상태는 별개이므로 레이어를 보이게 하는 것만으로 그릴 대상이 바뀌지는 않습니다. 수정하기 전에 선택된 행을 확인하고, 마스크가 있다면 그림과 마스크 중 어느 썸네일이 선택되었는지도 확인하세요.

목록에서 위에 있는 레이어가 아래 레이어 위로 보입니다. 일러스트 튜토리얼에서는 채우기가 선을 덮지 않도록 선화를 밑색 위에 둡니다. 레이어의 픽셀을 바꾸지 않아도 순서를 바꾸면 그림이 달라질 수 있습니다.

조정할 단위에 맞춰 분리

색 변경, 이동, 숨기기, 교체를 따로 할 부분은 다른 레이어에 둡니다. 스케치와 선화를 나누는 이유는 스케치만 흐리게 하거나 숨겨야 하기 때문입니다. 하이라이트도 아래의 명암과 별도로 조정할 필요가 있을 때 분리하면 됩니다.

머리카락이나 머리카락 명암처럼 내용을 알 수 있는 이름을 붙이세요. 결과가 불확실한 편집 전에는 레이어를 복제해 바로 비교할 원본을 남길 수 있습니다. 관련 레이어는 채색을 합치는 대신 그룹으로 묶을 수 있습니다.

불투명도, 잠금, 병합

레이어 불투명도는 기존 획을 포함한 전체 내용을 흐리게 합니다. 레이어 잠금은 실수로 편집하는 것을 막고, 알파 잠금은 투명도를 유지하면서 색을 바꿀 수 있게 합니다. 알파 잠금의 용도는 마스크 참조 문서에서 확인하세요.

더 이상 따로 편집할 필요가 없을 때만 레이어를 병합합니다. 병합 후에는 원래 각 레이어의 불투명도, 마스크, 혼합 설정을 독립적으로 조정할 수 없습니다. 한 장의 이미지를 공유할 목적이라면 작업 문서를 평면화하지 말고 내보내기를 사용하세요.
