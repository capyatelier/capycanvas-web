레이어 마스크와 클리핑

마스크, 클리핑, 알파 잠금은 서로 다른 방식으로 채색을 제한합니다. 마스크는 보이는 범위를 바꾸고, 클리핑은 별도 레이어를 밑색 모양에 맞추며, 알파 잠금은 기존 자국을 다시 칠할 때 사용합니다. 바꿀 내용과 보존할 내용에 따라 선택합니다.

이 가이드 초안은 예정된 작업 흐름을 설명하며, 아직 개발 중인 기능도 포함합니다.

이 페이지에서 배울 내용

  • 윤곽을 계속 수정할 수 있어야 한다면 마스크를 사용합니다.
  • 명암을 밑색과 따로 보관하려면 클리핑을 사용합니다.
  • 직접 색을 바꿀 때는 알파 잠금을, 편집 범위를 잠시 제한할 때는 선택 영역을 사용합니다.

선택 영역으로 마스크를 만드는 것은 예정된 작업 흐름의 일부입니다. 이 작업을 사용할 수 있게 되면 조작부 위치를 안내합니다.

레이어 마스크로 윤곽 수정

레이어 마스크는 레이어의 어느 부분이 보이는지 제어합니다. 마스크 썸네일을 선택한 뒤 검은색으로 칠하면 숨겨지고, 흰색으로 칠하면 드러나며, 회색은 반투명하게 표시합니다. 색 자체를 바꾸려면 그림 썸네일로 돌아가세요.

마스킹의 머리카락처럼 나중에 경계를 수정할 부분에 사용합니다. 튜토리얼에서는 레이어 전체를 채운 뒤 마스크를 다듬으므로 윤곽을 넓힌 곳에도 숨겨진 색이 남아 있습니다. 흰색은 기존 채색만 드러내며, 그리지 않은 부분이나 레이어에서 지운 픽셀을 복구하지는 못합니다.

클리핑으로 명암 분리

밑색 위에 새 레이어를 놓고 새 레이어의 클리핑을 켭니다. 여기에 그린 내용은 밑색 모양 안에서만 보입니다. 마스크 편집을 포함해 밑색 모양이 바뀌면 클리핑 결과도 달라집니다.

렌더링에서는 머리카락에 밑색을, 머리카락 명암에 그 위의 채색을 둡니다. 실루엣을 바꾸려면 밑색이나 그 마스크를, 명암만 바꾸려면 클리핑 레이어를 편집하세요. 여러 클리핑 레이어에서 같은 가장자리 문제가 보이면 각각 지우기 전에 밑색부터 확인합니다.

알파 잠금이나 선택 영역으로 색 변경

알파 잠금은 선화의 색을 바꾸는 경우처럼 기존 모양을 넓히지 않고 이미 그려진 픽셀에 덧칠할 때 사용합니다. 별도 클리핑 레이어에 수정하는 방법과 달리 원래 채색을 직접 변경합니다.

선택 영역은 편집 범위를 일시적으로 제한하며 두 방법과 함께 사용할 수 있습니다. 작업이 끝나면 선택을 해제하세요. 브러시가 보이지 않는 경계에서 갑자기 끊긴다면 마스크나 브러시를 바꾸기 전에 선택이 남아 있는지 확인합니다.
