브러시와 페인팅

Capy Canvas의 모든 브러시는 Pencil이나 Paint Brush 같은 그리기 도구에 속합니다. 도구는 어떤 종류의 자국을 남길지 정하고, Tool Set에서는 그 도구 안의 특정 브러시를 고릅니다. 기본 제공 브러시로 시작해서 다음 획에 필요한 것만 조절하세요.

이 페이지에서 배울 내용

  • 도구, 그룹, 브러시를 고릅니다.
  • 크기, 불투명도, 유량을 바꿉니다.
  • 물감을 지우고, 섞고, 밀어 움직입니다.

브러시 고르기

그리기 도구는 Paint 왼쪽 가장자리의 도구 모음에 있습니다. 선을 그릴 때는 Pen과 Pencil을, 채색에는 Paint Brush를, 부드러운 음영에는 Airbrush를 사용합니다. 도구를 고르면 Tool Set에 그 도구에 속한 브러시가 표시됩니다. 일부 도구에는 그룹이 여러 개 있습니다. 예를 들어 Paint Brush에는 Paint, Watercolor, Oil paint 그룹이 있습니다. 먼저 그룹을 고른 다음 Watercolor Wash 같은 브러시를 고르세요.

Sketch에서는 제목 표시줄의 Brush 버튼을 누르면 같은 선택지가 서랍으로 열립니다. 서랍에는 모든 종류의 브러시가 한곳에 모여 있고 마지막으로 쓴 브러시를 기억하므로, 한 번만 탭하면 그 브러시로 돌아갈 수 있습니다.

그리기 전에 Layers에서 어떤 레이어가 선택되어 있는지 확인하세요. 새로 칠하는 물감은 언제나 선택한 레이어에 들어갑니다.

크기와 불투명도 정하기

Tool 패널에는 현재 브러시의 설정이 표시됩니다. Brush size는 획의 너비를, Opacity는 새로 칠하는 물감이 얼마나 비치는지를 정합니다. 옆에 있는 Brush size 탭에는 여러 크기가 한 줄로 놓여 있어 빠르게 바꿔 쓸 수 있습니다. Sketch에서는 화면 가장자리의 슬라이더가 같은 역할을 하며, 드래그하는 동안 브러시 끝의 미리보기를 보여 줍니다.

불투명도는 앞으로 그릴 획에만 영향을 줍니다. 레이어에 이미 칠한 물감을 옅게 하려면 Layers에서 레이어의 불투명도를 낮추세요. Flow는 불투명도와 조금 다릅니다. 한 획 안에서 같은 부분을 지나갈 때 물감이 얼마나 쌓이는지를 정합니다. 자세한 내용은 브러시 설정에서 설명합니다.

지우고, 섞고, 밀어 움직이기

Eraser는 선택한 레이어에서 물감을 지웁니다. 펜 반대쪽 끝에 지우개가 있다면 펜을 뒤집기만 하면 지금 쓰는 브러시 모양 그대로 지울 수 있습니다. Blend는 캔버스에 이미 있는 색을 부드럽게 섞고, Liquify는 젖은 물감처럼 그림을 밀어 움직입니다. Sketch에서는 Blend와 Liquify가 Sculpt 버튼 아래에 함께 있습니다. 이 도구들은 이미 칠한 물감을 바꾸므로, 원본을 남겨 두고 싶다면 레이어를 복제한 사본에서 시험해 보세요.

색을 고르는 방법은 색상과 스포이트에서 이어집니다.
