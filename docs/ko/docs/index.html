문서

인물 일러스트를 그리면서 Capy Canvas의 조작을 설명합니다. 개별 도구와 설정은 참조 문서에서 확인할 수 있습니다.

이 가이드 초안은 예정된 작업 흐름을 설명하며, 아직 개발 중인 기능도 포함합니다.

기본 조작

빠른 시작

사용할 버전과 펜 동작을 확인한 뒤 일러스트 튜토리얼을 시작합니다.

작업 화면과 캔버스

그리기 편한 위치에 조작부를 배치하고 캔버스 보기를 조정합니다.

일러스트 튜토리얼

같은 문서에서 순서대로 진행합니다. 각 단계는 앞 단계에서 만든 레이어를 이어서 사용합니다.

튜토리얼 소개부터 시작하기

  1. 01

    스케치

    연필로 스케치하고 컬러 러프를 별도 레이어에 그립니다.

  2. 02

    선화

    스케치를 유지하면서 그 위의 레이어에 선을 정리합니다.

  3. 03

    마스킹

    밑색을 부위별로 나누고 나중에 경계를 수정할 수 있게 만듭니다.

  4. 04

    렌더링

    클리핑 레이어에 명암과 질감을 그리고 각각 조정합니다.

참조 문서

튜토리얼에서 사용하는 조작과 자신의 작업 방식에 맞게 조정할 설정을 설명합니다.

레이어

레이어, 마스크, 그룹으로 일러스트의 각 부분을 관리합니다.

도구와 파일

선택한 부분과 채우기 가장자리를 수정하고 결과를 저장하거나 내보냅니다.

고급 설정

원하는 자국에 맞춰 브러시 프리셋과 입력 설정을 조정합니다.
