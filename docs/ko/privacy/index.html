개인정보 처리방침

시행일: 2026년 9월 10일

이 방침은 Capy Canvas와 capycanvas.art 및 editor.capycanvas.art 웹사이트에 적용됩니다. Capy Canvas는 Zachary Drach가 Capy Atelier라는 프로젝트 이름으로 운영합니다.

개인정보 관련 문의나 요청은 zackdrach@gmail.com으로 보내 주세요.

앱 데이터

Capy Canvas는 기기에서 그림을 처리하며, 사용자가 열거나 저장하도록 선택한 파일에 접근합니다. 앱은 그림이나 불러온 이미지를 운영자에게 전송하지 않습니다. 지원 요청에 파일을 첨부하면 해당 파일을 받습니다.

설정과 웹사이트 환경설정은 기기에 저장됩니다. 웹 앱은 오프라인 사용을 위해 앱 파일도 캐시합니다. Capy Canvas를 사용하는 데 계정은 필요하지 않습니다.

광고나 사용 현황 분석을 사용하지 않으며, 개인정보를 판매하거나 여러 웹사이트에 걸쳐 사용자를 추적하는 도구를 포함하지 않습니다.

호스팅 및 진단

GitHub는 웹사이트와 웹 앱을 호스팅하며, 보안을 위해 방문자의 IP 주소를 기록합니다. Cloudflare는 DNS를 제공합니다.

앱 스토어에서 배포되는 버전의 경우, Apple, Google 또는 Microsoft에서 충돌 보고서와 기술 진단 정보를 받을 수 있습니다. 보고서에는 기기 정보, 앱 및 운영체제 버전, 오류 세부 정보가 포함될 수 있습니다. 이러한 플랫폼 제공 보고서는 문제를 조사하고 안정성을 개선하는 데 사용합니다. 정보의 수집과 공유는 플랫폼의 정책 및 진단 정보 공유 설정에 따릅니다.

지원 및 문의

문의 시 사용자가 제공한 사용자 이름 또는 이메일 주소, 메시지, 첨부 파일을 받습니다. 이 정보는 답변과 보고된 문제의 조사에 사용합니다.

GitHub Issues를 통한 지원 내용은 공개됩니다. 이메일은 Gmail을 통해 처리되며 Google 개인정보처리방침이 적용됩니다.

보관, 보안 및 사용자 선택

로컬 파일과 설정은 기기에 저장되며, 앱, 브라우저 또는 기기에서 제공하는 기능으로 삭제할 수 있습니다. 공개된 GitHub Issue는 삭제되지 않는 한 프로젝트의 지원 기록으로 남습니다. 비공개 서신은 요청 처리, 답변 기록 또는 법적 의무 이행에 필요한 기간 동안 보관합니다. 호스팅 로그와 플랫폼 진단 정보는 각 제공업체의 보관 방침에 따라 보관됩니다.

웹사이트와 웹 앱은 HTTPS를 사용합니다. 비공개 서신과 진단 보고서에는 제공업체의 계정 접근 제어를 통해 접근합니다.

위 이메일 주소로 운영자가 보유한 개인정보의 열람, 정정 또는 삭제를 요청할 수 있습니다. 요청은 관련 법률에 따라 처리합니다. 기기에만 저장된 그림은 운영자가 접근하거나 삭제할 수 없습니다. 기기나 플랫폼에서 관련 개인정보 설정을 제공하는 경우, 해당 설정에서 진단 정보 공유를 관리할 수 있습니다.
