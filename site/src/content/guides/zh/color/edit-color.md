可以在**编辑颜色**对话框中按数值设置颜色。选择**使用颜色**之前，颜色不会改变。

![编辑颜色对话框：左侧为色轮，右上为当前、新的和十六进制代码，下方为三个数值行，底栏为最近使用的颜色。](shot:color/edit-color "1 色轮和形状 · 2 当前和新的 · 3 从画布取色 · 4 十六进制 · 5 数值行 · 6 最近使用的颜色")

## 打开编辑颜色

执行以下任一操作：

- 选择[颜色面板](/zh/docs/color/color-panel/)右上角的**编辑颜色…**（铅笔）。
- 双击颜色面板中的前景色板或背景色板。
- 在属性中选择一个颜色按钮，例如纯色填充图层的**颜色**或黑白的**着色颜色**。
- 在图层面板中选择纯色填充图层的缩略图。
- 在渐变编辑器中选择色标的**颜色**。
- 在显示**画笔颜色**的面板中选择它。可以把它添加到画笔面板和画笔大小面板（参见[面板和列](/zh/docs/customize/panels/)）。
- 在 Windows、Linux 和 Android 上，右键单击或按住前景色板或背景色板，然后选择**编辑颜色…**。

## 色轮和形状

色轮的用法与颜色面板相同。选择色轮下方的 **OKLCH**、**HSB** 或 **HLS**，可将色域切换为圆形、正方形或三角形。

## 当前和新的

**新的**显示正在调配的颜色。选择**当前**可将**新的**恢复为开始时的颜色。

## 十六进制

十六进制字段以 sRGB 的 `#RRGGBB` 显示“新的”。选择该字段可输入十六进制代码或其他[颜色文本](#粘贴颜色)。

十六进制代码左侧的标记表示以下情况：

- “≈”：颜色超出 sRGB，十六进制显示最接近的 sRGB 颜色。
- “基础”：在 HDR 画作中，十六进制显示应用强度之前的颜色。
- “sRGB”：画作的色彩空间不是 sRGB。

## 数值行

每一行以一种格式显示“新的”。选择行首的格式名称可以换成其他格式。对话框会记住所选的格式。

| 行 | 格式 |
| --- | --- |
| 1 | **RGB**（0–255，默认）、**RGB 0–1**、**线性 RGB**（0–1）。数值采用画作的色彩空间，行上的标记会注明该空间。 |
| 2 | **HSB**（默认）、**HSL** |
| 3 | **OKLCH**（默认）、**OKLab** |

![数值行，第一行的格式菜单已打开。](shot:color/edit-color-formats)

## 编辑数值

- 选择一个数值即可输入数字。按 **Enter** 确认，按 **Escape** 取消。
- 上下拖动数值可更改它。按住 **Shift** 步长更大，按住 **Alt** 或 **Ctrl** 步长更小。
- 在数值上按 **Up Arrow** 或 **Down Arrow**，以一个步长更改数值。

超出字段范围的值会被设为最接近的极限值。色相在 360° 处循环。如果输入的文本既不是数字也不是颜色，字段会保持打开并显示错误。在修正该值或按 **Escape** 之前，**使用颜色**不可用。

## 复制颜色

选择十六进制字段或某一行末尾的复制按钮，可将该值复制为文本。按钮上出现对勾，表示已复制。在对话框中文本框以外的位置按 **Ctrl+C**，可复制十六进制代码。

| 格式 | sRGB 画作中复制的文本 | 其他色彩空间中 |
| --- | --- | --- |
| 十六进制 | `#RRGGBB` | `#RRGGBB` |
| RGB | `rgb(R G B)` | `color(display-p3 r g b)`、`color(a98-rgb r g b)` 或 `color(prophoto-rgb r g b)`，取值 0 到 1 |
| RGB 0–1 | `color(srgb r g b)` | 同 RGB |
| 线性 RGB | `color(srgb-linear r g b)` | `r g b` |
| HSB、HSL | `hsb(h s% b%)`、`hsl(h s% l%)` | `h° s% b%`、`h° s% l%` |
| OKLCH、OKLab | `oklch(L% C h)`、`oklab(L% a b)` | 相同 |

## 粘贴颜色

在对话框中文本框以外的位置按 **Ctrl+V**，可根据颜色文本设置“新的”。十六进制字段和数值字段接受同样的文本：

- 3、4、6 或 8 位十六进制代码，带 `#`、`0x` 或都不带（忽略 Alpha 位）；
- CSS 颜色名称，例如 `teal`；
- `rgb()`、`rgba()`、`hsl()`、`hsla()`、`hsb()`、`hsv()`、`oklch()` 和 `oklab()`；
- `color()`，其中使用 `srgb`、`display-p3`、`a98-rgb`、`prophoto-rgb` 或 `srgb-linear`；
- 三个数字。数值行按自己的格式读取这三个数字。在其他位置，它们按 0 到 255 的 RGB 读取；如果三个数都不大于 1 且其中一个带小数点，则按 0 到 1 的 RGB 读取。

颜色文本不会改变颜色的 Alpha 值。

## 从画布取色

选择**从画布取色**（当前和新的旁边的吸管），即可从画作中取样“新的”颜色。对话框隐藏，画布一角出现一条色带，显示当前颜色、取样颜色及其数值。

点按，或抬起数位笔或手指，即可取色。对话框重新出现，取到的颜色成为“新的”。按 **Escape** 或选择色带，可不做更改返回。

用手指取色时，取样点位于指尖上方。从其他对话框打开编辑颜色时，**从画布取色**会隐藏。

## 最近使用的颜色和调色板

底栏显示最近使用的颜色。选择其中一个，即可将其设为“新的”。

选择**最近使用的颜色和所有调色板**（最近使用的颜色后面的箭头），会打开一个面板，其中包含最近使用的颜色和所有[调色板](/zh/docs/color/palettes/)。在搜索框中输入内容，可以查找调色板名称、颜色名称或十六进制代码。调色板末尾的 **+** 会把“新的”保存到该调色板中。要关闭该面板，选择**关闭调色板**或按 **Escape**。

![色板面板，包含搜索框、最近使用的颜色和调色板。](shot:color/edit-color-swatches)

## HDR 强度

在 [HDR 画作](/zh/docs/color-management/hdr/)中，**强度（EV）** 行和色轮下方的弧线以相对于 SDR 白色的档数设置亮度。在弧线上以及拖动数值时，范围为 −2 到 +6 EV。输入的数值可以超出此范围，但不能超出画作位深度的范围。

## 使用颜色和取消

选择**使用颜色**可应用“新的”颜色。选择**取消**或按 **Escape**，可不做更改关闭对话框。如果格式菜单或色板面板处于打开状态，**Escape** 会先将其关闭。
