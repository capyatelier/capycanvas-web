可以在**工具设置**面板中设置湿画笔和混色画笔处理颜料的方式。每个分组只出现在其所在小节列出的画笔上。

![湿水彩的工具设置面板下半部分，包含混色、水彩、洇色和混合分组。](shot:brushes/wet-media-settings)

## 混色

**混色**分组出现在油画画笔、**不透明水粉**、水彩画笔和所有混色笔上。**平均拾色**、**持续度**和**压感补色**只出现在油画画笔、**不透明水粉**、**湿润混色**和**调色混合**上。

### 载色量

设置画笔自身携带的颜色量；对水彩画笔而言，设置的是颜料浓度。值越低，从图层上拾取的颜色越占主导。

### 拾色量

设置画笔把从图层上拾取的颜色沿笔迹拖出多远。

### 稀释

稀释画笔携带的颜料。值越高，画笔自身的颜色在混合中越弱。

### 平均拾色

设置笔尖各处拾取的颜色相互混合成一种的程度。为 0% 时，笔尖的每个部分保持各自的颜色。

### 持续度

设置平均后的颜色沿笔迹延续多远。只有**平均拾色**高于 0% 时才会出现。

### 压感补色

设置用力按压时把所选颜色重新装入画笔的程度。**混色画笔**在用力按压时落下自己的颜色，只有轻触时才混色。

## 混色笔

每支混色笔都会向**混色笔**分组添加设置。**扩散**位于**工具设置**面板顶部。

| 设置 | 混色笔 | 控制 |
| --- | --- | --- |
| **扩散** | 除**混色刀**和**大理石纹**外的所有混色笔 | 混色笔在笔迹每一点周围多大范围内收集颜色。 |
| **条纹** | **涂抹**、**柔和混色**、**纸擦笔**、**纸巾**、**自然混色**、**鬃毛混色**、**混色刀** | 笔迹沿其方向裂成条纹的程度。 |
| **锐度** | **锐化** | 笔迹增加的对比度。 |
| **保留质感** | **保留质感混色** | 笔迹下方的细微纹理有多少保留在混色之上。 |
| **细节大小** | **保留质感混色** | 所保留纹理的大小。 |
| **混合明度** | **色相混色** | 明度随色相和饱和度一起混合的程度。 |
| **颗粒感** | **散点混色** | 每个散开的像素替换其下方像素的完整程度。 |
| **拉伸** | **绘画混色**、**晶体混色** | 色块或单元沿笔迹拉伸的程度。 |
| **单元大小** | **晶体混色** | 单元的大小。 |
| **漩涡** | **大理石纹** | 颜料卷曲的强烈程度。 |
| **漩涡大小** | **大理石纹** | 漩涡的大小。 |
| **保边** | **梳理混色** | 混色在颜色之间的边缘处停下的难易程度。 |

## 水彩

**水彩平涂**和**湿水彩**有**水彩**分组，用于设置颜料积聚处较深的边缘。水彩只对同一图层上的颜料起反应。**边缘强度**位于**工具设置**面板顶部，在各分组上方。

### 边缘强度

设置边缘的深浅。

### 边缘宽度

设置边缘的宽度，范围为 0 到 32 px。

## 洇色

这两个水彩画笔的**洇色**分组设置水和颜料向笔迹周围的纸面洇开的方式。颜料只在绘制笔迹的过程中洇开，抬起数位笔后不再扩散。

### 湿洇色

设置颜料在已打湿的纸面上洇开的速度。

### 干洇色

设置颜料在干燥纸面上洇开的速度。

### 洇色距离

设置颜料从每个笔印洇开的最远距离，范围为 0 到 96 px。

### 含水量

设置每个笔印在纸面上留下的水量。它位于**工具设置**面板顶部，在各分组上方。

## 混色方式

可以选择混色画笔如何混合拾取到的颜色。

执行以下任一操作：

- 从 **工具设置** 面板的 **混色** 中选择 **Oklab 混色**、**线性光混色** 或 **经典混色**。
- 打开工具选项栏中的 **更多工具选项**，然后在工具设置抽屉中选择 **混色**（[大小、强度和不透明度](/zh/docs/brushes/basics/)）。
- 在命令搜索中搜索选项名称。

| 选项 | 混合方式 |
| --- | --- |
| **Oklab 混色** | 按人眼感知的方式均匀混合拾取的颜色。 |
| **线性光混色** | 按光线混合的方式混合拾取的颜色。 |
| **经典混色** | 按画作中存储的颜色值混合。 |

所有内置混色画笔的初始设置都是 **Oklab 混色**。该选项随画笔保存，画作的**颜色混合**设置不会改变它。对不混色的画笔，这些选项不可用。

![混色设置，显示 Oklab 混色。](shot:brushes/color-mixing-menu)

## 鬃毛

**鬃毛**分组只出现在**鬃毛画笔**上。该画笔会把前景色和背景色中的另一种颜色，以条纹形式带进厚涂颜料的笔脊中。

### 鬃毛比例

设置鬃毛痕迹相对于画笔大小的尺寸。滑块范围为 25% 到 200%，输入数值时最高可达 400%。

### 载色量

设置每道笔迹起笔时画笔携带的颜料量。
