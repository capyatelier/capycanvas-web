笔的设置位于**编辑 > 首选项**的**笔与输入**页面。

![首选项的笔与输入页面。](shot:pen/pen-and-input)

## 压感响应

可以用**笔响应**下的**压感响应**更改数位笔对轻压的响应。值越低，轻压的效果越强；值越高，需要用的力越大。范围为 0.25 × 到 4.00 ×。默认值 1.00 × 时，笔压按原样使用。

此设置适用于所有画笔和工具，包括**绘制选区**和**快速蒙版**。已经画好的笔迹不会改变。

## 笔迹预测

笔迹预测会在笔尖前方先画出一小段笔迹，绘画时由实际笔迹替换。相关设置位于**笔响应**下：

- **启用笔迹预测**同时打开或关闭两种预测。
- **使用*系统*笔迹预测**（例如**使用 Windows 笔迹预测**）使用系统或浏览器提供的预测。
- **预测量**设置 Capy Canvas 自身预测的提前量，范围为 0 到 64 ms。

两个开关默认都打开，**预测量**默认为 16 ms。**启用笔迹预测**关闭时，另外两项设置不可用。

| 系统 | 系统预测 |
| --- | --- |
| iPad | 可用 |
| Windows | Windows 提供时可用 |
| Android | Android 14 及更高版本，且使用系统支持的触控笔 |
| 网页版 | 在提供该功能的浏览器中可用 |
| macOS、Linux | 始终不可用 |

系统预测不可用时，其开关不可用，由**预测量**设置预测。使用系统预测时，**预测量**不可用（在 iPad 上隐藏）。

光标跟随数位笔，而不是跟随预测的笔迹。

![笔响应设置。](shot:pen/prediction)

## 光标形状

可以用**指针**下的**光标形状**选择画布上显示的指针。

| 选项 | 显示内容 |
| --- | --- |
| **画笔大小** | 按笔尖大小、形状和旋转显示的笔尖轮廓（默认） |
| **十字**、**三角形** | 十字或小三角形 |
| **圆点** | 很小的十字 |
| **单像素点** | 屏幕上的一个像素 |
| **准星** | 中心带圆点的十字 |
| **工具** | 工具图标，其作用点位于指针处 |
| **工具和画笔大小**、**画笔大小与十字**、**画笔大小与圆点**、**画笔大小与单像素点** | 画笔轮廓加上另一种标记 |
| **无** | 在显示屏上使用数位笔时不显示任何内容。使用鼠标、触控板或无屏数位板时显示**准星**。 |

光标形状适用于绘画工具和**绘制选区**。形状中包含**工具**时，其他工具显示其图标，否则显示十字。

![光标形状列表。](shot:pen/cursor-shapes)

## 绘画时隐藏光标

**绘画时隐藏光标**打开（默认）时，使用绘画工具期间，数位笔接触画布或按下鼠标按键时光标会消失。擦除时画笔轮廓保持可见。

## 橡皮擦端

可以选择数位笔的橡皮擦端执行什么操作。iPad 上不显示**橡皮擦端**组。

- **工具**：**当前工具**（默认）保持正在使用的工具。**橡皮擦**、**钢笔**、**铅笔**、**绘画画笔**、**喷枪**和**混色**会在使用橡皮擦端时切换到该工具，用完后恢复原来的工具。
- **用透明色绘画**：打开时（默认），橡皮擦端用工具的画笔擦除；关闭时，橡皮擦端进行绘画。**工具**为**橡皮擦**时，此开关隐藏。

## 笔按钮

可以为数位笔的每个侧键指定一项操作，还可以为每类工具分别指定不同的操作。

要设置笔按钮：

1. 在**笔按钮**下选择该按钮。
2. 选择**操作**，或关闭**所有工具相同**并选择一类工具，例如**绘画工具**。
3. 选择一项操作。**无操作**会清除该按钮的设置。

工具、画笔和模式（例如**平移**或**取样颜色**）在按住按钮期间持续生效。其他操作执行一次。在绘制笔迹过程中按下按钮，会在该笔结束后生效。

所有按钮初始都为**无操作**。设为**无操作**的按钮保留数位板驱动程序或系统为其指定的操作。

| 系统 | 列出的按钮 |
| --- | --- |
| Linux | **下侧按钮**、**上侧按钮**、**第三侧按钮** |
| Windows | **下侧按钮** |
| macOS、Android、网页版 | **下侧按钮**、**上侧按钮** |
| iPad | 无 |

在 Linux 和 Android 上，数位板快捷键面板上的按钮在[键盘快捷键](/zh/docs/input/keyboard/)页面中作为按键设置。

![下侧按钮的页面，为每类工具各设有一项操作。](shot:pen/pen-button-page)

## Apple Pencil 的轻点两下和挤压

在 iPad 上，轻点两下 Apple Pencil 和挤压 Apple Pencil Pro 的操作遵循 iPad 自身在**设置 > Apple Pencil** 中的设置。

- “在当前工具和橡皮擦之间切换”会切换到**橡皮擦**，再次操作时切换回来。
- “在当前工具和上次使用的工具之间切换”会切换到之前选择的工具。

其他选项在 Capy Canvas 中不起作用。挤压在松开时生效。Apple Pencil 悬停在屏幕上方时会显示光标。
