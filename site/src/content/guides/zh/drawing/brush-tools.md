可以使用**钢笔**、**铅笔**、**绘画画笔**、**喷枪**和**装饰**工具绘画，用**橡皮擦**擦除。每个工具包含一个或多个内置画笔预设分组。

## 工具和预设

| 工具 | 分组 | 预设 |
| --- | --- | --- |
| **钢笔** | **钢笔** | **G 笔**、**粗糙 G 笔**、**书法笔**、**古典蘸水笔**、**写实钢笔**、**湿墨**、**斑驳墨迹**、**写实水墨** |
| | **马克笔** | **马克笔** |
| **铅笔** | **铅笔** | **铅笔**、**尖头铅笔**、**排线铅笔** |
| | **色粉** | **炭笔**、**粉笔**、**色粉块** |
| **绘画画笔** | **绘画** | **画笔**、**鬃毛画笔**、**纹理扁笔**、**干擦叠色**、**透明罩染**、**不透明水粉**、**正片叠底罩染** |
| | **水彩** | **水彩平涂**、**湿水彩** |
| | **油画** | **饱蘸油彩**、**调色刀**、**湿圆笔** |
| **喷枪** | **喷枪** | **喷枪** |
| | **喷雾** | **喷雾** |
| **橡皮擦** | **橡皮擦** | **橡皮擦** |
| **装饰** | **纹理** | **双重纹理** |

工具及其每个分组都会保留上次使用的预设。预设本身不带颜色，所有画笔都使用[颜色面板](/zh/docs/color/color-panel/)中的当前颜色绘画。

## 预设的行为

以下行为是预设内置的，没有对应的设置。

| 预设 | 行为 |
| --- | --- |
| **书法笔**、**古典蘸水笔** | 斜切笔尖。 |
| **马克笔** | 斜口笔头。 |
| **铅笔**、**尖头铅笔**、**排线铅笔**、**炭笔** | 倾斜数位笔时笔迹变宽。 |
| **喷枪** | 数位笔停在原处不动时持续添加颜料。 |
| **喷雾** | 将笔印散布在笔迹周围。 |
| **正片叠底罩染** | 以正片叠底模式绘画。 |

## 选择画笔工具

执行以下任一操作：

- 按 **P** 选择钢笔和铅笔，按 **B** 选择绘画画笔、喷枪和装饰，按 **E** 选择橡皮擦。再次按 **P** 或 **B** 可切换到该键上的下一个工具。
- 在“绘画”中，在左边缘的“工具”工具栏中选择工具。
- 在“照片”中，在“工具”工具栏中选择**画笔**或**橡皮擦**。**画笔**包含绘画画笔、钢笔、铅笔、喷枪和装饰。
- 在“素描”中，选择标题栏中的**画笔**或**橡皮擦**。
- 在[命令搜索](/zh/docs/start/command-search/)中输入工具名、预设名，或分组名加“画笔”，例如**铅笔画笔**。

工具按钮显示上次使用的分组的图标，按钮的工具提示同时写出分组和工具，例如“马克笔 · 钢笔（P）”。

预设以及 **P** 和 **B** 键上的工具没有单独的快捷键。可以在[键盘快捷键](/zh/docs/input/keyboard/)页面为它们指定按键。

## 工具组面板

可以在**工具组**面板中选择分组和预设。

执行以下任一操作：

- 选择**窗口 > 工具组**。
- 在“绘画”中，选择左列的**工具组**标签页。
- 在“照片”中，选择右侧图标条中的**工具组**。
- 再次选择当前工具的按钮。打开的抽屉中包含**工具组**和**工具设置**。

![“绘画”中的工具组面板，钢笔和马克笔分组位于钢笔预设及其笔迹预览上方。](shot:drawing/brush-tool-set)

顶行列出该工具的分组。在“照片”中使用**画笔**时，顶行改为列出工具。顶行下方是所选分组的各个预设，每个预设都带有笔迹预览。

## 从按钮选择分组

可以从工具按钮的菜单中选择分组。右键单击或按住按钮即可打开菜单。当前分组带有勾选标记。

带菜单的按钮在角落有一个小三角形。

![“工具”工具栏中绘画画笔按钮的菜单，列出绘画、水彩和油画分组。](shot:drawing/brush-group-menu)

## “素描”中的抽屉

在“素描”中，选择标题栏中的**画笔**或**橡皮擦**，即可使用它上次的预设。再次选择会打开它的抽屉，再选择一次则关闭抽屉。

**画笔**抽屉分为三列：**画笔**列出分组，**工具**列出所选分组的预设，**工具设置**包含这些预设的设置。选择分组会选中该分组上次使用的预设，抽屉保持打开。**橡皮擦**抽屉只有**工具**和**工具设置**。

![“素描”中的画笔抽屉，包含画笔、工具和工具设置三列。](shot:drawing/sketch-brush-drawer)

## 橡皮擦

可以用**橡皮擦**擦除所选图层上的颜料。按 **E**，或在“工具”工具栏中选择**橡皮擦**；在“素描”中，则在标题栏中选择。

编辑蒙版时，橡皮擦会去除蒙版的覆盖区域。

在颜色面板中选择**透明绘画**后，所有画笔都会擦除。数位笔的橡皮擦端也可以擦除（[笔](/zh/docs/input/pen/)）。

在打开了**锁定透明度**的图层上，擦除不起作用。

## 接收颜料的图层

画笔笔迹画在所选图层上；编辑蒙版时，则画在该图层的蒙版上。在滤镜图层上，笔迹画在滤镜的蒙版上。如果滤镜没有蒙版，笔迹会画到滤镜所应用的图层，或画到下方的下一个图层（[滤镜的作用方式](/zh/docs/filters/how-filters-apply/)）。

存在选区时，颜料只会画在选区内。

在以下图层上，笔迹不会留下颜料，并会显示提示说明原因：

- 图层组或选区图层。
- 没有蒙版的填充图层。
- 打开了**锁定编辑**的图层，或位于已锁定图层组中的图层。
- 没有蒙版的滤镜图层，且其下方的图层已锁定或不存在。
- 已缩放或旋转的图层，直到选择**将变换应用于像素**为止（[移动和变换](/zh/docs/transform/move-transform/)）。

湿画笔、混色画笔和水彩画笔在蒙版上只绘制普通的覆盖。在每个蒙版上第一次用这类画笔绘画时，会显示提示。
