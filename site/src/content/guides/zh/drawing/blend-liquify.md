可以用**混色**涂抹、调和图层上的颜料，用**液化**移动图层的像素。

## 混色

执行以下任一操作：

- 按 **J**。
- 在“绘画”中，在“工具”工具栏中选择**混色**。**仿制图章**也在同一个按钮中。
- 在“照片”中，在“工具”工具栏中选择**混色**。
- 在“素描”中，在**塑形**抽屉中选择一支混色笔。
- 在命令搜索中搜索**混色**。

在**工具组**中选择一个分组和一支混色笔。**涂抹**是默认的混色笔。

| 分组 | 混色笔 |
| --- | --- |
| **混色** | **涂抹**、**柔和混色**、**模糊**、**纸擦笔**、**纸巾**、**颗粒混色**、**保留质感混色**、**色相混色** |
| **湿画** | **自然混色**、**湿润混色**、**调色混合**、**混色刀**、**鬃毛混色** |
| **效果** | **绘画混色**、**梳理混色**、**散点混色**、**锐化**、**大理石纹**、**晶体混色**、**抖动混色** |

每支混色笔的设置参见[混色、洇色和鬃毛](/zh/docs/brushes/wet-media/)。

## 液化

执行以下任一操作：

- 在混色处于使用状态时按 **J**。
- 在“绘画”或“照片”中，在“工具”工具栏中选择**液化**。右键单击或按住该按钮可选择模式。
- 在“素描”中，在**塑形**抽屉的**液化**分组中选择一种模式。
- 在命令搜索中搜索**液化**。

每种模式都是**工具组**中的一个预设：

| 预设 | 效果 |
| --- | --- |
| **液化推移** | 沿笔迹拖动像素。 |
| **液化逆时针旋转** | 让像素绕画笔中心逆时针旋转。 |
| **液化顺时针旋转** | 让像素绕画笔中心顺时针旋转。 |
| **液化收缩** | 把像素向画笔中心收拢。 |
| **液化膨胀** | 把像素从画笔中心向外推开。 |
| **液化结晶** | 把画笔下的图像打碎成分散的小块。 |
| **边缘** | 从两侧把像素拉向笔迹线。 |
| **重建** | 取回画笔下的液化变形。 |

液化没有应用按钮。每一笔都会改变图层，并各自成为一个撤销步骤。笔迹会一直在图层第一笔之前的像素上继续变形，直到你在图层上绘画、填充、使用滤镜、变换或粘贴。

## 调整液化和重置液化

可以用**调整液化**按比例减弱液化对图层所做的全部改动，或用**重置液化**让图层恢复到第一笔之前的像素。

执行以下任一操作：

- 在**工具设置**面板中，打开**调整液化**或选择**重置液化**。
- 在命令搜索中搜索**调整液化**或**重置液化**。

打开**调整液化**后，**工具设置**面板中会出现**程度**滑块。为 100% 时变形保持原样，为 0% 时变形消失。松开滑块算一个撤销步骤，**重置液化**也是一步。

在图层有液化改动之前，这两个命令都不可用，并显示“请先对此图层应用液化”。

## 液化设置

![液化结晶的工具设置面板，包含强度、显示扭曲和惯性的液化分组，以及调整液化和重置液化。](shot:drawing/liquify-settings)

**扭曲** 和 **惯性** 位于 **工具设置** 面板的 **液化** 分组中。

### 强度

设置每个笔印移动像素的距离。笔压较轻时，以及越靠近柔边笔尖的边缘，效果越弱。

### 扭曲量

使移动变得不规则。在**液化结晶**上，它设置小块散开的距离。**重建**没有**扭曲**。

### 惯性

抬起数位笔后，让效果沿笔迹最后的方向继续延伸。**重建**没有**惯性**。

## “素描”中的塑形抽屉

在“素描”中，选择标题栏中的**塑形**可使用上次用过的混色、液化或修饰工具，再次选择会打开它的抽屉，再选择一次则关闭抽屉。抽屉列出各分组、所选分组的工具及其设置。**塑形**和**画笔**各自保留上次使用的预设和画笔大小。

![“素描”中的塑形抽屉，左侧是混色、湿画、效果、液化和修饰分组，中间是混色分组的混色笔，右侧是涂抹的设置。](shot:drawing/sketch-sculpt-drawer)

## 在蒙版上绘画

在蒙版上，混色和液化只绘制普通的覆盖，不会涂抹或移动像素。在每个蒙版上第一次这样绘画时，会显示提示。
