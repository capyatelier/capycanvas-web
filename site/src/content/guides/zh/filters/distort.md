扭曲滤镜位于**滤镜 > 扭曲**和**滤镜**面板的**扭曲**类别中。在**属性**面板中更改其设置。每个扭曲滤镜都可以把颜料移到图层的透明区域中。

![滤镜面板显示扭曲类别，每个滤镜都有预览。](shot:filters/distort-list)

## 色差

沿**角度**方向，将红色通道向一侧、蓝色通道向另一侧各移动**分离距离**，在边缘添加色边。

| 设置 | 范围或选项 | 默认值 |
| --- | --- | --- |
| **分离距离** | 0–32 px | 3 px |
| **角度** | −180° 到 180° | 0° |

## 万花筒

将图像的一个扇区镜像为围绕中心的**分区数**个扇区。

| 设置 | 范围或选项 | 默认值 |
| --- | --- | --- |
| **分区数** | 2–24 | 6 |
| **角度** | −180° 到 180° | 0° |
| **中心 X**、**中心 Y**（位于**位置**下） | 画布宽度和高度的 0–100% | 50% |

## 旋涡

按**扭转**使图像围绕中心扭转，到**半径**处逐渐减弱为无扭转。

![旋涡的属性面板，包含扭转、半径和位置设置。](shot:filters/swirl-properties)

| 设置 | 范围或选项 | 默认值 |
| --- | --- | --- |
| **扭转** | −720° 到 720° | 120° |
| **半径** | 画布短边一半的 1–150% | 70% |
| **中心 X**、**中心 Y**（位于**位置**下） | 画布宽度和高度的 0–100% | 50% |

## 波纹

以围绕中心的环形移动图像，位移最多为**振幅**，环与环之间相隔**波长**。圆环随时间向外扩散。

| 设置 | 范围或选项 | 默认值 |
| --- | --- | --- |
| **振幅** | 0–48 px | 12 px |
| **波长** | 8–256 px | 64 px |
| **速度** | 0–4 | 0.5 |
| **中心 X**、**中心 Y**（位于**位置**下） | 画布宽度和高度的 0–100% | 50% |
| **启用动画** | 打开或关闭 | 打开 |
| **定格时间** | 0–3600 s | 0 s |

## 玻璃

用**纹理大小**的磨砂玻璃图案扭曲图像，位移最多为**扭曲量**。**粗糙度**添加更细的图案。

| 设置 | 范围或选项 | 默认值 |
| --- | --- | --- |
| **扭曲量** | 0–48 px | 12 px |
| **纹理大小** | 4–160 px | 24 px |
| **粗糙度** | 0–100% | 35% |

## 雨窗

添加随时间带着水痕向下滑落的雨滴，雨滴使图像弯折，最多为**折射**。**雨量**设置雨滴的数量。

| 设置 | 范围或选项 | 默认值 |
| --- | --- | --- |
| **折射** | 0–32 px | 8 px |
| **雨滴大小** | 12–120 px | 48 px |
| **雨量** | 0–100% | 65% |
| **速度** | 0–4 | 0.5 |
| **启用动画** | 打开或关闭 | 打开 |
| **定格时间** | 0–3600 s | 0 s |

## 热浪

使图像随时间闪动，画布底部的位移最多为**扭曲量**，顶部没有位移。**细节**添加更细的波纹。

| 设置 | 范围或选项 | 默认值 |
| --- | --- | --- |
| **扭曲量** | 0–48 px | 8 px |
| **波形大小** | 10–240 px | 90 px |
| **速度** | 0–4 | 0.6 |
| **细节** | 0–100% | 50% |
| **启用动画** | 打开或关闭 | 打开 |
| **定格时间** | 0–3600 s | 0 s |

## 纹理扭曲

用**图案大小**的大理石纹图案扭曲图像，位移最多为**扭曲量**。图案随时间漂移。

| 设置 | 范围或选项 | 默认值 |
| --- | --- | --- |
| **扭曲量** | 0–64 px | 24 px |
| **图案大小** | 8–256 px | 96 px |
| **速度** | 0–4 | 0.25 |
| **启用动画** | 打开或关闭 | 打开 |
| **定格时间** | 0–3600 s | 0 s |

## 动画

**波纹**、**雨窗**、**热浪**和**纹理扭曲**是动画滤镜，它们在**滤镜**面板中的行带有动画标记。打开**启用动画**时，滤镜按**速度**持续播放。关闭**启用动画**可使滤镜静止在**定格时间**设定的时刻。

导出的图像显示导出那一刻的动画画面。
