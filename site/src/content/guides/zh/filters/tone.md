明暗滤镜位于**滤镜 > 明暗**和**滤镜**面板的**明暗**类别中。在**属性**面板中更改其设置。

![滤镜面板显示明暗类别，每个滤镜都有预览。](shot:filters/tone-list)

## 阴影/高光

根据周围区域的亮度，用**阴影**提亮暗部，用**高光**压暗亮部。设为 100% 时，每项最多可将曝光改变 2 档。

| 设置 | 范围或选项 | 默认值 |
| --- | --- | --- |
| **阴影** | 0–100% | 0% |
| **高光** | 0–100% | 0% |

## 曲线

用曲线调整色调：**RGB** 页面上的曲线作用于所有通道，**红色**、**绿色**和**蓝色**页面上各有一条单通道曲线。各通道曲线先于 **RGB** 曲线生效。

| 设置 | 范围或选项 | 默认值 |
| --- | --- | --- |
| **RGB**、**红色**、**绿色**、**蓝色**页面 | 每页一条曲线 | 直线 |
| **选取点**、**在图像上调整** | 根据图像设置曲线（参见[添加和编辑滤镜](/zh/docs/filters/adding/)） | |
| **曲线空间** | **编码 RGB**、**对数 HDR**。仅在 [HDR 画作](/zh/docs/color-management/hdr/)中或设为**对数 HDR** 时显示。 | **编码 RGB**；HDR 画作中为**对数 HDR** |
| **HDR 范围** | 0–15 EV，输入时最高 127 EV。仅在使用**对数 HDR** 时显示，表示曲线达到的高于 SDR 白色的档数。 | 4 EV |

| 在图表上 | 操作方法 |
| --- | --- |
| 添加点 | 按下空白处。一条曲线最多可有 32 个点。 |
| 移动点 | 拖动该点，或选中后按方向键。按住 **Shift** 移动距离更大。端点只能上下移动。 |
| 设置精确值 | 选中一个点，在图表下方的**输入**和**输出**中输入数值。 |
| 移除点 | 双击该点、将其拖出图表，或选中后按 **Delete** 或 **Backspace**。 |
| 重新开始 | 选择**重置曲线**。 |

## 色阶

设置输入的黑场、白场和中间调，再将它们映射到**输出**范围。**红色**、**绿色**和**蓝色**页面先于 **RGB** 页面生效。

![色阶的属性面板，包含直方图、自动、选取点，以及输入、输出和截断设置。](shot:filters/levels-properties)

| 设置 | 范围或选项 | 默认值 |
| --- | --- | --- |
| **自动**、**选取点** | 根据图像设置输入（参见[添加和编辑滤镜](/zh/docs/filters/adding/)） | |
| **阴影**、**高光**（直方图下方） | 在画布上标出被截断的区域 | |
| **黑色**（**输入**） | 0–1，可输入任意值。始终低于输入**白色**。 | 0 |
| **白色**（**输入**） | 0–1，可输入任意值 | 1 |
| **中间调** | 0.1–10。大于 1 时变亮。 | 1 |
| **黑色**（**输出**） | 0–1，可输入任意值 | 0 |
| **白色**（**输出**） | 0–1，可输入任意值 | 1 |
| **限制输入范围** | 在每个页面上截断输入**黑色**和**白色**之外的色调 | 关闭 |
| **限制输出范围** | 在每个页面上将结果截断到输出范围内 | 关闭 |

## 亮度／对比度

**对比度**以中性灰为中心拉开或压缩色调，然后**亮度**将所有色调同等提亮或压暗。

| 设置 | 范围或选项 | 默认值 |
| --- | --- | --- |
| **亮度** | −100 到 100 | 0 |
| **对比度** | −100 到 100。50 使对比度加倍，−50 使其减半。 | 0 |

## 阈值

将比**阈值**暗的像素变为黑色，其余变为白色。

| 设置 | 范围或选项 | 默认值 |
| --- | --- | --- |
| **阈值** | 0–1，可输入任意值 | 0.5 |

## 曝光

以档为单位改变曝光。**偏移**提高或降低黑色。

| 设置 | 范围或选项 | 默认值 |
| --- | --- | --- |
| **曝光** | −10 到 10 EV，输入时最高 ±126 EV | 0 EV |
| **偏移** | −0.5 到 0.5 | 0 |
| **伽马** | 0.1–10。大于 1 时中间调变亮。 | 1 |

## 暗角

压暗与画布比例相同的椭圆以外的图像；**强度**为负值时则提亮。设为 ±100% 时，边缘最多改变 2 档。

| 设置 | 范围或选项 | 默认值 |
| --- | --- | --- |
| **强度** | −100% 到 100% | 40% |
| **半径** | 画布尺寸一半的 10–150% | 95% |
| **柔和度** | 用于过渡的半径的 0–100% | 55% |
| **中心 X**、**中心 Y**（位于**位置**下） | 画布宽度和高度的 0–100% | 50% |
