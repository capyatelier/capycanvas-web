颜色滤镜位于**滤镜 > 颜色**和**滤镜**面板的**颜色**类别中。在**属性**面板中更改其设置。

![滤镜面板显示颜色类别，每个滤镜都有预览。](shot:filters/color-list)

## 色相／饱和度

在**全局**页面上调整整幅图像的色相、饱和度和明度，或在**红色**到**洋红**页面上调整某一颜色范围。**着色**为每个像素赋予同一色相和饱和度，并保留其明度。

![色相／饱和度的属性面板，显示红色页面。](shot:filters/hue-saturation-properties)

| 设置 | 范围或选项 | 默认值 |
| --- | --- | --- |
| **色相** | −180° 到 180°；使用**着色**时为 0–360° | 0° |
| **饱和度** | −100% 到 100%；使用**着色**时为 0–100% | 0%；使用**着色**时为 25% |
| **明度** | −100% 到 100% | 0% |
| **中心** | 0–360° Oklab 色相。仅限颜色页面。 | 红色 30°、黄色 110°、绿色 145°、青色 195°、蓝色 265°、洋红 330° |
| **宽度** | 0–180°。仅限颜色页面。 | 30° |
| **羽化** | 0–90°。仅限颜色页面。 | 30° |
| **着色** | 打开或关闭。打开时只保留**全局**页面。 | 关闭 |

## 反相

反转每个颜色通道。没有设置。

## 去色

将每种颜色替换为 HSL 明度相同的灰色。没有设置。

## 照片滤镜

按**浓度**将图像向**颜色**偏色。

| 设置 | 范围或选项 | 默认值 |
| --- | --- | --- |
| **颜色** | 任意颜色 | #FFB873 |
| **浓度** | 0–100% | 25% |
| **保留明度** | 打开或关闭 | 打开 |

## 可选颜色

在每个页面上更改一个颜色范围中的青色、品红、黄色和黑色。**红色**到**洋红**页面作用于饱和的颜色，**白色**、**中性色**和**黑色**页面作用于接近灰色的色调。

| 设置 | 范围或选项 | 默认值 |
| --- | --- | --- |
| **青色** | −100% 到 100% | 0% |
| **品红** | −100% 到 100% | 0% |
| **黄色** | −100% 到 100% | 0% |
| **黑色** | −100% 到 100% | 0% |
| **方法** | **相对**按颜色中已有的油墨量按比例应用每项更改。**绝对**按原值添加更改。适用于每个页面。 | **相对** |

## 通道混合器

在**红色**、**绿色**和**蓝色**页面上，用红、绿、蓝输入通道的混合再加上**常量**来构建每个输出通道。打开**单色**时，只保留**灰色**页面，其混合结果生成灰度图像。

| 设置 | 范围或选项 | 默认值 |
| --- | --- | --- |
| **红色** | −200% 到 200% | **红色**页面上为 100%，**灰色**页面上为 21.26%，其他为 0% |
| **绿色** | −200% 到 200% | **绿色**页面上为 100%，**灰色**页面上为 71.52%，其他为 0% |
| **蓝色** | −200% 到 200% | **蓝色**页面上为 100%，**灰色**页面上为 7.22%，其他为 0% |
| **常量** | −100% 到 100% | 0% |
| **单色** | 打开或关闭 | 关闭 |

## 颜色查找（LUT）

将外观菜单中的查找表应用到颜色上（菜单显示当前外观，例如**暖色**），并按**强度**与原图混合。要使用自己的 LUT，选择外观菜单旁边的**导入 LUT…**，然后打开一个不超过 16 MB 的 3D `.cube` 文件。

![颜色查找（LUT）的属性面板，包含外观菜单和导入 LUT…。](shot:filters/color-lookup)

| 设置 | 范围或选项 | 默认值 |
| --- | --- | --- |
| 外观菜单 | **原始**（不更改）、**暖色**、**冷色**、**黑白**，或以标题列出的导入 LUT。导入的 LUT 保存在画作中。 | **原始** |
| **LUT 色彩空间** | **sRGB**、**Display P3**、**Adobe RGB (1998)**、**ProPhoto RGB**：导入的 LUT 所要求的色彩空间。选择**原始**和内置外观时隐藏。 | **sRGB** |
| **强度** | 0–100% | 100% |

## 色彩平衡

在**阴影**、**中间调**和**高光**页面上分别调整颜色。正值向每个滑块标签中的第二种颜色偏移。

| 设置 | 范围或选项 | 默认值 |
| --- | --- | --- |
| **青——红** | −100 到 100 | 0 |
| **洋红——绿** | −100 到 100 | 0 |
| **黄——蓝** | −100 到 100 | 0 |
| **保留明度** | 打开或关闭，作用于每个页面 | 打开 |

## 自然饱和度

**自然饱和度**对低饱和颜色的提升多于高饱和颜色。**饱和度**均匀地改变所有颜色。

| 设置 | 范围或选项 | 默认值 |
| --- | --- | --- |
| **自然饱和度** | −100% 到 100% | 0% |
| **饱和度** | −100% 到 100% | 0% |
| **保护肤色** | 打开或关闭。限制正的**自然饱和度**对橙色和肤色的作用。 | 打开 |

## 黑白

将图像转换为灰色，每种色相各有一个滑块控制其变亮的程度。**着色**用**着色颜色**为结果上色。

| 设置 | 范围或选项 | 默认值 |
| --- | --- | --- |
| **红色** | −100% 到 200% | 40% |
| **黄色** | −100% 到 200% | 60% |
| **绿色** | −100% 到 200% | 40% |
| **青色** | −100% 到 200% | 60% |
| **蓝色** | −100% 到 200% | 20% |
| **洋红** | −100% 到 200% | 80% |
| **着色** | 打开或关闭 | 关闭 |
| **着色颜色** | 任意颜色 | #BF874C |

## 渐变映射

将图像的色调映射到**渐变**上，最暗的色调对应左端色标，最亮的色调对应右端色标。**数量**将结果与原图混合。

| 设置 | 范围或选项 | 默认值 |
| --- | --- | --- |
| **渐变** | 任意渐变，按照[渐变](/zh/docs/drawing/gradient/)工具中的方式编辑 | 黑色到白色，**Oklab** 插值 |
| **数量** | 0–100% | 100% |

## 白平衡

用**色温**使图像变暖或变冷，用**色偏**使其偏向洋红或绿色。**属性**面板顶部的**选取中性点**会同时设置这两项，使在画布上点按的点变为中性色。

| 设置 | 范围或选项 | 默认值 |
| --- | --- | --- |
| **色温** | −100 到 100，输入时最高 ±1000。正值更暖。 | 0 |
| **色偏** | −100 到 100，输入时最高 ±800。正值更偏洋红。 | 0 |
| **保留明度** | 打开或关闭 | 打开 |

## 分离色调

将阴影向**阴影**颜色着色，将高光向**高光**颜色着色，并保持其亮度。

| 设置 | 范围或选项 | 默认值 |
| --- | --- | --- |
| **阴影** | 任意颜色 | #295494 |
| **高光** | 任意颜色 | #F5AD57 |
| **平衡** | −100 到 100。移动两种色调交汇的位置。正值使图像中更多区域呈现**阴影**颜色。 | 0 |
| **强度** | 0–100% | 30% |

## 曝光反转

在每个颜色通道比**阈值**亮的地方反转该通道。**强度**将结果与原图混合。

| 设置 | 范围或选项 | 默认值 |
| --- | --- | --- |
| **阈值** | 0–100% | 50% |
| **强度** | 0–100% | 100% |

## 虹彩

添加随图像亮度分布并随时间变化的薄膜彩虹色。导出的图像显示导出那一刻的颜色。

| 设置 | 范围或选项 | 默认值 |
| --- | --- | --- |
| **强度** | 0–100% | 55% |
| **薄膜纹理大小** | 8–240 px | 64 px |
| **速度** | 0–4 | 0.3 |
| **启用动画** | 打开或关闭。打开时，颜色按**速度**持续变化。 | 打开 |
| **定格时间** | 0–3600 s：**启用动画**关闭时显示的时刻 | 0 s |
