可以用蒙版隐藏图层的部分区域。蒙版上绘画过的区域显示图层，空白区域隐藏图层。绘画图层、照片图层、图层组、填充图层和滤镜都可以有蒙版。

## 添加蒙版

执行以下任一操作：

- 选择**图层 > 蒙版 > 添加蒙版**。
- 选择图层面板底部的**添加蒙版**。

![Ribbon 的图层行，蒙版缩略图周围带有轮廓。](shot:layers/masks-row)

蒙版缩略图出现在图层缩略图右侧，周围的轮廓表示画笔将在它上面绘画。新蒙版显示整个图层。如果有活动选区，蒙版只显示选中的区域，并且选区会被清除。

如果图层已有蒙版，**添加蒙版**会选中该蒙版用于绘画。不能为选区图层或已锁定的图层添加蒙版。

## 在蒙版上绘画

选择蒙版缩略图即可在蒙版上绘画。要重新在图层上绘画，选择图层缩略图或按 **Escape**。

> **备注**：在蒙版上，画笔会忽略绘画颜色。画笔显示图层，**橡皮擦**隐藏图层。

在反转的蒙版上，画笔和**橡皮擦**的作用互换。蒙版笔迹是干的，没有混色、洇色或纹理。

## 蒙版编辑栏

在蒙版上绘画时，画布底部会出现一个标有“正在编辑*图层*的蒙版”的栏。

![蒙版编辑栏，包含反转、禁用、应用蒙版、更多和编辑内容。](shot:layers/masks-bar)

- **反转**
- **禁用**关闭蒙版，之后该按钮显示为**启用**。
- **应用蒙版**擦除蒙版隐藏的像素，然后移除蒙版。
- **更多**中有**图层**菜单和**显示画布操作栏**。关闭**显示画布操作栏**可隐藏此栏。
- **编辑内容**返回到在图层上绘画。

## 从选区创建蒙版

可以用当前选区创建蒙版。

执行以下任一操作：

- 选择**图层 > 蒙版 > 蒙版：显示选区**或**蒙版：隐藏选区**。在已有蒙版的图层上，这两项显示为**替换蒙版：显示选区**和**替换蒙版：隐藏选区**。
- 选择画布上[选区操作栏](/zh/docs/selections/working/)中的**蒙版**。新蒙版显示选中的区域，并替换图层原有的蒙版。

在有活动选区时添加的滤镜或填充图层，会获得由该选区生成的蒙版。**粘贴入选区**会创建一个以选区为蒙版的新图层（参见[复制和粘贴](/zh/docs/transform/clipboard/)）。

## 从蒙版创建选区

可以将蒙版载入为选区。

执行以下任一操作：

- 选择**选择 > 从图层蒙版**，然后选择**将蒙版载入为选区**、**将蒙版加入选区**、**从选区减去蒙版**或**与蒙版相交**。
- 从蒙版菜单的**像素选区**中选择相同的项目。
- 按住 **Ctrl** 点按蒙版缩略图。加按 **Shift** 可添加到选区，加按 **Alt** 可从选区中减去，加按 **Shift+Alt** 可与选区相交。

## 蒙版菜单

执行以下任一操作：

- 选择**图层 > 蒙版**（第一项显示为**编辑蒙版**）。
- 右键单击或按住蒙版缩略图。
- 在蒙版上绘画时，打开**图层**菜单，或选择图层面板底部的**图层操作**。

在没有蒙版的图层上，**图层 > 蒙版**中只有**添加蒙版**、**蒙版：显示选区**、**蒙版：隐藏选区**和**粘贴蒙版**。

![Ribbon 的蒙版菜单。](shot:layers/masks-menu)

| 项目 | 作用 |
| --- | --- |
| **编辑图层内容** | 返回到在图层上绘画。 |
| **显示蒙版区域** | 在画布上显示蒙版，并选中蒙版用于绘画。 |
| **启用蒙版** | 打开或关闭蒙版，不更改蒙版内容。停用的蒙版缩略图会变淡。 |
| **将蒙版链接到图层** | 打开时，蒙版随图层移动。关闭时，**移动图层／蒙版**移动图层或蒙版，取决于正在哪一个上绘画。缩略图之间的链接按钮作用相同。 |
| **替换蒙版：显示选区**、**替换蒙版：隐藏选区** | 用选区替换蒙版。 |
| **复制蒙版** | 复制蒙版，以便在另一个图层上使用**用复制的蒙版替换**，或在没有蒙版的图层上使用**粘贴蒙版**。 |
| **反转蒙版** | 互换显示和隐藏的区域。 |
| **全部显示**、**全部隐藏** | 使蒙版显示或隐藏整个图层，并关闭反转。 |
| **将蒙版应用到图层** | 擦除蒙版隐藏的像素，然后移除蒙版。 |
| **删除蒙版** | 移除蒙版。图层的像素不变。 |
| **像素选区** | 将蒙版载入为选区。 |

除**编辑图层内容**、**显示蒙版区域**和**复制蒙版**外，每一项都要求图层未锁定。

## 应用蒙版

执行以下任一操作：

- 选择**图层 > 蒙版 > 将蒙版应用到图层**。
- 选择蒙版编辑栏中的**应用蒙版**。

**将蒙版应用到图层**只适用于绘画图层，并且蒙版必须处于启用状态。在已扭曲或网格变形的图层上，先选择**将变换应用于像素**。要应用图层组的蒙版，请使用**合并图层组**（参见[合并图层](/zh/docs/layers/merging/)）。

在照片图层上，**恢复原始照片**可恢复已应用的蒙版擦除的内容。

## 滤镜图层和填充图层上的蒙版

滤镜的蒙版决定滤镜作用的位置。选中滤镜图层或填充图层时，画笔总是在其蒙版上绘画。**填充**、**渐变**以及其他绘制画作的工具不能在滤镜的蒙版上使用。要在填充图层上绘画，需要先添加蒙版。
