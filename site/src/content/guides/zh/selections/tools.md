可以用选区工具选择画作的一部分。工具的设置位于工具设置面板中；在“照片”中，也位于窗口顶部的工具选项栏中。

| 工具 | 选择的内容 | 按键 |
| --- | --- | --- |
| **矩形选区** | 拖出的矩形 | |
| **椭圆选区** | 拖出的椭圆 | |
| **套索选区** | 徒手绘制的形状 | **M** |
| **多边形套索** | 逐个点按角点绘制的形状 | |
| **自动选择** | 颜色相近的连续区域 | **W** |
| **按颜色选择** | 所有颜色相近的像素，无论是否连续 | |
| **绘制选区** | 绘制涂抹的区域 | |
| **明暗范围** | 某一亮度范围内的像素（参见[按亮度选择](/zh/docs/selections/tonal-range/)） | |

## 选择选区工具

执行以下任一操作：

- 在[命令搜索](/zh/docs/start/command-search/)中输入工具名称。
- 按 **M** 选择**套索选区**，或按 **W** 选择**自动选择**。
- 在“绘画”中，选择“工具”工具栏中的**选择**或**自动选择／按颜色选择**。
- 在“照片”中，选择“工具”工具栏中的**矩形选区／椭圆选区**、**套索选区／多边形套索**、**自动选择／按颜色选择**或**绘制选区**。
- 在“素描”中，选择标题栏中的**选择**。再次选择它，可在工具设置面板旁打开包含所有选区工具的抽屉。

包含多个工具的工具栏按钮显示上次使用的工具。要选择其他工具，右键单击或按住该按钮，或在**工具组**面板中选择该工具。“素描”标题栏中的**选择**会返回上次使用的选区工具。

**明暗范围**在“绘画”和“照片”的工具栏上没有按钮。

在快速蒙版中或编辑选区图层时选择选区工具，会保持该模式打开。

## 模式

可以将接下来选择的区域与当前选区组合。

在工具设置面板的**模式**行中选择**新建选区**、**添加到选区**、**从选区减去**或**与选区相交**。默认为**新建选区**。

要只为一次选择更改模式，在开始选择时按住某个键：

- **Shift**：**添加到选区**
- **Alt**：**从选区减去**
- **Shift+Alt**：**与选区相交**
- **Ctrl**：**新建选区**

按住该键时，**模式**行会显示它所选的模式。**绘制选区**只有**添加到选区**和**从选区减去**。

## 抗锯齿和羽化半径

**抗锯齿**默认打开。**羽化半径**使每个新选区的边缘变柔和，最多 100 px，初始为 0。

**绘制选区**没有这两项设置。**明暗范围**有**羽化**，没有**抗锯齿**。

## 矩形选区和椭圆选区

从一个角拖到对角。开始拖动后，按住 **Shift** 可绘制正方形或圆形，按住 **Alt** 可从中心绘制。

- **固定宽高比**使选区保持**比例宽度**和**比例高度**中设置的比例，默认为 1 : 1。
- **固定大小**按设置的**宽度**和**高度**（以像素为单位）绘制选区。默认为 256 × 256。
- **从中心绘制**将选区中心放在开始拖动的位置。

打开**固定宽高比**会关闭**固定大小**，反之亦然。只点按而不拖动时，选区保持不变。

## 套索选区

围绕区域绘制。抬起数位笔或松开鼠标按钮时，闭合的形状成为选区。

## 多边形套索

依次点按形状的每个角点。要完成，执行以下任一操作：

- 再次点按第一个角点。
- 按 **Enter**。
- 选择画布操作栏上的**完成**，或工具设置面板中的**完成选区**。

多边形至少需要三个角点。

- 要移除最后一个角点，按 **Backspace** 或 **Delete**，或选择画布操作栏上的**移除点**或工具设置面板中的**移除最后一个点**。
- 要取消多边形，按 **Escape**，或选择画布操作栏上的**取消**或工具设置面板中的**取消选区**。
- 要使下一条边按 45° 的步长对齐，按住 **Shift**。要使每条边都对齐，在工具设置面板中打开**将边缘限制为 45°**。

放置角点期间，画布底部的[画布操作栏](/zh/docs/selections/working/)会显示**移除点**、**取消**和**完成**。

![多边形的画布操作栏，包含移除点、取消和完成。](shot:selections/tools-polygon-bar)

## 自动选择和按颜色选择

点按画布上的某个颜色。**自动选择**选取该点周围的连续区域，**按颜色选择**选取图像中任意位置的匹配像素。

![自动选择的工具设置面板，包含模式、抗锯齿、来源、容差、边缘设置和羽化半径。](shot:selections/tools-auto-select-settings)

### 来源

设置工具在哪里查找颜色：**可见画作**（默认）、**正在编辑的图层**或**参考图层**（标记为[用作参考](/zh/docs/layers/settings/)的图层）。

### 容差

设置颜色与点按处颜色相差多少仍会被选中。默认为 10%。

### 闭合间隙

闭合区域周围边缘中不超过此宽度的间隙，范围为 0 到 32 px。仅限**自动选择**。

### 扩展

将选区扩大最多 32 px；为负值时收缩选区。

### 边缘平滑

柔化选区的阶梯状边缘。为 0% 时，边缘沿整像素分布。**抗锯齿**关闭时隐藏。

**自动选择**和**按颜色选择**共用一个**来源**设置，并与[填充工具](/zh/docs/drawing/fill/)共用**容差**和**边缘**设置。

## 绘制选区

用圆形画笔涂抹区域。涂抹出的闭合环会被填满。

- **添加到选区**或**从选区减去**设置画笔的作用。
- **压感控制大小**默认关闭。
- **大小**、**硬度**和**不透明度**设置圆形画笔。

涂抹时按住 **Shift** 可添加，按住 **Alt** 可执行与当前设置相反的操作。数位笔的橡皮擦端执行减去。没有选区时，减去的笔迹不起作用。

## 选择按钮

工具设置面板中选区工具设置下方的**选择**会打开[选择菜单](/zh/docs/selections/working/)。**明暗范围**设置中没有**选择**按钮。
