{appName} 使用设备的图形处理器绘制和显示画布。支持情况取决于应用或浏览器、操作系统和图形硬件的组合。

## 原生应用

桌面应用支持 Windows、macOS 和 Linux。原生 iPad 应用要求 iPadOS 17.5 或更高版本。Android 应用要求 Android 12 或更高版本。

iPad 和 Android 应用为测试版本。满足操作系统要求并不代表所有图形处理器或笔都能正常工作。

## 网页编辑器

网页版编辑器支持以下浏览器：

| 系统 | 浏览器 |
| --- | --- |
| Windows | Chrome、Edge、Firefox 141 或更高版本 |
| macOS | Chrome、Edge、Safari 26 或更高版本，Apple 芯片上的 Firefox 147 或更高版本 |
| 使用 Wayland 的 Linux | Chrome、Edge |
| iPadOS 26 或更高版本 | Safari |
| Android 12 或更高版本 | Chrome |

原生 iPad 应用的 iPadOS 17.5 最低要求不适用于 Safari。网页编辑器要求 iPadOS 26 或更高版本，因为它使用该版本提供的浏览器图形功能。

## 图形支持

如果画布无法启动，{appName} 会显示说明缺少何种图形功能的消息。请先更新操作系统、浏览器和图形驱动程序。如果消息仍然出现，报告问题时请附上完整消息文本、设备型号和图形硬件型号。
