在[“绘画”](/zh/docs/start/workspaces/)工作区中分四个阶段绘制一幅抽象习作。每个阶段都会添加图层，不合并任何图层。

![“绘画”工作区，画布上是完成的抽象习作，图层面板中显示其图层。](shot:illustration/overview)

## 习作

这幅习作是一幅 1200 × 1200 的画作，由三个相互重叠的形状组成：一条弯曲的带子、一个圆盘和一个倾斜的方块。形状上和周围有随意的涂画和排线笔触。

## 各个阶段

1. [草稿](/zh/docs/illustration/draft/)：色稿和铅笔草稿。
2. [线稿](/zh/docs/illustration/ink/)：在淡化的草稿上方勾墨线。
3. [底色](/zh/docs/illustration/mask/)：每个形状一个带蒙版的颜色图层。
4. [细化](/zh/docs/illustration/render/)：在剪贴图层上绘制明暗，并导出 PNG。

## 完成后的图层

完成的画作从上到下有以下图层：

| 图层 | 内容 |
| --- | --- |
| *Line art* | 墨线 |
| *Ribbon texture* | 米白色排线和高光，剪贴到 *Ribbon* |
| *Ribbon shading* | 阴影和灰绿色点缀，剪贴到 *Ribbon* |
| *Ribbon* | 蓝绿色，蒙版限定在带子范围内 |
| *Disc shading* | 明暗和一处高光，剪贴到 *Disc* |
| *Disc* | 赭黄色，蒙版限定在圆盘范围内 |
| *Block shading* | 明暗和排线，剪贴到 *Block* |
| *Block* | 赤陶色，蒙版限定在方块范围内 |
| *Sketch* | 不透明度为 22% 的铅笔线，已隐藏 |
| *Color rough* | 不透明度为 50% 的平涂色块，已隐藏 |
| **纸张** | 白色 |
