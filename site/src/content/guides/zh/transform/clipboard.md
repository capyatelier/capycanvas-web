可以从图层或可见图像复制像素，并粘贴为新图层。这些命令位于**编辑**菜单和命令搜索中。

![编辑菜单中的剪贴板命令。](shot:transform/clipboard-edit-menu)

| 命令 | 按键 |
| --- | --- |
| **剪切** | **Ctrl+X** |
| **复制** | **Ctrl+C** |
| **合并复制** | **Ctrl+Shift+C** |
| **粘贴** | **Ctrl+V** |
| **原位粘贴** | **Ctrl+Shift+V** |
| **粘贴入选区** | |

[选区操作栏](/zh/docs/selections/working/)上的**复制**中有**复制**、**合并复制**和**剪切**。

## 复制

复制当前图层自身在选区内的像素，不包括图层的不透明度、蒙版和附加滤镜。没有选区时，复制画布范围内的整个图层。

## 剪切

与**复制**一样复制像素，然后从图层中擦除选中的像素。不能从打开了**锁定透明度**的图层中剪切。

## 合并复制

复制选区内的可见图像，与导出时的外观相同。

## 无法复制的内容

图层组、滤镜图层和选区图层没有自己的像素。要从图层组复制，选择组内的某个图层。在快速蒙版中不能复制画作，编辑蒙版时**复制**和**剪切**不可用。

复制大量内容时会显示进度提示和**取消**。

## 粘贴

将剪贴板内容添加为新的当前图层。

- 从 {appName} 复制的内容：如果复制位置在视图中，会放在原位置；否则放在视图中心。
- 来自其他应用的图像会在变换框中打开。**应用**置入图像，**取消**放弃粘贴（参见[移动和变换](/zh/docs/transform/move-transform/)）。

## 原位粘贴

将剪贴板内容作为新图层添加到复制时的位置，不显示变换框。来自其他应用的图像以原始尺寸放在视图中心。

## 粘贴入选区

与**原位粘贴**相同，并为新图层添加只显示选区的[蒙版](/zh/docs/layers/masks/)。之后选区会被移除。**粘贴入选区**需要选区。

## 在应用之间粘贴

其他应用接收到的 {appName} 复制内容是 8 位 sRGB PNG 图像。只要复制内容仍在剪贴板上，粘贴回 {appName} 时会使用其完整位深度。

粘贴到颜色设置不同的画作中的复制内容会成为[照片图层](/zh/docs/layers/types/)，并从其自身的色彩配置文件转换。

在文本框中输入时，剪贴板按键用于剪切、复制和粘贴文本。

在网页版编辑器中，粘贴的图像最大为 512 MiB。在无法粘贴图像的浏览器中，请改为选择**文件 > 将图像导入为图层…**。
