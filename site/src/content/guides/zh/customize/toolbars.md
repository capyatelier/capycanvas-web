每个工作区都有自己的工具栏和标题栏。**窗口 > 撤销布局更改**（**Ctrl+Alt+Z**）可撤回上一次更改。

## 工具栏菜单

要打开工具栏菜单，右键单击工具栏的背景或手柄，或用手指或数位笔按住它。右键单击或按住某个工具，可打开该工具的菜单。

![工具栏菜单及其中的图块大小。](shot:toolbars/toolbar-menu)

## 显示和隐藏工具栏

执行以下任一操作：

- 选择**窗口 > 快速访问工具栏**和工具栏名称。屏幕上已有的工具栏带有勾号。
- 从工具栏菜单中选择**隐藏*名称*工具栏**。
- 在[命令搜索](/zh/docs/start/command-search/)中输入工具栏名称。

重新显示的工具栏会在窗口顶部边缘打开。

删除**工具**或**命令**工具栏后，同一子菜单中会出现**恢复工具**或**恢复命令**，用于恢复该工具栏及其初始工具。

![窗口菜单中的快速访问工具栏子菜单。](shot:toolbars/quick-access-menu)

## 新建工具栏

执行以下任一操作：

- 选择**窗口 > 快速访问工具栏 > 新建工具栏…**。工具栏会在顶部边缘打开。
- 从标签页组的**面板组**菜单中选择**新建工具栏…**。工具栏会成为该组中的一个标签页。

在网页版和 Android 上，输入**工具栏名称**，选择要添加的工具，然后选择**创建工具栏**。在 Linux、Windows、macOS 和 iPad 应用中，输入名称，在**起始内容**下选择**空工具栏**或已保存的工具栏，然后选择**添加到工作区**。

每个工具栏的名称不能重复。

![选中了一个工具的新建工具栏对话框。](shot:toolbars/new-toolbar-picker)

## 添加和移除工具

- 要在末尾添加工具，从工具栏菜单中选择**添加工具…**。
- 要在某个工具之前添加工具，从该工具的菜单中选择**插入工具…**。
- 要移除工具，从其菜单中选择**移除工具**。
- 要移动工具，按住它，然后在工具栏内拖动，或拖到另一个工具栏中。

除了命令和工具，**添加工具**列表中还有画笔、画笔大小、**颜色选择器**、**画笔大小滑块**、**画笔不透明度滑块**、**工具选项**和**分隔线**。列表中每个面板也各有一项，例如**图层面板**，选择后会在抽屉中打开该面板。

**工具选项**会在工具栏的其余部分显示当前工具的设置。其菜单中有**横向：文本**、**横向：图标**和**显示滑块**。

![工具菜单，包含移除工具和插入工具…两项。](shot:toolbars/tool-menu)

## 图块大小

从工具栏菜单中选择**小图块**、**中图块**、**大图块**、**带标签的中图块**或**带标签的大图块**。带标签的图块会显示每个工具的名称。新工具栏使用**小图块**。

## 配置工具栏

从工具栏菜单中选择**配置*名称*工具栏…**。工具栏会放大显示，旁边一列列出其菜单中的命令。拖动放大后的工具栏中的按钮可调整顺序。按 **Escape** 可关闭该列。

![“工具”工具栏及其配置列。](shot:toolbars/configure)

## 浮动工具栏

双击浮动工具栏的手柄，可在网格、列和行之间切换其排列方式。

## 重命名和复制工具栏

从工具栏菜单中选择**重命名*名称*工具栏…** 或 **创建*名称*工具栏的副本…**。副本具有与原工具栏相同的工具和图块大小。

## 删除工具栏

要删除工具栏：

1. 选择**窗口 > 快速访问工具栏 > 管理工具栏…**。
2. 选择该工具栏。
3. 选择**删除工具栏…**。
4. 选择**删除工具栏**以确认。

**窗口 > 撤销布局更改**可恢复已删除的工具栏。

![选中了一个工具栏的管理工具栏对话框。](shot:toolbars/manage)

## 工具栏库

在 Linux、Windows、macOS 和 iPad 应用中，可以保存工具栏的副本，并将其添加到其他工作区。从工具栏菜单中选择**保存到工具栏库…**。要添加已保存的工具栏，打开**管理工具栏…**，转到**已保存的工具栏**，选择该工具栏，然后选择**添加到工作区**。

## 自定义标题栏

执行以下任一操作：

- 选择**窗口 > 自定义标题栏…**。
- 右键单击或按住标题栏，然后选择**自定义标题栏…**。

标题栏下方会打开一个栏，其中列出可添加的项目。

- 要添加项目，将其拖入标题栏。在该栏中选择项目不会有任何作用。
- 要移动项目，将其拖到新位置。
- 要移除项目，将其拖出标题栏，或选择它后按 **Delete**。

要添加工具，将**添加工具…** 拖入标题栏，然后选择要放在该位置的工具。该栏中还有用于设置标题栏大小的**小**、**中**和**大**，以及用于显示画布下方缩放和旋转栏的**显示底栏**。

选择**完成**保留更改，或选择**取消**放弃更改。在此之前，单键快捷键和命令搜索不可用。

![正在自定义的标题栏。](shot:title-bar/editing)

## 标题栏项目

| 项目 | 显示内容 |
| --- | --- |
| **Capy（专注模式）** | [专注模式](/zh/docs/customize/zen/)按钮 |
| **主菜单** | 包含所有菜单的单个按钮（macOS 上没有） |
| **菜单标签** | 以一排名称显示的菜单（macOS 上没有） |
| **设置** | 打开首选项的按钮 |
| **全屏** | 全屏按钮（仅限网页版） |
| **工作区切换器** | 每个工作区一个按钮 |
| **文档标题** | 画作名称，或每幅打开的画作各一个标签页 |
| **时钟**、**电池** | 时间和电池电量 |
| **空白** | 一段空白间隔 |
| 工具 | **添加工具**列表中除滑块和**工具选项**以外的任意项目 |

在网页版以及 Linux、Windows、macOS 和 iPad 应用中，**时钟**和**电池**只在全屏时显示。

除**空白**和工具以外，每个项目只能放置一次。放不下的项目会移入 **…** 菜单。
