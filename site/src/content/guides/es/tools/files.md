## Abrir un dibujo o una foto

Elija **File → Open…** para abrir un archivo `.capy`. Puede abrir fotos y otras imágenes de la misma manera, incluidos los archivos JPEG, PNG, TIFF, WebP, HEIC, AVIF y OpenEXR. Una fotografía se abre como un nuevo dibujo en su tamaño original y sus colores se mantienen tal como fueron capturados.

Para incorporar una imagen al dibujo que ya tiene abierto, elija **File → Import Image as Layer…** o arrastre el archivo de imagen al lienzo. También puedes copiar una imagen en otra aplicación y pegarla con **Ctrl+V**, que es útil para imágenes de referencia. [Editar una foto](/es/docs/filters/image-editing/) muestra ambas formas con más detalle.

## Trabajar con varios dibujos.

En Paint y Photo, cada dibujo que abre o crea tiene su propia pestaña en la parte superior de la ventana. Haga clic en una pestaña para cambiar a ese dibujo o arrastre las pestañas para cambiar su orden. Un punto junto al nombre indica que el dibujo tiene cambios que aún no se han guardado. **File → Drawings…** enumera todos los dibujos abiertos, en cualquier espacio de trabajo.

Cierra un dibujo con el botón de su pestaña o con **File → Close**. Si tiene cambios no guardados, Capy Canvas le preguntará si desea guardarlo primero.

## Guarda y recupera tu trabajo

Elija **File → Save As…** la primera vez que guarde un dibujo y luego **File → Save** para actualizar el mismo archivo. Cuando guarda una foto que abrió, Capy Canvas pregunta dónde guardar un nuevo archivo `.capy` y deja la foto original intacta.

Si el navegador se cierra antes de haber guardado, Capy Canvas le ofrece recuperar su dibujo la próxima vez que lo abra. Esto es sólo una red de seguridad, así que guarde sus archivos `.capy` con regularidad y conserve copias de los importantes.

Para crear una imagen para compartir o imprimir, consulte [Exportar una imagen](/es/docs/output/export/).
