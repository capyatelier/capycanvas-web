可以用選取範圍工具選擇畫作的一部分。工具的設定位於工具設定面板中；在「照片」中，也位於視窗頂部的工具選項欄中。

| 工具 | 選擇的內容 | 按鍵 |
| --- | --- | --- |
| **矩形選取範圍** | 拖出的矩形 | |
| **橢圓選取範圍** | 拖出的橢圓 | |
| **套索選取範圍** | 徒手繪製的形狀 | **M** |
| **多邊形套索** | 逐個點按角點繪製的形狀 | |
| **自動選取** | 色彩相近的連續區域 | **W** |
| **依色彩選取** | 所有色彩相近的像素，無論是否連續 | |
| **繪製選取範圍** | 繪製塗抹的區域 | |
| **明暗範圍** | 某一亮度範圍內的像素（參見[按亮度選擇](/zh-Hant/docs/selections/tonal-range/)） | |

## 選擇選取工具

執行以下任一操作：

- 在[命令搜尋](/zh-Hant/docs/start/command-search/)中輸入工具名稱。
- 按 **M** 選擇**套索選取範圍**，或按 **W** 選擇**自動選取**。
- 在「繪畫」中，選擇「工具」工具列中的**選取**或**自動選取／依色彩選取**。
- 在「照片」中，選擇「工具」工具列中的**矩形選取範圍／橢圓選取範圍**、**套索選取範圍／多邊形套索**、**自動選取／依色彩選取**或**繪製選取範圍**。
- 在「素描」中，選擇標題列中的**選取**。再次選擇它，可在工具設定面板旁開啟包含所有選取範圍工具的抽屜。

包含多個工具的工具列按鈕顯示上次使用的工具。要選擇其他工具，右鍵按一下或按住該按鈕，或在**工具組**面板中選擇該工具。「素描」標題列中的**選取**會返回上次使用的選取範圍工具。

**明暗範圍**在「繪畫」和「照片」的工具列上沒有按鈕。

在快速遮罩中或編輯選取範圍圖層時選擇選取範圍工具，會保持該模式開啟。

![「素描」中的選擇抽屜，選取範圍工具位於矩形選取範圍的工具設定面板旁邊。](shot:selections/tools-sketch-select-drawer)

## 模式

可以將接下來選擇的區域與目前選取範圍組合。

在工具設定面板的**模式**行中選擇**新增選取範圍**、**加入選取範圍**、**從選取範圍減去**或**與選取範圍相交**。預設為**新增選取範圍**。

要只為一次選擇更改模式，在開始選擇時按住某個鍵：

- **Shift**：**加入選取範圍**
- **Alt**：**從選取範圍減去**
- **Shift+Alt**：**與選取範圍相交**
- **Ctrl**：**新增選取範圍**

按住該鍵時，**模式**行會顯示它所選的模式。**繪製選取範圍**只有**加入選取範圍**和**從選取範圍減去**。

## 消除鋸齒和羽化半徑

**消除鋸齒**預設開啟。**羽化半徑**使每個新選取範圍的邊緣變柔和，最多 100 px，初始為 0。

**繪製選取範圍**沒有這兩項設定。**明暗範圍**有**羽化**，沒有**消除鋸齒**。

## 矩形選取範圍和橢圓選取範圍

從一個角拖到對角。開始拖動後，按住 **Shift** 可繪製正方形或圓形，按住 **Alt** 可從中心繪製。

- **固定長寬比**使選取範圍保持**比例寬度**和**比例高度**中設定的比例，預設為 1 : 1。
- **固定大小**按設定的**寬度**和**高度**（以像素為單位）繪製選取範圍。預設為 256 × 256。
- **從中心繪製**將選取範圍中心放在開始拖動的位置。

開啟**固定長寬比**會關閉**固定大小**，反之亦然。只點按而不拖動時，選取範圍保持不變。

## 套索選取範圍

圍繞區域繪製。抬起數位筆或鬆開滑鼠按鈕時，閉合的形狀成為選取範圍。

## 多邊形套索

依次點按形狀的每個角點。要完成，執行以下任一操作：

- 再次點按第一個角點。
- 按 **Enter**。
- 選擇畫布操作欄上的**完成**，或工具設定面板中的**完成選取範圍**。

多邊形至少需要三個角點。

- 要移除最後一個角點，按 **Backspace** 或 **Delete**，或選擇畫布操作欄上的**移除點**或工具設定面板中的**移除最後一個點**。
- 要取消多邊形，按 **Escape**，或選擇畫布操作欄上的**取消**或工具設定面板中的**取消選取範圍**。
- 要使下一條邊按 45° 的步長對齊，按住 **Shift**。要使每條邊都對齊，在工具設定面板中開啟**將邊緣限制為 45°**。

放置角點期間，畫布底部的[畫布操作欄](/zh-Hant/docs/selections/working/)會顯示**移除點**、**取消**和**完成**。

## 自動選取和按色彩選擇

點按畫布上的某個色彩。**自動選取**選取該點周圍的連續區域，**依色彩選取**選取影像中任意位置的匹配像素。

![自動選取的工具設定面板，包含模式、消除鋸齒、來源、容差、邊緣設定和羽化半徑。](shot:selections/tools-auto-select-settings)

### 來源

設定工具在哪裡查詢色彩：**可見畫作**（預設）、**正在編輯的圖層**或**參考圖層**（標記為[用作參考](/zh-Hant/docs/layers/settings/)的圖層）。

### 容差

設定色彩與點按處色彩相差多少仍會被選取。預設為 10%。

### 閉合間隙

閉合區域周圍邊緣中不超過此寬度的間隙，範圍為 0 到 32 px。僅限**自動選取**。

### 擴展

將選取範圍擴大最多 32 px；為負值時收縮選取範圍。

### 邊緣平滑

柔化選取範圍的階梯狀邊緣。為 0% 時，邊緣沿整像素分佈。**消除鋸齒**關閉時隱藏。

**自動選取**和**依色彩選取**共用一個**來源**設定，並與[填色工具](/zh-Hant/docs/drawing/fill/)共用**容差**和**邊緣**設定。

## 繪製選取範圍

用圓形筆刷塗抹區域。塗抹出的閉合環會被填滿。

- **加入選取範圍**或**從選取範圍減去**設定筆刷的作用。
- **筆壓控制大小**預設關閉。
- **大小**、**硬度**和**不透明度**設定圓形筆刷。

塗抹時按住 **Shift** 可新增，按住 **Alt** 可執行與目前設定相反的操作。數位筆的橡皮擦端執行減去。沒有選取範圍時，減去的筆跡不起作用。

## 選擇按鈕

工具設定面板中選取範圍工具設定下方的**選取**會開啟[選擇選單](/zh-Hant/docs/selections/working/)。**明暗範圍**設定中沒有**選取**按鈕。
