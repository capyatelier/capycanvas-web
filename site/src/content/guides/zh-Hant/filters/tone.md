明暗濾鏡位於**濾鏡 > 明暗**和**濾鏡**面板的**明暗**類別中。在**屬性**面板中更改其設定。

![濾鏡面板顯示明暗類別，每個濾鏡都有預覽。](shot:filters/tone-list)

## 陰影/亮部

根據周圍區域的亮度，用**暗部**提亮暗部，用**亮部**壓暗亮部。設為 100% 時，每項最多可將曝光改變 2 檔。

| 設定 | 範圍或選項 | 預設值 |
| --- | --- | --- |
| **暗部** | 0–100% | 0% |
| **亮部** | 0–100% | 0% |

## 曲線

用曲線調整色調：**RGB** 頁面上的曲線作用於所有通道，**紅色**、**綠色**和**藍色**頁面上各有一條單通道曲線。各通道曲線先於 **RGB** 曲線生效。

| 設定 | 範圍或選項 | 預設值 |
| --- | --- | --- |
| **RGB**、**紅色**、**綠色**、**藍色**頁面 | 每頁一條曲線 | 直線 |
| **選取點**、**在影像上調整** | 根據影像設定曲線（參見[新增和編輯濾鏡](/zh-Hant/docs/filters/adding/)） | |
| **曲線空間** | **編碼 RGB**、**對數 HDR**。僅在 [HDR 畫作](/zh-Hant/docs/color-management/hdr/)中或設為**對數 HDR** 時顯示。 | **編碼 RGB**；HDR 畫作中為**對數 HDR** |
| **HDR 範圍** | 0–15 EV，輸入時最高 127 EV。僅在使用**對數 HDR** 時顯示，表示曲線達到的高於 SDR 白色的檔數。 | 4 EV |

| 在圖表上 | 操作方法 |
| --- | --- |
| 新增點 | 按下空白處。一條曲線最多可有 32 個點。 |
| 移動點 | 拖動該點，或選取後按方向鍵。按住 **Shift** 移動距離更大。端點只能上下移動。 |
| 設定精確值 | 選取一個點，在圖表下方的**輸入**和**輸出**中輸入數值。 |
| 移除點 | 按兩下該點、將其拖出圖表，或選取後按 **Delete** 或 **Backspace**。 |
| 重新開始 | 選擇**重設曲線**。 |

## 色階

設定輸入的黑場、白場和中間調，再將它們對映到**輸出**範圍。**紅色**、**綠色**和**藍色**頁面先於 **RGB** 頁面生效。

![色階的屬性面板，包含直方圖、自動、選取點，以及輸入、輸出和截斷設定。](shot:filters/levels-properties)

| 設定 | 範圍或選項 | 預設值 |
| --- | --- | --- |
| **自動**、**選取點** | 根據影像設定輸入（參見[新增和編輯濾鏡](/zh-Hant/docs/filters/adding/)） | |
| **陰影**、**亮部**（直方圖下方） | 在畫布上標出被截斷的區域 | |
| **黑色**（**輸入**） | 0–1，可輸入任意值。始終低於輸入**白色**。 | 0 |
| **白色**（**輸入**） | 0–1，可輸入任意值 | 1 |
| **中間調** | 0.1–10。大於 1 時變亮。 | 1 |
| **黑色**（**輸出**） | 0–1，可輸入任意值 | 0 |
| **白色**（**輸出**） | 0–1，可輸入任意值 | 1 |
| **限制輸入範圍** | 在每個頁面上截斷輸入**黑色**和**白色**之外的色調 | 關閉 |
| **限制輸出範圍** | 在每個頁面上將結果截斷到輸出範圍內 | 關閉 |

## 亮度／對比

**對比**以中性灰為中心拉開或壓縮色調，然後**亮度**將所有色調同等提亮或壓暗。

| 設定 | 範圍或選項 | 預設值 |
| --- | --- | --- |
| **亮度** | −100 到 100 | 0 |
| **對比** | −100 到 100。50 使對比加倍，−50 使其減半。 | 0 |

## 臨界值

將比**臨界值**暗的像素變為黑色，其餘變為白色。

| 設定 | 範圍或選項 | 預設值 |
| --- | --- | --- |
| **臨界值** | 0–1，可輸入任意值 | 0.5 |

## 曝光

以檔為單位改變曝光。**偏移**提高或降低黑色。

| 設定 | 範圍或選項 | 預設值 |
| --- | --- | --- |
| **曝光** | −10 到 10 EV，輸入時最高 ±126 EV | 0 EV |
| **偏移** | −0.5 到 0.5 | 0 |
| **伽瑪** | 0.1–10。大於 1 時中間調變亮。 | 1 |

## 暗角

壓暗與畫布比例相同的橢圓以外的影像；**強度**為負值時則提亮。設為 ±100% 時，邊緣最多改變 2 檔。

| 設定 | 範圍或選項 | 預設值 |
| --- | --- | --- |
| **強度** | −100% 到 100% | 40% |
| **半徑** | 畫布尺寸一半的 10–150% | 95% |
| **柔和度** | 用於過渡的半徑的 0–100% | 55% |
| **中心 X**、**中心 Y**（位於**位置**下） | 畫布寬度和高度的 0–100% | 50% |
