在[「繪畫」](/zh-Hant/docs/start/workspaces/)工作區中分四個階段繪製一幅抽象習作。每個階段都會新增圖層，不合併任何圖層。

![「繪畫」工作區，畫布上是完成的抽象習作，圖層面板中顯示其圖層。](shot:illustration/overview)

## 習作

這幅習作是一幅 1200 × 1200 的畫作，由三個相互重疊的形狀組成：一條彎曲的帶子、一個圓盤和一個傾斜的方塊。形狀上和周圍有隨意的塗畫和排線筆觸。

## 各個階段

1. [草稿](/zh-Hant/docs/illustration/draft/)：色稿和鉛筆草稿。
2. [線稿](/zh-Hant/docs/illustration/ink/)：在淡化的草稿上方勾墨線。
3. [底色](/zh-Hant/docs/illustration/mask/)：每個形狀一個帶遮罩的色彩圖層。
4. [細化](/zh-Hant/docs/illustration/render/)：在剪貼圖層上繪製明暗，並匯出 PNG。

## 完成後的圖層

完成的畫作從上到下有以下圖層：

| 圖層 | 內容 |
| --- | --- |
| *Line art* | 墨線 |
| *Ribbon texture* | 米白色排線和高光，剪貼到 *Ribbon* |
| *Ribbon shading* | 陰影和灰綠色點綴，剪貼到 *Ribbon* |
| *Ribbon* | 藍綠色，遮罩限定在帶子範圍內 |
| *Disc shading* | 明暗和一處高光，剪貼到 *Disc* |
| *Disc* | 赭黃色，遮罩限定在圓盤範圍內 |
| *Block shading* | 明暗和排線，剪貼到 *Block* |
| *Block* | 赤陶色，遮罩限定在方塊範圍內 |
| *Sketch* | 不透明度為 22% 的鉛筆線，已隱藏 |
| *Color rough* | 不透明度為 50% 的平塗色塊，已隱藏 |
| **紙張** | 白色 |
