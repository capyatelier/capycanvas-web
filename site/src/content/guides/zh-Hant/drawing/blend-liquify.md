可以用**混色**塗抹、調和圖層上的顏料，用**液化**移動圖層的像素。

## 混色

執行以下任一操作：

- 按 **J**。
- 在「繪畫」中，在「工具」工具列中選擇**混色**。**仿製印章**也在同一個按鈕中。
- 在「照片」中，在「工具」工具列中選擇**混色**。
- 在「素描」中，在**塑形**抽屜中選擇**混色**。
- 在命令搜尋中搜尋**混色**。

混色有兩個預設：**自然混色**和**塗抹**。兩者的**載色量**初始都為 0%，本身不帶色彩。**拾色量**決定它們沿筆跡把色彩拖出多遠（[混色、暈染和鬃毛](/zh-Hant/docs/brushes/wet-media/)）。

## 液化

執行以下任一操作：

- 在混色處於使用狀態時按 **J**。
- 在「繪畫」或「照片」中，在「工具」工具列中選擇**液化**。右鍵按一下或按住該按鈕可選擇模式。
- 在「素描」中，在**塑形**抽屜中選擇**液化**。
- 在命令搜尋中搜尋**液化**。

每種模式都是**工具組**中的一個預設：

| 預設 | 效果 |
| --- | --- |
| **液化推移** | 沿筆跡拖動像素。 |
| **液化逆時針旋轉** | 讓像素繞筆刷中心逆時針旋轉。 |
| **液化順時針旋轉** | 讓像素繞筆刷中心順時針旋轉。 |
| **液化收縮** | 把像素向筆刷中心收攏。 |
| **液化膨脹** | 把像素從筆刷中心向外推開。 |
| **液化結晶** | 把筆刷下的影像打碎成分散的小塊。 |

## 液化設定

![液化結晶的工具設定面板，液化分組中顯示強度和扭曲量。](shot:drawing/liquify-settings)

**強度**、**扭曲量**和**慣性**位於**工具設定**面板的**液化**分組中。液化沒有**流量**。

### 強度

設定每個筆印移動像素的距離。筆壓較輕時，以及越靠近柔邊筆尖的邊緣，效果越弱。

### 扭曲量

設定**液化結晶**打散像素的程度。其他模式都沒有這項設定。

### 慣性

使**液化推移**帶動像素移動的距離超過數位筆移動的距離。只在這種模式下顯示。

## 「素描」中的塑形抽屜

在「素描」中，標題列中的**塑形**包含混色、液化和修飾工具。

- 選擇**塑形**可使用上次用過的塑形預設。第一次使用時為**自然混色**。
- 再次選擇**塑形**會開啟它的抽屜，再選擇一次則關閉抽屜。

抽屜分為三列。**塑形**列出**混色**、**液化**、**仿製**、**修復**和**污點修復**。**工具**列出所選分組的預設，**工具設定**包含這些預設的設定。

**塑形**和**筆刷**各自保留上次使用的預設和筆刷大小。

![「素描」中的塑形抽屜，塑形列中選取了液化，工具列中是六個液化預設。](shot:drawing/sketch-sculpt-drawer)

## 在遮罩上繪畫

在遮罩上，混色和液化只繪製普通的覆蓋，不會塗抹或移動像素。在每個遮罩上第一次這樣繪畫時，會顯示提示。
