可以使用**鋼筆**、**鉛筆**、**繪畫筆刷**、**噴槍**和**裝飾**工具繪畫，用**橡皮擦**擦除。每個工具包含一個或多個內建筆刷預設分組。

## 工具和預設

| 工具 | 分組 | 預設 |
| --- | --- | --- |
| **鋼筆** | **鋼筆** | **G 筆**、**粗糙 G 筆**、**書法筆**、**古典沾水筆**、**寫實鋼筆**、**濕墨**、**斑駁墨跡**、**寫實水墨** |
| | **麥克筆** | **麥克筆** |
| **鉛筆** | **鉛筆** | **鉛筆**、**尖頭鉛筆**、**排線鉛筆** |
| | **粉彩** | **炭筆**、**粉筆**、**粉彩塊** |
| **繪畫筆刷** | **繪畫** | **筆刷**、**鬃毛筆刷**、**紋理扁筆**、**乾擦疊色**、**透明罩染**、**不透明水粉**、**色彩增值罩染** |
| | **水彩** | **水彩平塗**、**濕水彩** |
| | **油畫** | **飽蘸油彩**、**調色刀**、**濕圓筆** |
| **噴槍** | **噴槍** | **噴槍** |
| | **噴霧** | **噴霧** |
| **橡皮擦** | **橡皮擦** | **橡皮擦** |
| **裝飾** | **紋理** | **雙重紋理** |

工具及其每個分組都會保留上次使用的預設。預設本身不帶色彩，所有筆刷都使用[色彩面板](/zh-Hant/docs/color/color-panel/)中的目前色彩繪畫。

## 預設的行為

以下行為是預設內建的，沒有對應的設定。

| 預設 | 行為 |
| --- | --- |
| **書法筆**、**古典沾水筆** | 斜切筆尖。 |
| **麥克筆** | 斜口筆頭。 |
| **鉛筆**、**尖頭鉛筆**、**排線鉛筆**、**炭筆** | 傾斜數位筆時筆跡變寬。 |
| **噴槍** | 數位筆停在原處不動時持續新增顏料。 |
| **噴霧** | 將筆印散佈在筆跡周圍。 |
| **色彩增值罩染** | 以色彩增值模式繪畫。 |

## 選擇筆刷工具

執行以下任一操作：

- 按 **P** 選擇鋼筆和鉛筆，按 **B** 選擇繪畫筆刷、噴槍和裝飾，按 **E** 選擇橡皮擦。再次按 **P** 或 **B** 可切換到該鍵上的下一個工具。
- 在「繪畫」中，在左邊緣的「工具」工具列中選擇工具。
- 在「照片」中，在「工具」工具列中選擇**筆刷**或**橡皮擦**。**筆刷**包含繪畫筆刷、鋼筆、鉛筆、噴槍和裝飾。
- 在「素描」中，選擇標題列中的**筆刷**或**橡皮擦**。
- 在[命令搜尋](/zh-Hant/docs/start/command-search/)中輸入工具名、預設名，或分組名加「筆刷」，例如**鉛筆筆刷**。

工具按鈕顯示上次使用的分組的圖示，按鈕的工具提示同時寫出分組和工具，例如「麥克筆 · 鋼筆（P）」。

預設以及 **P** 和 **B** 鍵上的工具沒有單獨的快捷鍵。可以在[鍵盤快捷鍵](/zh-Hant/docs/input/keyboard/)頁面為它們指定按鍵。

## 工具組面板

可以在**工具組**面板中選擇分組和預設。

執行以下任一操作：

- 選擇**視窗 > 工具組**。
- 在「繪畫」中，選擇左列的**工具組**分頁。
- 在「照片」中，選擇右側圖示條中的**工具組**。
- 再次選擇目前工具的按鈕。開啟的抽屜中包含**工具組**和**工具設定**。

![「繪畫」中的工具組面板，鋼筆和麥克筆分組位於鋼筆預設及其筆跡預覽上方。](shot:drawing/brush-tool-set)

頂行列出該工具的分組。在「照片」中使用**筆刷**時，頂行改為列出工具。頂行下方是所選分組的各個預設，每個預設都帶有筆跡預覽。

## 從按鈕選擇分組

可以從工具按鈕的選單中選擇分組。右鍵按一下或按住按鈕即可開啟選單。目前分組帶有勾選標記。

帶選單的按鈕在角落有一個小三角形。

![「工具」工具列中繪畫筆刷按鈕的選單，列出繪畫、水彩和油畫分組。](shot:drawing/brush-group-menu)

## 「素描」中的抽屜

在「素描」中，選擇標題列中的**筆刷**或**橡皮擦**，即可使用它上次的預設。再次選擇會開啟它的抽屜，再選擇一次則關閉抽屜。

**筆刷**抽屜分為三列：**筆刷**列出分組，**工具**列出所選分組的預設，**工具設定**包含這些預設的設定。選擇分組會選取該分組上次使用的預設，抽屜保持開啟。**橡皮擦**抽屜只有**工具**和**工具設定**。

![「素描」中的筆刷抽屜，包含筆刷、工具和工具設定三列。](shot:drawing/sketch-brush-drawer)

## 橡皮擦

可以用**橡皮擦**擦除所選圖層上的顏料。按 **E**，或在「工具」工具列中選擇**橡皮擦**；在「素描」中，則在標題列中選擇。

編輯遮罩時，橡皮擦會去除遮罩的覆蓋區域。

在色彩面板中選擇**透明繪畫**後，所有筆刷都會擦除。數位筆的橡皮擦端也可以擦除（[筆](/zh-Hant/docs/input/pen/)）。

在開啟了**鎖定透明度**的圖層上，擦除不起作用。

## 接收顏料的圖層

筆刷筆跡畫在所選圖層上；編輯遮罩時，則畫在該圖層的遮罩上。在濾鏡圖層上，筆跡畫在濾鏡的遮罩上。如果濾鏡沒有遮罩，筆跡會畫到濾鏡所應用的圖層，或畫到下方的下一個圖層（[濾鏡的作用方式](/zh-Hant/docs/filters/how-filters-apply/)）。

存在選取範圍時，顏料只會畫在選取範圍內。

在以下圖層上，筆跡不會留下顏料，並會顯示提示說明原因：

- 圖層群組或選取範圍圖層。
- 沒有遮罩的填色圖層。
- 開啟了**鎖定編輯**的圖層，或位於已鎖定圖層群組中的圖層。
- 沒有遮罩的濾鏡圖層，且其下方的圖層已鎖定或不存在。
- 已縮放或旋轉的圖層，直到選擇**將變形套用至像素**為止（[移動與變形](/zh-Hant/docs/transform/move-transform/)）。

溼筆刷、混色筆刷和水彩筆刷在遮罩上只繪製普通的覆蓋。在每個遮罩上第一次用這類筆刷繪畫時，會顯示提示。
