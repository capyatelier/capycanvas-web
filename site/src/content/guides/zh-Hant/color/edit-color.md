## 開啟編輯色彩

執行以下任一操作：

- 選擇[色彩面板](/zh-Hant/docs/color/color-panel/)右上角的**編輯色彩…**（鉛筆）。
- 按兩下色彩面板中的前景色板或背景色板。
- 在屬性中選擇一個色彩按鈕，例如純色填色圖層的**色彩**或黑白的**著色色彩**。
- 在圖層面板中選擇純色填色圖層的縮圖。
- 在漸層編輯器中選擇色標的**色彩**。
- 在顯示**筆刷色彩**的面板中選擇它。可以把它新增到筆刷面板和筆刷大小面板（參見[面板和列](/zh-Hant/docs/customize/panels/)）。
- 在 Windows、Linux 和 Android 上，右鍵按一下或按住前景色板或背景色板，然後選擇**編輯色彩…**。

## 色輪和形狀

色輪的用法與色彩面板相同。選擇色輪下方的 **OKLCH**、**HSB** 或 **HLS**，可將色域切換為圓形、正方形或三角形。

## 目前和新的

**新的**顯示正在調配的色彩。選擇**目前**可將**新的**恢復為開始時的色彩。

## 十六進位

十六進位欄位以 sRGB 的 `#RRGGBB` 顯示「新的」。選擇該欄位可輸入十六進位程式碼或其他[色彩文字](#貼上色彩)。

十六進位程式碼左側的標記表示以下情況：

- 「≈」：色彩超出 sRGB，十六進位顯示最接近的 sRGB 色彩。
- 「基礎」：在 HDR 畫作中，十六進位顯示應用強度之前的色彩。
- 「sRGB」：畫作的色彩空間不是 sRGB。

## 數值行

每一行以一種格式顯示「新的」。選擇行首的格式名稱可以換成其他格式。對話方塊會記住所選的格式。

| 行 | 格式 |
| --- | --- |
| 1 | **RGB**（0–255，預設）、**RGB 0–1**、**線性 RGB**（0–1）。數值採用畫作的色彩空間，行上的標記會註明該空間。 |
| 2 | **HSB**（預設）、**HSL** |
| 3 | **OKLCH**（預設）、**OKLab** |

![數值行，第一行的格式選單已開啟。](shot:color/edit-color-formats)

## 編輯數值

- 選擇一個數值即可輸入數字。按 **Enter** 確認，按 **Escape** 取消。
- 上下拖動數值可更改它。按住 **Shift** 步長更大，按住 **Alt** 或 **Ctrl** 步長更小。
- 在數值上按 **Up Arrow** 或 **Down Arrow**，以一個步長更改數值。

超出欄位範圍的值會被設為最接近的極限值。色相在 360° 處迴圈。如果輸入的文字既不是數字也不是色彩，欄位會保持開啟並顯示錯誤。在修正該值或按 **Escape** 之前，**使用色彩**無法使用。

## 複製色彩

選擇十六進位欄位或某一行末尾的複製按鈕，可將該值複製為文字。按鈕上出現對勾，表示已複製。在對話方塊中文字框以外的位置按 **Ctrl+C**，可複製十六進位程式碼。

| 格式 | sRGB 畫作中複製的文字 | 其他色彩空間中 |
| --- | --- | --- |
| 十六進位 | `#RRGGBB` | `#RRGGBB` |
| RGB | `rgb(R G B)` | `color(display-p3 r g b)`、`color(a98-rgb r g b)` 或 `color(prophoto-rgb r g b)`，取值 0 到 1 |
| RGB 0–1 | `color(srgb r g b)` | 同 RGB |
| 線性 RGB | `color(srgb-linear r g b)` | `r g b` |
| HSB、HSL | `hsb(h s% b%)`、`hsl(h s% l%)` | `h° s% b%`、`h° s% l%` |
| OKLCH、OKLab | `oklch(L% C h)`、`oklab(L% a b)` | 相同 |

## 貼上色彩

在對話方塊中文字框以外的位置按 **Ctrl+V**，可根據色彩文字設定「新的」。十六進位欄位和數值欄位接受同樣的文字：

- 3、4、6 或 8 位元十六進位程式碼，帶 `#`、`0x` 或都不帶（忽略 Alpha 位）；
- CSS 色彩名稱，例如 `teal`；
- `rgb()`、`rgba()`、`hsl()`、`hsla()`、`hsb()`、`hsv()`、`oklch()` 和 `oklab()`；
- `color()`，其中使用 `srgb`、`display-p3`、`a98-rgb`、`prophoto-rgb` 或 `srgb-linear`；
- 三個數字。數值行按自己的格式讀取這三個數字。在其他位置，它們按 0 到 255 的 RGB 讀取；如果三個數都不大於 1 且其中一個帶小數點，則按 0 到 1 的 RGB 讀取。

色彩文字不會改變色彩的 Alpha 值。

## 從畫布取色

選擇**從畫布取色**（目前和新的旁邊的吸管），即可從畫作中取樣「新的」色彩。對話方塊隱藏，畫布一角出現一條色帶，顯示目前色彩、取樣色彩及其數值。

點按，或抬起數位筆或手指，即可取色。對話方塊重新出現，取到的色彩成為「新的」。按 **Escape** 或選擇色帶，可不做更改返回。

用手指取色時，取樣點位於指尖上方。從其他對話方塊開啟編輯色彩時，**從畫布取色**會隱藏。

## 最近使用的色彩和色票盤

底欄顯示最近使用的色彩。選擇其中一個，即可將其設為「新的」。

選擇**最近使用的色彩和所有色票盤**（最近使用的色彩後面的箭頭），會開啟一個面板，其中包含最近使用的色彩和所有[色票盤](/zh-Hant/docs/color/palettes/)。在搜尋框中輸入內容，可以尋找色票盤名稱、色彩名稱或十六進位程式碼。色票盤末尾的 **+** 會把「新的」儲存到該色票盤中。要關閉該面板，選擇**關閉色票盤**或按 **Escape**。

## HDR 強度

在 [HDR 畫作](/zh-Hant/docs/color-management/hdr/)中，**強度（EV）** 行和色輪下方的弧線以相對於 SDR 白色的檔數設定亮度。在弧線上以及拖動數值時，範圍為 −2 到 +6 EV。輸入的數值可以超出此範圍，但不能超出畫作位元深度的範圍。

## 使用色彩和取消

選擇**使用色彩**可應用「新的」色彩。選擇**取消**或按 **Escape**，可不做更改關閉對話方塊。如果格式選單或色板面板處於開啟狀態，**Escape** 會先將其關閉。
