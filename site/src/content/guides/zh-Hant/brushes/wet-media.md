可以在**工具設定**面板中設定溼筆刷和混色筆刷處理顏料的方式。每個分組只出現在其所在小節列出的筆刷上。

![濕水彩的工具設定面板下半部，包含混色、水彩、暈染和混合分組。](shot:brushes/wet-media-settings)

## 混色

**混色**分組出現在油畫筆刷、**不透明水粉**、水彩筆刷和所有混色筆上。**平均拾色**、**持續度**和**壓感補色**只出現在油畫筆刷、**不透明水粉**、**濕潤混色**和**調色混合**上。

### 載色量

設定筆刷自身攜帶的色彩量；對水彩筆刷而言，設定的是顏料濃度。值越低，從圖層上拾取的色彩越佔主導。

### 拾色量

設定筆刷把從圖層上拾取的色彩沿筆跡拖出多遠。

### 稀釋

稀釋筆刷攜帶的顏料。值越高，筆刷自身的色彩在混合中越弱。

### 平均拾色

設定筆尖各處拾取的色彩相互混合成一種的程度。為 0% 時，筆尖的每個部分保持各自的色彩。

### 持續度

設定平均後的色彩沿筆跡延續多遠。只有**平均拾色**高於 0% 時才會出現。

### 壓感補色

設定用力按壓時把所選色彩重新裝入筆刷的程度。**混色筆刷**在用力按壓時落下自己的色彩，只有輕觸時才混色。

## 混色筆

每支混色筆都會向**混色筆**分組新增設定。**擴散**位於**工具設定**面板頂部。

| 設定 | 混色筆 | 控制 |
| --- | --- | --- |
| **擴散** | 除**混色刀**和**大理石紋**外的所有混色筆 | 混色筆在筆跡每一點周圍多大範圍內收集色彩。 |
| **條紋** | **塗抹**、**柔和混色**、**紙擦筆**、**紙巾**、**自然混色**、**鬃毛混色**、**混色刀** | 筆跡沿其方向裂成條紋的程度。 |
| **銳利度** | **銳利化** | 筆跡增加的對比。 |
| **保留質感** | **保留質感混色** | 筆跡下方的細微紋理有多少保留在混色之上。 |
| **細節大小** | **保留質感混色** | 所保留紋理的大小。 |
| **混合明度** | **色相混色** | 明度隨色相和飽和度一起混合的程度。 |
| **顆粒感** | **散點混色** | 每個散開的像素取代其下方像素的完整程度。 |
| **拉伸** | **繪畫混色**、**晶體混色** | 色塊或單元沿筆跡拉伸的程度。 |
| **單元大小** | **晶體混色** | 單元的大小。 |
| **漩渦** | **大理石紋** | 顏料捲曲的強烈程度。 |
| **漩渦大小** | **大理石紋** | 漩渦的大小。 |
| **保邊** | **梳理混色** | 混色在色彩之間的邊緣處停下的難易程度。 |

## 水彩

**水彩平塗**和**濕水彩**有**水彩**分組，用於設定顏料積聚處較深的邊緣。水彩只對同一圖層上的顏料起反應。**邊緣強度**位於**工具設定**面板頂部，在各分組上方。

### 邊緣強度

設定邊緣的深淺。

### 邊緣寬度

設定邊緣的寬度，範圍為 0 到 32 px。

## 暈染

這兩個水彩筆刷的**暈染**分組設定水和顏料向筆跡周圍的紙面洇開的方式。顏料只在繪製筆跡的過程中洇開，抬起數位筆後不再擴散。

### 濕暈染

設定顏料在已打溼的紙面上洇開的速度。

### 乾暈染

設定顏料在乾燥紙面上洇開的速度。

### 暈染距離

設定顏料從每個筆印洇開的最遠距離，範圍為 0 到 96 px。

### 含水量

設定每個筆印在紙面上留下的水量。它位於**工具設定**面板頂部，在各分組上方。

## 混色方式

可以選擇混色筆刷如何混合拾取到的色彩。

執行以下任一操作：

- 從 **工具設定** 面板的 **混色** 中選擇 **Oklab 混色**、**線性光混色** 或 **經典混色**。
- 開啟工具選項欄中的 **更多工具選項**，然後在工具設定抽屜中選擇 **混色**（[大小、強度和不透明度](/zh-Hant/docs/brushes/basics/)）。
- 在命令搜索中搜索選項名稱。

| 選項 | 混合方式 |
| --- | --- |
| **Oklab 混色** | 按人眼感知的方式均勻混合拾取的色彩。 |
| **線性光混色** | 按光線混合的方式混合拾取的色彩。 |
| **經典混色** | 按畫作中儲存的色彩值混合。 |

所有內建混色筆刷的初始設定都是 **Oklab 混色**。該選項隨筆刷儲存，畫作的**色彩混合**設定不會改變它。對不混色的筆刷，這些選項無法使用。

![混色設定，顯示 Oklab 混色。](shot:brushes/color-mixing-menu)

## 鬃毛

**鬃毛**分組只出現在**鬃毛筆刷**上。該筆刷會把前景色和背景色中的另一種色彩，以條紋形式帶進厚塗顏料的筆脊中。

### 鬃毛比例

設定鬃毛痕跡相對於筆刷大小的尺寸。滑塊範圍為 25% 到 200%，輸入數值時最高可達 400%。

### 載色量

設定每道筆跡起筆時筆刷攜帶的顏料量。
