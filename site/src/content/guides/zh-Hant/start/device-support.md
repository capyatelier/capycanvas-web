{appName} 使用設備的圖形處理器繪製和顯示畫布。支持情況取決於應用或瀏覽器、操作系統和圖形硬件的組合。

## 原生應用程式

桌面應用程式支持 Windows、macOS 和 Linux。原生 iPad 應用程式要求 iPadOS 17.5 或更高版本。Android 應用程式要求 Android 12 或更高版本。

iPad 和 Android 應用程式為測試版本。滿足操作系統要求並不代表所有圖形處理器或筆都能正常工作。

## 網頁編輯器

網頁版編輯器支援以下瀏覽器：

| 系統 | 瀏覽器 |
| --- | --- |
| Windows | Chrome、Edge、Firefox 141 或更高版本 |
| macOS | Chrome、Edge、Safari 26 或更高版本，Apple 芯片上的 Firefox 147 或更高版本 |
| 使用 Wayland 的 Linux | Chrome、Edge |
| iPadOS 26 或更高版本 | Safari |
| Android 12 或更高版本 | Chrome |

原生 iPad 應用程式的 iPadOS 17.5 最低要求不適用於 Safari。網頁編輯器要求 iPadOS 26 或更高版本，因為它使用該版本提供的瀏覽器圖形功能。

## 圖形支持

如果畫布無法啓動，{appName} 會顯示說明缺少何種圖形功能的消息。請先更新操作系統、瀏覽器和圖形驅動程式。如果消息仍然出現，報告問題時請附上完整消息文本、設備型號和圖形硬件型號。
