每個工作區都有自己的工具列和標題列。**視窗 > 復原版面配置變更**（**Ctrl+Alt+Z**）可撤回上一次更改。

## 工具列選單

要開啟工具列選單，右鍵按一下工具列的背景或手柄，或用手指或數位筆按住它。右鍵按一下或按住某個工具，可開啟該工具的選單。

![工具列選單及其中的圖塊大小。](shot:toolbars/toolbar-menu)

## 顯示和隱藏工具列

執行以下任一操作：

- 選擇**視窗 > 快速存取工具列**和工具列名稱。螢幕上已有的工具列帶有勾號。
- 從工具列選單中選擇**隱藏*名稱*工具列**。
- 在[命令搜尋](/zh-Hant/docs/start/command-search/)中輸入工具列名稱。

重新顯示的工具列會在視窗頂部邊緣開啟。

刪除**工具**或**命令**工具列後，同一子選單中會出現**恢復工具工具列**或**恢復命令工具列**，用於恢復該工具列及其初始工具。

![視窗選單中的快速存取工具列子選單。](shot:toolbars/quick-access-menu)

## 新增工具列

執行以下任一操作：

- 選擇**視窗 > 快速存取工具列 > 新增工具列…**。工具列會在頂部邊緣開啟。
- 從分頁組的**面板群組**選單中選擇**新增工具列…**。工具列會成為該組中的一個分頁。

在網頁版和 Android 上，輸入**工具列名稱**，選擇要新增的工具，然後選擇**建立工具列**。在 Linux、Windows、macOS 和 iPad 應用程式中，輸入名稱，在**起始內容**下選擇**空工具列**或已儲存的工具列，然後選擇**新增至工作區**。

每個工具列的名稱不能重複。

![選取了一個工具的新增工具列對話方塊。](shot:toolbars/new-toolbar-picker)

## 新增和移除工具

- 要在末尾新增工具，從工具列選單中選擇**新增工具…**。
- 要在某個工具之前新增工具，從該工具的選單中選擇**插入工具…**。
- 要移除工具，從其選單中選擇**移除工具**。
- 要移動工具，按住它，然後在工具列內拖動，或拖到另一個工具列中。

除了命令和工具，**新增工具**列表中還有筆刷、筆刷大小、**色彩選擇器**、**筆刷大小滑桿**、**筆刷不透明度滑桿**、**工具選項**和**分隔線**。列表中每個面板也各有一項，例如**圖層面板**，選擇後會在抽屜中開啟該面板。

**工具選項**會在工具列的其餘部分顯示目前工具的設定。其選單中有**橫向：文字**、**橫向：圖示**和**顯示滑桿**。

![工具選單，包含移除工具和插入工具…兩項。](shot:toolbars/tool-menu)

## 圖塊大小

從工具列選單中選擇**小圖塊**、**中圖塊**、**大圖塊**、**附標籤的中圖塊**或**附標籤的大圖塊**。帶標籤的圖塊會顯示每個工具的名稱。新工具列使用**小圖塊**。

## 配置工具列

從工具列選單中選擇**設定*名稱*工具列…**。工具列會放大顯示，旁邊一列列出其選單中的命令。拖動放大後的工具列中的按鈕可調整順序。按 **Escape** 可關閉該列。

![「工具」工具列及其配置列。](shot:toolbars/configure)

## 浮動工具列

按兩下浮動工具列的手柄，可在網格、列和行之間切換其排列方式。

## 重新命名和複製工具列

從工具列選單中選擇**重新命名*名稱*工具列…** 或 **建立*名稱*工具列的副本…**。副本具有與原工具列相同的工具和圖塊大小。

## 刪除工具列

要刪除工具列：

1. 選擇**視窗 > 快速存取工具列 > 管理工具列…**。
2. 選擇該工具列。
3. 選擇**刪除工具列…**。
4. 選擇**刪除工具列**以確認。

**視窗 > 復原版面配置變更**可恢復已刪除的工具列。

![選取了一個工具列的管理工具列對話方塊。](shot:toolbars/manage)

## 工具列庫

在 Linux、Windows、macOS 和 iPad 應用程式中，可以儲存工具列的副本，並將其新增到其他工作區。從工具列選單中選擇**儲存至工具列庫…**。要新增已儲存的工具列，開啟**管理工具列…**，轉到**已儲存的工具列**，選擇該工具列，然後選擇**新增至工作區**。

## 自訂標題列

執行以下任一操作：

- 選擇**視窗 > 自訂標題列…**。
- 右鍵按一下或按住標題列，然後選擇**自訂標題列…**。

標題列下方會開啟一個欄，其中列出可新增的項目。

- 要新增項目，將其拖入標題列。在該欄中選擇項目不會有任何作用。
- 要移動項目，將其拖到新位置。
- 要移除項目，將其拖出標題列，或選擇它後按 **Delete**。

要新增工具，將**新增工具…** 拖入標題列，然後選擇要放在該位置的工具。該欄中還有用於設定標題列大小的**小**、**中**和**大**，以及用於顯示畫布下方縮放和旋轉欄的**顯示底列**。

選擇**完成**保留更改，或選擇**取消**捨棄變更。在此之前，單鍵快捷鍵和命令搜尋無法使用。

![正在自訂的標題列。](shot:title-bar/editing)

## 標題列項目

| 項目 | 顯示內容 |
| --- | --- |
| **Capy（專注模式）** | [專注模式](/zh-Hant/docs/customize/zen/)按鈕 |
| **主選單** | 包含所有選單的單個按鈕（macOS 上沒有） |
| **選單標籤** | 以一排名稱顯示的選單（macOS 上沒有） |
| **設定** | 開啟偏好設定的按鈕 |
| **全螢幕** | 全屏按鈕（僅限網頁版） |
| **工作區切換器** | 每個工作區一個按鈕 |
| **文件標題** | 畫作名稱，或每幅開啟的畫作各一個分頁 |
| **時鐘**、**電池** | 時間和電池電量 |
| **空白** | 一段空白間隔 |
| 工具 | **新增工具**列表中除滑塊和**工具選項**以外的任意項目 |

在網頁版以及 Linux、Windows、macOS 和 iPad 應用程式中，**時鐘**和**電池**只在全屏時顯示。

除**空白**和工具以外，每個項目只能放置一次。放不下的項目會移入 **…** 選單。
