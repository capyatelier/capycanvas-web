Vous pouvez masquer la barre de titre, les panneaux ancrés et les barres d’outils
ancrées en mode Zen. La toile occupe alors toute la fenêtre.

![La toile en mode Zen, avec un panneau flottant et le bouton Capy dans le coin.](shot:zen/zen-canvas)

## Activer et quitter le mode Zen

Effectuez l’une des opérations suivantes :

- Choisissez **Affichage > Mode Zen**.
- Appuyez sur **Tabulation**.
- Sélectionnez le bouton Capy à l’extrémité gauche de la barre de titre. En mode Zen, le bouton se trouve dans le coin supérieur gauche de la fenêtre.
- Tapez « Mode Zen » dans la [recherche de commandes](/fr/docs/start/command-search/).
- Avec les raccourcis **Style Procreate**, touchez la toile avec quatre doigts.

Répétez la même action pour quitter le mode Zen.

Le mode Zen est enregistré avec chaque espace de travail et reste actif après un
redémarrage. **Personnaliser la barre de titre…** désactive le mode Zen.

## Ce qui reste à l’écran

Le mode Zen masque aussi les colonnes réduites et le pied de page. Restent
affichés :

- les panneaux flottants
- les [bulles d’outils](/fr/docs/customize/bubbles/), avec leurs halos, sélecteurs et menus
- la barre d’actions de la toile à côté d’une sélection ou d’une transformation
- le bouton Capy, sauf si **Afficher Capy en mode Zen** est désactivé
- les avis

Les touches et la recherche de commandes (**Ctrl+K**) fonctionnent normalement.

## Garder des barres d’outils en mode Zen

Dans l’application Linux, choisissez **Afficher en mode Zen** dans le menu d’une
barre d’outils pour garder cette barre d’outils à l’écran en mode Zen.

Sur un écran tactile, dans l’application Linux, balayez vers l’intérieur avec un
doigt à moins de 24 px du bord de la fenêtre pour afficher les barres d’outils et
les panneaux ancrés à ce bord. Ils se masquent de nouveau quand vous touchez en
dehors. Un stylet ou une souris ne peut pas les afficher.

## Ancrer en mode Zen

Quand les panneaux ancrés sont masqués, un panneau flottant que vous faites glisser ne peut rejoindre que d’autres panneaux flottants.

## Menu du bouton Capy

Cliquez avec le bouton droit sur le bouton Capy, ou appuyez longuement dessus
avec un doigt, pour ouvrir son menu. **Changer l’icône…** ouvre les Préférences
à **Icône du bouton**. Dans la barre de titre, le menu contient aussi
**Personnaliser la barre de titre…**.

Un appui long du doigt sur le bouton Capy n’active ni ne désactive le mode Zen.

![Le menu du bouton Capy.](shot:zen/capy-menu)

## Préférences du mode Zen

Choisissez **Édition > Préférences**, sélectionnez **Apparence**, puis trouvez le
groupe **Mode Zen**. Ces réglages s’appliquent à tous les espaces de travail.

### Afficher Capy en mode Zen

Garde le bouton Capy dans le coin supérieur gauche en mode Zen. Activé par
défaut. Quand ce réglage est désactivé, appuyez sur **Tabulation** ou utilisez la
recherche de commandes pour quitter le mode Zen.

### Icône du bouton

Définit l’image du bouton Capy : **Regard vers le haut** (par défaut),
**Regard de face**, **Baignade** ou **Sommeil**. Un bouton **Mode Zen** dans une barre
d’outils utilise la même image.
