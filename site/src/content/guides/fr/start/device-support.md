{appName} utilise le processeur graphique de l’appareil pour dessiner et afficher la toile. La compatibilité dépend à la fois de l’application ou du navigateur, du système d’exploitation et du matériel graphique.

## Applications natives

L’application de bureau prend en charge Windows, macOS et Linux. L’application iPad native exige iPadOS 17.5 ou ultérieur. L’application Android exige Android 12 ou ultérieur.

Les applications iPad et Android sont des versions bêta. Respecter l’exigence de système d’exploitation ne confirme pas à lui seul que tous les processeurs graphiques ou stylets fonctionnent.

## Éditeur web

L’éditeur web fonctionne dans ces navigateurs :

| Système | Navigateurs |
| --- | --- |
| Windows | Chrome, Edge, Firefox 141 ou ultérieur |
| macOS | Chrome, Edge, Safari 26 ou ultérieur, Firefox 147 ou ultérieur sur Apple silicon |
| Linux avec Wayland | Chrome, Edge |
| iPadOS 26 ou ultérieur | Safari |
| Android 12 ou ultérieur | Chrome |

Le minimum iPadOS 17.5 de l’application iPad native ne s’applique pas à Safari. L’éditeur web exige iPadOS 26 ou ultérieur, car il utilise des fonctions graphiques du navigateur fournies par cette version.

## Prise en charge graphique

Si la toile ne peut pas démarrer, {appName} affiche un message décrivant la fonction graphique manquante. Mettez d’abord à jour le système, le navigateur et le pilote graphique. Si le message persiste, joignez son texte exact ainsi que le modèle de l’appareil et du matériel graphique à votre signalement.
