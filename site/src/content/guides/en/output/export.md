## Choose where the image is going

Choose **File → Export…** to open the **Export image** dialog. The easiest place to start is **Destination**, which fills in sensible settings for you. **Web / Share** makes a standard image that looks right in any browser or app. **Wide-color image** keeps the more vivid colors that modern screens can show, and **Further editing** keeps as much detail as possible for opening in another editor.

Only the visible layers are exported, so hide any sketch or reference layers you don't want in the final image first.

## Adjust the details

If you want more control, change the settings below the destination. **Format** chooses between PNG, JPEG and TIFF. PNG is a good choice for artwork with sharp edges or transparent areas, while JPEG makes smaller files for photos. **Output profile** sets the color space of the file, and **Bit depth** sets how finely colors are stored.

**Transparency** decides what happens to empty areas of the drawing. You can keep them transparent in formats that support it, or fill them with white or black. **Pixel size** lets you make a smaller copy, for example for a website. When you like a combination of settings, you can save it as a preset of your own.

## Save the file

Select **Preview Output** if you'd like to see the result before saving, then select **Choose File…** to pick a name and a place for the image. Open the exported file once to check that it looks the way you expect.

HDR drawings have more choices under **Dynamic range**, including HDR JPEG and AVIF files that look bright on HDR screens and still look right on ordinary ones. [Color spaces, HDR and proofing](/docs/color/management/) explains when to use them.
