## Troque ou crie um espaço de trabalho

Use o alternador na barra de título para alternar entre **Sketch**, **Paint** e **Photo**. Cada espaço de trabalho volta exatamente como você o deixou, com seu próprio layout de painel e configurações de pincel. Seus desenhos abertos permanecem abertos quando você alterna.

Para criar um novo espaço de trabalho, escolha **Window → Workspaces → New Workspace…**. Ele começa como uma cópia do espaço de trabalho atual, que você pode reorganizar e dar um nome. **Window → Workspaces → Manage Workspaces…** lista todos os espaços de trabalho. Selecione um para visualizá-lo e escolha **Switch to Workspace** para usá-lo ou **Cancel** para ficar onde está.

## Escolha o que o switcher mostra

No **Manage Workspaces**, abra o menu de um espaço de trabalho e ative **Show in top bar** para adicioná-lo ao switcher ou desative-o para ocultá-lo. Arraste os espaços de trabalho para cima ou para baixo na lista para alterar sua ordem no alternador. Com uma caneta ou um dedo, arraste uma área de trabalho pela alça.

Essas escolhas são salvas imediatamente. Sketch, Paint e Photo podem ser reorganizados como qualquer outro espaço de trabalho, mas não podem ser renomeados ou excluídos.

## Restaure a parte certa

**Restore Starting Layout…** coloca os painéis da área de trabalho atual de volta onde começaram, enquanto mantém as configurações do pincel. **Reset All Brushes…** faz o contrário: redefine os pincéis e deixa o layout como está. [Salvar e redefinir as configurações do pincel](/pt-BR/docs/advanced/custom-brushes/) explica a diferença com mais detalhes.

Os espaços de trabalho são armazenados no aplicativo, separadamente dos seus desenhos. Para manter um desenho, [salve-o](/pt-BR/docs/tools/files/) como um arquivo `.capy`.
