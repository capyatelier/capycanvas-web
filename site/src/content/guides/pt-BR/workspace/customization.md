## Organize os painéis

Arraste um painel pela guia ou alça para movê-lo. À medida que você arrasta, os marcadores mostram os locais onde ele pode encaixar; solte em qualquer outro lugar e o painel flutuará livremente. Solte um painel nas guias de outro painel para agrupá-los e arraste a borda entre os painéis para aumentar um deles. Uma coluna também pode ser recolhida em uma faixa de ícones, de forma que cada painel seja aberto como uma gaveta somente quando você precisar dele.

Os painéis se movem assim que você começa a arrastá-los. Os botões dentro de uma barra de ferramentas são diferentes: pressione e segure um botão por um momento antes de arrastá-lo, para que um toque rápido nunca seja confundido com um movimento.

## Escolha suas barras de ferramentas

Clique com o botão direito em uma barra de ferramentas ou pressione e segure-a para escolher quais ferramentas e comandos ela mostrará. As barras de ferramentas podem conter mais do que botões: você pode adicionar controles deslizantes de tamanho e opacidade do pincel ou uma barra **Tool Options** que sempre mostra as configurações da ferramenta atual. Arraste uma barra de ferramentas pela alça para movê-la e solte-a próximo ao início, meio ou fim de qualquer borda da tela para anexá-la ali. **Window → Quick Access Toolbars** cria e gerencia barras de ferramentas extras.

**Window → Customize Title Bar…** permite organizar os botões na parte superior da janela, incluindo o alternador de área de trabalho. Arraste os itens para o lugar e finalize para manter o novo arranjo.

## Alterar a aparência ou desfazer uma alteração

**Preferences → Appearance** contém configurações para a aparência da interface. Você pode escolher um tema claro ou escuro, escolher uma cor de destaque e definir a transparência dos painéis, para que sua arte possa aparecer suavemente através deles.

Use **Window → Undo Layout Change** e **Redo Layout Change** para retroceder nas alterações no layout; desfazer comum é apenas para o seu desenho. Para voltar ao modo como um espaço de trabalho foi iniciado, escolha **Restore Starting Layout…**. Se desejar manter mais de um arranjo, salve cada um como seu próprio [workspace](/pt-BR/docs/workspace/management/).
