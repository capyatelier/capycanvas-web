## Abra um desenho ou uma foto

Escolha **File → Open…** para abrir um arquivo `.capy`. Você pode abrir fotos e outras imagens da mesma maneira, incluindo arquivos JPEG, PNG, TIFF, WebP, HEIC, AVIF e OpenEXR. Uma foto é aberta como um novo desenho em seu tamanho original e suas cores são mantidas exatamente como foram capturadas.

Para trazer uma imagem para o desenho que você já abriu, escolha **File → Import Image as Layer…** ou arraste o arquivo de imagem para a tela. Você também pode copiar uma imagem em outro aplicativo e colá-la com **Ctrl+V**, o que é útil para imagens de referência. [Editar uma foto](/pt-BR/docs/filters/image-editing/) mostra os dois lados com mais detalhes.

## Trabalhe com vários desenhos

Em Paint e Photo, cada desenho que você abre ou cria recebe sua própria guia na parte superior da janela. Clique em uma guia para alternar para esse desenho ou arraste as guias para alterar sua ordem. Um ponto próximo ao nome indica que o desenho possui alterações que ainda não foram salvas. **File → Drawings…** lista todos os desenhos abertos, em qualquer área de trabalho.

Feche um desenho com o botão em sua aba ou com **File → Close**. Se houver alterações não salvas, Capy Canvas perguntará se você deseja salvá-las primeiro.

## Salve e recupere seu trabalho

Escolha **File → Save As…** na primeira vez que salvar um desenho e depois **File → Save** para atualizar o mesmo arquivo. Quando você salva uma foto aberta, Capy Canvas pergunta onde salvar um novo arquivo `.capy` e deixa a foto original intacta.

Se o navegador fechar antes de você salvar, Capy Canvas oferece a recuperação do desenho na próxima vez que você abri-lo. Esta é apenas uma rede de segurança, portanto salve seus arquivos `.capy` regularmente e mantenha cópias dos arquivos importantes.

Para criar uma imagem para compartilhamento ou impressão, consulte [Exportar uma imagem](/pt-BR/docs/output/export/).
