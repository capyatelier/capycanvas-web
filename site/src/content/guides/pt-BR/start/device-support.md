{appName} usa o processador gráfico do dispositivo para desenhar e exibir a tela. A compatibilidade depende do aplicativo ou navegador, do sistema operacional e do hardware gráfico em conjunto.

## Aplicativos nativos

O aplicativo para desktop é compatível com Windows, macOS e Linux. O aplicativo nativo para iPad exige iPadOS 17.5 ou posterior. O aplicativo para Android exige Android 12 ou posterior.

Os aplicativos para iPad e Android são versões beta. Atender ao requisito do sistema operacional não confirma, por si só, que todos os processadores gráficos ou canetas funcionem.

## Editor web

O editor web funciona nestes navegadores:

| Sistema | Navegadores |
| --- | --- |
| Windows | Chrome, Edge, Firefox 141 ou posterior |
| macOS | Chrome, Edge, Safari 26 ou posterior, Firefox 147 ou posterior em Apple silicon |
| Linux com Wayland | Chrome, Edge |
| iPadOS 26 ou posterior | Safari |
| Android 12 ou posterior | Chrome |

O mínimo de iPadOS 17.5 do aplicativo nativo para iPad não se aplica ao Safari. O editor web exige iPadOS 26 ou posterior porque usa recursos gráficos do navegador fornecidos por essa versão.

## Compatibilidade gráfica

Se a tela não puder iniciar, {appName} mostra uma mensagem que descreve o recurso gráfico ausente. Atualize primeiro o sistema operacional, o navegador e o driver gráfico. Se a mensagem persistir, inclua seu texto exato e o modelo do dispositivo e do hardware gráfico ao relatar o problema.
