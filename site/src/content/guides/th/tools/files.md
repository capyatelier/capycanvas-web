## เปิดภาพวาดหรือภาพถ่าย

เลือก **File → Open…** เพื่อเปิดไฟล์ `.capy` คุณสามารถเปิดรูปภาพและรูปภาพอื่นๆ ได้ในลักษณะเดียวกัน รวมถึงไฟล์ JPEG, PNG, TIFF, WebP, HEIC, AVIF และ OpenEXR รูปภาพจะเปิดขึ้นเป็นภาพวาดใหม่ในขนาดดั้งเดิม และสีจะถูกเก็บไว้เช่นเดียวกับที่ถ่าย

หากต้องการนำรูปภาพมาไว้ในภาพวาดที่คุณเปิดไว้ ให้เลือก **File → Import Image as Layer…** แทน หรือลากไฟล์รูปภาพลงบนผืนผ้าใบ คุณยังสามารถคัดลอกรูปภาพในแอปอื่นแล้ววางด้วย **Ctrl+V** ซึ่งสะดวกสำหรับรูปภาพอ้างอิง [แก้ไขรูปภาพ](/th/docs/filters/image-editing/) แสดงทั้งสองวิธีโดยละเอียดยิ่งขึ้น

## ทำงานกับภาพวาดหลายแบบ

ใน Paint และ Photo ทุกภาพวาดที่คุณเปิดหรือสร้างจะมีแท็บของตัวเองที่ด้านบนของหน้าต่าง คลิกแท็บเพื่อสลับเป็นรูปวาดนั้น หรือลากแท็บเพื่อเปลี่ยนลำดับ จุดถัดจากชื่อจะบอกคุณว่าภาพวาดมีการเปลี่ยนแปลงที่ยังไม่ได้บันทึก **File → Drawings…** แสดงรายการภาพวาดที่เปิดอยู่ทุกรายการในพื้นที่ทำงานใดๆ

ปิดภาพวาดด้วยปุ่มบนแท็บหรือด้วย **File → Close** หากมีการเปลี่ยนแปลงที่ยังไม่ได้บันทึก Capy Canvas จะถามว่าคุณต้องการบันทึกก่อนหรือไม่

## บันทึกและกู้คืนงานของคุณ

เลือก **File → Save As…** ในครั้งแรกที่คุณบันทึกภาพวาด และ **File → Save** หลังจากนั้นเพื่ออัปเดตไฟล์เดียวกัน เมื่อคุณบันทึกรูปภาพที่คุณเปิด Capy Canvas จะถามว่าจะบันทึกไฟล์ `.capy` ใหม่ได้ที่ไหน และปล่อยให้รูปภาพต้นฉบับไม่ถูกแตะต้อง

หากเบราว์เซอร์ปิดก่อนที่คุณจะบันทึก Capy Canvas จะเสนอให้กู้คืนรูปวาดของคุณในครั้งถัดไปที่คุณเปิดขึ้นมา นี่เป็นเพียงเครือข่ายความปลอดภัยเท่านั้น ดังนั้นให้บันทึกไฟล์ `.capy` ของคุณเป็นประจำและเก็บสำเนาของไฟล์ที่สำคัญไว้

หากต้องการสร้างรูปภาพเพื่อแชร์หรือพิมพ์ โปรดดู [ส่งออกรูปภาพ](/th/docs/output/export/)
