## เปิดรูปภาพ

เลือก **Photo** ในตัวสลับพื้นที่ทำงาน จากนั้นเลือก **File → Open…** แล้วเลือกรูปภาพของคุณ Capy Canvas เปิดไฟล์ JPEG, PNG, TIFF, WebP, HEIC, AVIF และ OpenEXR ดังนั้นรูปภาพจากกล้องและโทรศัพท์ส่วนใหญ่จึงสามารถเปิดได้โดยตรง รูปภาพจะเปิดในแท็บขนาดเต็มโดยมีสีดั้งเดิม

หากต้องการเพิ่มรูปภาพลงในภาพวาดที่คุณเปิดไว้แล้ว ให้เลือก **File → Import Image as Layer…** หรือลากไฟล์ลงบนผืนผ้าใบ รูปภาพจะแสดงพร้อมที่จับเพื่อให้คุณสามารถย้ายและปรับขนาดได้ เลือก **Apply** เมื่อติดตั้งแล้ว หรือเลือก **Original Size (100%)** เพื่อใช้งานตามขนาดจริง

## ทำการปรับเปลี่ยน

เปิด **Filters** และเลือกการปรับเปลี่ยน เช่น **Curves**, **Vibrance** หรือ **Hue / Saturation** มันถูกเพิ่มเป็นเลเยอร์ใหม่เหนือรูปภาพ และการตั้งค่าจะปรากฏใน **Properties** ค่อยๆ เปลี่ยนและดูภาพตามที่คุณไป ซ่อนและแสดงเลเยอร์การปรับเพื่อเปรียบเทียบผลลัพธ์กับต้นฉบับ

เนื่องจากการปรับเปลี่ยนมีผลในเลเยอร์ของตัวเอง คุณจึงสามารถกลับมาแก้ไขได้ตลอดเวลา หรือลบออกอย่างไร้ร่องรอย หากต้องการปรับเพียงบางส่วนของภาพ ให้เลือกพื้นที่นั้นก่อน เช่น ท้องฟ้าด้วย [เลือกตามความสว่าง](/th/docs/selections/tonal-range/) [ตัวกรองและการปรับเปลี่ยน](/th/docs/filters/overview/) อธิบายวิธีอื่นๆ ในการจำกัดการปรับเปลี่ยน

## บันทึกและส่งออก

เมื่อคุณบันทึกรูปภาพที่คุณแก้ไขแล้ว Capy Canvas จะบันทึกไฟล์ `.capy` พร้อมด้วยเลเยอร์การปรับแต่งทั้งหมดของคุณ และรูปภาพต้นฉบับของคุณจะไม่ถูกเขียนทับ หากต้องการแชร์ผลลัพธ์ ให้เลือก **File → Export…** และบันทึก JPEG หรือ PNG [ส่งออกรูปภาพ](/th/docs/output/export/) อธิบายการตั้งค่าการส่งออก
