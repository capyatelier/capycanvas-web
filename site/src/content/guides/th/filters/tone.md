ฟิลเตอร์โทนอยู่ใน **ฟิลเตอร์ > โทน** และในหมวด **โทน** ของแผง **ฟิลเตอร์** คุณเปลี่ยนการตั้งค่าของฟิลเตอร์เหล่านี้ได้ในแผง **คุณสมบัติ**

![แผงฟิลเตอร์ที่แสดงหมวดโทนพร้อมภาพตัวอย่างของแต่ละฟิลเตอร์](shot:filters/tone-list)

## เงา/ไฮไลต์

ยกบริเวณมืดขึ้นด้วย **เงา** และกดบริเวณสว่างลงด้วย **ไฮไลต์** โดยพิจารณาจากความสว่างของบริเวณรอบข้าง ที่ 100% แต่ละค่าจะเปลี่ยนการรับแสงได้สูงสุด 2 สต็อป

| การตั้งค่า | ช่วงหรือตัวเลือก | ค่าเริ่มต้น |
| --- | --- | --- |
| **เงา** | 0–100% | 0% |
| **ไฮไลต์** | 0–100% | 0% |

## เส้นโค้ง

เปลี่ยนโทนด้วยเส้นโค้งหนึ่งเส้นสำหรับทุกช่องสีในหน้า **RGB** และเส้นโค้งของแต่ละช่องสีในหน้า **แดง** **เขียว** และ **น้ำเงิน** เส้นโค้งของช่องสีจะมีผลก่อนเส้นโค้ง **RGB**

| การตั้งค่า | ช่วงหรือตัวเลือก | ค่าเริ่มต้น |
| --- | --- | --- |
| หน้า **RGB** **แดง** **เขียว** **น้ำเงิน** | หน้าละหนึ่งเส้นโค้ง | เส้นตรง |
| **เลือกจุดตัวอย่าง** **ปรับแต่งบนภาพ** | ตั้งเส้นโค้งจากภาพ (ดู[การเพิ่มและแก้ไขฟิลเตอร์](/th/docs/filters/adding/)) | |
| **ปริภูมิเส้นโค้ง** | **RGB เข้ารหัส** **HDR ลอการิทึม** แสดงเฉพาะใน[ภาพวาด HDR](/th/docs/color-management/hdr/) หรือขณะตั้งเป็น **HDR ลอการิทึม** | **RGB เข้ารหัส** หรือ **HDR ลอการิทึม** ในภาพวาด HDR |
| **ช่วง HDR** | 0–15 EV หรือพิมพ์ได้สูงสุด 127 EV แสดงเฉพาะเมื่อใช้ **HDR ลอการิทึม** คือจำนวนสต็อปเหนือสีขาว SDR ที่เส้นโค้งไปถึง | 4 EV |

| บนกราฟ | วิธีทำ |
| --- | --- |
| เพิ่มจุด | กดที่ตำแหน่งว่าง เส้นโค้งหนึ่งเส้นมีได้สูงสุด 32 จุด |
| ย้ายจุด | ลากจุด หรือเลือกจุดแล้วกดแป้นลูกศร กด **Shift** ร่วมด้วยเพื่อย้ายได้ไกลขึ้น จุดปลายทั้งสองย้ายได้เฉพาะขึ้นและลง |
| ตั้งค่าที่แน่นอน | เลือกจุดแล้วพิมพ์ใน **ขาเข้า** และ **ผลลัพธ์** ใต้กราฟ |
| ลบจุด | ดับเบิลคลิกที่จุด ลากจุดออกนอกกราฟ หรือเลือกจุดแล้วกด **Delete** หรือ **Backspace** |
| เริ่มใหม่ | เลือก **รีเซ็ตเส้นโค้ง** |

## ระดับ

ตั้งจุดดำ จุดขาว และโทนกลางของค่าขาเข้า แล้วจับคู่กับช่วง **ผลลัพธ์** หน้า **แดง** **เขียว** และ **น้ำเงิน** จะมีผลก่อนหน้า **RGB**

![แผงคุณสมบัติของระดับที่มีฮิสโตแกรม อัตโนมัติ เลือกจุดตัวอย่าง และการตั้งค่าขาเข้า ผลลัพธ์ และการตัดค่า](shot:filters/levels-properties)

| การตั้งค่า | ช่วงหรือตัวเลือก | ค่าเริ่มต้น |
| --- | --- | --- |
| **อัตโนมัติ** **เลือกจุดตัวอย่าง** | ตั้งค่าขาเข้าจากภาพ (ดู[การเพิ่มและแก้ไขฟิลเตอร์](/th/docs/filters/adding/)) | |
| **เงา** **ส่วนสว่าง** (ใต้ฮิสโตแกรม) | ทำเครื่องหมายบริเวณที่ล้นบนผืนผ้าใบ | |
| **ดำ** (**ขาเข้า**) | 0–1 พิมพ์ค่าใดก็ได้ ต้องต่ำกว่า **ขาว** ของขาเข้า | 0 |
| **ขาว** (**ขาเข้า**) | 0–1 พิมพ์ค่าใดก็ได้ | 1 |
| **โทนกลาง** | 0.1–10 ค่าที่มากกว่า 1 จะทำให้สว่างขึ้น | 1 |
| **ดำ** (**ผลลัพธ์**) | 0–1 พิมพ์ค่าใดก็ได้ | 0 |
| **ขาว** (**ผลลัพธ์**) | 0–1 พิมพ์ค่าใดก็ได้ | 1 |
| **จำกัดค่าขาเข้า** | ตัดโทนที่อยู่นอก **ดำ** และ **ขาว** ของขาเข้าในทุกหน้า | ปิด |
| **จำกัดค่าขาออก** | ตัดผลลัพธ์ให้อยู่ในช่วงขาออกในทุกหน้า | ปิด |

## ความสว่าง / คอนทราสต์

**คอนทราสต์** ขยายหรือบีบโทนรอบสีเทากลาง จากนั้น **ความสว่าง** จะทำให้ทุกโทนสว่างขึ้นหรือมืดลงเท่ากัน

| การตั้งค่า | ช่วงหรือตัวเลือก | ค่าเริ่มต้น |
| --- | --- | --- |
| **ความสว่าง** | −100 ถึง 100 | 0 |
| **คอนทราสต์** | −100 ถึง 100 ค่า 50 เพิ่มคอนทราสต์เป็นสองเท่า และ −50 ลดลงครึ่งหนึ่ง | 0 |

## เกณฑ์

เปลี่ยนพิกเซลที่มืดกว่า **เกณฑ์** เป็นสีดำ และพิกเซลที่เหลือเป็นสีขาว

| การตั้งค่า | ช่วงหรือตัวเลือก | ค่าเริ่มต้น |
| --- | --- | --- |
| **เกณฑ์** | 0–1 พิมพ์ค่าใดก็ได้ | 0.5 |

## การรับแสง

เปลี่ยนการรับแสงเป็นสต็อป **ระยะเยื้อง** ยกหรือกดจุดดำ

| การตั้งค่า | ช่วงหรือตัวเลือก | ค่าเริ่มต้น |
| --- | --- | --- |
| **การรับแสง** | −10 ถึง 10 EV หรือพิมพ์ได้ถึง ±126 EV | 0 EV |
| **ระยะเยื้อง** | −0.5 ถึง 0.5 | 0 |
| **แกมมา** | 0.1–10 ค่าที่มากกว่า 1 จะทำให้โทนกลางสว่างขึ้น | 1 |

## ขอบมืด

ทำให้ภาพนอกวงรีที่มีสัดส่วนเท่าผืนผ้าใบมืดลง หรือสว่างขึ้นเมื่อ **ความแรง** เป็นค่าลบ ที่ ±100% ขอบภาพจะเปลี่ยนได้สูงสุด 2 สต็อป

| การตั้งค่า | ช่วงหรือตัวเลือก | ค่าเริ่มต้น |
| --- | --- | --- |
| **ความแรง** | −100% ถึง 100% | 40% |
| **รัศมี** | 10–150% ของครึ่งหนึ่งของขนาดผืนผ้าใบ | 95% |
| **ความนุ่ม** | 0–100% ของรัศมีที่ใช้ไล่จาง | 55% |
| **ศูนย์กลาง X** **ศูนย์กลาง Y** (ใต้ **ตำแหน่ง**) | 0–100% ของความกว้างและความสูงของผืนผ้าใบ | 50% |
