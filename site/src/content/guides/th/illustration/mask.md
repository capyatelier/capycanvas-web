## 1. เลือกรูปร่าง

ซ่อน **Sketch** และ **Color rough** เลือก **Lasso selection** และติดตามรอบๆ Ribbon อย่างระมัดระวัง ดังตัวอย่าง

หากภาพลายเส้นของคุณปิดรอบรูปร่าง **Auto select** สามารถทำได้ในคลิกเดียว ทำเครื่องหมาย **Line art** เป็นเลเยอร์อ้างอิงโดยเลือก **Layer Settings → Use as reference** ในเมนู จากนั้นเลือก **Auto select** เลือก **Sample reference layers** ในแผงเครื่องมือ และคลิกภายในรูปร่าง [เครื่องมือการเลือก](/th/docs/tools/selections/) อธิบายการตั้งค่าที่ควบคุมการกระจายการเลือก

## 2. สร้างเลเยอร์สีที่มาสก์

เพิ่มเลเยอร์ใหม่ชื่อ **Ribbon** ใต้ภาพลายเส้น ขณะที่ส่วนที่เลือกยังคงทำงานอยู่ ให้เปิดเมนูของ Ribbon แล้วเลือก **Mask → Mask: reveal selection** ตอนนี้เลเยอร์มีมาสก์ที่แสดงเฉพาะรูปร่างของริบบิ้นเท่านั้น

คลิกภาพขนาดย่อของ Ribbon และเลือกสีของริบบิ้น เลือก **Select → Select all pixels** จากนั้นเลือก **Edit → Fill selection** เพื่อเติมสีให้เต็มเลเยอร์ และปิดท้ายด้วย **Select → Deselect pixels** มีเพียงริบบิ้นเท่านั้นที่แสดง แต่สียังคงอยู่ใต้มาส์ก พร้อมใช้เมื่อคุณต้องการขยายรูปร่างให้กว้างขึ้น

## 3. ปรับขอบ

คลิกรูปขนาดย่อของมาสก์ของ Ribbon เพื่อแก้ไขมาสก์ ตอนนี้แปรงใดๆ ก็เผยให้เห็นสีที่คุณวาดได้มากขึ้น และ **Eraser** ก็ซ่อนมันไว้อีกครั้ง คลิกรูปขนาดย่อของสีอีกครั้งเมื่อคุณต้องการเปลี่ยนสี

ทำ **Disc** และ **Block** ในลักษณะเดียวกัน เก็บ Disc ไว้ด้านล่าง Ribbon และ Block ด้านล่าง Disc โดยมีภาพลายเส้นอยู่เหนือทั้งสาม บันทึกภาพวาดของคุณ จากนั้นไปที่ [Rendering](/th/docs/illustration/render/).
