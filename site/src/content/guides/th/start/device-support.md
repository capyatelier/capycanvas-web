{appName} ใช้ตัวประมวลผลกราฟิกของอุปกรณ์ในการวาดและแสดงผืนผ้าใบ การรองรับขึ้นอยู่กับแอปหรือเบราว์เซอร์ ระบบปฏิบัติการ และฮาร์ดแวร์กราฟิกร่วมกัน

## แอปเนทีฟ

แอปเดสก์ท็อปรองรับ Windows, macOS และ Linux แอป iPad เนทีฟต้องใช้ iPadOS 17.5 ขึ้นไป แอป Android ต้องใช้ Android 12 ขึ้นไป

แอป iPad และ Android เป็นรุ่นเบตา การผ่านข้อกำหนดระบบปฏิบัติการเพียงอย่างเดียวไม่ยืนยันว่าตัวประมวลผลกราฟิกหรือปากกาทุกแบบจะทำงานได้

## เว็บเอดิเตอร์

เว็บเอดิเตอร์ทำงานในเบราว์เซอร์เหล่านี้:

| ระบบ | เบราว์เซอร์ |
| --- | --- |
| Windows | Chrome, Edge, Firefox 141 ขึ้นไป |
| macOS | Chrome, Edge, Safari 26 ขึ้นไป, Firefox 147 ขึ้นไปบน Apple silicon |
| Linux ที่ใช้ Wayland | Chrome, Edge |
| iPadOS 26 ขึ้นไป | Safari |
| Android 12 ขึ้นไป | Chrome |

ข้อกำหนดขั้นต่ำ iPadOS 17.5 ของแอป iPad เนทีฟไม่ใช้กับ Safari เว็บเอดิเตอร์ต้องใช้ iPadOS 26 ขึ้นไปเพราะใช้ความสามารถกราฟิกของเบราว์เซอร์ที่มีในรุ่นนั้น

## การรองรับกราฟิก

หากผืนผ้าใบเริ่มทำงานไม่ได้ {appName} แสดงข้อความอธิบายความสามารถกราฟิกที่ขาดไป อัปเดตระบบปฏิบัติการ เบราว์เซอร์ และไดรเวอร์กราฟิกก่อน หากข้อความยังอยู่ ให้แนบข้อความตรงตามที่แสดงและรุ่นอุปกรณ์กับกราฟิกเมื่อรายงานปัญหา
