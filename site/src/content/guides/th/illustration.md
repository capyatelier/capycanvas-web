คุณจะวาดภาพศึกษาแนวแอบสแตรกต์ในสี่ขั้นตอนในพื้นที่ทำงาน[ระบายสี](/th/docs/start/workspaces/) แต่ละขั้นตอนจะเพิ่มเลเยอร์ และไม่มีการรวมเลเยอร์ใดเลย

![พื้นที่ทำงานระบายสีที่มีภาพศึกษาแนวแอบสแตรกต์ที่เสร็จแล้วบนผืนผ้าใบและเลเยอร์ของภาพในแผงเลเยอร์](shot:illustration/overview)

## ภาพศึกษา

ภาพศึกษานี้เป็นภาพวาดขนาด 1200 × 1200 ของรูปทรงสามชิ้นที่ซ้อนกัน ได้แก่ ริบบิ้นโค้ง แผ่นกลม และบล็อกที่เอียง เส้นขีดเขียนหลวม ๆ และเส้นแรเงาอยู่บนและรอบรูปทรงเหล่านั้น

## ขั้นตอน

1. [การร่างภาพ](/th/docs/illustration/draft/): ร่างสีและภาพร่างด้วยดินสอ
2. [ลายเส้น](/th/docs/illustration/ink/): เส้นหมึกเหนือภาพร่างที่ทำให้จางลง
3. [สีพื้น](/th/docs/illustration/mask/): เลเยอร์สีที่มีมาสก์สำหรับรูปทรงแต่ละชิ้น
4. [การลงแสงเงา](/th/docs/illustration/render/): การแรเงาบนเลเยอร์ที่ตัดตาม และการส่งออกเป็น PNG

## เลเยอร์เมื่อเสร็จแล้ว

ภาพวาดที่เสร็จแล้วมีเลเยอร์ต่อไปนี้ จากบนลงล่าง:

| เลเยอร์ | เนื้อหา |
| --- | --- |
| *Line art* | เส้นหมึก |
| *Ribbon texture* | เส้นแรเงาและไฮไลต์สีครีม ตัดตาม *Ribbon* |
| *Ribbon shading* | เงาและจุดเน้นสีเขียวเสจ ตัดตาม *Ribbon* |
| *Ribbon* | สีเขียวหัวเป็ด มาสก์ตามริบบิ้น |
| *Disc shading* | การแรเงาและไฮไลต์ ตัดตาม *Disc* |
| *Disc* | สีโอเคอร์ มาสก์ตามแผ่นกลม |
| *Block shading* | การแรเงาและเส้นแรเงา ตัดตาม *Block* |
| *Block* | สีดินเผา มาสก์ตามบล็อก |
| *Sketch* | เส้นดินสอที่ความทึบ 22% ซ่อนอยู่ |
| *Color rough* | สีเรียบที่ความทึบ 50% ซ่อนอยู่ |
| **กระดาษ** | สีขาว |
