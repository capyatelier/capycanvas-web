คุณกำหนดวิธีที่พู่กันแบบเปียกและแบบเกลี่ยสีจัดการกับสีได้ในแผง **เครื่องมือ** แต่ละกลุ่มจะแสดงเฉพาะในพู่กันที่ระบุไว้ในหัวข้อของกลุ่มนั้น

![ส่วนล่างของแผงเครื่องมือของสีน้ำเปียก ที่มีกลุ่มการผสม สีน้ำ สีซึม และการผสม](shot:brushes/wet-media-settings)

## การผสม

**การผสม** แสดงในพู่กันสีน้ำมัน **สีกวอชทึบ** พู่กันสีน้ำ และตัวเกลี่ยสีทุกตัว **การรับสีแบบเฉลี่ย** **ความคงทน** และ **เติมสีตามแรงกด** แสดงเฉพาะในพู่กันสีน้ำมัน **สีกวอชทึบ** **เกลี่ยสีเปียก** และ **ผสมสี**

### ปริมาณสี

กำหนดว่าพู่กันจะพาสีของตัวเองไปมากเพียงใด และสำหรับพู่กันสีน้ำจะกำหนดความเข้มของเม็ดสี ค่าที่ต่ำลงจะให้สีที่รับมาจากเลเยอร์มีผลมากกว่า

### การรับสี

กำหนดว่าพู่กันจะลากสีที่รับมาจากเลเยอร์ไปตามเส้นได้ไกลเพียงใด

### การเจือจาง

ทำให้สีที่พู่กันพาไปเจือจางลง ค่าที่สูงขึ้นจะทำให้สีของพู่กันเองในส่วนผสมอ่อนลง

### การรับสีแบบเฉลี่ย

กำหนดว่าสีที่รับมาทั่วปลายพู่กันจะผสมเป็นสีเดียวมากเพียงใด ที่ 0% แต่ละส่วนของปลายพู่กันจะคงสีของตัวเองไว้

### ความคงทน

กำหนดว่าสีเฉลี่ยจะถูกพาไปตามเส้นได้ไกลเพียงใด แสดงเฉพาะเมื่อ **การรับสีแบบเฉลี่ย** สูงกว่า 0%

### เติมสีตามแรงกด

กำหนดว่าแรงกดหนักจะเติมสีที่เลือกกลับเข้าพู่กันมากเพียงใด **พู่กันผสมสี** จะวางสีของตัวเองเมื่อกดหนัก และจะเกลี่ยสีเท่านั้นเมื่อสัมผัสเบา

## ตัวเกลี่ยสี

ตัวเกลี่ยสีแต่ละตัวเพิ่มการตั้งค่าในกลุ่ม **ตัวเกลี่ยสี** **การแผ่** อยู่ด้านบนของแผง **เครื่องมือ**

| การตั้งค่า | ตัวเกลี่ยสี | กำหนด |
| --- | --- | --- |
| **การแผ่** | ทั้งหมดยกเว้น **เกรียงเกลี่ยสี** และ **ลายหินอ่อน** | กำหนดว่าตัวเกลี่ยสีจะรวบรวมสีรอบแต่ละจุดของเส้นได้ไกลเพียงใด |
| **ริ้ว** | **เกลี่ยสี**, **เกลี่ยสีนุ่ม**, **แท่งเกลี่ยสี**, **กระดาษทิชชู**, **เกลี่ยสีธรรมชาติ**, **เกลี่ยสีขนแปรง**, **เกรียงเกลี่ยสี** | กำหนดว่าเส้นจะแตกเป็นริ้วไปตามทิศทางของเส้นมากเพียงใด |
| **ความคมชัด** | **เพิ่มความคมชัด** | กำหนดว่าเส้นจะเพิ่มคอนทราสต์มากเพียงใด |
| **การรักษาพื้นผิว** | **เกลี่ยสีรักษาพื้นผิว** | กำหนดว่าพื้นผิวละเอียดใต้เส้นจะคงอยู่เหนือสีที่เกลี่ยแล้วมากเพียงใด |
| **ขนาดรายละเอียด** | **เกลี่ยสีรักษาพื้นผิว** | ขนาดของพื้นผิวที่คงไว้ |
| **เกลี่ยความสว่าง** | **เกลี่ยสีเฉพาะเฉดสี** | กำหนดว่าความสว่างจะเกลี่ยไปพร้อมกับเฉดสีและความอิ่มสีมากเพียงใด |
| **ความหยาบ** | **เกลี่ยสีกระจาย** | กำหนดว่าพิกเซลที่กระจายแต่ละจุดจะแทนที่พิกเซลด้านล่างได้เต็มที่เพียงใด |
| **การยืด** | **เกลี่ยสีแบบภาพวาด**, **เกลี่ยสีผลึก** | กำหนดว่าแผ่นหรือเซลล์จะยืดไปตามเส้นได้ไกลเพียงใด |
| **ขนาดเซลล์** | **เกลี่ยสีผลึก** | ขนาดของเซลล์ |
| **การหมุนวน** | **ลายหินอ่อน** | กำหนดว่าสีจะม้วนเป็นวงมากเพียงใด |
| **ขนาดวงหมุน** | **ลายหินอ่อน** | ขนาดของวงหมุน |
| **การรักษาขอบ** | **เกลี่ยสีแบบหวี** | กำหนดว่าการเกลี่ยจะหยุดที่ขอบระหว่างสีได้ง่ายเพียงใด |

## สีน้ำ

**ระบายสีน้ำ** และ **สีน้ำเปียก** มีกลุ่ม **สีน้ำ** สำหรับขอบที่เข้มขึ้นในจุดที่สีไปรวมตัวกัน สีน้ำมีปฏิกิริยากับสีบนเลเยอร์เดียวกันเท่านั้น **ความเข้มขอบ** อยู่ด้านบนของแผง **เครื่องมือ** เหนือกลุ่มต่าง ๆ

### ความเข้มขอบ

กำหนดว่าขอบจะเข้มเพียงใด

### ความกว้างขอบ

กำหนดความกว้างของขอบ ตั้งแต่ 0 ถึง 32 px

## สีซึม

กลุ่ม **สีซึม** ของพู่กันสีน้ำทั้งสองอันกำหนดวิธีที่น้ำและเม็ดสีซึมเข้าไปในกระดาษรอบเส้น สีจะซึมเฉพาะระหว่างวาดเส้น ไม่ซึมต่อหลังจากคุณยกปากกาขึ้น

### สีซึมเมื่อเปียก

กำหนดว่าสีจะซึมเข้าไปในกระดาษที่เปียกอยู่แล้วเร็วเพียงใด

### สีซึมเมื่อแห้ง

กำหนดว่าสีจะซึมเข้าไปในกระดาษแห้งเร็วเพียงใด

### ระยะสีซึม

กำหนดว่าสีจะซึมออกจากแต่ละแต้มได้ไกลเพียงใด ตั้งแต่ 0 ถึง 96 px

### ปริมาณน้ำ

กำหนดว่าแต่ละแต้มจะวางน้ำลงบนกระดาษมากเพียงใด อยู่ด้านบนของแผง **เครื่องมือ** เหนือกลุ่มต่าง ๆ

## การผสมสี

คุณเลือกได้ว่าพู่กันที่ผสมสีจะรวมสีที่รับมาอย่างไร

ทำอย่างใดอย่างหนึ่งต่อไปนี้:

- เลือก **ผสมสี Oklab** **ผสมสีแสงเชิงเส้น** หรือ **ผสมสีคลาสสิก** จาก **การผสมสี** ในแผง **เครื่องมือ**
- เปิด **ตัวเลือกเครื่องมือเพิ่มเติม** ในแถบตัวเลือกเครื่องมือ แล้วเลือก **การผสมสี** ในลิ้นชักเครื่องมือ ([ขนาด ความแรง และความทึบ](/th/docs/brushes/basics/))
- ค้นหาคำสั่งด้วยชื่อตัวเลือก

| ตัวเลือก | การผสม |
| --- | --- |
| **ผสมสี Oklab** | ผสมสีที่รับมาอย่างสม่ำเสมอตามที่ตามองเห็น |
| **ผสมสีแสงเชิงเส้น** | ผสมสีที่รับมาแบบเดียวกับที่แสงผสมกัน |
| **ผสมสีคลาสสิก** | ผสมค่าสีตามที่เก็บไว้ในภาพวาด |

พู่กันผสมสีที่มีมาในแอปทุกอันเริ่มต้นที่ **ผสมสี Oklab** ตัวเลือกนี้จะถูกบันทึกไว้กับพู่กัน และการตั้งค่า **การผสม** ของภาพวาดไม่เปลี่ยนตัวเลือกนี้ สำหรับพู่กันที่ไม่ผสมสี ตัวเลือกเหล่านี้จะใช้ไม่ได้

![การตั้งค่าการผสมสีที่แสดงผสมสี Oklab](shot:brushes/color-mixing-menu)

## ขนพู่กัน

กลุ่ม **ขนพู่กัน** แสดงเฉพาะใน **พู่กันขนแข็ง** พู่กันนี้ลากอีกสีหนึ่งของคู่สีพื้นหน้าและพื้นหลังเป็นริ้วลงในสันสีที่หนา

### ขนาดขนพู่กัน

กำหนดขนาดของรอยขนพู่กันเทียบกับขนาดพู่กัน ตัวเลื่อนปรับได้ตั้งแต่ 25% ถึง 200% และคุณพิมพ์ค่าได้ถึง 400%

### ปริมาณสี

กำหนดว่าพู่กันจะมีสีมากเพียงใดเมื่อเริ่มแต่ละเส้น
