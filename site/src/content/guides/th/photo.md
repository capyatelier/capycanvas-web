คุณจะแต่งภาพถ่ายหนึ่งภาพในสามขั้นตอนในพื้นที่ทำงาน[ภาพถ่าย](/th/docs/start/workspaces/) ให้ใช้ภาพถ่ายของคุณเอง ภาพตัวอย่างเป็นตู้ต้นไม้ที่มีหินลาวาและเฟิร์นบนพื้นหลังสีดำ

![พื้นที่ทำงานภาพถ่ายที่มีภาพถ่ายตู้ต้นไม้ที่แต่งแล้วบนผืนผ้าใบและเลเยอร์ของภาพในแผงเลเยอร์](shot:photo/overview)

## พื้นที่ทำงานภาพถ่าย

เลือก **ภาพถ่าย** ในตัวสลับพื้นที่ทำงานในแถบชื่อเรื่อง บทช่วยสอนนี้ใช้ส่วนต่าง ๆ ของพื้นที่ทำงานดังนี้:

- แถบเครื่องมือวาดภาพทางซ้าย ที่มี **ครอบตัด** เครื่องมือเลือกพื้นที่ และเครื่องมือซ่อมแซม
- **ตัวเลือกเครื่องมือ** ที่ด้านบน ซึ่งมีการตั้งค่าของเครื่องมือปัจจุบัน
- แผง **คุณสมบัติ** และ **เลเยอร์** ในคอลัมน์ขวา

## ขั้นตอน

1. [การเปิดและครอบตัด](/th/docs/photo/crop/): เปิดภาพถ่ายแล้วครอบตัดเป็น 5:4
2. [การรีทัช](/th/docs/photo/retouch/): ลบฝุ่นและรอยเปื้อนบนเลเยอร์ที่อยู่เหนือภาพถ่าย
3. [การปรับแต่งและส่งออก](/th/docs/photo/adjust/): **เส้นโค้ง** **ความสดสี** และ **เงา/ไฮไลต์** เฉพาะจุด จากนั้นบันทึกไฟล์ `.capy` และส่งออก JPEG สำหรับเว็บ

## เลเยอร์เมื่อเสร็จแล้ว

ภาพถ่ายที่แต่งแล้วมีเลเยอร์ต่อไปนี้ จากบนลงล่าง:

| เลเยอร์ | เนื้อหา |
| --- | --- |
| **เงา/ไฮไลต์** | ยกเงาในหิน โดยมาสก์ตามพื้นที่เลือกที่ฟุ้งขอบ |
| **ความสดสี** | เพิ่มความสดสีของทั้งภาพ |
| **เส้นโค้ง** | เส้นโค้งรูปตัว S สำหรับทั้งภาพ |
| *Retouch* | เส้นซ่อมแซม |
| เลเยอร์ภาพถ่าย | ภาพถ่าย ตั้งชื่อตามไฟล์ |
| **กระดาษ** | ซ่อนอยู่ |

ไม่มีการระบายใด ๆ บนเลเยอร์ภาพถ่าย
