{appName} использует графический процессор устройства для рисования и отображения холста. Поддержка зависит от сочетания приложения или браузера, операционной системы и графического оборудования.

## Приложения

Настольное приложение поддерживает Windows, macOS и Linux. Приложение для iPad требует iPadOS 17.5 или новее. Приложение для Android требует Android 12 или новее.

Приложения для iPad и Android выпускаются в бета-версиях. Соответствие требованиям к операционной системе само по себе не подтверждает работу каждого графического процессора или пера.

## Веб-редактор

Веб-редактор работает в следующих браузерах:

| Система | Браузеры |
| --- | --- |
| Windows | Chrome, Edge, Firefox 141 или новее |
| macOS | Chrome, Edge, Safari 26 или новее, Firefox 147 или новее на Apple silicon |
| Linux с Wayland | Chrome, Edge |
| iPadOS 26 или новее | Safari |
| Android 12 или новее | Chrome |

Минимум iPadOS 17.5 для приложения iPad не относится к Safari. Веб-редактор требует iPadOS 26 или новее, поскольку использует графические возможности браузера из этой версии.

## Поддержка графики

Если холст не запускается, {appName} показывает сообщение об отсутствующей графической возможности. Сначала обновите систему, браузер и графический драйвер. Если сообщение остаётся, при сообщении о проблеме укажите точный текст, модель устройства и графики.
