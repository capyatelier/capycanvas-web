Рисовать можно инструментами **Перо**, **Карандаш**, **Кисть для рисования**,
**Аэрограф** и **Декор**, а стирать инструментом **Ластик**. В каждом
инструменте есть одна или несколько групп встроенных шаблонов кистей.

## Инструменты и шаблоны

| Инструмент | Группы | Шаблоны |
| --- | --- | --- |
| **Перо** | **Перо** | **G-перо**, **Грубое G-перо**, **Каллиграфическое перо**, **Старинное перо**, **Реалистичное перо**, **Влажная тушь**, **Пятнистая тушь**, **Реалистичная тушь кистью** |
| | **Маркер** | **Маркер** |
| **Карандаш** | **Карандаш** | **Карандаш**, **Острый карандаш**, **Карандаш для штриховки** |
| | **Пастель** | **Уголь**, **Мел**, **Пастельный брусок** |
| **Кисть для рисования** | **Краска** | **Кисть для рисования**, **Щетинная кисть**, **Текстурная плоская кисть**, **Сухая протирка**, **Прозрачная лессировка**, **Укрывистая гуашь**, **Лессировка с умножением** |
| | **Акварель** | **Акварельная размывка**, **Влажная акварель** |
| | **Масляная краска** | **Густое масло**, **Мастихин**, **Влажная круглая кисть** |
| **Аэрограф** | **Аэрограф** | **Аэрограф** |
| | **Распыление** | **Распыление** |
| **Ластик** | **Ластик** | **Ластик** |

Инструмент и каждая его группа запоминают последний использованный шаблон.
У шаблонов нет собственного цвета: все кисти рисуют текущим цветом
([Панель «Цвет»](/ru/docs/color/color-panel/)).

## Поведение шаблонов

Это поведение встроено в шаблоны, и настройки для него нет.

| Шаблон | Поведение |
| --- | --- |
| **Каллиграфическое перо**, **Старинное перо** | Скошенное перо. |
| **Маркер** | Скошенный наконечник. |
| **Карандаш**, **Острый карандаш**, **Карандаш для штриховки**, **Уголь** | Более широкий след при наклоне пера. |
| **Аэрограф** | Продолжает добавлять краску, пока перо стоит на месте. |
| **Распыление** | Разбрасывает отпечатки вокруг мазка. |
| **Лессировка с умножением** | Рисует в режиме «Умножение». |

## Выбор кистевого инструмента

Выполните одно из действий:

- Нажмите **P** для пера и карандаша, **B** для кисти для рисования, аэрографа и декора или **E** для ластика. Нажмите **P** или **B** ещё раз, чтобы переключиться на следующий инструмент на этой клавише.
- В рабочем пространстве «Краска» выберите инструмент на панели инструментов у левого края.
- В рабочем пространстве «Фотография» выберите **Кисть** или **Ластик** на панели инструментов. В **Кисть** входят кисть для рисования, перо, карандаш, аэрограф и декор.
- В рабочем пространстве «Набросок» выберите **Кисть** или **Ластик** в заголовке окна.
- Найдите через [поиск команд](/ru/docs/start/command-search/) инструмент, шаблон или группу кистей, например **Кисти «Карандаш»**.

Кнопка инструмента показывает значок последней использованной группы, а её
подсказка называет и группу, и инструмент, например «Маркер · Перо (P)».

У шаблонов и у инструментов на клавишах **P** и **B** нет собственных
клавиш. Их можно назначить на странице
[Сочетания клавиш](/ru/docs/input/keyboard/).

## Панель «Набор инструментов»

Группу и шаблон можно выбрать на панели **Набор инструментов**.

Выполните одно из действий:

- Выберите **Окно > Набор инструментов**.
- В рабочем пространстве «Краска» выберите вкладку **Набор инструментов** в левой колонке.
- В рабочем пространстве «Фотография» выберите **Набор инструментов** на полосе значков справа.
- Ещё раз выберите кнопку активного инструмента. В открывшейся выдвижной области есть **Набор инструментов** и **Инструмент**.

![Панель «Набор инструментов» в рабочем пространстве «Краска»: группы «Перо» и «Маркер» над шаблонами пера с образцами мазков.](shot:drawing/brush-tool-set)

В верхнем ряду перечислены группы инструмента. У инструмента **Кисть** в
рабочем пространстве «Фотография» в верхнем ряду вместо групп перечислены
инструменты. Ниже у каждого шаблона выбранной группы есть образец мазка.

## Выбор группы из кнопки

Группу можно выбрать в меню кнопки инструмента. Чтобы открыть меню, щёлкните
кнопку правой кнопкой мыши или удерживайте её. Текущая группа отмечена флажком.

Маленький треугольник в углу отмечает каждую кнопку, у которой есть меню.

![Меню кнопки «Кисть для рисования» на панели инструментов с группами «Краска», «Акварель» и «Масляная краска».](shot:drawing/brush-group-menu)

## Выдвижные области в «Наброске»

В рабочем пространстве «Набросок» выберите **Кисть** или **Ластик** в заголовке
окна, чтобы рисовать последним шаблоном. Выберите кнопку ещё раз, чтобы открыть
выдвижную область, и ещё раз, чтобы закрыть её.

В выдвижной области **Кисть** три колонки. В колонке **Кисти** перечислены
группы, в колонке **Инструменты** шаблоны выбранной группы, а в колонке
**Инструмент** их настройки. При выборе группы выбирается её последний шаблон, а
выдвижная область остаётся открытой. В выдвижной области **Ластик** есть
только **Инструменты** и **Инструмент**.

![Выдвижная область «Кисть» в рабочем пространстве «Набросок» с колонками «Кисти», «Инструменты» и «Инструмент».](shot:drawing/sketch-brush-drawer)

## Ластик

Инструмент **Ластик** стирает краску с выбранного слоя. Нажмите **E** или
выберите **Ластик** на панели инструментов, а в рабочем пространстве «Набросок»
в заголовке окна.

Когда вы редактируете маску, ластик убирает покрытие маски.

Если на панели «Цвет» выбрана **Прозрачная краска**, стирает любая кисть.
Стирать можно и обратным концом пера ([Перо](/ru/docs/input/pen/)).

На слое с включённой **Блокировка альфы** ластик ничего не стирает.

## Какой слой получает краску

Мазок кисти рисует на выбранном слое или на его маске, пока вы редактируете
маску. На слое фильтра мазок рисует на маске фильтра. Если у фильтра нет маски,
мазок попадает на слой, к которому применяется фильтр, или на следующий слой
ниже ([Как применяются фильтры](/ru/docs/filters/how-filters-apply/)).

Активное выделение ограничивает краску областью выделения.

На следующих слоях мазок ничего не рисует, а уведомление называет причину:

- Группа или слой выделения.
- Слой заливки без маски.
- Слой с включённым **Заблокировать редактирование** или слой внутри заблокированной группы.
- Слой фильтра без маски, если слой под ним заблокирован или отсутствует.
- Масштабированный или повёрнутый слой, пока вы не выберете **Применить трансформацию к пикселям** ([Перемещение и трансформация](/ru/docs/transform/move-transform/)).

Влажные, смешивающие и акварельные кисти рисуют на маске простым покрытием.
Первый такой мазок на каждой маске показывает уведомление.
