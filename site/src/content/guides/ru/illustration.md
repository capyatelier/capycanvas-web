Вы пишете абстрактный этюд в четыре этапа в рабочем пространстве
[«Краска»](/ru/docs/start/workspaces/). Каждый этап добавляет слои, и ни один
слой не объединяется.

![Рабочее пространство «Краска» с готовым абстрактным этюдом на холсте и его слоями на панели «Слои».](shot:illustration/overview)

## Этюд

Этюд размером 1200 × 1200 состоит из трёх перекрывающихся фигур: изогнутой
ленты, диска и наклонного бруска. На фигурах и вокруг них лежат
свободные каракули и штрихи.

## Этапы

1. [Эскиз](/ru/docs/illustration/draft/): цветовой эскиз и карандашный набросок.
2. [Контурный рисунок](/ru/docs/illustration/ink/): линии туши над побледневшим наброском.

3. [Базовые цвета](/ru/docs/illustration/mask/): цветовой слой с маской для каждой фигуры.
4. [Проработка](/ru/docs/illustration/render/): тени на обтравленных слоях и экспорт в PNG.

## Слои готового рисунка

В готовом рисунке следующие слои, сверху вниз:

| Слой | Содержимое |
| --- | --- |
| *Line art* | Линии туши |
| *Ribbon texture* | Кремовая штриховка и блики, обтравлен по *Ribbon* |
| *Ribbon shading* | Тени и акценты цвета шалфея, обтравлен по *Ribbon* |
| *Ribbon* | Бирюзовый, с маской по ленте |
| *Disc shading* | Светотень и блик, обтравлен по *Disc* |
| *Disc* | Охра, с маской по диску |
| *Block shading* | Светотень и штриховка, обтравлен по *Block* |
| *Block* | Терракота, с маской по бруску |
| *Sketch* | Карандашные линии с непрозрачностью 22%, скрыт |
| *Color rough* | Плоские цвета с непрозрачностью 50%, скрыт |
| **Бумага** | Белый |
