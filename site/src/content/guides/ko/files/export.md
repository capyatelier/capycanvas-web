그림을 하나로 병합한 이미지 사본을 내보낼 수 있습니다. 내보내기는 `.capy` 그림을 바꾸지 않으며 저장으로 처리되지도 않습니다.

## 이미지 내보내기

다음 중 하나를 수행합니다.

- **파일 > 내보내기…** 메뉴를 선택합니다.
- **Ctrl+Shift+E** 키를 누릅니다.

**이미지 내보내기** 대화 상자가 **웹 / 공유** 용도로 열립니다. **파일 선택…** 버튼을 선택하고 저장 위치를 고릅니다. 제안되는 이름은 그림 이름에 형식의 확장자를 붙인 이름(예: “제목 없음.png”)입니다. Firefox와 Safari에서는 대신 **파일 다운로드** 대화 상자가 열립니다([열기와 저장](/ko/docs/files/open-save/) 참조).

파일 이름은 형식의 확장자로 끝나야 합니다. 자르기나 변형이 진행 중일 때는 **내보내기…** 명령을 사용할 수 없습니다.

## 설정

![용도가 웹 / 공유로 설정된 이미지 내보내기 대화 상자.](shot:files/export-dialog)

일부 설정은 특정 형식에서만 표시됩니다.

### 용도

나머지 설정을 한꺼번에 정합니다. 저장한 내보내기 사전 설정은 다음 기본 제공 용도 뒤에 표시됩니다.

- **웹 / 공유**: 원래 크기의 8비트 sRGB PNG.
- **넓은 색역 이미지**: 같은 설정을 Display P3로.
- **추가 편집**: 그림의 색 공간으로 된 16비트 TIFF.
- **사용자 지정**: **웹 / 공유**와 같은 설정으로 시작합니다.

### 다이내믹 레인지

SDR 그림에서는 **SDR**, HDR 그림에서는 HDR 형식 중 하나를 고릅니다(아래 HDR 내보내기 참조).

### 범위를 벗어난 HDR 색상 클리핑

HDR PNG, HDR JPEG, HDR AVIF의 범위를 넘는 색을 잘라 냅니다. 이 형식에서만 표시됩니다.

### 형식

**PNG 이미지**, **TIFF 이미지**, **JPEG 이미지**, **WebP · 무손실** 중에서 고릅니다(아래 형식별 제한 참조).

### 출력 프로파일

**sRGB**, **Display P3**, **Adobe RGB (1998)**, **ProPhoto RGB** 중에서 고르며, 자체 프로파일이 포함된 사진 레이어마다 “원본: *이름*” 항목이 추가됩니다.

### 비트 심도

**8비트** 또는 **16비트**입니다.

### 투명도

**유지**, **흰색 배경**, **검정 배경** 중에서 고릅니다.

### 렌더링 의도

**상대 색도계**(기본값), **지각적**, **채도**, **절대 색도계** 중에서 고릅니다.

### 디더링

**없음** 또는 **무작위 디더링(8비트 출력)**.

### 품질

압축 품질이며 1에서 100까지, 기본값은 90입니다. JPEG, HDR JPEG, HDR AVIF에서 표시됩니다.

### 픽셀 크기

**원래 크기** 또는 **지정 크기 안에 맞추기**입니다. **지정 크기 안에 맞추기**를 선택하면 **최대 너비(px)**, **최대 높이(px)** 필드가 추가되며, 이미지가 비율을 유지한 채 그 안에 들어가도록 축소됩니다.

### 해상도 메타데이터

**원래 설정 유지**, **인치당 픽셀 수**, **생략** 중에서 고릅니다. **인치당 픽셀 수**를 선택하면 1에서 65535까지 입력하는 필드가 추가되며, 기본값은 300입니다.

### 메타데이터

**모두**, **저작권과 연락처**, **없음** 중에서 고릅니다. **모두**에서는 **위치 정보 제거**가 기본적으로 켜져 있습니다. 이 행은 카메라 정보나 저작권 정보가 있는 사진에서 연 그림에서만 표시됩니다.

### ICC 프로파일 가져오기…와 저장된 프로파일…

**ICC 프로파일 가져오기…** 버튼은 16 MiB 이하의 `.icc` 또는 `.icm` 파일을 **출력 프로파일**에 추가합니다. **저장된 프로파일…** 버튼은 **색상 프로파일 라이브러리**를 엽니다.

### 사전 설정 이름과 사전 설정 버튼

**사전 설정 저장**은 현재 설정을 **사전 설정 이름**에 입력한 이름의 새 용도로 저장합니다. **사전 설정 업데이트**와 **사전 설정 삭제**는 선택한 저장 사전 설정을 변경하거나 제거합니다. **용도 설정 초기화**는 기본 제공 용도의 설정을 복원합니다.

### 출력 미리보기

내보낼 이미지를 그림 옆에 **그림**과 **출력**이라는 설명과 함께 표시하며, 출력 색역을 벗어나는 색이 있으면 경고를 표시합니다. 설정을 하나라도 바꾸면 미리 보기가 지워집니다.

### 파일 선택…

이미지를 저장할 위치를 묻습니다.

## 형식별 제한

- JPEG 및 WebP는 8비트만 지원합니다.
- JPEG 형식은 투명도를 유지할 수 없습니다.
- WebP는 각 변이 16,384픽셀까지 가능합니다.
- 회색조 출력 프로파일에서는 WebP를 사용할 수 없습니다.
- CMYK 출력 프로파일에서는 TIFF와 JPEG만 사용할 수 있으며 투명도는 지원되지 않습니다.

다른 설정과 맞지 않는 선택 항목은 흐리게 표시됩니다.

## 내보내기 사전 설정

내보낸 뒤 기본 제공 용도는 사용한 설정을 유지합니다. 저장한 사전 설정으로 내보내면 설정은 **사용자 지정**에 유지되며, 사전 설정 자체는 **사전 설정 업데이트**로만 바뀝니다.

사전 설정 이름은 80자까지 입력할 수 있고, 사전 설정은 64개까지 저장할 수 있습니다. 사전 설정은 모든 그림에 적용됩니다.

## HDR 내보내기

![출력 미리보기를 실행한 뒤 HDR JPEG · 게인 맵이 선택된 HDR 그림의 이미지 내보내기 대화 상자.](shot:files/export-hdr-preview)

16비트 또는 32비트 부동 소수점 그림에서는 **다이내믹 레인지**에 다음 선택 항목이 있습니다.

| 선택 항목 | 내보내는 파일 |
| --- | --- |
| **SDR 표시 버전** | SDR 설정을 적용한 그림의 SDR 버전 |
| **HDR JPEG · 게인 맵** | 게인 맵이 있는 `.jpg` |
| **HDR AVIF · 투명도가 있는 게인 맵** | 게인 맵과 투명도가 있는 `.avif` |
| **HDR PNG · BT.2020 PQ** | BT.2020 PQ로 인코딩되고 투명도가 있는 `.png` |
| **OpenEXR · 32비트 부동소수점** | 그림의 색 공간으로 저장되고 투명도가 있는 `.exr` |

**SDR 표시 버전**은 [SDR 표시 조정](/ko/docs/color-management/hdr/)으로 설정한 SDR 버전을 사용합니다. OpenEXR에는 카메라 정보나 저작권 정보가 저장되지 않습니다. HDR 그림에서는 **추가 편집** 대신 **추가 편집(SDR)** 항목이 표시되며 OpenEXR을 사용합니다.

HDR JPEG 및 HDR AVIF에서는 **출력 미리보기**를 선택하면 **미리보기 버전**이 추가되며, **HDR 재구성 · SDR 미리보기**와 **인코딩된 SDR 기본 이미지** 중에서 고를 수 있습니다.

미리 보기에서 HDR PNG, JPEG, AVIF의 범위를 넘는 색이 발견되면 **범위를 벗어난 HDR 색상 클리핑**을 켜거나 OpenEXR을 선택할 때까지 **파일 선택…** 버튼을 사용할 수 없습니다.

## 다시 내보내기

**파일 > 다시 내보내기**는 대화 상자 없이 그림의 마지막 내보내기를 같은 설정과 같은 파일로 반복합니다. 그림을 한 번 내보내기 전에는 사용할 수 없습니다.

그림마다 마지막 내보내기가 따로 유지되며, 다시 시작한 뒤에도 유지됩니다. Firefox와 Safari에서는 **다시 내보내기**가 **파일 다운로드** 대화 상자를 표시합니다.

## 다른 플랫폼

Linux에서는 설정이 **크기**, **색상과 투명도**, **사전 설정** 페이지로 나뉘며 일부 레이블이 다릅니다. iPad와 macOS 대화 상자도 각각의 레이블을 사용합니다.
