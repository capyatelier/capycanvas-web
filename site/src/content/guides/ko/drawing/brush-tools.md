**펜**, **연필**, **페인트 브러시**, **에어브러시**, **장식** 도구로 그리고, **지우개**로 지울 수 있습니다. 각 도구에는 기본 제공 브러시 사전 설정 그룹이 하나 이상 들어 있습니다.

## 도구와 사전 설정

| 도구 | 그룹 | 사전 설정 |
| --- | --- | --- |
| **펜** | **펜** | **G펜**, **거친 G펜**, **캘리그래피 펜**, **앤티크 펜**, **사실적인 펜**, **젖은 잉크**, **번지는 잉크**, **사실적인 먹 붓** |
| | **마커** | **마커** |
| **연필** | **연필** | **연필**, **뾰족한 연필**, **음영 연필** |
| | **파스텔** | **목탄**, **분필**, **사각 파스텔** |
| **페인트 브러시** | **페인팅** | **페인트 브러시**, **붓털 브러시**, **질감 있는 평붓**, **마른 덧칠**, **투명 글레이징**, **불투명 과슈**, **곱하기 글레이징** |
| | **수채** | **수채 워시**, **습식 수채** |

| **에어브러시** | **에어브러시** | **에어브러시** |
| | **스프레이** | **스프레이** |
| **지우개** | **지우개** | **지우개** |

도구와 각 그룹은 마지막으로 사용한 사전 설정을 기억합니다. 사전 설정에는 자체 색이 없으며, 모든 브러시는 [색상 패널](/ko/docs/color/color-panel/)의 현재 색으로 그립니다.

## 사전 설정별 동작

다음 동작은 사전 설정에 내장되어 있으며 따로 설정할 수 없습니다.

| 사전 설정 | 동작 |
| --- | --- |
| **캘리그래피 펜**, **앤티크 펜** | 펜촉이 비스듬합니다. |
| **마커** | 치즐형 브러시 끝입니다. |
| **연필**, **뾰족한 연필**, **음영 연필**, **목탄** | 펜을 기울이면 선이 넓어집니다. |
| **에어브러시** | 펜을 움직이지 않고 대고 있는 동안 계속 물감을 더합니다. |
| **스프레이** | 획 주위로 자국을 흩뿌립니다. |
| **곱하기 글레이징** | 곱하기 모드로 그립니다. |

## 브러시 도구 선택

다음 중 하나를 수행합니다.

- 펜과 연필은 **P** 키, 페인트 브러시와 에어브러시와 장식은 **B** 키, 지우개는 **E** 키를 누릅니다. **P**나 **B** 키를 한 번 더 누르면 같은 키의 다음 도구로 전환됩니다.
- 페인팅 작업 영역에서는 왼쪽 가장자리의 “도구” 도구 모음에서 도구를 선택합니다.
- 사진 작업 영역에서는 “도구” 도구 모음에서 **브러시**나 **지우개**를 선택합니다. **브러시**에는 페인트 브러시, 펜, 연필, 에어브러시, 장식이 들어 있습니다.
- 스케치 작업 영역에서는 제목 표시줄에서 **브러시**나 **지우개**를 선택합니다.
- [명령 검색](/ko/docs/start/command-search/)에서 도구나 사전 설정, 또는 그룹 이름 뒤에 “브러시”를 붙여(예: **연필 브러시**) 검색합니다.

도구 버튼에는 마지막으로 사용한 그룹의 아이콘이 표시되고, 도구 설명에는 그룹과 도구의 이름이 모두 표시됩니다(예: “마커 · 펜 (P)”).

사전 설정과, **P**나 **B** 키를 공유하는 도구에는 자체 키가 없습니다. [키보드 단축키](/ko/docs/input/keyboard/) 페이지에서 키를 지정할 수 있습니다.

## 도구 세트 패널

**도구 세트** 패널에서 그룹과 사전 설정을 고를 수 있습니다.

다음 중 하나를 수행합니다.

- **창 > 도구 세트**를 선택합니다.
- 페인팅 작업 영역에서는 왼쪽 열의 **도구 세트** 탭을 선택합니다.
- 사진 작업 영역에서는 오른쪽 아이콘 줄에서 **도구 세트**를 선택합니다.
- 활성 도구의 버튼을 한 번 더 선택합니다. **도구 세트**와 **도구**가 들어 있는 서랍이 열립니다.

![펜 사전 설정과 획 미리 보기 위에 펜 그룹과 마커 그룹이 있는 페인팅 작업 영역의 도구 세트 패널.](shot:drawing/brush-tool-set)

맨 위 줄에는 도구의 그룹이 나열됩니다. 사진 작업 영역의 **브러시**에서는 맨 위 줄에 그룹 대신 도구가 나열됩니다. 그 아래에는 선택한 그룹의 각 사전 설정이 획 미리 보기와 함께 표시됩니다.

## 버튼에서 그룹 고르기

도구 버튼의 메뉴에서 그룹을 고를 수 있습니다. 버튼을 마우스 오른쪽 버튼으로 클릭하거나 길게 누르면 메뉴가 열립니다. 현재 그룹에는 체크 표시가 있습니다.

메뉴가 있는 버튼에는 모서리에 작은 삼각형이 표시됩니다.

![“도구” 도구 모음의 페인트 브러시 버튼 메뉴. 페인팅, 수채, 유화 그룹이 나열되어 있습니다.](shot:drawing/brush-group-menu)

## 스케치 작업 영역의 서랍

스케치 작업 영역에서 제목 표시줄의 **브러시**나 **지우개**를 선택하면 마지막 사전 설정을 사용합니다. 한 번 더 선택하면 서랍이 열리고, 다시 선택하면 서랍이 닫힙니다.

**브러시** 서랍에는 열이 세 개 있습니다. **브러시**에는 그룹이, **도구 목록**에는 선택한 그룹의 사전 설정이, **도구**에는 그 설정이 표시됩니다. 그룹을 고르면 그 그룹의 마지막 사전 설정이 선택되고 서랍은 열린 채로 있습니다. **지우개** 서랍에는 **도구 목록**과 **도구**만 있습니다.

![브러시, 도구 목록, 도구 열이 있는 스케치 작업 영역의 브러시 서랍.](shot:drawing/sketch-brush-drawer)

## 지우개

**지우개**로 선택한 레이어의 물감을 지울 수 있습니다. **E** 키를 누르거나, “도구” 도구 모음 또는 스케치 작업 영역의 제목 표시줄에서 **지우개**를 선택합니다.

마스크를 편집하는 동안에는 지우개가 마스크 영역을 지웁니다.

색상 패널에서 **투명색 그리기**를 선택하면 모든 브러시가 지우개로 작동합니다. 펜의 지우개 쪽 끝으로도 지울 수 있습니다([펜](/ko/docs/input/pen/)).

**투명도 잠금**이 켜진 레이어에서는 지워지지 않습니다.

## 물감이 칠해지는 레이어

브러시 획은 선택한 레이어에 칠해지며, 마스크를 편집하는 동안에는 그 마스크에 칠해집니다. 필터 레이어에서는 획이 필터의 마스크에 칠해집니다. 필터에 마스크가 없으면 필터가 적용되는 레이어나 바로 아래 레이어에 칠해집니다([필터 적용 방식](/ko/docs/filters/how-filters-apply/)).

선택 영역이 활성화되어 있으면 선택 영역 안에만 칠해집니다.

다음 레이어에서는 획이 아무것도 칠하지 않으며, 알림에 그 이유가 표시됩니다.

- 그룹이나 선택 영역 레이어.
- 마스크가 없는 채우기 레이어.
- **편집 잠금**이 켜진 레이어나 잠긴 그룹 안의 레이어.
- 바로 아래 레이어가 잠겨 있거나 없는 경우, 마스크가 없는 필터 레이어.
- 크기를 조절하거나 회전한 레이어. **픽셀에 변형 적용**을 선택할 때까지 칠해지지 않습니다([이동과 변형](/ko/docs/transform/move-transform/)).

물기가 있는 브러시, 혼색 브러시, 수채 브러시는 마스크에 단순한 마스크 영역만 칠합니다. 마스크마다 처음 이런 획을 그으면 알림이 표시됩니다.
