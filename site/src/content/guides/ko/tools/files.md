문서 저장과 내보내기 조작부는 개발 중입니다. 사용할 수 있게 되면 지원 형식과 레이어 호환성을 여기에 안내합니다. 아래는 예정된 작업 흐름입니다.

## 편집 가능한 작업 파일 유지

작업 사본은 Capy Canvas의 레이어와 마스크를 보존하는 문서 형식으로 저장합니다. 튜토리얼의 분리된 구조를 유지하면 다른 부분을 다시 칠하지 않고 밑색이나 명암을 바꿀 수 있습니다. 평면화된 이미지에는 이러한 편집 관계가 남지 않습니다.

다른 앱으로 옮기기 전에 사용한 기능을 대상 앱이 지원하는지 확인하세요. 레이어를 지원하더라도 클리핑, 마스크, 혼합이 똑같이 재현된다는 보장은 없습니다. 옮긴 사본을 열어 확인할 때까지 원본 문서를 보관합니다.

## 공유용 사본 내보내기

일러스트를 게시하거나 다른 문서에 넣으려면 이미지를 내보냅니다. 내보내기는 작업 레이어를 병합하지 않고 현재 보이는 결과를 합성합니다. 스케치와 컬러 러프를 숨기고 배경의 표시 상태를 확인하세요.

투명 배경이 필요하다면 투명도를 지원하는 형식을 선택합니다. 내보낸 파일을 열어 모양과 이미지 크기를 확인하세요. 편집기의 확대 비율은 내보낸 이미지의 크기에 영향을 주지 않습니다.

## 기기 사이에서 파일 이동

웹 버전에서는 브라우저가 파일을 어디에 저장하는지 확인하세요. 웹 앱을 오프라인용으로 설치해도 문서가 다른 기기에 자동으로 생기지는 않습니다. 저장한 문서 자체를 옮기고, 대상 기기에서 열리는지 확인한 뒤 원래 사본을 정리합니다.

내보낸 이미지에서 가장자리 수정이 필요하다면 [렌더링](/ko/docs/illustration/render/)으로 돌아갑니다. 밑색 마스크와 명암 레이어를 따로 보관하면 완성된 채색 전체를 다시 만들지 않고 고칠 수 있습니다.
