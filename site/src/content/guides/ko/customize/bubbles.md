도구, 브러시, 색상환, 레이어를 도구 모음에서 버블로 꺼내 캔버스에 둘 수 있습니다.

## 버블 꺼내기

제목 표시줄의 버튼, 도구 모음의 도구, 도구 패널이나 서랍의 재료 또는 브러시를 캔버스로 드래그합니다. 도구 모음, 패널, 제목 표시줄에 놓거나 원래 있던 막대나 패널에서 80 px 이내에 놓으면 아무것도 꺼내지지 않습니다. 버블은 작업 영역마다 따로 저장됩니다.

| 드래그하는 것 | 얻는 것 | 메뉴 항목 |
| --- | --- | --- |
| **브러시**, **지우개**, **형태 다듬기**, **선택 영역** 같은 도구 | 도구 버블 | 도구의 설정, **제자리에 두기** |
| 재료 또는 브러시 | 재료 또는 브러시 버블 | 브러시의 설정, **제자리에 두기** |
| **색상 선택기** | **브러시 크기** 호와 **강도** 호가 있고 드래그하는 동안 값이 표시되는 버블. 가운데를 탭하면 색상 선택기를 시작하거나 멈춥니다 | **슬라이더 바꾸기**, **제자리에 두기** |
| **실행 취소** 또는 **다시 실행** | 하나의 버블. 왼쪽 절반을 탭하면 실행 취소하고 오른쪽 절반을 탭하면 다시 실행합니다. 실행 취소하거나 다시 실행할 것이 없으면 그쪽 절반이 흐려집니다 | **제자리에 두기** |
| **브러시 색상** | 색상 링 | **최근 색상**, **팔레트**, **주 색상과 보조 색상**, **작게**, **중간**, **크게**, **제자리에 두기** |
| **레이어 패널** | 레이어 카드 | **간단히**, **전체**, **사용하지 않을 때 접기**, **닫기**, **제자리에 두기** |

![설정 헤일로가 있는 브러시 버블, 크기 값이 표시된 색상 선택기 버블, 실행 취소와 다시 실행 버블.](shot:bubbles/halo-controls)

도구의 버블은 하나뿐이며, 같은 도구를 다시 꺼내면 버블이 옮겨집니다. **저장** 같은 명령, 슬라이더, **도구 옵션**, 구분선은 버블이 될 수 없습니다.

## 헤일로와 선택 링

도구 버블을 선택하면 설정 링이 열립니다. 다시 선택하면 선택기가 열립니다. 브러시 버블은 선택기 대신 설정 링을 열거나 닫습니다. 선택기에서 도구나 브러시를 고르면 해당 설정 링이 열립니다.

헤일로 호를 따라 드래그하면 설정이 바뀌고, 호를 두 번 탭하거나 두 번 클릭하면 재설정됩니다. 선택 링은 도구의 재료를 버블 둘레에 고리 모양으로 늘어놓습니다. 재료를 선택하면 그 브러시가 부채꼴로 펼쳐지고, 그중에서 브러시를 선택합니다.

버블을 길게 누르거나 마우스 오른쪽 버튼으로 클릭하면 메뉴가 열립니다. 메뉴의 체크 항목으로 설정을 헤일로에 둘 수 있으며, 브러시마다 최대 여섯 개까지입니다.

![수채 재료를 선택해 그 브러시가 옆에 나타난 버블의 선택 링.](shot:bubbles/dial-chooser)

## 슬라이더 표시

설정 호를 숨기려면 버블 메뉴에서 **슬라이더 표시**를 끄세요. 설정은 현재 작업 영역의 도구, 매체, 브러시 및 **색상 선택기** 거품에 적용되며 다시 가져온 후에도 저장된 상태로 유지됩니다. 이 설정이 꺼져 있으면 도구나 브러시를 선택하면 해당 슬라이더가 숨겨집니다.

![도구 풍선 메뉴의 슬라이더 표시 항목입니다.](shot:bubbles/show-sliders)

## 색상 링

[색상 패널](/ko/docs/color/color-panel/)에서처럼 링에서 색을 고를 수 있습니다. 새 링은 색상환만 있습니다. 메뉴에서 **최근 색상**, **팔레트**, **주 색상과 보조 색상**을 켜면 구슬이 추가되고, **작게**, **중간**, **크게**로 크기를 고릅니다. 구슬을 선택하면 그 색을 사용하고, 구슬 줄을 따라 밀면 스크롤됩니다. 팔레트 구슬을 선택하면 팔레트를 바꾸거나 **팔레트 편집…** 을 선택할 수 있습니다. 두 손가락으로 핀치하면 링 크기를 바꿉니다.

![구슬과 메뉴가 있는 색상 링.](shot:bubbles/color-ring)

## 레이어 카드

**레이어 패널** 버블은 카드로 열립니다. **간단히**는 각 레이어의 눈, 썸네일, 이름을 표시하고, **전체**는 레이어 서랍을 표시합니다. 다른 곳을 선택하거나 그리면 카드가 레이어 수가 적힌 정사각형으로 접히며, 정사각형을 선택하면 다시 열립니다. **사용하지 않을 때 접기**를 끄면 **닫기**를 선택할 때까지 카드가 열려 있습니다.

![간단히 모드의 레이어 카드.](shot:bubbles/layers-card)

## 옮기기와 제자리에 두기

버블의 면을 드래그하면 옮겨지고, 색상 링에서는 판의 테두리를 드래그합니다. 터치에서는 두 손가락으로 버블의 어디에서든 옮길 수 있습니다. 버블끼리는 서로 밀어냅니다.

버블을 제자리에 두려면 다음 중 하나를 수행합니다.

- 도구 모음, 패널, 제목 표시줄에 놓습니다.
- 메뉴에서 **제자리에 두기**를 선택합니다.
- **보기 > 모든 버블을 제자리에 두기**를 선택합니다.

**창 > 레이아웃 변경 실행 취소**는 꺼내기, 옮기기, 제자리에 두기를 되돌립니다.

## 그리기와 집중 모드

버블 근처를 지나는 획은 버블을 흐리게 하고 그 아래로 지나갑니다. 그리면 선택 링이 닫히고 레이어 카드가 접힙니다. 버블은 [집중 모드](/ko/docs/customize/zen/)에서도 화면에 남습니다.
