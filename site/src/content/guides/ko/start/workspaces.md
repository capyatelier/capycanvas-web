작업 영역은 제목 표시줄, 도구 모음, 패널의 배치를 저장한 것입니다. Capy Canvas에는 **스케치**, **페인팅**, **사진**의 세 가지 작업 영역이 들어 있습니다. 처음에는 페인팅 작업 영역으로 열리고, 그다음부터는 마지막으로 사용한 작업 영역으로 열립니다.

## 스케치

![일러스트 예제가 캔버스에 열린 스케치 작업 영역.](shot:start/workspaces-sketch "1 제목 표시줄 왼쪽 · 2 작업 영역 전환기 · 3 제목 표시줄 오른쪽 · 4 브러시 조절")

스케치 작업 영역에는 도킹된 패널이 없습니다. 제목 표시줄의 도구 버튼과 패널 버튼은 서랍을 엽니다.

1. **Capy(집중 모드)**, **주 메뉴**, **필터 패널**, **선택 영역**, **변형**.
2. 작업 영역 전환기.
3. **브러시**, **형태 다듬기**, **지우개**, **레이어 패널**, **브러시 색상**. 웹 편집기에서는 **전체 화면**이 추가됩니다.
4. **브러시 크기 슬라이더**, **색상 선택기**, **브러시 불투명도 슬라이더**, **실행 취소**, **다시 실행**.

| 버튼 | 서랍에 있는 패널 |
| --- | --- |
| **브러시** | **브러시**, **도구 목록**, **도구** |
| **형태 다듬기** | **형태 다듬기**, **도구 목록**, **도구** |
| **지우개**, **선택 영역** | **도구 목록**, **도구** |
| **변형** | **도구 세트**, **도구** |
| **필터 패널** | **필터 유형**, **필터**, **속성** |
| **레이어 패널** | **레이어** |
| **브러시 색상** | **색상** |

**주 메뉴**를 선택하면 메뉴가 열립니다(macOS에서는 메뉴가 시스템 메뉴 막대에 있습니다). **선택 영역** 버튼은 마지막으로 사용한 선택 도구로 전환합니다.

스케치 작업 영역에서는 확대/축소 배율이 표시되는 하단 표시줄이 숨겨져 있습니다. 하단 표시줄을 표시하려면 **창 > 제목 표시줄 사용자 지정…** 명령을 선택하고 **하단 표시줄 표시**를 켭니다.

## 페인팅

![일러스트 예제가 캔버스에 열린 페인팅 작업 영역.](shot:start/workspaces-paint "1 제목 표시줄 · 2 “명령” 도구 모음 · 3 “도구” 도구 모음 · 4 왼쪽 열 · 5 오른쪽 열 · 6 하단 표시줄")

페인팅 작업 영역은 캔버스 양쪽의 열에 패널을 도킹합니다.

1. **Capy(집중 모드)** 버튼과 메뉴, 가운데의 그림 제목, 그리고 작업 영역 전환기와 **환경 설정**. 웹 편집기에서는 **전체 화면**이 추가됩니다.
2. **새로 만들기…**, **열기…**, **저장**, **실행 취소**, **다시 실행**, **레이어 전체 지우기**, **선택 영역 채우기**, **변형**, **화면 좌우 반전**.
3. **펜**, **연필**, **페인트 브러시**, **지우개**, **에어브러시**, **장식**, **혼색**, **왜곡**, 선택 도구, **채우기**, **그레이디언트**, **작업**, **도형**, **자**, **손**, **스포이트**, **브러시 색상**.
4. **도구 세트**와 **진단**, **도구**와 **브러시 크기**, **색상**과 **팔레트** 탭.
5. **내비게이터**와 **교정**, **속성**과 **필터**, **레이어** 아이콘.
6. 확대/축소 및 회전 표시. [캔버스 보기](/ko/docs/start/canvas/)에서 설명합니다.

도구 버튼 모서리의 작은 삼각형은 도구 그룹을 나타냅니다. 이 버튼에는 그룹에서 마지막으로 사용한 도구가 표시됩니다.

페인팅 레이아웃을 변경하지 않았다면 페인팅 작업 영역을 불러올 때 오른쪽 열이 열립니다. 오른쪽 열을 닫으려면 **Esc** 키를 누르거나 강조 표시된 아이콘을 선택합니다.

## 사진

![테라리움 사진이 열린 사진 작업 영역.](shot:start/workspaces-photo "1 “명령” 도구 모음 · 2 도구 옵션 · 3 “도구” 도구 모음 · 4 오른쪽 열 · 5 패널 아이콘")

사진 작업 영역은 사진 편집용 패널을 오른쪽에 열어 둡니다. 제목 표시줄은 페인팅 작업 영역과 같습니다.

1. **새로 만들기…**, **열기…**, **저장**, **실행 취소**, **다시 실행**, **변형**.
2. 현재 도구의 설정인 **도구 옵션**.
3. **작업**, **자르기**, 선택 도구, **브러시**, **지우개**, **복제 도장**, **스팟 복구 브러시**, **혼색**, **왜곡**, **그레이디언트**, **손**, **스포이트**, **브러시 색상**.
4. **히스토그램**과 **파형**, **속성**과 **필터**, **레이어**.
5. **도구 세트**와 **진단**, **도구**와 **브러시 크기**, **내비게이터**와 **교정** 아이콘. 각 아이콘은 해당 그룹만 서랍으로 엽니다.

사진 작업 영역에서는 **색상**과 **팔레트**가 숨겨져 있습니다. **브러시 색상**으로 색을 고르거나 **창** 메뉴에서 패널을 표시합니다. 사진 작업 영역의 “도구” 도구 모음에는 **도형**과 **자**가 없습니다.

## 작업 영역 전환

창을 다른 작업 영역으로 전환할 수 있습니다. 그림과 화면 보기, 도구 설정은 바뀌지 않습니다.

![스케치, 페인팅, 사진과 옵션 버튼이 있는 작업 영역 전환기.](shot:start/workspaces-switcher)

다음 중 하나를 수행합니다.

- 제목 표시줄의 작업 영역 전환기에서 작업 영역을 선택합니다.
- **창 > 작업 영역**에서 작업 영역을 선택합니다.
- [명령 검색](/ko/docs/start/command-search/)에 작업 영역 이름을 입력합니다.

기본적으로 작업 영역을 전환하는 키는 지정되어 있지 않습니다.

전환기에서는 현재 작업 영역이 강조 표시됩니다. 제목 표시줄이 좁으면 전환기가 **작업 영역** 메뉴로 바뀝니다.

획을 긋거나 드래그하는 동안에는 전환할 수 없습니다. 다른 창에서 열려 있는 작업 영역으로도 전환할 수 없습니다.

## 작업 영역 옵션

전환기에 표시할 작업 영역을 고를 수 있습니다.

![작업 영역마다 확인란이 있고 작업 영역 관리… 항목이 있는 작업 영역 옵션 메뉴.](shot:start/workspaces-switcher-options)

**작업 영역 옵션** 메뉴를 열려면 다음 중 하나를 수행합니다.

- 전환기 오른쪽 끝의 **⋮** 버튼을 선택합니다.
- 전환기를 마우스 오른쪽 버튼으로 클릭하거나, 펜이나 손가락으로 길게 누릅니다.
- 전환기에 포커스가 있을 때 **Shift+F10** 키를 누릅니다(macOS와 iPad 제외).

작업 영역을 켜면 전환기에 표시됩니다. **작업 영역 관리…** 항목은 모든 작업 영역의 목록을 엽니다([작업 영역 관리](/ko/docs/customize/workspaces/) 참조).

전환기는 모든 작업 영역과 창에서 같은 작업 영역을 표시합니다. 새 작업 영역은 만들 때 전환기에 추가되고, 현재 작업 영역은 꺼져 있어도 표시됩니다.

## 작업 영역에 유지되는 항목

각 작업 영역은 레이아웃 변경 내용을 자동으로 저장합니다. 레이아웃을 저장하는 명령은 없습니다.

| 작업 영역마다 따로 유지 | 모든 작업 영역이 공유 |
| --- | --- |
| 패널, 열, 탭과 그 크기 | 열린 그림과 그 화면 보기 |
| 도구 모음과 그 도구 | 현재 도구와 모든 브러시의 설정 |
| 제목 표시줄 항목과 크기, **하단 표시줄 표시** | 색과 팔레트 |
| 집중 모드 | 선택 영역, 채우기, 그레이디언트 옵션 |
| 레이아웃 기록과 시작 레이아웃 | 환경 설정과 키보드 단축키 |

**스케치**, **페인팅**, **사진**은 이름을 바꾸거나 삭제할 수 없습니다. 이 작업 영역을 시작 레이아웃으로 되돌리려면 **창 > 작업 영역 > 시작 레이아웃 복원…** 메뉴를 선택합니다.
