{appName}은 기기의 그래픽 프로세서로 캔버스를 그리고 표시합니다. 지원 여부는 앱 또는 브라우저, 운영체제, 그래픽 하드웨어의 조합에 따라 달라집니다.

## 기본 앱

데스크톱 앱은 Windows, macOS, Linux를 지원합니다. 기본 iPad 앱은 iPadOS 17.5 이상이 필요합니다. Android 앱은 Android 12 이상이 필요합니다.

iPad 및 Android 앱은 베타 버전입니다. 운영체제 요구 사항을 충족해도 모든 그래픽 프로세서나 펜의 작동이 확인되는 것은 아닙니다.

## 웹 편집기

웹 편집기는 다음 브라우저에서 실행됩니다.

| 시스템 | 브라우저 |
| --- | --- |
| Windows | Chrome, Edge, Firefox 141 이상 |
| macOS | Chrome, Edge, Safari 26 이상, Apple silicon의 Firefox 147 이상 |
| Wayland를 사용하는 Linux | Chrome, Edge |
| iPadOS 26 이상 | Safari |
| Android 12 이상 | Chrome |

기본 iPad 앱의 최소 요구 사항인 iPadOS 17.5는 Safari에 적용되지 않습니다. 웹 편집기는 iPadOS 26에서 제공되는 브라우저 그래픽 기능을 사용하므로 iPadOS 26 이상이 필요합니다.

## 그래픽 지원

캔버스를 시작할 수 없으면 {appName}이 부족한 그래픽 기능을 설명하는 메시지를 표시합니다. 먼저 운영체제, 브라우저, 그래픽 드라이버를 업데이트합니다. 메시지가 계속 나타나면 문제를 보고할 때 메시지의 정확한 내용과 기기 및 그래픽 모델을 포함합니다.
