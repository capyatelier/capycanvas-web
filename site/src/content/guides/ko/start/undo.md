그림의 변경 내용을 한 단계씩 실행 취소하고, 취소한 단계를 다시 실행할 수 있습니다. 열려 있는 그림마다 기록이 따로 있습니다.

![“명령” 도구 모음의 실행 취소 버튼과 다시 실행 버튼.](shot:start/undo-commands)

## 실행 취소

다음 중 하나를 수행합니다.

- **편집 > 실행 취소**를 선택합니다.
- **Ctrl+Z** 키를 누릅니다.
- “명령” 도구 모음에서 **실행 취소**를 선택합니다. 스케치 작업 영역에서는 **실행 취소**가 화면 왼쪽 가장자리의 막대에 있습니다.
- 두 손가락으로 캔버스를 탭합니다.

## 다시 실행

다음 중 하나를 수행합니다.

- **편집 > 다시 실행**을 선택합니다.
- **Ctrl+Shift+Z** 또는 **Ctrl+Y** 키를 누릅니다.
- “명령” 도구 모음에서, 또는 스케치 작업 영역에서는 왼쪽 가장자리의 막대에서 **다시 실행**을 선택합니다.
- 세 손가락으로 캔버스를 탭합니다.

실행 취소한 뒤 새로 변경하면 다시 실행할 수 있던 단계가 지워집니다.

## 단계로 기록되는 작업

획, 채우기, 필터 변경, 변형, 자르기, 캔버스 크기 변경, 선택 영역 변경은 각각 한 단계이며, 레이어를 변경할 때마다 한 단계가 기록됩니다. 화면 보기, 도구, 브러시, 색, 레이아웃을 바꾸는 것은 단계로 기록되지 않습니다.

이미지를 배치하거나, 레이어를 변형하거나, 자르기 도구를 사용하는 동안에는 실행 취소가 이전 단계로 돌아가는 대신 해당 작업을 취소합니다.

## 기록 길이

그림마다 단계를 256개까지 유지합니다. 가장 오래된 단계부터 삭제됩니다.

## 저장과 다시 열기

저장해도 기록은 지워지지 않습니다. `.capy` 파일에서 연 그림은 빈 기록으로 시작하지만, {appName}를 다시 시작할 때 다시 열리는 그림은 실행 취소 단계를 유지합니다.

## 레이아웃 변경

패널, 도구 모음, 제목 표시줄, 작업 영역의 변경에는 별도의 기록이 있습니다. **편집 > 실행 취소**는 레이아웃 변경을 취소하지 않습니다.

다음 중 하나를 수행합니다.

- **창 > 레이아웃 변경 실행 취소** 또는 **창 > 레이아웃 변경 다시 실행**을 선택합니다.
- **Ctrl+Alt+Z** 또는 **Ctrl+Alt+Shift+Z** 키를 누릅니다.

작업 영역마다 레이아웃 기록이 따로 있으며, 이 기록은 다시 시작한 뒤에도 남습니다. **창 > 작업 영역 > 레이아웃 기록…** 메뉴는 현재 작업 영역의 이전 레이아웃을 나열합니다.
