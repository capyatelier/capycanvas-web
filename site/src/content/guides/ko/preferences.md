**환경 설정** 대화 상자에서 앱 전체에 적용되는 설정을 바꿀 수 있습니다. 변경 내용은 바로 적용되고 저장됩니다.

![모양 페이지가 열린 환경 설정 대화 상자.](shot:preferences/appearance)

## 환경 설정 열기

다음 중 하나를 수행합니다.

- **편집 > 환경 설정**을 선택합니다. macOS에서는 앱 메뉴에서 **Settings…** 항목을 선택합니다.
- **Ctrl+,** 키를 누릅니다.
- 페인팅과 사진 작업 영역에서는 제목 표시줄 오른쪽 끝의 톱니바퀴 버튼을 선택합니다.
- [명령 검색](/ko/docs/start/command-search/)에 “환경 설정”을 입력합니다.

환경 설정은 **모양** 페이지에서 열립니다. **도움말 > 키보드 단축키**를 선택하면 **키보드 단축키** 페이지에서, **도움말 > Capy Canvas 정보**를 선택하면 **앱 정보** 페이지에서 열립니다.

환경 설정이 열려 있는 동안에는 캔버스 단축키, 펜 버튼, 손가락 탭이 작동하지 않습니다.

## 환경 설정 검색

사이드바 맨 위의 **환경 설정 검색**을 선택하거나, 텍스트 필드 밖의 아무 곳에서나 입력을 시작합니다.

검색으로 키보드 단축키, 펜 버튼, 손가락 탭도 찾을 수 있습니다. 단축키를 선택하면 해당 단축키 편집기가 열립니다. 다른 언어에서도 영어 이름으로 검색할 수 있습니다.

![환경 설정 사이드바에서 “cursor”를 검색한 결과.](shot:preferences/search)

## 설정 초기화

웹과 Linux 앱에서는 설정을 마우스 오른쪽 버튼으로 클릭하거나 손가락이나 펜으로 길게 누른 다음 **기본값으로 재설정**을 선택합니다. 메뉴 항목에 기본값이 표시됩니다. 설정이 기본값이면 이 항목을 사용할 수 없습니다.

숫자 필드나 16진수 색 필드를 비워도 기본값으로 돌아갑니다.

![어두운 테마 기본 색상 설정의 기본값으로 재설정 메뉴.](shot:preferences/reset-menu)

## 모양

기본 색상과 강조 색상은 인터페이스만 바꾸며 그림은 바꾸지 않습니다.

### 언어

인터페이스의 언어를 설정합니다. 기본값은 **시스템 언어 사용**이며, 각 언어는 그 언어로 된 이름으로 나열됩니다.

### 색상 테마

**시스템**(기본값), **밝은 테마**, **어두운 테마** 중에서 고릅니다. 명령 검색의 **어두운 모드** 명령은 **밝은 테마**와 **어두운 테마** 사이를 전환합니다.

### 패널 투명도

패널과 표시줄 너머로 흐린 그림이 비치는 정도를 **끔**, **낮음**(기본값), **중간**, **높음** 중에서 설정합니다([패널과 열](/ko/docs/customize/panels/) 참조).

### 어두운 테마 기본 색상

어두운 테마에서 인터페이스의 회색을 설정합니다. 견본을 고르거나, **사용자 지정**을 선택해 6자리 16진수 색을 입력합니다.

### 밝은 테마 기본 색상

밝은 테마에서 인터페이스의 회색을 설정하며, 선택 항목은 같습니다.

### 강조 색상

**시스템**은 운영 체제의 강조 색상을 사용합니다. Linux, Windows, macOS, Android에서는 기본값이며, 웹과 iPad에서는 제공되지 않습니다. 그 밖의 선택 항목은 **파랑**(웹과 iPad의 기본값), **청록**, **초록**, **노랑**, **주황**, **빨강**, **분홍**, **보라**, **청회색**, **사용자 지정**입니다.

### 집중 모드에서 Capy 표시

[집중 모드](/ko/docs/customize/zen/)에서 Capy 버튼을 화면에 표시합니다. 기본적으로 켜져 있습니다.

### 화면 가장자리에서 패널 표시

집중 모드에서 포인터가 숨겨진 컨트롤이 있는 화면 가장자리 근처에 있는 동안 숨겨진 컨트롤을 표시합니다. 기본적으로 꺼져 있습니다.

### 버튼 아이콘

Capy 버튼의 그림을 **올려다보기**(기본값), **정면 바라보기**, **목욕하기**, **잠자기** 중에서 고릅니다.

## 캔버스

### 스크롤 이동 속도

마우스 휠, 트랙패드, 게임 컨트롤러의 왼쪽 스틱으로 캔버스가 스크롤되는 거리의 배율을 0.25 ×에서 4.00 ×까지 설정합니다(기본값 1.00 ×).

### 스크롤 확대/축소 속도

**Ctrl** 키와 마우스 휠, 또는 게임 컨트롤러의 오른쪽 스틱으로 확대/축소하는 배율을 0.25 ×에서 4.00 ×까지 설정합니다(기본값 1.00 ×).

### 새 그룹에 통과 모드 사용

새 그룹을 [통과](/ko/docs/layers/blend-modes/)로 설정합니다. 기본적으로 꺼져 있습니다. 기존 그룹은 바뀌지 않습니다.

## 색상

**새 그림** 설정은 이후에 [만드는 그림](/ko/docs/files/new/)에 적용됩니다. **사진 열기** 설정은 여는 사진에 적용됩니다.

![환경 설정의 색상 페이지.](shot:preferences/color)

### 색 공간

**sRGB**(기본값), **Display P3**, **Adobe RGB (1998)**, **ProPhoto RGB** 중에서 고릅니다.

### 비트 심도

**8비트 SDR**(기본값), **16비트 SDR**, **16비트 부동 소수점 HDR**, **32비트 부동 소수점 HDR** 중에서 고릅니다.

### 배경

**흰색**(기본값) 또는 **투명**을 고릅니다.

### 편집 정밀도

**원본 심도**(기본값)는 사진 자체의 비트 심도를 유지합니다. **16비트**는 8비트 사진을 16비트로 열며, 부동 소수점 사진은 부동 소수점으로 유지됩니다.

### 프로파일 없는 RGB 및 회색조

색상 프로파일이 없는 사진을 여는 방식을 **sRGB로 간주**(기본값) 또는 **묻기**로 설정합니다. 프로파일이 있는 사진은 그 프로파일을 유지합니다.

### 프로파일 관리…

색상 프로파일 라이브러리를 엽니다([색 공간, 비트 심도, 색상 합성](/ko/docs/color-management/color-spaces/) 참조).

## 펜 및 입력

이 페이지의 설정은 [펜](/ko/docs/input/pen/)과 [터치 제스처](/ko/docs/input/touch/)에서 설명합니다.

## 키보드 단축키

이 페이지의 키맵, 보조 키, 단축키는 [키보드 단축키](/ko/docs/input/keyboard/)에서 설명합니다.

## 앱 정보

**앱 정보** 페이지에는 **버전**, **앱 라이선스**, **캔버스 렌더링**, **웹사이트**, **소스 코드**, **헌정 대상** 행이 있습니다.

## 환경 설정이 저장되는 위치

기기마다 환경 설정이 따로 저장됩니다. 웹 앱에서는 환경 설정이 브라우저에 속하며 그 브라우저의 모든 탭이 공유합니다. 키, 보조 키, 펜 버튼, 손가락 탭을 다른 기기로 옮기려면 [키보드 단축키](/ko/docs/input/keyboard/) 페이지에서 키맵을 내보냅니다.
