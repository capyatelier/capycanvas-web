레이어나 보이는 이미지에서 픽셀을 복사해 새 레이어로 붙여넣을 수 있습니다. 명령은
**편집** 메뉴와 명령 검색에 있습니다.

![편집 메뉴의 클립보드 명령.](shot:transform/clipboard-edit-menu)

| 명령 | 키 |
| --- | --- |
| **잘라내기** | **Ctrl+X** |
| **복사** | **Ctrl+C** |
| **병합하여 복사** | **Ctrl+Shift+C** |
| **붙여넣기** | **Ctrl+V** |
| **제자리에 붙여넣기** | **Ctrl+Shift+V** |
| **선택 영역 안에 붙여넣기** | |

[선택 영역 표시줄](/ko/docs/selections/working/)의 **복사**에는 **복사**,
**병합하여 복사**, **잘라내기**가 있습니다.

## 복사

선택 영역 안에 있는 활성 레이어 자체의 픽셀을 복사합니다. 레이어의 불투명도, 마스크,
연결된 필터는 반영되지 않습니다. 선택 영역이 없으면 캔버스 안의 레이어 전체를
복사합니다.

## 잘라내기

**복사**와 같이 복사한 다음, 레이어에서 선택한 픽셀을 지웁니다. **투명도 잠금**이 켜진
레이어에서는 잘라낼 수 없습니다.

## 병합하여 복사

선택 영역 안의 보이는 이미지를 내보낼 때와 같은 모습으로 복사합니다.

## 복사할 수 없는 경우

그룹, 필터 레이어, 선택 영역 레이어에는 자체 픽셀이 없습니다. 그룹에서 복사하려면 그룹
안의 레이어를 선택합니다. 빠른 마스크에서는 그림을 복사할 수 없으며, 마스크를 편집하는
동안에는 **복사**와 **잘라내기**를 사용할 수 없습니다.

복사하는 양이 많으면 진행 상황 알림이 **취소**와 함께 표시됩니다.

## 붙여넣기

클립보드의 내용을 새 활성 레이어로 추가합니다.

- {appName}에서 복사한 내용은 복사한 위치가 화면에 보이면 그 위치에, 보이지 않으면 화면 가운데에 놓입니다.
- 다른 앱의 이미지는 변형 상자에 열립니다. **적용**은 이미지를 배치하고, **취소**는 붙여넣기를 취소합니다([이동과 변형](/ko/docs/transform/move-transform/) 참조).

## 제자리에 붙여넣기

클립보드의 내용을 변형 상자 없이 복사한 위치에 새 레이어로 추가합니다. 다른 앱의
이미지는 원래 크기로 화면 가운데에 놓입니다.

## 선택 영역 안에 붙여넣기

**제자리에 붙여넣기**와 같이 동작하며, 새 레이어에 선택 영역만 보여 주는
[마스크](/ko/docs/layers/masks/)를 추가합니다. 그다음 선택 영역은 사라집니다.
**선택 영역 안에 붙여넣기**는 선택 영역이 있어야 합니다.

## 앱 사이에서 붙여넣기

다른 앱은 {appName}에서 복사한 내용을 8비트 sRGB PNG 이미지로 받습니다. 클립보드에
그 내용이 남아 있는 동안 {appName}에 다시 붙여넣으면 원래 비트 심도 그대로
사용됩니다.

색 설정이 다른 그림에 붙여넣은 내용은 자체 색상 프로파일에서 변환된
[사진 레이어](/ko/docs/layers/types/)가 됩니다.

텍스트 필드에 입력하는 동안에는 클립보드 키가 텍스트를 잘라내고, 복사하고,
붙여넣습니다.

웹 편집기에서는 붙여넣는 이미지가 최대 512 MiB까지 가능합니다. 이미지를 붙여넣을 수
없는 브라우저에서는 대신 **파일 > 이미지를 레이어로 가져오기…** 명령을 선택합니다.
