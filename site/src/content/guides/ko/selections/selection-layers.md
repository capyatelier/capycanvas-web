선택 영역을 레이어 패널에 레이어로 보관해 두었다가 나중에 다시 불러올 수 있습니다.

## 선택 영역 저장

다음 중 하나를 수행합니다.

- **선택 영역 > 선택 영역 레이어로 저장**을 선택합니다.
- 선택 영역 표시줄이나 빠른 마스크 표시줄에서 **저장**을 선택합니다.
- 빠른 마스크에서 **레이어 > 선택 영역 레이어로 저장**을 선택합니다.

새 레이어는 레이어 목록 맨 위에 *선택 영역*과 번호로 된 이름으로 추가됩니다. 레이어는
편집 상태로 열리며, 이름을 바로 입력할 수 있습니다. 빠른 마스크에서 저장하면 빠른
마스크의 오버레이 색상과 불투명도도 함께 저장됩니다.

그룹 안에 저장하려면 그룹 메뉴를 열고 **현재 선택 영역을 그룹에 저장…** 명령을
선택합니다.

## 새 선택 영역 레이어

빈 선택 영역 레이어로 시작해 선택 영역을 칠할 수 있습니다.

다음 중 하나를 수행합니다.

- **선택 영역 > 새 선택 영역 레이어**를 선택합니다.
- 레이어 패널 아래쪽의 **새 선택 영역 레이어**를 선택합니다.
- 그룹 메뉴를 열고 **그룹에 새 선택 영역 레이어 만들기…** 명령을 선택합니다.

## 선택 영역 레이어 행

선택 영역 레이어의 행에는 선택 영역 썸네일, 오버레이를 표시하거나 숨기는 눈 버튼,
썸네일 옆의 불러오기 버튼이 있습니다.

행을 선택하면 레이어가 편집 상태로 열립니다. 선택 영역 레이어에는 불투명도, 혼합 모드,
마스크가 없으며, 병합할 수 없고 편집 상태가 아닐 때는 칠할 수 없습니다.

![레이어 패널의 선택 영역 레이어 행. 썸네일 옆에 불러오기 버튼이 있습니다.](shot:selections/selection-layer-row)

## 선택 영역 레이어 편집

선택 영역 레이어를 편집하는 동안에는 [빠른 마스크](/ko/docs/selections/quick-mask/)와
마찬가지로 브러시, **채우기**, **그레이디언트**가 저장된 선택 영역을 바꿉니다. 속성
패널에는 레이어의 **오버레이 색상**과 **오버레이 불투명도**, 그리고 공유되는 **모드**가
표시됩니다.

캔버스 아래쪽의 [캔버스 작업 표시줄](/ko/docs/selections/working/)에는 “*이름* 편집 중”이라는
제목이 붙습니다. 캔버스 작업 표시줄을 숨기면 이 표시줄도 나타나지 않습니다.

- **불러오기**는 레이어를 현재 선택 영역으로 만들고 그림으로 돌아갑니다.
- **반전**은 저장된 선택 영역을 반전하고 레이어를 편집 상태로 유지합니다.
- **그림으로 돌아가기**는 편집을 끝냅니다. **Escape** 키도 같은 동작을 합니다.

편집을 마치면 이전에 편집하던 레이어가 다시 활성 레이어가 되며, 그런 레이어가 없었으면
맨 위의 페인팅 레이어가 활성 레이어가 됩니다.

저장된 선택 영역을 다듬으려면 선택 영역 레이어의 메뉴를 열고 **수정**에서 명령을
선택합니다. **선택 영역 > 선택 영역 확대…** 등 **선택 영역** 메뉴의 다듬기 명령은 먼저
그림으로 돌아간 다음 현재 선택 영역을 바꿉니다.

![불러오기, 반전, 그림으로 돌아가기가 있는 선택 영역 레이어 편집용 캔버스 작업 표시줄.](shot:selections/selection-layer-bar)

## 선택 영역 레이어 불러오기

다음 중 하나를 수행합니다.

- **선택 영역 > 선택 영역 불러오기**를 선택하고 레이어를 고른 다음, **선택 영역 불러오기**, **선택 영역에 추가**, **선택 영역에서 빼기**, **선택 영역과 교차**, **반전한 선택 영역 불러오기** 중 하나를 선택합니다.
- 레이어 행의 불러오기 버튼을 선택합니다.
- **Ctrl** 키를 누른 채 레이어 썸네일을 클릭합니다. **Shift** 키를 함께 누르면 더하고, **Alt** 키를 누르면 빼고, **Shift+Alt** 키를 누르면 교차합니다.
- 레이어를 편집하는 동안 캔버스 작업 표시줄에서 **불러오기**를 선택합니다.

불러오면 먼저 그림으로 돌아갑니다. 선택 영역 레이어는 그대로 남습니다. 그룹 안의
레이어는 **선택 영역 불러오기** 아래에 *그룹 1 / 선택 영역 1*처럼 그룹 경로로
표시됩니다.

## 선택 영역 레이어 교체

현재 선택 영역을 기존 선택 영역 레이어에 저장하려면
**선택 영역 > 현재 선택 영역으로 선택 영역 레이어 교체**를 선택하고 레이어를 고릅니다.
잠긴 선택 영역 레이어는 교체할 수 없습니다.

## 선택 영역 레이어 메뉴

선택 영역 레이어의 행을 마우스 오른쪽 버튼으로 클릭하거나 길게 누르면 메뉴가 열립니다.

- **선택 영역 불러오기**: 선택 영역 메뉴에 있는 것과 같은 다섯 항목.
- **수정**: **현재 선택 영역으로 교체**, **반전**, **모두 선택**, **지우기**, **채우기**, **확대…**, **축소…**, **페더…**, **테두리…**, **매끄럽게…**.
- **정리**: **선택한 레이어 그룹화**, **최상위로 이동**, **위로 이동**, **아래로 이동**, **그룹으로 이동**.
- **이름 변경…**, **복제**, **삭제**, **편집 잠금**. 잠긴 레이어에서는 **편집 잠금**이 **편집 잠금 해제**로 표시됩니다.

잠긴 선택 영역 레이어에서는 **수정**을 사용할 수 없습니다. 여러 레이어를 선택한
상태에서는 메뉴에 **선택한 레이어 복제**와 **선택한 레이어 삭제**가 표시됩니다.
