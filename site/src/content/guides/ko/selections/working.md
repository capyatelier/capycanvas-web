선택 영역과 그 안의 픽셀은 **선택 영역** 메뉴와 캔버스의 선택 영역 표시줄에서 바꿀
수 있습니다.

## 캔버스 작업 표시줄

캔버스 작업 표시줄은 캔버스 위에 나타나는 버튼 줄로, 지금 편집하는 대상에 대한 다음
단계 버튼이 들어 있습니다.

| 캔버스 작업 표시줄이 나타나는 때 | 설명하는 곳 |
| --- | --- |
| 새 선택 영역 옆 | 아래의 선택 영역 표시줄 |
| **다각형 올가미** 선택 영역의 모서리를 찍는 동안 | [선택 도구](/ko/docs/selections/tools/) |
| 빠른 마스크에서 | [빠른 마스크](/ko/docs/selections/quick-mask/) |
| 선택 영역 레이어를 편집하는 동안 | [선택 영역 레이어](/ko/docs/selections/selection-layers/) |
| 레이어의 마스크를 편집하는 동안 | [마스크](/ko/docs/layers/masks/) |
| 레이어나 픽셀을 변형하거나 이미지를 배치하는 동안 | [이동과 변형](/ko/docs/transform/move-transform/) |
| 자르는 동안 | [자르기](/ko/docs/transform/crop/) |
| 안내선을 선택했을 때 | [자와 안내선](/ko/docs/drawing/ruler/) |
| 샘플 지점 원을 클릭했을 때 | [복제와 복구](/ko/docs/retouch/clone-heal/) |
| 레벨, 곡선, 화이트 밸런스의 샘플 지점을 고르는 동안 | [필터 추가와 편집](/ko/docs/filters/adding/) |

표시줄은 대상 옆이나 캔버스 아래쪽 가장자리에 나타납니다. 왼쪽부터 다음 항목이
있습니다.

- “빠른 마스크”나 “선택 영역 윤곽 변형” 같은 제목.
- 버튼. 흐리게 표시된 버튼은 사용할 수 없으며, 선택하면 이유가 표시됩니다.
- **더 보기**. 들어가지 못한 버튼이 있고, 그 아래에 선택 영역에서는 **선택 영역** 메뉴가, 마스크에서는 **레이어** 메뉴가 있습니다.
- **적용**이나 **종료**처럼 작업을 마치는 버튼.

대상 옆에 나타난 표시줄은 캔버스를 터치하거나 화면을 움직이는 동안 숨겨집니다.

캔버스 작업 표시줄을 숨기려면 다음 중 하나를 수행합니다.

- **보기 > 캔버스 작업 표시줄 표시**를 선택합니다.
- **더 보기** 맨 아래의 **캔버스 작업 표시줄 표시**를 선택합니다.

이 설정은 작업 영역마다 따로 저장됩니다. 표시줄을 숨겨도 자르기, 변형, 배치한 이미지,
다각형에서는 마치는 버튼이 캔버스 아래쪽 가장자리에 표시됩니다.

## 선택 영역 표시줄

선택 도구나 **작업** 도구가 활성 상태일 때 선택 영역 옆에 선택 영역 표시줄이
나타납니다. 다른 도구에서는 새 선택 영역 옆에 나타나지만, 실행 취소나 다시 실행으로
되살아난 선택 영역 옆에는 나타나지 않습니다. 브러시, 채우기 도구, **그레이디언트**,
**도형**에서는 표시줄이 나타나지 않습니다.

![사각형 선택 영역 아래의 선택 영역 표시줄.](shot:selections/working-selection-bar)

- **선택 해제**와 **반전**: 아래의 선택 영역 메뉴에서 설명합니다.
- **복사본 남기기**: **작업** 도구에만 있습니다([이동과 변형](/ko/docs/transform/move-transform/) 참조).
- **레이어로 복사**: **선택 영역을 새 레이어로 복사** 또는 **선택 영역을 새 레이어로 잘라내기**.
- **복사**: **복사**, **병합하여 복사**, **잘라내기**([복사와 붙여넣기](/ko/docs/transform/clipboard/) 참조).
- **변형**: 선택한 픽셀을 변형합니다.
- **다듬기**: 다듬기 명령과 **선택 영역 윤곽 변형**.
- **마스크**: 활성 레이어를 선택 영역으로 마스크합니다.
- **조정**: 선택 영역을 마스크로 쓰는 필터를 추가합니다([필터 적용 방식](/ko/docs/filters/how-filters-apply/) 참조).
- **채우기**: **선택 영역 채우기**.
- **지우기**: **선택한 픽셀 지우기** 또는 **선택 영역 밖 지우기**.
- **자르기**: **선택 영역에 맞춰 캔버스 자르기**([자르기](/ko/docs/transform/crop/) 참조).
- **빠른 마스크**: [빠른 마스크](/ko/docs/selections/quick-mask/)에서 설명합니다.
- **저장**: **선택 영역 레이어로 저장**([선택 영역 레이어](/ko/docs/selections/selection-layers/) 참조).

## 선택 영역 메뉴

**선택 영역** 메뉴는 선택 영역 표시줄의 **더 보기**에서, 그리고 도구 패널의 선택 도구
설정 아래에 있는 **선택 영역** 버튼에서도 열 수 있습니다.

| 명령 | 동작 | 키 |
| --- | --- | --- |
| **모든 픽셀 선택** | 캔버스 전체를 선택합니다 | **Ctrl+A** |
| **픽셀 선택 해제** | 선택 영역을 없애고, 빠른 마스크나 선택 영역 레이어 편집을 끝냅니다 | **Ctrl+D** |
| **다시 선택** | 마지막 변경으로 사라진 선택 영역을 되살립니다 | **Ctrl+Shift+D** |
| **선택 영역 반전** | 선택 영역 밖의 모든 부분을 선택합니다 | **Ctrl+Shift+I** |
| **선택 영역 윤곽 표시** | 선택 영역 윤곽을 표시하거나 숨깁니다 | |

**다시 선택**은 아무것도 선택되어 있지 않을 때만 사용할 수 있습니다.

선택 영역 윤곽을 숨겨도 선택 영역은 유지됩니다. **선택 영역 윤곽 표시**는 보기
메뉴에도 있습니다.

![선택 영역 메뉴.](shot:selections/working-select-menu)

## 선택 영역 다듬기

실시간 미리 보기를 보면서 선택 영역을 확대, 축소, 페더, 테두리, 매끄럽게 하기로 다듬을 수 있습니다.

다음 중 하나를 수행합니다.

- **선택 영역 > 선택 영역 확대…**, **선택 영역 축소…**, **선택 영역 페더…**, **선택 영역 테두리…**, **선택 영역 매끄럽게…** 중 하나를 선택합니다.
- 선택 영역 표시줄에서 **다듬기**를 선택하고 **확대…**, **축소…**, **페더…**, **테두리…**, **매끄럽게…** 중 하나를 선택합니다.

캔버스 아래쪽에 값 하나가 있는 패널이 열립니다. 결과를 적용하려면 **적용**을 선택하거나
**Enter** 키를 누릅니다. **취소**나 **Escape** 키는 원래 선택 영역으로 되돌립니다.

| 명령 | 값 | 범위 | 기본값 |
| --- | --- | --- | --- |
| **선택 영역 확대…** | **Grow by** | 1~128 px | 5 px |
| **선택 영역 축소…** | **Shrink by** | 1~128 px | 5 px |
| **선택 영역 페더…** | **Feather radius** | 0.1~100 px | 5 px |
| **선택 영역 테두리…** | **Border width** | 1~128 px | 5 px |
| **선택 영역 매끄럽게…** | **Smooth radius** | 1~64 px | 5 px |

**선택 영역 테두리…** 명령은 선택 영역을 가장자리를 따라 이어지는 띠로 바꿉니다.
매끄럽게 하기는 반경의 두 배보다 좁은 홈을 메우고 뾰족한 부분을 없애지만, 캔버스
테두리에 놓인 가장자리는 움직이지 않습니다. 확대와 축소는 부드러운 가장자리를 부드럽게
유지합니다.

빠른 마스크에서는 이 명령들이 마스크를 바꿉니다.

![선택 영역 표시줄의 다듬기 메뉴.](shot:selections/working-refine-menu)

## 선택 영역 윤곽 변형

픽셀은 움직이지 않고 선택 영역 윤곽만 이동, 크기 조절, 회전, 기울이기, 뒤집기를 할
수 있습니다.

다음 중 하나를 수행합니다.

- **선택 영역 > 선택 영역 윤곽 변형**을 선택합니다.
- 선택 영역 표시줄에서 **다듬기 > 선택 영역 윤곽 변형**을 선택합니다.

변형 상자가 “선택 영역 윤곽 변형”이라는 제목의 캔버스 작업 표시줄과 함께 나타납니다.
**자유 왜곡**, **뒤틀기**, **보간**을 쓸 수 없다는 점을 빼면
[변형](/ko/docs/transform/move-transform/)과 같은 방식으로 동작합니다.

## 채우기와 지우기

- **선택 영역 채우기**는 활성 페인팅 레이어에서 선택한 픽셀에 브러시의 불투명도로 현재 색을 채웁니다.
- **선택한 픽셀 지우기**는 활성 레이어에서 선택한 픽셀을 지웁니다. 부드러운 가장자리는 부분적으로 지워집니다.
- **선택 영역 밖 지우기**는 선택 영역 밖의 픽셀을 지웁니다.

다음 중 하나를 수행합니다.

- **편집** 메뉴에서 명령을 선택합니다. 지우기 명령은 **선택 영역** 메뉴에도 있습니다.
- 채우려면 **Shift+Backspace** 키를, 선택한 픽셀을 지우려면 **Delete** 또는 **Backspace** 키를 누릅니다.
- 선택 영역 표시줄에서 **채우기**를 선택하거나, **지우기**를 선택하고 명령을 고릅니다.
- 페인팅 작업 영역에서는 “명령” 도구 모음의 **선택 영역 채우기**를 선택합니다.
- 레이어 메뉴를 열고 **픽셀 선택 영역 > 선택 영역 채우기**를 선택합니다.

빠른 마스크, 마스크, **투명도 잠금**이 켜진 레이어에서는 픽셀을 지울 수 없습니다.

## 새 레이어로 복사

**선택 영역을 새 레이어로 복사**는 활성 페인팅 레이어에서 선택한 픽셀을 바로 위의 새
레이어에 같은 위치로 복사합니다. **선택 영역을 새 레이어로 잘라내기**는 원래
레이어에서 그 픽셀을 지우기도 합니다.

다음 중 하나를 수행합니다.

- **선택 영역 > 선택 영역을 새 레이어로 복사** 또는 **선택 영역 > 선택 영역을 새 레이어로 잘라내기**를 선택합니다.
- 복사하려면 **Ctrl+J** 키를, 잘라내려면 **Ctrl+Shift+J** 키를 누릅니다.
- 선택 영역 표시줄에서 **레이어로 복사**를 선택하고 명령을 고릅니다.

새 레이어의 이름은 원래 레이어의 이름을 따르며(예: *Ribbon 복사본*), 불투명도, 표시
여부, 혼합 모드를 그대로 유지합니다. 선택 영역은 **다시 선택**을 선택할 때까지
사라집니다.

선택 영역이 없으면 **선택 영역을 새 레이어로 복사**는 선택한 레이어를 복제합니다.

## 선택 영역으로 레이어 마스크하기

활성 레이어에 선택 영역만 보여 주는 마스크를 추가할 수 있습니다.

다음 중 하나를 수행합니다.

- 레이어 메뉴를 열고 **마스크 > 마스크: 선택 영역 표시**를 선택합니다. 선택한 영역을 숨기려면 **마스크 > 마스크: 선택 영역 숨기기**를 선택합니다.
- 선택 영역 표시줄에서 **마스크**를 선택합니다.

레이어에 이미 마스크가 있으면 선택 영역이 기존 마스크를 대체합니다. 선택 영역은
사라지고, 마스크가 편집 상태로 열립니다([마스크](/ko/docs/layers/masks/) 참조).

## 레이어로 선택 영역 만들기

레이어의 물감, 마스크, 또는 선택 영역 레이어를 선택 영역으로 불러올 수 있습니다.

다음 중 하나를 수행합니다.

- 페인팅 레이어에서는 **선택 영역 > 레이어 불투명도에서**의 항목 중 하나를 선택합니다. 항목은 **레이어 불투명도 선택**, **선택 영역에 불투명도 추가**, **선택 영역에서 불투명도 빼기**, **레이어 불투명도와 교차**입니다.
- 마스크가 있는 레이어에서는 **선택 영역 > 레이어 마스크에서**의 항목 중 하나를 선택합니다. 항목은 **마스크를 선택 영역으로 불러오기**, **선택 영역에 마스크 추가**, **선택 영역에서 마스크 빼기**, **마스크와 교차**입니다.
- 레이어 메뉴를 열고 **픽셀 선택 영역** 아래의 같은 항목을 선택합니다.
- **Ctrl** 키를 누른 채 레이어 패널에서 레이어의 썸네일을 클릭합니다. **Shift** 키를 함께 누르면 선택 영역에 더하고, **Alt** 키를 누르면 빼고, **Shift+Alt** 키를 누르면 교차합니다.

**선택 영역 > 선택 영역 불러오기**는 [선택 영역 레이어](/ko/docs/selections/selection-layers/)를
불러옵니다.
