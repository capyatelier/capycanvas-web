왜곡 필터는 **필터 > 왜곡**과 **필터** 패널의 **왜곡** 분류에 있습니다. 설정은
**속성** 패널에서 바꿉니다. 모든 왜곡 필터는 레이어의 투명한 영역으로 물감을 옮길
수 있습니다.

![왜곡 분류의 필터별 미리 보기가 표시된 필터 패널.](shot:filters/distort-list)

## 색수차

빨강 채널과 파랑 채널을 **각도** 방향으로 **분리 거리**만큼 서로 반대쪽으로 밀어
가장자리에 색 번짐을 더합니다.

| 설정 | 범위 또는 선택 항목 | 기본값 |
| --- | --- | --- |
| **분리 거리** | 0~32 px | 3 px |
| **각도** | −180°~180° | 0° |

## 만화경

이미지의 한 조각을 중심 주위의 **분할 수**만큼의 조각으로 반사해 복제합니다.

| 설정 | 범위 또는 선택 항목 | 기본값 |
| --- | --- | --- |
| **분할 수** | 2~24 | 6 |
| **각도** | −180°~180° | 0° |
| **중심 X**, **중심 Y**(**위치** 아래) | 캔버스 너비와 높이의 0~100% | 50% |

## 소용돌이

이미지를 중심 주위로 **비틀기**만큼 비틀며, **반경**에 이르면 비틀림이 사라집니다.

![비틀기, 반경, 위치 설정이 있는 소용돌이의 속성 패널.](shot:filters/swirl-properties)

| 설정 | 범위 또는 선택 항목 | 기본값 |
| --- | --- | --- |
| **비틀기** | −720°~720° | 120° |
| **반경** | 캔버스 짧은 변 절반의 1~150% | 70% |
| **중심 X**, **중심 Y**(**위치** 아래) | 캔버스 너비와 높이의 0~100% | 50% |

## 물결

이미지를 중심 주위의 고리 모양으로 최대 **진폭**만큼 움직이며, 고리 사이의 간격은
**파장**입니다. 고리는 시간에 따라 바깥쪽으로 퍼져 나갑니다.

| 설정 | 범위 또는 선택 항목 | 기본값 |
| --- | --- | --- |
| **진폭** | 0~48 px | 12 px |
| **파장** | 8~256 px | 64 px |
| **속도** | 0~4 | 0.5 |
| **중심 X**, **중심 Y**(**위치** 아래) | 캔버스 너비와 높이의 0~100% | 50% |
| **애니메이션 사용** | 켬 또는 끔 | 켬 |
| **고정 시간** | 0~3600 s | 0 s |

## 유리

**질감 크기**의 젖빛 유리 패턴으로 이미지를 최대 **왜곡**만큼 일그러뜨립니다.
**거칠기**는 더 미세한 패턴을 더합니다.

| 설정 | 범위 또는 선택 항목 | 기본값 |
| --- | --- | --- |
| **왜곡** | 0~48 px | 12 px |
| **질감 크기** | 4~160 px | 24 px |
| **거칠기** | 0~100% | 35% |

## 빗물 유리

시간에 따라 자국을 남기며 흘러내리는 빗방울을 더하고, 이미지를 최대 **굴절**만큼
굴절시킵니다. **비**는 빗방울의 수를 정합니다.

| 설정 | 범위 또는 선택 항목 | 기본값 |
| --- | --- | --- |
| **굴절** | 0~32 px | 8 px |
| **빗방울 크기** | 12~120 px | 48 px |
| **비** | 0~100% | 65% |
| **속도** | 0~4 | 0.5 |
| **애니메이션 사용** | 켬 또는 끔 | 켬 |
| **고정 시간** | 0~3600 s | 0 s |

## 아지랑이

이미지를 시간에 따라 일렁이게 합니다. 일렁임은 캔버스 아래쪽에서 최대 **왜곡**이고
위쪽에서는 없습니다. **세부 묘사**는 더 미세한 물결을 더합니다.

| 설정 | 범위 또는 선택 항목 | 기본값 |
| --- | --- | --- |
| **왜곡** | 0~48 px | 8 px |
| **물결 크기** | 10~240 px | 90 px |
| **속도** | 0~4 | 0.6 |
| **세부 묘사** | 0~100% | 50% |
| **애니메이션 사용** | 켬 또는 끔 | 켬 |
| **고정 시간** | 0~3600 s | 0 s |

## 패턴 왜곡

**패턴 크기**의 마블링 패턴으로 이미지를 최대 **왜곡**만큼 뒤틉니다. 패턴은 시간에
따라 흘러갑니다.

| 설정 | 범위 또는 선택 항목 | 기본값 |
| --- | --- | --- |
| **왜곡** | 0~64 px | 24 px |
| **패턴 크기** | 8~256 px | 96 px |
| **속도** | 0~4 | 0.25 |
| **애니메이션 사용** | 켬 또는 끔 | 켬 |
| **고정 시간** | 0~3600 s | 0 s |

## 애니메이션

**물결**, **빗물 유리**, **아지랑이**, **패턴 왜곡**은 애니메이션 필터이며, **필터**
패널의 해당 행에 애니메이션 표시가 있습니다. **애니메이션 사용**을 켜면 필터가
**속도**에 따라 계속 재생됩니다. **애니메이션 사용**을 끄면 필터가 **고정 시간**으로
정한 순간에 멈춥니다.

내보낸 이미지에는 내보낸 순간의 애니메이션이 담깁니다.
