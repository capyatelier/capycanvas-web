색상 필터는 **필터 > 색상**과 **필터** 패널의 **색상** 분류에 있습니다. 설정은
**속성** 패널에서 바꿉니다.

![색상 분류의 필터별 미리 보기가 표시된 필터 패널.](shot:filters/color-list)

## 색조 / 채도

**전체** 페이지에서는 이미지 전체의, **빨강 계열**부터 **마젠타 계열**까지의
페이지에서는 한 색 범위의 색조, 채도, 명도를 바꿉니다. **색상 입히기**는 모든 픽셀에
하나의 색조와 채도를 주고 명도는 유지합니다.

![빨강 계열 페이지를 표시한 색조 / 채도의 속성 패널.](shot:filters/hue-saturation-properties)

| 설정 | 범위 또는 선택 항목 | 기본값 |
| --- | --- | --- |
| **색조** | −180°~180°, **색상 입히기**에서는 0~360° | 0° |
| **채도** | −100%~100%, **색상 입히기**에서는 0~100% | 0%, **색상 입히기**에서는 25% |
| **명도** | −100%~100% | 0% |
| **중심** | 0~360°의 Oklab 색조. 색 범위 페이지에만 있습니다. | 빨강 계열 30°, 노랑 계열 110°, 초록 계열 145°, 시안 계열 195°, 파랑 계열 265°, 마젠타 계열 330° |
| **너비** | 0~180°. 색 범위 페이지에만 있습니다. | 30° |
| **페더** | 0~90°. 색 범위 페이지에만 있습니다. | 30° |
| **색상 입히기** | 켬 또는 끔. 켜져 있는 동안에는 **전체** 페이지만 남습니다. | 끔 |

## 반전

모든 색상 채널을 반전합니다. 설정은 없습니다.

## 채도 제거

각 색을 HSL 명도가 같은 회색으로 바꿉니다. 설정은 없습니다.

## 포토 필터

이미지를 **농도**만큼 **색상** 쪽으로 물들입니다.

| 설정 | 범위 또는 선택 항목 | 기본값 |
| --- | --- | --- |
| **색상** | 모든 색 | #FFB873 |
| **농도** | 0~100% | 25% |
| **광도 유지** | 켬 또는 끔 | 켬 |

## 선택 색상

페이지마다 한 색 범위의 시안, 마젠타, 노랑, 검정을 바꿉니다. **빨강 계열**부터
**마젠타 계열**까지는 채도가 높은 색에, **흰색 계열**, **중간색 계열**,
**검정 계열**은 회색에 가까운 톤에 작용합니다.

| 설정 | 범위 또는 선택 항목 | 기본값 |
| --- | --- | --- |
| **시안** | −100%~100% | 0% |
| **마젠타** | −100%~100% | 0% |
| **노랑** | −100%~100% | 0% |
| **검정** | −100%~100% | 0% |
| **방식** | **상대값**은 색에 이미 들어 있는 잉크 양에 비례해 변화량을 조절하고, **절대값**은 변화량을 그대로 더합니다. 모든 페이지에 적용됩니다. | **상대값** |

## 채널 믹서

**빨강**, **초록**, **파랑** 페이지에서 각 출력 채널을 빨강, 초록, 파랑 입력 채널의
혼합에 **상수**를 더해 만듭니다. **단색**을 켜면 **회색** 페이지만 남으며, 그
페이지의 혼합으로 회색조 이미지를 만듭니다.

| 설정 | 범위 또는 선택 항목 | 기본값 |
| --- | --- | --- |
| **빨강** | −200%~200% | **빨강** 페이지에서 100%, **회색**에서 21.26%, 그 밖에는 0% |
| **초록** | −200%~200% | **초록** 페이지에서 100%, **회색**에서 71.52%, 그 밖에는 0% |
| **파랑** | −200%~200% | **파랑** 페이지에서 100%, **회색**에서 7.22%, 그 밖에는 0% |
| **상수** | −100%~100% | 0% |
| **단색** | 켬 또는 끔 | 끔 |

## 색상 조회(LUT)

룩 메뉴(**따뜻하게**처럼 현재 룩이 표시됩니다)에서 고른 조회 테이블을 색에 적용하고,
**강도**만큼 원본과 섞습니다. 직접 만든 LUT를 사용하려면 룩 메뉴 옆의
**LUT 가져오기…** 버튼을 선택하고 16MB 이하의 3D `.cube` 파일을 엽니다.

![룩 메뉴와 LUT 가져오기…가 있는 색상 조회(LUT)의 속성 패널.](shot:filters/color-lookup)

| 설정 | 범위 또는 선택 항목 | 기본값 |
| --- | --- | --- |
| 룩 메뉴 | **원본**(변화 없음), **따뜻하게**, **차갑게**, **흑백**, 또는 제목으로 표시되는 가져온 LUT. 가져온 LUT는 그림에 저장됩니다. | **원본** |
| **LUT 색 공간** | **sRGB**, **Display P3**, **Adobe RGB (1998)**, **ProPhoto RGB**. 가져온 LUT가 전제하는 색 공간입니다. **원본**과 기본 제공 룩에서는 숨겨집니다. | **sRGB** |
| **강도** | 0~100% | 100% |

## 색상 균형

**어두운 영역**, **중간톤**, **밝은 영역** 페이지에서 색을 따로 이동합니다. 양수
값은 각 슬라이더 이름의 두 번째 색 쪽으로 이동합니다.

| 설정 | 범위 또는 선택 항목 | 기본값 |
| --- | --- | --- |
| **시안 — 빨강** | −100~100 | 0 |
| **마젠타 — 초록** | −100~100 | 0 |
| **노랑 — 파랑** | −100~100 | 0 |
| **광도 유지** | 켬 또는 끔. 모든 페이지에 적용됩니다. | 켬 |

## 생동감

**생동감**은 채도가 높은 색보다 탁한 색의 채도를 더 많이 올립니다. **채도**는 모든
색을 고르게 바꿉니다.

| 설정 | 범위 또는 선택 항목 | 기본값 |
| --- | --- | --- |
| **생동감** | −100%~100% | 0% |
| **채도** | −100%~100% | 0% |
| **피부 톤 보호** | 켬 또는 끔. 주황색과 피부색 색조에서 양수 **생동감**을 제한합니다. | 켬 |

## 흑백

이미지를 회색으로 변환하며, 색조별로 얼마나 밝아질지 정하는 슬라이더가 있습니다.
**색조 적용**은 결과에 **색조 색상**을 입힙니다.

| 설정 | 범위 또는 선택 항목 | 기본값 |
| --- | --- | --- |
| **빨강 계열** | −100%~200% | 40% |
| **노랑 계열** | −100%~200% | 60% |
| **초록 계열** | −100%~200% | 40% |
| **시안 계열** | −100%~200% | 60% |
| **파랑 계열** | −100%~200% | 20% |
| **마젠타 계열** | −100%~200% | 80% |
| **색조 적용** | 켬 또는 끔 | 끔 |
| **색조 색상** | 모든 색 | #BF874C |

## 그레이디언트 맵

이미지의 톤을 **그레이디언트**에 대응시킵니다. 가장 어두운 톤은 왼쪽 정지점에, 가장
밝은 톤은 오른쪽 정지점에 대응합니다. **양**은 결과를 원본과 섞습니다.

| 설정 | 범위 또는 선택 항목 | 기본값 |
| --- | --- | --- |
| **그레이디언트** | 모든 그레이디언트. [그레이디언트](/ko/docs/drawing/gradient/) 도구와 같은 방식으로 편집합니다. | 검정에서 흰색, **Oklab** 보간 |
| **양** | 0~100% | 100% |

## 화이트 밸런스

**색온도**로 이미지를 따뜻하거나 차갑게 하고, **색조**로 마젠타나 초록 쪽으로
이동합니다. **속성** 패널 맨 위의 **중성색 지점 선택**은 캔버스에서 클릭한 지점이
중성색이 되도록 두 값을 설정합니다.

| 설정 | 범위 또는 선택 항목 | 기본값 |
| --- | --- | --- |
| **색온도** | −100~100, 직접 입력하면 최대 ±1000. 양수 값일수록 따뜻해집니다. | 0 |
| **색조** | −100~100, 직접 입력하면 최대 ±800. 양수 값일수록 마젠타가 강해집니다. | 0 |
| **광도 유지** | 켬 또는 끔 | 켬 |

## 분할 톤

밝기를 유지하면서 어두운 부분은 **어두운 영역** 색 쪽으로, 밝은 부분은
**밝은 영역** 색 쪽으로 물들입니다.

| 설정 | 범위 또는 선택 항목 | 기본값 |
| --- | --- | --- |
| **어두운 영역** | 모든 색 | #295494 |
| **밝은 영역** | 모든 색 | #F5AD57 |
| **균형** | −100~100. 두 색이 만나는 지점을 옮깁니다. 양수 값일수록 이미지의 더 많은 부분이 **어두운 영역** 색을 띱니다. | 0 |
| **강도** | 0~100% | 30% |

## 솔라리제이션

각 색상 채널에서 **임계값**보다 밝은 부분을 반전합니다. **강도**는 결과를 원본과
섞습니다.

| 설정 | 범위 또는 선택 항목 | 기본값 |
| --- | --- | --- |
| **임계값** | 0~100% | 50% |
| **강도** | 0~100% | 100% |

## 무지갯빛

이미지의 밝기를 따라가며 시간에 따라 변하는 박막 무지개색을 더합니다. 내보낸
이미지에는 내보낸 순간의 색이 담깁니다.

| 설정 | 범위 또는 선택 항목 | 기본값 |
| --- | --- | --- |
| **강도** | 0~100% | 55% |
| **막 크기** | 8~240 px | 64 px |
| **속도** | 0~4 | 0.3 |
| **애니메이션 사용** | 켬 또는 끔. 켜져 있는 동안 색이 **속도**에 따라 계속 변합니다. | 켬 |
| **고정 시간** | 0~3600 s. **애니메이션 사용**이 꺼져 있을 때 표시되는 순간입니다. | 0 s |
