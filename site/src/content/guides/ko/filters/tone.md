톤 필터는 **필터 > 톤**과 **필터** 패널의 **톤** 분류에 있습니다. 설정은 **속성**
패널에서 바꿉니다.

![톤 분류의 필터별 미리 보기가 표시된 필터 패널.](shot:filters/tone-list)

## 어두운 영역/밝은 영역

주변 영역의 밝기를 기준으로 **어두운 영역**으로 어두운 부분을 끌어올리고
**밝은 영역**으로 밝은 부분을 끌어내립니다. 100%에서는 각각 노출을 최대 2스톱까지
바꿉니다.

| 설정 | 범위 또는 선택 항목 | 기본값 |
| --- | --- | --- |
| **어두운 영역** | 0~100% | 0% |
| **밝은 영역** | 0~100% | 0% |

## 곡선

**RGB** 페이지에서는 모든 채널에 대한 곡선 하나로, **빨강**, **초록**, **파랑**
페이지에서는 채널별 곡선으로 톤을 바꿉니다. 채널 곡선은 **RGB** 곡선보다 먼저
적용됩니다.

| 설정 | 범위 또는 선택 항목 | 기본값 |
| --- | --- | --- |
| **RGB**, **빨강**, **초록**, **파랑** 페이지 | 페이지마다 곡선 하나 | 직선 |
| **포인트 선택**, **이미지에서 조정** | 이미지에서 곡선을 설정합니다([필터 추가와 편집](/ko/docs/filters/adding/) 참조) | |
| **곡선 색 공간** | **인코딩된 RGB**, **로그 HDR**. [HDR 그림](/ko/docs/color-management/hdr/)에서나 **로그 HDR**로 설정되어 있을 때만 표시됩니다. | **인코딩된 RGB**, HDR 그림에서는 **로그 HDR** |
| **HDR 범위** | 0~15 EV, 직접 입력하면 최대 127 EV. **로그 HDR**에서만 표시되며, 곡선이 닿는 SDR 흰색 위의 스톱 수입니다. | 4 EV |

| 그래프에서 | 방법 |
| --- | --- |
| 포인트 추가 | 빈 곳을 누릅니다. 곡선 하나에 포인트를 최대 32개까지 둘 수 있습니다. |
| 포인트 이동 | 포인트를 드래그하거나, 선택한 다음 화살표 키를 누릅니다. **Shift** 키를 누르면 더 멀리 움직입니다. 끝점은 위아래로만 움직입니다. |
| 정확한 값 설정 | 포인트를 선택하고 그래프 아래의 **입력**과 **출력**에 값을 입력합니다. |
| 포인트 제거 | 포인트를 두 번 클릭하거나, 그래프 밖으로 드래그하거나, 선택한 다음 **Delete** 또는 **Backspace** 키를 누릅니다. |
| 처음부터 다시 | **곡선 초기화**를 선택합니다. |

## 레벨

입력의 검은 점, 흰 점, 중간톤을 설정한 다음 **출력** 범위에 대응시킵니다.
**빨강**, **초록**, **파랑** 페이지는 **RGB** 페이지보다 먼저 적용됩니다.

![히스토그램, 자동, 포인트 선택, 입력, 출력, 클리핑 설정이 있는 레벨의 속성 패널.](shot:filters/levels-properties)

| 설정 | 범위 또는 선택 항목 | 기본값 |
| --- | --- | --- |
| **자동**, **포인트 선택** | 이미지에서 입력을 설정합니다([필터 추가와 편집](/ko/docs/filters/adding/) 참조) | |
| **그림자**, **밝은 영역**(히스토그램 아래) | 캔버스에서 클리핑된 영역을 표시합니다 | |
| **검정**(**입력**) | 0~1, 직접 입력하면 제한 없음. 입력 **흰색**보다 낮게 유지됩니다. | 0 |
| **흰색**(**입력**) | 0~1, 직접 입력하면 제한 없음 | 1 |
| **중간톤** | 0.1~10. 1보다 크면 밝아집니다. | 1 |
| **검정**(**출력**) | 0~1, 직접 입력하면 제한 없음 | 0 |
| **흰색**(**출력**) | 0~1, 직접 입력하면 제한 없음 | 1 |
| **입력값 범위 제한** | 모든 페이지에서 입력 **검정**과 **흰색** 밖의 톤을 잘라 냅니다 | 끔 |
| **출력값 범위 제한** | 모든 페이지에서 결과를 출력 범위로 잘라 냅니다 | 끔 |

## 밝기 / 대비

**대비**는 중간 회색을 중심으로 톤을 넓히거나 좁히고, 그다음 **밝기**가 모든 톤을
같은 양만큼 밝히거나 어둡게 합니다.

| 설정 | 범위 또는 선택 항목 | 기본값 |
| --- | --- | --- |
| **밝기** | −100~100 | 0 |
| **대비** | −100~100. 50이면 대비가 두 배가 되고 −50이면 절반이 됩니다. | 0 |

## 임계값

**임계값**보다 어두운 픽셀은 검정으로, 나머지는 흰색으로 바꿉니다.

| 설정 | 범위 또는 선택 항목 | 기본값 |
| --- | --- | --- |
| **임계값** | 0~1, 직접 입력하면 제한 없음 | 0.5 |

## 노출

노출을 스톱 단위로 바꿉니다. **오프셋**은 검정을 올리거나 내립니다.

| 설정 | 범위 또는 선택 항목 | 기본값 |
| --- | --- | --- |
| **노출** | −10~10 EV, 직접 입력하면 최대 ±126 EV | 0 EV |
| **오프셋** | −0.5~0.5 | 0 |
| **감마** | 0.1~10. 1보다 크면 중간톤이 밝아집니다. | 1 |

## 비네팅

캔버스와 같은 비율의 타원 밖을 어둡게 하며, **강도**가 음수이면 밝게 합니다. ±100%에서는
가장자리가 최대 2스톱까지 바뀝니다.

| 설정 | 범위 또는 선택 항목 | 기본값 |
| --- | --- | --- |
| **강도** | −100%~100% | 40% |
| **반경** | 캔버스 크기 절반의 10~150% | 95% |
| **부드러움** | 반경 중 페이드에 쓰이는 비율 0~100% | 55% |
| **중심 X**, **중심 Y**(**위치** 아래) | 캔버스 너비와 높이의 0~100% | 50% |
