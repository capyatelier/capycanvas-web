ワークスペースは、タイトルバー、ツールバー、パネルの配置を保存したものです。Capy Canvasには**スケッチ**、**ペイント**、**写真**の3つが用意されています。初回は「ペイント」で開き、以降は前回使ったワークスペースで開きます。

## スケッチ

![イラストの作例をキャンバスに表示した「スケッチ」ワークスペース。](shot:start/workspaces-sketch "1 タイトルバーの左側 · 2 ワークスペース切り替え · 3 タイトルバーの右側 · 4 ブラシのコントロール")

「スケッチ」にはドッキングされたパネルがありません。タイトルバーのツールボタンとパネルボタンで、引き出しが開きます。

1. **Capy（集中モード）**、**メインメニュー**、**フィルターパネル**、**選択範囲**、**変形**。
2. ワークスペース切り替え。
3. **ブラシ**、**形を整える**、**消しゴム**、**レイヤーパネル**、**ブラシの色**。ウェブ版では**全画面表示**も加わります。
4. **ブラシサイズのスライダー**、**色の選択**、**ブラシの不透明度のスライダー**、**元に戻す**、**やり直す**。

| ボタン | 引き出しに表示されるパネル |
| --- | --- |
| **ブラシ** | **ブラシ**、**ツール**、**ツール** |
| **形を整える** | **形を整える**、**ツール**、**ツール** |
| **消しゴム**、**選択範囲** | **ツール**、**ツール** |
| **変形** | **ツールセット**、**ツール** |
| **フィルターパネル** | **フィルターの種類**、**フィルター**、**プロパティ** |
| **レイヤーパネル** | **レイヤー** |
| **ブラシの色** | **色** |

**メインメニュー**でメニューが開きます（macOSでは、メニューはシステムのメニューバーにあります）。**選択範囲**を選択すると、前回使った選択ツールに切り替わります。

「スケッチ」では、ズーム表示のあるフッターが非表示になっています。表示するには、**ウィンドウ > タイトルバーをカスタマイズ…** で**フッターを表示**をオンにします。

## ペイント

![イラストの作例をキャンバスに表示した「ペイント」ワークスペース。](shot:start/workspaces-paint "1 タイトルバー · 2 「コマンド」ツールバー · 3 「ツール」ツールバー · 4 左の列 · 5 右の列 · 6 フッター")

「ペイント」では、キャンバスの両側の列にパネルがドッキングされています。

1. **Capy（集中モード）** とメニュー、中央に作品のタイトル、続いてワークスペース切り替えと**設定**。ウェブ版では**全画面表示**も加わります。
2. **新規作成…**、**開く…**、**保存**、**元に戻す**、**やり直す**、**レイヤー全体を消去**、**選択範囲を塗りつぶす**、**変形**、**表示を左右反転**。
3. **ペン**、**鉛筆**、**絵筆**、**消しゴム**、**エアブラシ**、**装飾**、**混色**、**ゆがみ**、選択ツール、**塗りつぶし**、**グラデーション**、**操作**、**図形**、**定規**、**手のひら**、**スポイト**、**ブラシの色**。
4. **ツールセット**と**診断**、**ツール**と**ブラシサイズ**、**色**と**パレット**のタブ。
5. **ナビゲーター**と**校正表示**、**プロパティ**と**フィルター**、**レイヤー**のアイコン。
6. ズームと回転の表示（[キャンバスの表示](/ja/docs/start/canvas/)を参照）。

ツールボタンの隅にある小さな三角形は、ツールのグループを示します。ボタンには、そのグループで前回使ったツールが表示されます。

「ペイント」のレイアウトを変更していなければ、「ペイント」を読み込んだときに右の列が開きます。閉じるには、**Esc**を押すか、ハイライトされているアイコンを選択します。

## 写真

![テラリウムの写真を開いた「写真」ワークスペース。](shot:start/workspaces-photo "1 「コマンド」ツールバー · 2 ツールのオプション · 3 「ツール」ツールバー · 4 右の列 · 5 パネルのアイコン")

「写真」では、写真編集用のパネルが右側に開いたままになります。タイトルバーは「ペイント」と同じです。

1. **新規作成…**、**開く…**、**保存**、**元に戻す**、**やり直す**、**変形**。
2. **ツールのオプション**（現在のツールの設定）。
3. **操作**、**切り抜き**、選択ツール、**ブラシ**、**消しゴム**、**コピースタンプ**、**スポット修復ブラシ**、**混色**、**ゆがみ**、**グラデーション**、**手のひら**、**スポイト**、**ブラシの色**。
4. **ヒストグラム**と**波形**、**プロパティ**と**フィルター**、**レイヤー**。
5. **ツールセット**と**診断**、**ツール**と**ブラシサイズ**、**ナビゲーター**と**校正表示**のアイコン。アイコンを選択すると、そのグループだけが引き出しとして開きます。

「写真」では**色**と**パレット**が非表示です。色は**ブラシの色**で選ぶか、**ウィンドウ**メニューからパネルを表示します。**図形**と**定規**は、「写真」の「ツール」ツールバーにはありません。

## ワークスペースの切り替え

ウィンドウを別のワークスペースに切り替えられます。作品、その表示、ツールの設定は変わりません。

![スケッチ、ペイント、写真とオプションボタンがあるワークスペース切り替え。](shot:start/workspaces-switcher)

次のいずれかの操作を行います。

- タイトルバーのワークスペース切り替えで、ワークスペースを選択します。
- **ウィンドウ > ワークスペース**でワークスペースを選びます。
- [コマンド検索](/ja/docs/start/command-search/)でワークスペースの名前を入力します。

初期設定では、ワークスペースを切り替えるキーはありません。

現在のワークスペースは、切り替えの中でハイライトされます。タイトルバーの幅が狭いときは、切り替えが**ワークスペース**メニューになります。

ストロークやドラッグの途中には切り替えられません。別のウィンドウで開いているワークスペースにも切り替えられません。

## ワークスペースのオプション

切り替えに表示するワークスペースを選べます。

![ワークスペースごとのチェックボックスと「ワークスペースを管理…」がある、ワークスペースのオプションメニュー。](shot:start/workspaces-switcher-options)

**ワークスペースのオプション**メニューを開くには、次のいずれかの操作を行います。

- 切り替えの右端にある **⋮** を選択します。
- 切り替えを右クリックするか、ペンまたは指で長押しします。
- 切り替えにフォーカスがある状態で**Shift+F10**を押します（macOSとiPadを除く）。

ワークスペースをオンにすると、切り替えに表示されます。**ワークスペースを管理…** を選択すると、すべてのワークスペースの一覧が開きます（[ワークスペースの管理](/ja/docs/customize/workspaces/)を参照）。

切り替えに表示されるワークスペースは、どのワークスペースとウィンドウでも同じです。新しいワークスペースは作成した時点で追加されます。現在のワークスペースは、オフにしていても表示されます。

## ワークスペースが保持する内容

各ワークスペースは、レイアウトの変更を自動で保存します。レイアウトを保存するコマンドはありません。

| ワークスペースごとに保持 | すべてのワークスペースで共通 |
| --- | --- |
| パネル、列、タブとそのサイズ | 開いている作品とその表示 |
| ツールバーとそのツール | 現在のツールと、すべてのブラシの設定 |
| タイトルバーの項目とサイズ、**フッターを表示** | 色とパレット |
| 集中モード | 選択範囲、塗りつぶし、グラデーションのオプション |
| レイアウト履歴と開始時のレイアウト | 環境設定とキーボードショートカット |

**スケッチ**、**ペイント**、**写真**は、名前の変更も削除もできません。開始時のレイアウトに戻すには、**ウィンドウ > ワークスペース > 開始時のレイアウトに戻す…** を選びます。
