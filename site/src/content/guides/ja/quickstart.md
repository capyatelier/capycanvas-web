## {appName}を開く

次のいずれかの操作を行います。

- [editor.capycanvas.art](https://editor.capycanvas.art/)でウェブ版を開きます。
- [ダウンロード](/ja/download/)ページで、デスクトップアプリかiPad版またはAndroid版のベータを入手するか、ウェブ版をアプリとしてインストールする手順を確認します。

ウェブ版は次のブラウザーで動作します。

| システム | ブラウザー |
| --- | --- |
| Windows | Chrome、Edge、Firefox 141以降 |
| macOS | Chrome、Edge、Safari 26以降、Firefox 147以降（Appleシリコン） |
| Linux（Wayland） | Chrome、Edge |
| iPadOS 26以降 | Safari |
| Android 12以降 | Chrome |

一度アクセスすると、以降はインターネットに接続していなくてもウェブ版が開きます。

## 最初の作品

![新しい作品のレイヤーパネル。用紙の上に現在のインクがあります。](shot:files/new-layers)

{appName}を初めて開くと、[「ペイント」](/ja/docs/start/workspaces/)ワークスペースに白紙の作品が表示され、タイトルバーには「無題 · 2048 × 1536」と表示されます。白い塗りつぶしレイヤー**用紙**の上で、空のペイントレイヤー**現在のインク**が選択されています。ツールは**ペン**で、ブラシは**Gペン**、色は黒に近い色です。

2回目以降は、前回使ったワークスペースと、開いていた作品で{appName}が開きます。

## 描画

ペンまたはマウスでキャンバス上をドラッグします。別のツールを使うには、ウィンドウ左端の「ツール」ツールバーでツールを選択します。「スケッチ」では、タイトルバーの**ブラシ**を選択します。

> **メモ：** 指では描画できません。キャンバスに2本の指を置くと、表示の移動、ズーム、回転ができます。

ストロークを取り消すには、**編集 > 元に戻す**を選ぶか、**Ctrl+Z**を押すか、キャンバスを2本の指でタップします（[元に戻す・やり直す](/ja/docs/start/undo/)を参照）。

## macOSとiPadでのキー

このマニュアルでは、キーをWindowsとLinuxの表記で示します。macOSとiPadでは、**Ctrl**と書かれている箇所で**Command**（⌘）を押します。ウェブ版とmacOSアプリでは**Ctrl**も使えます。

ウェブ版では、すべてのショートカットが**Ctrl**で表示されます。**F5**、**F11**、**F12**、および**Ctrl**または**Ctrl+Shift**と**W**、**T**、**N**、**R**、**L**、**Q**、**P**の組み合わせは、ブラウザーが使用します。これらのキーを使うコマンドには、ウェブ版ではキーが割り当てられていません。メニューか[コマンド検索](/ja/docs/start/command-search/)から選びます。

## 別の作品を始める

**ファイル > 新規作成…** を選び、[新規作品](/ja/docs/files/new/)ダイアログで**作成**を選択します。新しい作品は、最初の作品の隣に専用のタブで開きます。

## 作品の保存

![新規作成…、開く…、保存、別名で保存…、書き出し…がある「ファイル」メニュー。](shot:files/file-menu)

作品をすべてのレイヤーごと保存するには：

1. **ファイル > 保存**を選ぶか、**Ctrl+S**を押します。
2. フォルダーと名前を選びます。名前の候補は「無題.capy」です。

保存後は、タイトルバーにファイル名が表示されます。FirefoxとSafariでは、**ファイルをダウンロード**ダイアログで**ダウンロード**を選択し、続けて**ファイルを保存しました**を選択するまで、作品は保存済みになりません。

## PNGの書き出し

![用途がWeb / 共有に設定された「画像を書き出す」ダイアログ。](shot:files/export-dialog)

作品を統合したPNGのコピーとして書き出すには：

1. **ファイル > 書き出し…** を選ぶか、**Ctrl+Shift+E**を押します。
2. **用途**は**Web / 共有**のままにして、**ファイルを選択…** を選びます。
3. フォルダーと名前を選びます。名前の候補は「無題.png」です。

**Web / 共有**では、作品の元のサイズのまま、8ビットsRGBのPNGが書き出されます。書き出しによって作品が変更されたり保存されたりすることはありません。
