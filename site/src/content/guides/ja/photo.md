[「写真」](/ja/docs/start/workspaces/)ワークスペースで、1枚の写真を3つの段階で編集します。自分の写真を使ってください。作例は、黒い背景の前にある、溶岩石とシダの入ったテラリウムの写真です。

![「写真」ワークスペース。キャンバスに編集したテラリウムの写真、レイヤーパネルにそのレイヤーが表示されています。](shot:photo/overview)

## 「写真」ワークスペース

タイトルバーのワークスペース切り替えで、**写真**を選択します。このチュートリアルでは、ワークスペースの次の部分を使います。

- 左側の「ツール」ツールバー。**切り抜き**、選択ツール、修復ツールがあります。
- 上部の**ツールのオプション**。現在のツールの設定があります。
- 右の列の**プロパティ**パネルと**レイヤー**パネル。

## 段階

1. [開いて切り抜く](/ja/docs/photo/crop/)：写真を開き、5:4に切り抜きます。
2. [レタッチ](/ja/docs/photo/retouch/)：写真の上のレイヤーで、ほこりと汚れを取り除きます。
3. [調整と書き出し](/ja/docs/photo/adjust/)：**トーンカーブ**、**自然な彩度**、部分的な**シャドウ／ハイライト**をかけ、`.capy`ファイルとWeb用のJPEGを保存します。

## 完成したレイヤー

編集した写真には、上から順に次のレイヤーがあります。

| レイヤー | 内容 |
| --- | --- |
| **シャドウ／ハイライト** | 岩のシャドウを持ち上げます。ぼかした選択範囲でマスク |
| **自然な彩度** | 写真全体の自然な彩度を上げます |
| **トーンカーブ** | 写真全体へのS字カーブ |
| *Retouch* | 修復のストローク |
| 写真レイヤー | 写真。名前はファイル名に基づきます |
| **用紙** | 非表示 |

写真レイヤーには何も描きません。

最初の段階：[開いて切り抜く](/ja/docs/photo/crop/)。
