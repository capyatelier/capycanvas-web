選択ツールで、作品の一部を選択できます。ツールの設定はツールパネルにあり、「写真」ではウィンドウ上部の「ツールのオプション」バーにもあります。

| ツール | 選択する範囲 | キー |
| --- | --- | --- |
| **長方形選択** | ドラッグした長方形 | |
| **楕円選択** | ドラッグした楕円 | |
| **投げなわ選択** | フリーハンドで描いた形 | **M** |
| **多角形選択** | 角を1つずつクリックした形 | |
| **自動選択** | 似た色のつながった範囲 | **W** |
| **色で選択** | 似た色のすべての画素（つながっているかどうかは問いません） | |
| **選択範囲を描く** | 描いた範囲 | |
| **階調範囲** | 一定の明るさの帯に含まれる画素（[明るさで選択](/ja/docs/selections/tonal-range/)を参照） | |

## 選択ツールを選ぶ

次のいずれかの操作を行います。

- [コマンド検索](/ja/docs/start/command-search/)にツールの名前を入力します。
- **M**を押すと**投げなわ選択**、**W**を押すと**自動選択**になります。
- 「ペイント」では、「ツール」ツールバーで**選択範囲**または**自動選択 / 色で選択**を選択します。
- 「写真」では、「ツール」ツールバーで**長方形選択 / 楕円選択**、**投げなわ選択 / 多角形選択**、**自動選択 / 色で選択**、**選択範囲を描く**のいずれかを選択します。
- 「スケッチ」では、タイトルバーの**選択範囲**を選択します。もう一度選択すると、ツールパネルの横に、すべての選択ツールがある引き出しが開きます。

複数のツールをまとめたツールバーのボタンには、最後に使ったツールが表示されます。ほかのツールを選ぶには、ボタンを右クリックまたは長押しするか、**ツールセット**パネルでツールを選択します。「スケッチ」のタイトルバーの**選択範囲**を選ぶと、最後に使った選択ツールに戻ります。

**階調範囲**には、「ペイント」と「写真」のツールバーにボタンがありません。

クイックマスク中や選択範囲レイヤーの編集中に選択ツールを選んでも、そのモードはオンのままです。

![「スケッチ」の選択範囲の引き出し。長方形選択のツールパネルの横に、選択ツールが並んでいます。](shot:selections/tools-sketch-select-drawer)

## モード

次に選択する範囲を、現在の選択範囲と組み合わせられます。

ツールパネルの**モード**の行で、**新しい選択範囲**、**選択範囲に追加**、**選択範囲から削除**、**選択範囲の共通部分**のいずれかを選択します。初期設定は**新しい選択範囲**です。

1回の選択だけモードを変えるには、選択を始めるときに次のキーを押したままにします。

- **Shift**：**選択範囲に追加**
- **Alt**：**選択範囲から削除**
- **Shift+Alt**：**選択範囲の共通部分**
- **Ctrl**：**新しい選択範囲**

キーを押している間は、**モード**の行に、そのキーで選ばれるモードが表示されます。**選択範囲を描く**にあるのは、**選択範囲に追加**と**選択範囲から削除**だけです。

## アンチエイリアスとぼかし半径

**アンチエイリアス**は、初期設定でオンです。**ぼかし半径**は、新しい選択範囲の縁を最大100 pxまでぼかします。初期値は0です。

**選択範囲を描く**には、どちらの設定もありません。**階調範囲**には**ぼかし**があり、**アンチエイリアス**はありません。

## 長方形選択と楕円選択

角から反対側の角までドラッグします。ドラッグを始めた後、**Shift**を押したままにすると正方形または円、**Alt**を押したままにすると中心から描けます。

- **縦横比を固定**は、選択範囲を**比率の幅**と**比率の高さ**で設定した比率に保ちます。初期設定は1 : 1です。
- **サイズを固定**は、設定した**幅**と**高さ**（ピクセル単位）の選択範囲を作ります。初期設定は256 × 256です。
- **中心から描く**は、ドラッグを始めた位置を選択範囲の中心にします。

**縦横比を固定**をオンにすると**サイズを固定**はオフになり、その逆も同じです。ドラッグせずにクリックしただけでは、選択範囲は変わりません。

## 投げなわ選択

範囲を囲むように描きます。ペンを離すかマウスボタンを放すと、閉じた形が選択範囲になります。

## 多角形選択

形の角を1つずつクリックします。終えるには、次のいずれかの操作を行います。

- 最初の角をもう一度クリックします。
- **Enter**を押します。
- キャンバス操作バーの**確定**、またはツールパネルの**選択範囲を確定**を選択します。

多角形には、少なくとも3つの角が必要です。

- 最後の角を削除するには、**Backspace**または**Delete**を押すか、キャンバス操作バーの**点を削除**またはツールパネルの**最後の点を削除**を選択します。
- 多角形をキャンセルするには、**Escape**を押すか、キャンバス操作バーの**キャンセル**またはツールパネルの**選択範囲をキャンセル**を選択します。
- 次の辺を45°単位に揃えるには、**Shift**を押したままにします。すべての辺を揃えるには、ツールパネルで**辺の角度を45°単位に制限**をオンにします。

角を置いている間は、キャンバス下部の[キャンバス操作バー](/ja/docs/selections/working/)に**点を削除**、**キャンセル**、**確定**が表示されます。

![多角形用のキャンバス操作バー。点を削除、キャンセル、確定があります。](shot:selections/tools-polygon-bar)

## 自動選択と色で選択

キャンバス上の色をクリックします。**自動選択**はその点の周りのつながった範囲を、**色で選択**は画像内のどこにあっても一致する画素を選択します。

![自動選択のツールパネル。モード、アンチエイリアス、参照対象、許容差、縁の設定、ぼかし半径があります。](shot:selections/tools-auto-select-settings)

### 参照対象

ツールが色を調べる対象を設定します。**表示中の作品**（初期設定）、**編集中のレイヤー**、**参照レイヤー**（[参照に使用](/ja/docs/layers/settings/)を指定したレイヤー）から選びます。

### 許容差

クリックした色からどれだけ離れた色まで選択するかを設定します。初期値は10%です。

### 隙間を閉じる

範囲を囲む縁にある、この幅までの隙間を閉じます（0から32 pxまで）。**自動選択**のみ。

### 拡張

選択範囲を最大32 px広げます。負の値では縮めます。

### 縁の滑らかさ

選択範囲の縁の段差を滑らかにします。0%では、縁はピクセル単位に沿います。**アンチエイリアス**がオフの間は表示されません。

**自動選択**と**色で選択**は**参照対象**の設定を共有し、**許容差**と**縁**の設定は[塗りつぶしツール](/ja/docs/drawing/fill/)とも共有します。

## 選択範囲を描く

丸いブラシで範囲を塗ります。閉じた輪を描くと、内側も塗りつぶされます。

- **選択範囲に追加**または**選択範囲から削除**で、ブラシの働きを設定します。
- **筆圧でサイズを変える**は、初期設定でオフです。
- **サイズ**、**硬さ**、**不透明度**で、丸いブラシを設定します。

描きながら**Shift**を押したままにすると追加、**Alt**を押したままにすると現在の設定と逆の操作になります。ペンの消しゴム側で描くと削除になります。選択範囲がないときは、削除のストロークは何もしません。

## 選択範囲ボタン

ツールパネルで選択ツールの設定の下にある**選択範囲**は、[選択範囲メニュー](/ja/docs/selections/working/)を開きます。**階調範囲**の設定には、**選択範囲**ボタンはありません。
