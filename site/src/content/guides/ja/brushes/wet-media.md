**ツール**パネルで、水気のあるブラシや混色するブラシの絵の具の扱いを設定できます。各グループは、そのセクションで挙げたブラシにだけ表示されます。

![ウェット水彩のツールパネルの下部。混色、水彩、にじみ、合成のグループがあります。](shot:brushes/wet-media-settings)

## 混色

**混色**は、油彩のブラシ、**不透明ガッシュ**、水彩ブラシ、すべての混色ブラシに表示されます。**平均して取り込む**、**色の持続**、**筆圧で補充**は、油彩のブラシ、**不透明ガッシュ**、**ウェット混色**、**色混ぜ**にだけ表示されます。

### 絵の具の量

ブラシが含む自分の色の量を設定します。水彩ブラシでは顔料の強さも設定します。値を小さくすると、レイヤーから取り込んだ色が優勢になります。

### 色の取り込み

ブラシがレイヤーから取り込んだ色を、ストロークに沿ってどこまで引きずるかを設定します。

### 希釈

ブラシが含む絵の具を薄めます。値を大きくすると、混ざった色の中でブラシ自身の色が弱くなります。

### 平均して取り込む

ブラシ先端全体で取り込んだ色を、どこまで1色に混ぜるかを設定します。0%では、先端の各部分が自分の色を保ちます。

### 色の持続

平均した色をストロークに沿ってどこまで持ち運ぶかを設定します。**平均して取り込む**が0%を超えているときだけ表示されます。

### 筆圧で補充

強く押したときに、選択した色がブラシにどれだけ補充されるかを設定します。**混色筆**は強く押すと自分の色を置き、軽いタッチのときだけ混色します。

## 色混ぜ

それぞれの混色ブラシは、**色混ぜ**グループに設定を加えます。**広がり**は**ツール**パネルの一番上にあります。

| 設定 | 混色ブラシ | 設定内容 |
| --- | --- | --- |
| **広がり** | **混色ナイフ**と**マーブリング**以外のすべて | ストロークの各点の周りで、混色ブラシが色を集める範囲。 |
| **筋** | **指先**、**ソフト混色**、**擦筆**、**ティッシュ**、**自然な混色**、**筆跡混色**、**混色ナイフ** | ストロークがその方向に沿って筋に分かれる度合い。 |
| **シャープさ** | **シャープ** | ストロークが加えるコントラストの量。 |
| **質感の保持** | **質感を保つ混色** | ストロークの下にある細かいテクスチャが、混ぜた色の上に残る度合い。 |
| **細部の大きさ** | **質感を保つ混色** | 残すテクスチャの大きさ。 |
| **明るさも混ぜる** | **色相混色** | 色相と彩度に加えて、明るさも混ざる度合い。 |
| **粒立ち** | **散らし混色** | 散らした各ピクセルが、下のピクセルを置き換える度合い。 |
| **引き伸ばし** | **絵画風混色**、**結晶混色** | パッチまたはセルがストロークに沿って伸びる長さ。 |
| **セルの大きさ** | **結晶混色** | セルの大きさ。 |
| **渦** | **マーブリング** | 絵の具が渦を巻く強さ。 |
| **渦の大きさ** | **マーブリング** | 渦の大きさ。 |
| **輪郭の保持** | **くし混色** | 色と色の境界で、混色が止まりやすい度合い。 |

## 水彩

**水彩ウォッシュ**と**ウェット水彩**には、絵の具がたまる部分にできる濃い縁を調整する**水彩**グループがあります。水彩は、同じレイヤー上の絵の具にだけ反応します。**縁の強さ**は**ツール**パネルの一番上、グループの上にあります。

### 縁の強さ

縁の濃さを設定します。

### 縁の幅

縁の幅を0から32 pxまでの範囲で設定します。

## にじみ

2つの水彩ブラシの**にじみ**グループでは、水と顔料がストロークの周りの紙にどう広がるかを設定します。絵の具が広がるのはストロークの間だけで、ペンを離した後は広がりません。

### 湿ったにじみ

すでに濡れている紙に絵の具が広がる速さを設定します。

### 乾いたにじみ

乾いた紙に絵の具が広がる速さを設定します。

### にじみの距離

各ダブから絵の具が広がる距離の上限を、0から96 pxまでの範囲で設定します。

### 水の量

各ダブが紙に置く水の量を設定します。**ツール**パネルの一番上、グループの上にあります。

## 混色の方法

混色するブラシが、取り込んだ色をどう混ぜるかを選べます。

次のいずれかの操作を行います。

- **ツール**パネルの**混色**から、**Oklabで混色**、**リニアライトで混色**、**クラシック混色**のいずれかを選びます。
- 「ツールのオプション」バーの**その他のツールオプション**を開き、「ツール」の引き出しで**混色**を選びます（[サイズ、強さ、不透明度](/ja/docs/brushes/basics/)）。
- 選択肢の名前でコマンドを検索します。

| 選択肢 | 混ぜ方 |
| --- | --- |
| **Oklabで混色** | 取り込んだ色を、目に見えるとおりに均等に混ぜます。 |
| **リニアライトで混色** | 取り込んだ色を、光が混ざるように混ぜます。 |
| **クラシック混色** | 作品に保存されている色の値をそのまま混ぜます。 |

内蔵の混色ブラシは、すべて**Oklabで混色**に設定されています。選択はブラシと一緒に保存され、作品の**色の合成**の設定では変わりません。混色しないブラシでは、これらの選択肢は使用できません。

![Oklabで混色を表示した混色の設定。](shot:brushes/color-mixing-menu)

## 筆毛

**筆毛**グループは**硬毛ブラシ**にだけ表示されます。このブラシは、描画色と背景色のうちもう一方の色を筋状に混ぜ込み、厚く盛り上がった絵の具の跡を作ります。

### 毛の模様の大きさ

毛の跡の大きさを、ブラシサイズに対する割合で設定します。スライダーは25%から200%までで、400%までの値を入力できます。

### 絵の具の量

各ストロークの開始時にブラシが含む絵の具の量を設定します。
