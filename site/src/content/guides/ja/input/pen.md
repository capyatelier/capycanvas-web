ペンの設定は、**編集 > 環境設定**の**ペンと入力**ページにあります。

![環境設定の「ペンと入力」ページ。](shot:pen/pen-and-input)

## 筆圧の応答

**ペンの応答**の**筆圧の応答**で、弱い筆圧に対するペンの反応を変更できます。値を小さくすると弱い筆圧が強く反映され、値を大きくするとより強い力が必要になります。範囲は0.25 ×から4.00 ×までです。初期値の1.00 ×では、ペンの筆圧がそのまま使われます。

この設定は、**選択範囲を描く**と**クイックマスク**を含む、すべてのブラシとツールに適用されます。描画済みのストロークは変わりません。

## ストローク予測

ストローク予測では、ペン先より少し先までストロークが描かれ、描き進めると実際のストロークに置き換わります。設定は**ペンの応答**にあります。

- **ストローク予測を有効にする**は、両方の種類の予測をまとめてオンまたはオフにします。
- ***システム*のストローク予測を使用**（例：**Windowsのストローク予測を使用**）は、システムまたはブラウザーの予測を使います。
- **予測量**は、{appName}独自の予測をどこまで先まで行うかを、0から64 msまでの範囲で設定します。

初期設定では両方のスイッチがオンで、**予測量**は16 msです。**ストローク予測を有効にする**がオフの間は、ほかの2つの設定は使用できません。

| システム | システムの予測 |
| --- | --- |
| iPad | 使用可能 |
| Windows | Windowsが提供している場合に使用可能 |
| Android | Android 14以降で、システムが対応しているスタイラスを使う場合 |
| ウェブ | 予測を提供しているブラウザーで使用可能 |
| macOS、Linux | 使用不可 |

システムの予測を使えない環境では、そのスイッチは使用できず、**予測量**で予測を設定します。システムの予測を使っている間は、**予測量**は使用できません（iPadでは表示されません）。

カーソルは、予測されたストロークではなくペンに追従します。

![「ペンの応答」の設定。](shot:pen/prediction)

## カーソルの形

**ポインター**の**カーソルの形**で、キャンバス上に表示するポインターを選べます。

| 選択肢 | 表示 |
| --- | --- |
| **ブラシサイズ** | ブラシ先端の輪郭を、そのサイズ、形、回転で表示（初期設定） |
| **十字**、**三角** | 十字または小さな三角 |
| **点** | ごく小さな十字 |
| **1ピクセルの点** | 画面の1ピクセル |
| **照準** | 中心に点がある十字 |
| **ツール** | ツールのアイコン。ツールの作用点がポインターの位置に来ます |
| **ツールとブラシサイズ**、**ブラシサイズと十字**、**ブラシサイズと点**、**ブラシサイズと1ピクセルの点** | ブラシの輪郭と、もう一方の印 |
| **なし** | ディスプレイ上のペンでは何も表示しません。マウス、トラックパッド、画面のないタブレットでは**照準**が表示されます。 |

この形は、描画ツールと**選択範囲を描く**に適用されます。その他のツールでは、形に**ツール**が含まれる場合はツールのアイコンが、それ以外の場合は十字が表示されます。

![「カーソルの形」の一覧。](shot:pen/cursor-shapes)

## 描画中はカーソルを隠す

**描画中はカーソルを隠す**がオン（初期設定）の場合、描画ツールでペンがキャンバスに触れている間や、マウスボタンを押している間は、カーソルが消えます。消去中は、ブラシの輪郭が表示されたままです。

## ペンの消しゴム側

ペンの消しゴム側の動作を選べます。**ペンの消しゴム側**グループはiPadには表示されません。

- **ツール**：**現在のツール**（初期設定）では、使用中のツールのままです。**消しゴム**、**ペン**、**鉛筆**、**絵筆**、**エアブラシ**、**混色**では、消しゴム側を使っている間はそのツールに切り替わり、使い終わると前のツールに戻ります。
- **透明色で描画**：オン（初期設定）のときは、消しゴム側でツールのブラシを使って消去します。オフのときは、消しゴム側で描画します。**ツール**が**消しゴム**の間は、このスイッチは表示されません。

## ペンボタン

ペンのサイドボタンごとに操作を割り当てられます。ツールの種類ごとに別の操作を割り当てることもできます。

ペンボタンを設定するには：

1. **ペンボタン**でボタンを選択します。
2. **操作**を選択するか、**すべてのツールで共通**をオフにして、**描画のツール**などのツールの種類を選択します。
3. 操作を選びます。**なし**を選ぶと、ボタンの割り当てが解除されます。

**表示を移動**や**色を取得**などのツール、ブラシ、モードは、ボタンを押している間だけ有効です。その他の操作は1回実行されます。ストロークの途中でボタンを押した場合は、ストロークの後で有効になります。

どのボタンも初期設定は**なし**です。**なし**に設定したボタンでは、タブレットドライバーやシステムが割り当てた動作がそのまま使われます。

| システム | 表示されるボタン |
| --- | --- |
| Linux | **下のサイドボタン**、**上のサイドボタン**、**3つ目のサイドボタン** |
| Windows | **下のサイドボタン** |
| macOS、Android、ウェブ | **下のサイドボタン**、**上のサイドボタン** |
| iPad | なし |

LinuxとAndroidでは、タブレットのパッドにあるボタンは、[キーボードショートカット](/ja/docs/input/keyboard/)ページでキーとして設定します。

![下のサイドボタンのページ。ツールの種類ごとに操作が設定されています。](shot:pen/pen-button-page)

## Apple Pencilのダブルタップとスクイーズ

iPadでは、Apple Pencilのダブルタップと、Apple Pencil Proのスクイーズは、iPad本体の**設定 > Apple Pencil**の設定に従います。

- 「現在使用中のツールと消しゴムを切り替える」では、**消しゴム**との間で切り替わります。
- 「現在使用中のツールと最後に使用したツールを切り替える」では、その前に選んでいたツールに切り替わります。

その他の選択肢は、{appName}では何もしません。スクイーズは、握る力を緩めたときに動作します。Apple Pencilを画面の上にかざすと、カーソルが表示されます。
