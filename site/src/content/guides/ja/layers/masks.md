マスクを使って、レイヤーの一部を隠せます。マスクに描いた部分ではレイヤーが表示され、何も描いていない部分では隠れます。マスクを持てるのは、ペイントレイヤー、写真レイヤー、グループ、塗りつぶしレイヤー、フィルターです。

## マスクの追加

次のいずれかの操作を行います。

- **レイヤー > マスク > マスクを追加**を選びます。
- レイヤーパネル下部の**マスクを追加**を選択します。

![Ribbonの行。マスクのサムネイルが枠で囲まれています。](shot:layers/masks-row)

レイヤーのサムネイルの右にマスクのサムネイルが表示され、ブラシの描画先であることを示す枠で囲まれます。新しいマスクは、レイヤー全体を表示します。選択範囲があるときは、マスクは選択範囲だけを表示し、選択範囲は解除されます。

レイヤーにすでにマスクがあるときは、**マスクを追加**でそのマスクが描画先として選択されます。選択範囲レイヤーとロックされたレイヤーには、マスクを追加できません。

## マスクに描く

マスクのサムネイルを選択すると、マスクに描けます。レイヤーに描く状態に戻るには、レイヤーのサムネイルを選択するか、**Escape**を押します。

> **メモ：** マスク上では、ブラシは描画色を無視します。ブラシで描くとレイヤーが表示され、**消しゴム**で消すと隠れます。

反転したマスクでは、ブラシと**消しゴム**の役割が入れ替わります。マスクへのストロークはドライで、混色、にじみ、テクスチャはありません。

## マスク編集バー

マスクに描いている間は、キャンバスの下部に「*レイヤー名*」のマスクを編集中と書かれたバーが表示されます。

![反転、無効にする、マスクを適用、その他、内容を編集のボタンがあるマスク編集バー。](shot:layers/masks-bar)

- **反転**
- **無効にする**はマスクをオフにします。オフにすると、ボタンは**有効にする**になります。
- **マスクを適用**は、マスクで隠れている画素を消してから、マスクを削除します。
- **その他**には、**レイヤー**メニューと**キャンバス操作バーを表示**があります。バーを隠すには、**キャンバス操作バーを表示**をオフにします。
- **内容を編集**で、レイヤーに描く状態に戻ります。

## 選択範囲からマスクを作る

現在の選択範囲からマスクを作れます。

次のいずれかの操作を行います。

- **レイヤー > マスク > マスク：選択範囲を表示**または**マスク：選択範囲を隠す**を選びます。マスクのあるレイヤーでは、項目が**マスクを置換：選択範囲を表示**と**マスクを置換：選択範囲を隠す**になります。
- キャンバス上の[選択範囲バー](/ja/docs/selections/working/)で**マスク**を選択します。新しいマスクは選択範囲を表示し、レイヤーにあったマスクと置き換わります。

選択範囲があるときに追加したフィルターや塗りつぶしレイヤーには、選択範囲からマスクが作られます。**選択範囲内に貼り付け**は、選択範囲でマスクした新しいレイヤーを作成します（[コピーと貼り付け](/ja/docs/transform/clipboard/)を参照）。

## マスクから選択範囲を作る

マスクを選択範囲として読み込めます。

次のいずれかの操作を行います。

- **選択範囲 > レイヤーマスクから**を選び、**マスクを選択範囲として読み込む**、**マスクを選択範囲に追加**、**選択範囲からマスクを削除**、**マスクとの共通範囲**のいずれかを選びます。
- マスクのメニューの**ピクセルの選択範囲**から、同じ項目を選びます。
- マスクのサムネイルを**Ctrl**+クリックします。**Shift**を加えると選択範囲に追加、**Alt**を加えると選択範囲から削除、**Shift+Alt**を加えると選択範囲との共通範囲になります。

## マスクのメニュー

次のいずれかの操作を行います。

- **レイヤー > マスク**を選びます（最初の項目は**マスクを編集**になります）。
- マスクのサムネイルを右クリックまたは長押しします。
- マスクに描いている間に、**レイヤー**メニューを開くか、レイヤーパネル下部の**レイヤー操作**を選択します。

マスクのないレイヤーでは、**レイヤー > マスク**にあるのは**マスクを追加**、**マスク：選択範囲を表示**、**マスク：選択範囲を隠す**、**マスクを貼り付け**だけです。

![Ribbonのマスクのメニュー。](shot:layers/masks-menu)

| 項目 | 機能 |
| --- | --- |
| **レイヤーの内容を編集** | レイヤーに描く状態に戻ります。 |
| **マスク領域を表示** | キャンバスにマスクを表示し、マスクを描画先として選択します。 |
| **マスクを有効にする** | マスクを変更せずに、オンまたはオフにします。無効なマスクは、サムネイルが薄く表示されます。 |
| **マスクをレイヤーにリンク** | オンのときは、マスクがレイヤーと一緒に動きます。オフのときは、**レイヤー／マスクを移動**で、レイヤーとマスクのうち描画先になっているほうが動きます。サムネイルの間のリンクボタンも同じ働きをします。 |
| **マスクを置換：選択範囲を表示**、**マスクを置換：選択範囲を隠す** | マスクを選択範囲で置き換えます。 |
| **マスクをコピー** | マスクをコピーします。ほかのレイヤーの**コピーしたマスクで置換**、またはマスクのないレイヤーの**マスクを貼り付け**で使います。 |
| **マスクを反転** | 表示する部分と隠す部分を入れ替えます。 |
| **すべて表示**、**すべて隠す** | マスクでレイヤー全体を表示または非表示にし、反転をオフにします。 |
| **マスクをレイヤーに適用** | マスクで隠れている画素を消してから、マスクを削除します。 |
| **マスクを削除** | マスクを削除します。レイヤーの画素は変わりません。 |
| **ピクセルの選択範囲** | マスクを選択範囲として読み込みます。 |

**レイヤーの内容を編集**、**マスク領域を表示**、**マスクをコピー**以外の項目は、ロックされていないレイヤーでのみ使えます。

## マスクの適用

次のいずれかの操作を行います。

- **レイヤー > マスク > マスクをレイヤーに適用**を選びます。
- マスク編集バーの**マスクを適用**を選択します。

**マスクをレイヤーに適用**はペイントレイヤーでのみ使え、マスクが有効である必要があります。自由なゆがみやメッシュ変形をかけたレイヤーでは、先に**変形をピクセルに適用**を選びます。グループのマスクを適用するには、**グループを結合**を使います（[レイヤーの結合](/ja/docs/layers/merging/)を参照）。

写真レイヤーでは、**元の写真に戻す**で、適用したマスクで消えた部分が戻ります。

## フィルターと塗りつぶしレイヤーのマスク

フィルターのマスクは、フィルターがかかる範囲を決めます。フィルターや塗りつぶしレイヤーを選択しているときは、ブラシは常にそのマスクに描きます。**塗りつぶし**、**グラデーション**など絵柄を描くツールは、フィルターのマスクでは使えません。塗りつぶしレイヤーに描くには、マスクが必要です。
