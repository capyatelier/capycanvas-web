階調のフィルターは、**フィルター > 階調**と、**フィルター**パネルの**階調**カテゴリーにあります。設定は**プロパティ**パネルで変更します。

![階調カテゴリーを表示したフィルターパネル。各フィルターのプレビューがあります。](shot:filters/tone-list)

## シャドウ／ハイライト

周囲の明るさをもとに、**シャドウ**で暗い部分を持ち上げ、**ハイライト**で明るい部分を抑えます。100%では、それぞれ露出を最大2段変えます。

| 設定 | 範囲または選択肢 | 初期値 |
| --- | --- | --- |
| **シャドウ** | 0–100% | 0% |
| **ハイライト** | 0–100% | 0% |

## トーンカーブ

**RGB**ページの全チャンネル共通のカーブと、**赤**、**緑**、**青**の各ページのチャンネルごとのカーブで、階調を変えます。チャンネルごとのカーブは、**RGB**のカーブより先に適用されます。

| 設定 | 範囲または選択肢 | 初期値 |
| --- | --- | --- |
| **RGB**、**赤**、**緑**、**青**のページ | それぞれ1本のカーブ | 直線 |
| **ポイントを指定**、**画像上で調整** | 画像からカーブを設定します（[フィルターの追加と編集](/ja/docs/filters/adding/)を参照） | |
| **カーブの色空間** | **符号化RGB**、**対数HDR**。[HDRの作品](/ja/docs/color-management/hdr/)のとき、または**対数HDR**に設定しているときだけ表示されます。 | **符号化RGB**（HDRの作品では**対数HDR**） |
| **HDRの範囲** | 0–15 EV（数値入力では最大127 EV）。**対数HDR**のときだけ表示されます。カーブが届く、SDRの白より上の段数です。 | 4 EV |

| グラフでの操作 | 方法 |
| --- | --- |
| 点を追加 | 何もない場所を押します。1本のカーブに置ける点は最大32個です。 |
| 点を移動 | ドラッグするか、点を選択して矢印キーを押します。**Shift**を押すと大きく動きます。端点は上下にのみ動きます。 |
| 正確な値を設定 | 点を選択し、グラフの下の**入力**と**出力**に値を入力します。 |
| 点を削除 | ダブルクリックするか、グラフの外にドラッグするか、点を選択して**Delete**または**Backspace**を押します。 |
| 最初からやり直す | **カーブをリセット**を選択します。 |

## レベル補正

入力の黒点、白点、中間調を設定し、**出力**の範囲に割り当てます。**赤**、**緑**、**青**のページは、**RGB**ページより先に適用されます。

![レベル補正のプロパティパネル。ヒストグラム、自動、ポイントを指定と、入力、出力、値の制限の設定があります。](shot:filters/levels-properties)

| 設定 | 範囲または選択肢 | 初期値 |
| --- | --- | --- |
| **自動**、**ポイントを指定** | 画像から入力を設定します（[フィルターの追加と編集](/ja/docs/filters/adding/)を参照） | |
| **シャドウ**、**ハイライト**（ヒストグラムの下） | キャンバス上で、黒つぶれや白飛びしている部分に印を付けます | |
| **黒**（**入力**） | 0–1（数値入力では任意の値）。入力の**白**より小さい値に保たれます。 | 0 |
| **白**（**入力**） | 0–1（数値入力では任意の値） | 1 |
| **中間調** | 0.1–10。1より大きいと明るくなります。 | 1 |
| **黒**（**出力**） | 0–1（数値入力では任意の値） | 0 |
| **白**（**出力**） | 0–1（数値入力では任意の値） | 1 |
| **入力を制限** | すべてのページで、入力の**黒**と**白**の外側の階調をクリップします | オフ |
| **出力を制限** | すべてのページで、結果を出力の範囲にクリップします | オフ |

## 明るさ／コントラスト

**コントラスト**は中間グレーを中心に階調を広げたり狭めたりし、そのあと**明るさ**ですべての階調を同じ量だけ明るく、または暗くします。

| 設定 | 範囲または選択肢 | 初期値 |
| --- | --- | --- |
| **明るさ** | −100〜100 | 0 |
| **コントラスト** | −100〜100。50でコントラストが2倍、−50で半分になります。 | 0 |

## しきい値

**しきい値**より暗い画素を黒に、それ以外を白にします。

| 設定 | 範囲または選択肢 | 初期値 |
| --- | --- | --- |
| **しきい値** | 0–1（数値入力では任意の値） | 0.5 |

## 露光量

露出を段数で変えます。**オフセット**は、黒を持ち上げたり下げたりします。

| 設定 | 範囲または選択肢 | 初期値 |
| --- | --- | --- |
| **露光量** | −10〜10 EV（数値入力では最大±126 EV） | 0 EV |
| **オフセット** | −0.5〜0.5 | 0 |
| **ガンマ** | 0.1–10。1より大きいと中間調が明るくなります。 | 1 |

## 周辺光量補正

キャンバスと同じ縦横比の楕円の外側を暗くします。**強さ**が負の値のときは明るくします。±100%では、周辺部が最大2段変わります。

| 設定 | 範囲または選択肢 | 初期値 |
| --- | --- | --- |
| **強さ** | −100%〜100% | 40% |
| **半径** | キャンバスのサイズの半分に対する10–150% | 95% |
| **柔らかさ** | 半径のうちフェードに使う割合（0–100%） | 55% |
| **中心X**、**中心Y**（**位置**の下） | キャンバスの幅と高さに対する0–100% | 50% |
