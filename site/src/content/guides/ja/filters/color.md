色のフィルターは、**フィルター > 色**と、**フィルター**パネルの**色**カテゴリーにあります。設定は**プロパティ**パネルで変更します。

![色カテゴリーを表示したフィルターパネル。各フィルターのプレビューがあります。](shot:filters/color-list)

## 色相／彩度

**全体**ページでは画像全体の、**レッド**から**マゼンタ**までのページでは1つの色域の、色相、彩度、明度を変えます。**着色**は、すべての画素の明度を保ったまま、1つの色相と彩度にします。

![レッドのページを表示した色相／彩度のプロパティパネル。](shot:filters/hue-saturation-properties)

| 設定 | 範囲または選択肢 | 初期値 |
| --- | --- | --- |
| **色相** | −180°〜180°（**着色**では0–360°） | 0° |
| **彩度** | −100%〜100%（**着色**では0–100%） | 0%（**着色**では25%） |
| **明度** | −100%〜100% | 0% |
| **中心** | Oklabの色相で0–360°。色のページのみ。 | レッド 30°、イエロー 110°、グリーン 145°、シアン 195°、ブルー 265°、マゼンタ 330° |
| **幅** | 0–180°。色のページのみ。 | 30° |
| **ぼかし** | 0–90°。色のページのみ。 | 30° |
| **着色** | オンまたはオフ。オンの間は、**全体**ページだけになります。 | オフ |

## 階調の反転

すべてのカラーチャンネルを反転します。設定はありません。

## 彩度を下げる

各色を、HSLの明度が同じ灰色に置き換えます。設定はありません。

## レンズフィルター

画像を**色**の方向に、**適用量**の分だけ色付けします。

| 設定 | 範囲または選択肢 | 初期値 |
| --- | --- | --- |
| **色** | 任意の色 | #FFB873 |
| **適用量** | 0–100% | 25% |
| **明るさを保持** | オンまたはオフ | オン |

## 特定色域の補正

ページごとに1つの色域で、シアン、マゼンタ、イエロー、ブラックの量を変えます。**レッド**から**マゼンタ**までは彩度の高い色に、**ホワイト系**、**中間色系**、**ブラック系**は灰色に近い階調に作用します。

| 設定 | 範囲または選択肢 | 初期値 |
| --- | --- | --- |
| **シアン** | −100%〜100% | 0% |
| **マゼンタ** | −100%〜100% | 0% |
| **黄色** | −100%〜100% | 0% |
| **黒** | −100%〜100% | 0% |
| **補正方法** | **相対値**は、色にすでに含まれるインクの量に比例して変化させます。**絶対値**は、変化量をそのまま加えます。すべてのページに適用されます。 | **相対値** |

## チャンネルミキサー

**赤**、**緑**、**青**の各ページで、入力の赤、緑、青のチャンネルと**定数**を混ぜて、出力の各チャンネルを作ります。**モノクロ**をオンにすると**灰色**ページだけになり、その混合でグレーの画像を作ります。

| 設定 | 範囲または選択肢 | 初期値 |
| --- | --- | --- |
| **赤** | −200%〜200% | **赤**ページでは100%、**灰色**では21.26%、それ以外は0% |
| **緑** | −200%〜200% | **緑**ページでは100%、**灰色**では71.52%、それ以外は0% |
| **青** | −200%〜200% | **青**ページでは100%、**灰色**では7.22%、それ以外は0% |
| **定数** | −100%〜100% | 0% |
| **モノクロ** | オンまたはオフ | オフ |

## カラールックアップ（LUT）

ルックのメニュー（**暖色**など、現在のルックが表示されます）のルックアップテーブルを色に適用し、**強度**に応じて元の色と混ぜます。自分のLUTを使うには、ルックのメニューの隣の**LUTを読み込む…** を選択し、16 MBまでの3D `.cube`ファイルを開きます。

![ルックのメニューとLUTを読み込む…があるカラールックアップ（LUT）のプロパティパネル。](shot:filters/color-lookup)

| 設定 | 範囲または選択肢 | 初期値 |
| --- | --- | --- |
| ルックのメニュー | **元の色**（変化なし）、**暖色**、**寒色**、**モノクロ**、または読み込んだLUT（タイトルで表示）。読み込んだLUTは作品に保存されます。 | **元の色** |
| **LUTの色空間** | **sRGB**、**Display P3**、**Adobe RGB (1998)**、**ProPhoto RGB**：読み込んだLUTが前提とする色空間です。**元の色**と内蔵のルックでは表示されません。 | **sRGB** |
| **強度** | 0–100% | 100% |

## カラーバランス

**シャドウ**、**中間調**、**ハイライト**の各ページで、色を個別にずらします。正の値にすると、各スライダーのラベルの2番目の色に近づきます。

| 設定 | 範囲または選択肢 | 初期値 |
| --- | --- | --- |
| **シアン — レッド** | −100〜100 | 0 |
| **マゼンタ — グリーン** | −100〜100 | 0 |
| **イエロー — ブルー** | −100〜100 | 0 |
| **明るさを保持** | オンまたはオフ（すべてのページ共通） | オン |

## 自然な彩度

**自然な彩度**は、くすんだ色の彩度を、鮮やかな色より大きく上げます。**彩度**は、すべての色を均等に変えます。

| 設定 | 範囲または選択肢 | 初期値 |
| --- | --- | --- |
| **自然な彩度** | −100%〜100% | 0% |
| **彩度** | −100%〜100% | 0% |
| **肌の色を保護** | オンまたはオフ。オレンジや肌の色相で、正の**自然な彩度**を抑えます。 | オン |

## 白黒

画像をグレーに変換します。色相ごとに、どのくらい明るくするかをスライダーで決めます。**着色**は、結果を**着色の色**で色付けします。

| 設定 | 範囲または選択肢 | 初期値 |
| --- | --- | --- |
| **レッド** | −100%〜200% | 40% |
| **イエロー** | −100%〜200% | 60% |
| **グリーン** | −100%〜200% | 40% |
| **シアン** | −100%〜200% | 60% |
| **ブルー** | −100%〜200% | 20% |
| **マゼンタ** | −100%〜200% | 80% |
| **着色** | オンまたはオフ | オフ |
| **着色の色** | 任意の色 | #BF874C |

## グラデーションマップ

画像の階調を**グラデーション**に割り当てます。最も暗い階調は左端のストップ、最も明るい階調は右端のストップになります。**量**は、結果を元の画像と混ぜます。

| 設定 | 範囲または選択肢 | 初期値 |
| --- | --- | --- |
| **グラデーション** | 任意のグラデーション。[グラデーション](/ja/docs/drawing/gradient/)ツールと同じように編集します | 黒から白、**Oklab**補間 |
| **量** | 0–100% | 100% |

## ホワイトバランス

**色温度**で画像を暖かく、または冷たくし、**色かぶり**でマゼンタまたはグリーンの方向にずらします。**プロパティ**パネル上部の**中間色の点を選択**は、キャンバス上でクリックした点が無彩色になるように、両方を設定します。

| 設定 | 範囲または選択肢 | 初期値 |
| --- | --- | --- |
| **色温度** | −100〜100（数値入力では最大±1000）。正の値で暖かくなります。 | 0 |
| **色かぶり** | −100〜100（数値入力では最大±800）。正の値でマゼンタ寄りになります。 | 0 |
| **明るさを保持** | オンまたはオフ | オン |

## 明暗の色分け

明るさを保ったまま、シャドウを**シャドウ**の色に、ハイライトを**ハイライト**の色に色付けします。

| 設定 | 範囲または選択肢 | 初期値 |
| --- | --- | --- |
| **シャドウ** | 任意の色 | #295494 |
| **ハイライト** | 任意の色 | #F5AD57 |
| **バランス** | −100〜100。2つの色が切り替わる位置を動かします。正の値にすると、画像のより広い部分が**シャドウ**の色になります。 | 0 |
| **強さ** | 0–100% | 30% |

## ソラリゼーション

各カラーチャンネルで、**しきい値**より明るい部分を反転します。**強さ**は、結果を元の画像と混ぜます。

| 設定 | 範囲または選択肢 | 初期値 |
| --- | --- | --- |
| **しきい値** | 0–100% | 50% |
| **強さ** | 0–100% | 100% |

## 虹色光沢

画像の明るさに沿った薄膜の虹色を加え、時間とともに変化させます。書き出した画像には、書き出した瞬間の色が写ります。

| 設定 | 範囲または選択肢 | 初期値 |
| --- | --- | --- |
| **強さ** | 0–100% | 55% |
| **薄膜の大きさ** | 8–240 px | 64 px |
| **速度** | 0–4 | 0.3 |
| **アニメーション** | オンまたはオフ。オンの間は、**速度**に応じて色が変化し続けます。 | オン |
| **固定時刻** | 0–3600 s：**アニメーション**がオフのときに表示する時点 | 0 s |
