**混色**でレイヤーの絵の具をこすって混ぜ、**ゆがみ**でピクセルを動かせます。

## 混色

次のいずれかの操作を行います。

- **J**を押します。
- 「ペイント」では、「ツール」ツールバーの**混色**を選択します。同じボタンに**コピースタンプ**も含まれます。
- 「写真」では、「ツール」ツールバーの**混色**を選択します。
- 「スケッチ」では、**形を整える**の引き出しで混色ブラシを選びます。
- コマンド検索で**混色**を検索します。

**ツールセット**でセットと混色ブラシを選びます。**指先**が初期の混色ブラシです。

| セット | 混色ブラシ |
| --- | --- |
| **混色** | **指先**、**ソフト混色**、**ぼかし**、**擦筆**、**ティッシュ**、**ざらざら混色**、**質感を保つ混色**、**色相混色** |
| **ウェット** | **自然な混色**、**ウェット混色**、**色混ぜ**、**混色ナイフ**、**筆跡混色** |
| **エフェクト** | **絵画風混色**、**くし混色**、**散らし混色**、**シャープ**、**マーブリング**、**結晶混色**、**ディザ混色** |

各混色ブラシの設定は、[混色、にじみ、筆毛](/ja/docs/brushes/wet-media/)にあります。

### 筆跡混色

**筆跡混色** は絵の具を筋状に引き延ばします。この例の左端は混ぜる前の状態です。

![右側の色帯を 筆跡混色 で筋状に混ぜた状態。](shot:examples/bristle-blender)

### ディザ混色

**ディザ混色** は色帯をディザーパターンで混ぜます。

![右側の色帯を ディザ混色 で混ぜた状態。](shot:examples/dither-blender)

### マーブリング

**マーブリング** は絵の具を渦状に曲げます。

![右側の色帯を マーブリング で渦状に曲げた状態。](shot:examples/marbling)

## ゆがみ

次のいずれかの操作を行います。

- 混色を使用中に**J**を押します。
- 「ペイント」または「写真」では、「ツール」ツールバーの**ゆがみ**を選択します。ボタンを右クリックするか長押しすると、モードを選べます。
- 「スケッチ」では、**形を整える**の引き出しの**ゆがみ**セットでモードを選びます。
- コマンド検索で**ゆがみ**を検索します。

各モードは、**ツールセット**のプリセットです。

| プリセット | 効果 |
| --- | --- |
| **ゆがみ・押す** | ストロークに沿ってピクセルを引きずります。 |
| **ゆがみ・左回り** | ブラシの中心の周りで、ピクセルを反時計回りに回転させます。 |
| **ゆがみ・右回り** | ブラシの中心の周りで、ピクセルを時計回りに回転させます。 |
| **ゆがみ・収縮** | ピクセルをブラシの中心に向かって引き寄せます。 |
| **ゆがみ・膨張** | ピクセルをブラシの中心から外側へ押し出します。 |
| **ゆがみ・結晶** | ブラシの下の画像を、散らばった小さなセルに分割します。 |
| **エッジ** | ストロークの線に向かって、両側からピクセルを引き寄せます。 |
| **復元** | ブラシの下で、ゆがみによる変形を元に戻します。 |

ゆがみには適用ボタンがありません。ストロークごとにレイヤーが変わり、それぞれが1つの取り消しステップになります。ストロークは、最初のストロークの前にレイヤーにあったピクセルを変形し続けます。これは、レイヤーに描く、塗りつぶす、フィルターをかける、変形する、貼り付けるのいずれかを行うまで続きます。

### エッジ

**エッジ** は絵の具をストロークの線に引き寄せます。左側の色帯は元の状態です。

![右側の水平ストロークに向かって エッジ が色帯を引き寄せた状態。](shot:examples/liquify-edge)

### 復元

**復元** はブラシの下の絵の具を元に戻します。この例では変形した色帯の右半分を戻しています。

![左側の変形した色帯と、右側の 復元 で元に戻した色帯。](shot:examples/liquify-reconstruct)

## ゆがみを調整／ゆがみをリセット

レイヤーにこれまで加えたゆがみ全体は、**ゆがみを調整**で弱めたり、**ゆがみをリセット**で最初のストロークの前のピクセルに戻したりできます。

次のいずれかの操作を行います。

- **ツール**パネルで**ゆがみを調整**をオンにするか、**ゆがみをリセット**を選択します。
- コマンド検索で**ゆがみを調整**または**ゆがみをリセット**を検索します。

**ゆがみを調整**がオンの間は、**ツール**パネルに**適用量**スライダーが表示されます。100%ではゆがみがそのまま残り、0%ではゆがみがなくなります。スライダーを離すと1つの取り消しステップになり、**ゆがみをリセット**も1ステップです。

どちらのコマンドも、レイヤーにゆがみの変更がない間は使用できず、「先にこのレイヤーにゆがみを適用してください」と表示されます。

## ゆがみの設定

![ゆがみ・結晶のツールパネル。強さ、ゆがみと勢いが表示されたゆがみグループ、ゆがみを調整とゆがみをリセットがあります。](shot:drawing/liquify-settings)

**ゆがみ**と**勢い**は**ツール**パネルの**ゆがみ**グループにあります。

### 強さ

1つのダブでピクセルを動かす距離を設定します。筆圧が弱いときと、柔らかいブラシ先端の縁に近いところでは、効果が弱くなります。

### ゆがみ

動きを不規則にします。**ゆがみ・結晶**では、セルが散らばる距離を設定します。**復元**には**ゆがみ**はありません。

### 勢い

ペンを離した後も、ストロークの最後の方向に効果を運び続けます。**復元**には**勢い**はありません。

## 「スケッチ」の「形を整える」の引き出し

「スケッチ」では、タイトルバーの**形を整える**を選択すると最後に使った混色、ゆがみ、レタッチのツールを使え、もう一度選択すると引き出しが開き、さらにもう一度選択すると引き出しが閉じます。引き出しには、セット、選んだセットのツール、その設定が並びます。**形を整える**と**ブラシ**は、それぞれ最後に使ったプリセットとブラシサイズを個別に保持します。

![「スケッチ」の「形を整える」の引き出し。左に混色、ウェット、エフェクト、ゆがみ、レタッチのセット、中央に混色セットの混色ブラシ、右に指先の設定があります。](shot:drawing/sketch-sculpt-drawer)

## マスクへの描画

マスク上では、混色とゆがみは絵の具をこすったりピクセルを動かしたりせず、濃淡だけを描きます。それぞれのマスクで最初にこのようなストロークを描いたときに、通知が表示されます。
