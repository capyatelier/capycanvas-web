**ペン**、**鉛筆**、**絵筆**、**エアブラシ**、**装飾**の各ツールで描画し、**消しゴム**で消すことができます。各ツールには、内蔵のブラシプリセットのグループが1つ以上あります。

## ツールとプリセット

| ツール | グループ | プリセット |
| --- | --- | --- |
| **ペン** | **ペン** | **Gペン**、**ざらついたGペン**、**カリグラフィーペン**、**アンティークペン**、**リアルなペン**、**湿ったインク**、**にじみインク**、**墨筆** |
| | **マーカー** | **マーカー** |
| **鉛筆** | **鉛筆** | **鉛筆**、**尖った鉛筆**、**陰影用鉛筆** |
| | **パステル** | **木炭**、**チョーク**、**角形パステル** |
| **絵筆** | **ペイント** | **絵筆**、**硬毛ブラシ**、**質感のある平筆**、**かすれ塗り**、**透明グレーズ**、**不透明ガッシュ**、**乗算グレーズ** |
| | **水彩** | **水彩ウォッシュ**、**ウェット水彩** |
| | **油彩** | **厚塗り油彩**、**パレットナイフ**、**湿った丸筆** |
| **エアブラシ** | **エアブラシ** | **エアブラシ** |
| | **スプレー** | **スプレー** |
| **消しゴム** | **消しゴム** | **消しゴム** |
| **装飾** | **テクスチャ** | **二重テクスチャ** |

ツールとその各グループは、最後に使ったプリセットを保持します。プリセット自体には色がありません。どのブラシも、[色パネル](/ja/docs/color/color-panel/)の現在の色で描画します。

## プリセットの動作

次の動作はプリセットに組み込まれていて、設定はありません。

| プリセット | 動作 |
| --- | --- |
| **カリグラフィーペン**、**アンティークペン** | ペン先が斜めにカットされています。 |
| **マーカー** | 平たいチゼル型の先端です。 |
| **鉛筆**、**尖った鉛筆**、**陰影用鉛筆**、**木炭** | ペンを傾けると線が太くなります。 |
| **エアブラシ** | ペンを止めて押し当てている間も、絵の具が加わり続けます。 |
| **スプレー** | ダブがストロークの周囲に散らばります。 |
| **乗算グレーズ** | 乗算モードで描画します。 |

## ブラシツールの選択

次のいずれかの操作を行います。

- ペンと鉛筆は**P**、絵筆、エアブラシ、装飾は**B**、消しゴムは**E**を押します。**P**または**B**をもう一度押すと、そのキーの次のツールに切り替わります。
- 「ペイント」では、左端の「ツール」ツールバーでツールを選択します。
- 「写真」では、「ツール」ツールバーで**ブラシ**または**消しゴム**を選択します。**ブラシ**には、絵筆、ペン、鉛筆、エアブラシ、装飾が含まれます。
- 「スケッチ」では、タイトルバーの**ブラシ**または**消しゴム**を選択します。
- [コマンド検索](/ja/docs/start/command-search/)で、ツール、プリセット、またはグループ名に「のブラシ」を付けた名前（**鉛筆のブラシ**など）を検索します。

ツールのボタンには最後に使ったグループのアイコンが表示され、ツールチップには「マーカー · ペン (P)」のように両方の名前が表示されます。

プリセットと、**P**と**B**に割り当てられたツールには、個別のキーがありません。[キーボードショートカット](/ja/docs/input/keyboard/)のページでキーを割り当てられます。

## ツールセットパネル

**ツールセット**パネルで、グループとプリセットを選べます。

次のいずれかの操作を行います。

- **ウィンドウ > ツールセット**を選びます。
- 「ペイント」では、左の列の**ツールセット**タブを選択します。
- 「写真」では、右側のアイコン列で**ツールセット**を選択します。
- 使用中のツールのボタンをもう一度選択します。**ツールセット**と**ツール**を含む引き出しが開きます。

![「ペイント」のツールセットパネル。ペンとマーカーのグループの下に、ペンのプリセットとストロークのプレビューが並んでいます。](shot:drawing/brush-tool-set)

上の行には、ツールのグループが並びます。「写真」の**ブラシ**では、上の行にツールが並びます。その下に、選んだグループの各プリセットがストロークのプレビュー付きで表示されます。

## ボタンからのグループの選択

ツールのボタンのメニューからグループを選べます。ボタンを右クリックするか長押しすると、メニューが開きます。現在のグループにはチェックマークが付きます。

メニューがあるボタンには、隅に小さな三角形が表示されます。

![「ツール」ツールバーの絵筆ボタンのメニュー。ペイント、水彩、油彩のグループが並んでいます。](shot:drawing/brush-group-menu)

## 「スケッチ」の引き出し

「スケッチ」では、タイトルバーの**ブラシ**または**消しゴム**を選択すると、最後に使ったプリセットを使えます。もう一度選択すると引き出しが開き、さらにもう一度選択すると引き出しが閉じます。

**ブラシ**の引き出しには3つの列があります。**ブラシ**にはグループが、1つ目の**ツール**には選んだグループのプリセットが並び、2つ目の**ツール**にはその設定があります。グループを選ぶと、そのグループで最後に使ったプリセットが選択され、引き出しは開いたままになります。**消しゴム**の引き出しには、プリセットの**ツール**と設定の**ツール**の列しかありません。

![「スケッチ」のブラシの引き出し。ブラシ、ツール、ツールの各列があります。](shot:drawing/sketch-brush-drawer)

## 消しゴム

**消しゴム**で、選択したレイヤーの絵の具を消せます。**E**を押すか、「ツール」ツールバー（「スケッチ」ではタイトルバー）で**消しゴム**を選択します。

マスクの編集中は、消しゴムでマスクの範囲を消します。

色パネルで**透明色で描画**を選択していると、どのブラシでも消せます。ペンの消しゴム側でも消せます（[ペン](/ja/docs/input/pen/)）。

**透明度をロック**がオンのレイヤーでは、消しても何も変わりません。

## 絵の具が描かれるレイヤー

ブラシのストロークは、選択したレイヤーに描かれます。マスクの編集中は、そのマスクに描かれます。フィルターレイヤーでは、ストロークはフィルターのマスクに描かれます。フィルターにマスクがない場合は、フィルターが適用されるレイヤー、またはそのすぐ下のレイヤーに描かれます（[フィルターの適用のしくみ](/ja/docs/filters/how-filters-apply/)）。

選択範囲がある間は、選択範囲の中にだけ描かれます。

次のレイヤーでは、ストロークを描いても何も描かれず、理由が通知されます。

- グループまたは選択範囲レイヤー。
- マスクのない塗りつぶしレイヤー。
- **編集をロック**がオンのレイヤー、またはロックされたグループ内のレイヤー。
- マスクのないフィルターレイヤーで、その下のレイヤーがロックされているか、存在しない場合。
- 拡大・縮小または回転したレイヤー。**変形をピクセルに適用**を選ぶまで描けません（[移動と変形](/ja/docs/transform/move-transform/)）。

にじみ、混色、水彩のブラシでマスクに描くと、濃淡だけが描かれます。それぞれのマスクで最初にこのようなストロークを描いたときに、通知が表示されます。
