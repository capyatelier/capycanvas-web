Anda dapat menyembunyikan bilah judul serta panel dan bilah alat yang tertambat dalam
Mode Zen. Kanvas kemudian memenuhi jendela.

![Kanvas dalam Mode Zen, dengan panel mengambang dan tombol Capy di sudut.](shot:zen/zen-canvas)

## Masuk dan keluar dari Mode Zen

Lakukan salah satu langkah berikut:

- Pilih **Tampilan > Mode Zen**.
- Tekan **Tab**.
- Pilih tombol Capy di ujung kiri bilah judul. Dalam Mode Zen, tombol ini ada di sudut kiri atas jendela.
- Ketik "Mode Zen" di [pencarian perintah](/id/docs/start/command-search/).
- Dengan pemetaan tombol **Gaya Procreate**, ketuk kanvas dengan empat jari.

Lakukan hal yang sama lagi untuk keluar dari mode Zen.

Mode Zen disimpan bersama setiap ruang kerja dan tetap aktif setelah aplikasi dimulai
ulang. **Sesuaikan Bilah Judul…** menonaktifkan Mode Zen.

## Yang tetap tampil di layar

Mode Zen juga menyembunyikan kolom yang diciutkan dan bagian bawah jendela. Yang tetap
tampil:

- panel mengambang
- bilah tindakan kanvas di samping seleksi atau transformasi
- tombol Capy, kecuali jika **Tampilkan Capy dalam mode Zen** nonaktif
- pemberitahuan

Tombol pintasan dan pencarian perintah (**Ctrl+K**) berfungsi seperti biasa.

## Menambatkan dalam Mode Zen

Saat panel tertambat disembunyikan, panel mengambang yang diseret hanya dapat bergabung dengan panel mengambang lain.

## Menu tombol Capy

Klik kanan tombol Capy, atau tahan dengan jari, untuk membuka menunya.
**Ubah ikon…** membuka Preferensi di **Ikon tombol**. Di bilah judul, menu ini juga
berisi **Sesuaikan Bilah Judul…**.

Menahan tombol Capy dengan jari tidak mengaktifkan atau menonaktifkan Mode Zen.

![Menu tombol Capy.](shot:zen/capy-menu)

## Preferensi Mode Zen

Pilih **Edit > Preferensi**, pilih **Tampilan**, lalu cari grup **Mode Zen**.
Pengaturan ini berlaku untuk semua ruang kerja.

### Tampilkan Capy dalam mode Zen

Mempertahankan tombol Capy di sudut kiri atas dalam Mode Zen. Aktif secara bawaan.
Selama pengaturan ini nonaktif, tekan **Tab** atau gunakan pencarian perintah untuk
keluar dari Mode Zen.

### Ikon tombol

Mengatur gambar tombol Capy: **Menengadah** (bawaan), **Menghadap depan**, **Mandi**,
atau **Tidur**. Tombol **Mode Zen** di bilah alat memakai gambar yang sama.
