## Buka gambar atau foto

Pilih **File → Open…** untuk membuka file `.capy`. Anda dapat membuka foto dan gambar lain dengan cara yang sama, termasuk file JPEG, PNG, TIFF, WebP, HEIC, AVIF, dan OpenEXR. Sebuah foto dibuka sebagai gambar baru pada ukuran aslinya, dan warnanya dipertahankan seperti saat diambil.

Untuk memasukkan gambar ke dalam gambar yang sudah Anda buka, pilih **File → Import Image as Layer…**, atau seret file gambar ke kanvas. Anda juga dapat menyalin gambar di aplikasi lain dan menempelkannya dengan **Ctrl+V**, yang berguna untuk gambar referensi. [Edit foto](/id/docs/filters/image-editing/) menunjukkan kedua cara secara lebih detail.

## Bekerja dengan beberapa gambar

Di Paint dan Photo, setiap gambar yang Anda buka atau buat memiliki tabnya sendiri di bagian atas jendela. Klik tab untuk beralih ke gambar tersebut, atau seret tab untuk mengubah urutannya. Titik di sebelah nama memberi tahu Anda bahwa gambar tersebut memiliki perubahan yang belum disimpan. **File → Drawings…** mencantumkan setiap gambar terbuka, di ruang kerja mana pun.

Tutup gambar dengan tombol pada tabnya atau dengan **File → Close**. Jika ada perubahan yang belum disimpan, Capy Canvas menanyakan apakah Anda ingin menyimpannya terlebih dahulu.

## Simpan dan pulihkan pekerjaan Anda

Pilih **File → Save As…** saat pertama kali Anda menyimpan gambar, dan **File → Save** setelahnya untuk memperbarui file yang sama. Saat Anda menyimpan foto yang Anda buka, Capy Canvas menanyakan di mana menyimpan file `.capy` baru dan membiarkan foto aslinya tidak tersentuh.

Jika browser ditutup sebelum Anda menyimpannya, Capy Canvas menawarkan untuk memulihkan gambar Anda saat Anda membukanya lagi. Ini hanya jaring pengaman, jadi simpan file `.capy` Anda secara teratur dan simpan salinan file penting.

Untuk membuat gambar untuk dibagikan atau dicetak, lihat [Mengekspor gambar](/id/docs/output/export/).
