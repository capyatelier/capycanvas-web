{appName} menggunakan prosesor grafis perangkat untuk menggambar dan menampilkan kanvas. Dukungan bergantung pada kombinasi aplikasi atau browser, sistem operasi, dan perangkat keras grafis.

## Aplikasi native

Aplikasi desktop mendukung Windows, macOS, dan Linux. Aplikasi native iPad memerlukan iPadOS 17.5 atau lebih baru. Aplikasi Android memerlukan Android 12 atau lebih baru.

Aplikasi iPad dan Android merupakan rilis beta. Memenuhi persyaratan sistem operasi saja tidak menjamin setiap prosesor grafis atau pena berfungsi.

## Editor web

Editor web berjalan di browser berikut:

| Sistem | Browser |
| --- | --- |
| Windows | Chrome, Edge, Firefox 141 atau lebih baru |
| macOS | Chrome, Edge, Safari 26 atau lebih baru, Firefox 147 atau lebih baru pada Apple silicon |
| Linux dengan Wayland | Chrome, Edge |
| iPadOS 26 atau lebih baru | Safari |
| Android 12 atau lebih baru | Chrome |

Batas minimum iPadOS 17.5 untuk aplikasi native iPad tidak berlaku bagi Safari. Editor web memerlukan iPadOS 26 atau lebih baru karena menggunakan fitur grafis browser yang tersedia pada rilis tersebut.

## Dukungan grafis

Jika kanvas tidak dapat dimulai, {appName} menampilkan pesan yang menjelaskan kemampuan grafis yang tidak tersedia. Perbarui sistem operasi, browser, dan driver grafis terlebih dahulu. Jika pesan tetap muncul, sertakan teks persisnya serta model perangkat dan grafis saat melaporkan masalah.
