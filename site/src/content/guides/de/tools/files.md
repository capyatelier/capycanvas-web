## Öffnen Sie eine Zeichnung oder ein Foto

Wählen Sie **File → Open…**, um eine `.capy`-Datei zu öffnen. Sie können Fotos und andere Bilder auf die gleiche Weise öffnen, einschließlich der Dateien JPEG, PNG, TIFF, WebP, HEIC, AVIF und OpenEXR. Ein Foto wird als neue Zeichnung in Originalgröße geöffnet und die Farben bleiben so erhalten, wie sie aufgenommen wurden.

Um ein Bild in die bereits geöffnete Zeichnung einzufügen, wählen Sie stattdessen **File → Import Image as Layer…** oder ziehen Sie die Bilddatei auf die Leinwand. Sie können ein Bild auch in eine andere App kopieren und mit **Ctrl+V** einfügen, was für Referenzbilder praktisch ist. [Ein Foto bearbeiten](/de/docs/filters/image-editing/) zeigt beide Richtungen detaillierter.

## Arbeiten Sie mit mehreren Zeichnungen

In Paint und Photo erhält jede Zeichnung, die Sie öffnen oder erstellen, eine eigene Registerkarte oben im Fenster. Klicken Sie auf eine Registerkarte, um zu dieser Zeichnung zu wechseln, oder ziehen Sie die Registerkarten, um ihre Reihenfolge zu ändern. Ein Punkt neben dem Namen zeigt an, dass die Zeichnung Änderungen aufweist, die noch nicht gespeichert wurden. **File → Drawings…** listet jede geöffnete Zeichnung in jedem Arbeitsbereich auf.

Schließen Sie eine Zeichnung mit der Schaltfläche auf ihrer Registerkarte oder mit **File → Close**. Wenn nicht gespeicherte Änderungen vorhanden sind, werden Sie von Capy Canvas gefragt, ob Sie sie zuerst speichern möchten.

## Speichern Sie Ihre Arbeit und stellen Sie sie wieder her

Wählen Sie **File → Save As…**, wenn Sie eine Zeichnung zum ersten Mal speichern, und anschließend **File → Save**, um dieselbe Datei zu aktualisieren. Wenn Sie ein geöffnetes Foto speichern, fragt Capy Canvas, wo eine neue `.capy`-Datei gespeichert werden soll, und lässt das Originalfoto unberührt.

Wenn der Browser geschlossen wird, bevor Sie gespeichert haben, bietet Capy Canvas an, Ihre Zeichnung beim nächsten Öffnen wiederherzustellen. Dies ist nur ein Sicherheitsnetz. Speichern Sie Ihre `.capy`-Dateien daher regelmäßig und bewahren Sie Kopien wichtiger Dateien auf.

Informationen zum Erstellen eines Bilds zum Teilen oder Drucken finden Sie unter [Bild exportieren](/de/docs/output/export/).
