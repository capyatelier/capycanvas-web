## Ordnen Sie die Paneele an

Ziehen Sie ein Bedienfeld an seiner Lasche oder seinem Griff, um es zu verschieben. Beim Ziehen zeigen Markierungen die Stellen an, an denen es andocken kann. Lassen Sie es an einer anderen Stelle los und das Panel schwebt frei. Ziehen Sie ein Panel auf die Registerkarten eines anderen Panels, um sie zu gruppieren, und ziehen Sie die Kante zwischen den Panels, um eines zu vergrößern. Eine Spalte kann auch zu einer Leiste mit Symbolen zusammengeklappt werden, sodass jedes Bedienfeld nur dann als Schublade geöffnet wird, wenn Sie es benötigen.

Panels verschieben sich, sobald Sie mit dem Ziehen beginnen. Die Schaltflächen innerhalb einer Symbolleiste sind unterschiedlich: Halten Sie eine Schaltfläche einen Moment lang gedrückt, bevor Sie sie ziehen, damit ein schnelles Tippen nie mit einer Bewegung verwechselt wird.

## Wählen Sie Ihre Symbolleisten

Klicken Sie mit der rechten Maustaste auf eine Symbolleiste oder halten Sie sie gedrückt, um auszuwählen, welche Werkzeuge und Befehle angezeigt werden. Symbolleisten können mehr als nur Schaltflächen enthalten: Sie können Schieberegler für Pinselgröße und Deckkraft hinzufügen oder eine **Tool Options**-Leiste, die immer die Einstellungen des aktuellen Werkzeugs anzeigt. Ziehen Sie eine Symbolleiste an ihrem Griff, um sie zu verschieben, und legen Sie sie am Anfang, in der Mitte oder am Ende einer beliebigen Bildschirmkante ab, um sie dort zu befestigen. **Window → Quick Access Toolbars** erstellt und verwaltet zusätzliche Symbolleisten.

Mit **Window → Customize Title Bar…** können Sie die Schaltflächen oben im Fenster anordnen, einschließlich des Arbeitsbereich-Umschalters. Ziehen Sie die Elemente an ihren Platz und beenden Sie den Vorgang, um die neue Anordnung beizubehalten.

## Ändern Sie das Aussehen oder machen Sie eine Änderung rückgängig

**Preferences → Appearance** enthält Einstellungen für das Aussehen der Benutzeroberfläche. Sie können ein helles oder dunkles Thema wählen, eine Akzentfarbe auswählen und festlegen, wie durchsichtig die Paneele sind, sodass Ihr Kunstwerk sanft durch sie hindurchscheinen kann.

Verwenden Sie **Window → Undo Layout Change** und **Redo Layout Change**, um schrittweise durch Änderungen am Layout zu gehen. Das normale Rückgängigmachen gilt nur für Ihre Zeichnung. Um zum Anfang eines Arbeitsbereichs zurückzukehren, wählen Sie **Restore Starting Layout…**. Wenn Sie mehr als eine Anordnung behalten möchten, speichern Sie jede als eigene [workspace](/de/docs/workspace/management/).
