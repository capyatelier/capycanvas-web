## Wählen Sie, wohin das Bild gehen soll

Wählen Sie **File → Export…**, um das Dialogfeld **Export image** zu öffnen. Der einfachste Ausgangspunkt ist **Destination**, wo sinnvolle Einstellungen für Sie vorgenommen werden. **Web / Share** erstellt ein Standardbild, das in jedem Browser oder jeder App gut aussieht. **Wide-color image** behält die lebendigeren Farben bei, die moderne Bildschirme anzeigen können, und **Further editing** behält so viele Details wie möglich zum Öffnen in einem anderen Editor bei.

Es werden nur die sichtbaren Ebenen exportiert. Blenden Sie daher zunächst alle Skizzen- oder Referenzebenen aus, die Sie nicht im endgültigen Bild haben möchten.

## Passen Sie die Details an

Wenn Sie mehr Kontrolle wünschen, ändern Sie die Einstellungen unterhalb des Ziels. **Format** wählt zwischen PNG, JPEG und TIFF. PNG ist eine gute Wahl für Grafiken mit scharfen Kanten oder transparenten Bereichen, während JPEG kleinere Dateien für Fotos erstellt. Normalerweise können Sie **Output profile** und **Bit depth** so belassen, wie sie vom Ziel festgelegt werden.

**Transparency** entscheidet, was mit leeren Bereichen der Zeichnung passiert. Sie können sie in Formaten, die dies unterstützen, transparent halten oder sie mit Weiß oder Schwarz füllen. Mit **Pixel size** können Sie eine kleinere Kopie erstellen, beispielsweise für eine Website. Wenn Ihnen eine Kombination von Einstellungen gefällt, können Sie sie als eigene Voreinstellung speichern.

## Speichern Sie die Datei

Wählen Sie **Preview Output** aus, wenn Sie das Ergebnis vor dem Speichern sehen möchten, und wählen Sie dann **Choose File…** aus, um einen Namen und einen Ort für das Bild auszuwählen. Öffnen Sie die exportierte Datei einmal, um zu überprüfen, ob sie Ihren Erwartungen entspricht.

HDR-Zeichnungen bieten unter **Dynamic range** mehr Auswahlmöglichkeiten, einschließlich HDR JPEG- und AVIF-Dateien, die auf HDR-Bildschirmen hell und auf normalen Bildschirmen immer noch gut aussehen. [Farbräume, HDR und Proofing](/de/docs/color/management/) erklärt, wann sie zu verwenden sind.
