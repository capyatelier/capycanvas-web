## Verfeinern Sie eine Auswahl in der Schnellmaske

Treffen Sie mit einem beliebigen Auswahlwerkzeug eine grobe Auswahl und wählen Sie dann **Select → Quick Mask** oder drücken Sie **Q**. Die Auswahl wird als farbige Überlagerung angezeigt und oben im Ebenenbedienfeld wird eine temporäre **Quick Mask**-Ebene angezeigt. Malen Sie nun mit einem beliebigen Pinsel, um die Auswahl zu erweitern, und entfernen Sie sie mit dem **Eraser**. Weiche Bürsten sorgen für weiche Kanten, was genau das ist, was Sie sich für Fell oder Blätter wünschen.

Wenn die Überlagerung auf Ihrer Zeichnung schwer zu erkennen ist, ändern Sie ihre Farbe oder Deckkraft in **Properties**. Wenn die Auswahl richtig aussieht, wählen Sie **Return to Artwork**, um mit der aktiven Auswahl zum Malen zurückzukehren.

## Paint direkt eine Auswahl

Wenn Sie den ersten Schritt lieber überspringen möchten, wählen Sie das Tool **Paint selection** aus den Auswahltools. Jeder Strich, den Sie ausführen, erweitert die Auswahl, und wenn Sie einen Bereich einkreisen, wird alles darin ausgewählt. Halten Sie **Alt** gedrückt oder wechseln Sie den Modus im Werkzeugfenster, um Teile der Auswahl wieder wegzumalen.

## Speichern Sie die Auswahl für später

Eine Auswahl geht verloren, sobald Sie eine neue erstellen. Speichern Sie daher jede Auswahl, die Sie erneut benötigen. Wählen Sie **Select → Save as Selection Layer** oder **Save as Selection Layer** aus dem Menü der Schnellmaskenebene. Die Auswahl wird als Auswahlebene im Ebenenbedienfeld gespeichert und zusammen mit Ihrer Zeichnung gespeichert.

Um es erneut zu verwenden, wählen Sie **Select → Load Selection** oder halten Sie **Ctrl** gedrückt und klicken Sie auf die Miniaturansicht der Auswahlebene. Sie können es auch mit der aktuellen Auswahl aus dem Ebenenmenü kombinieren. Mit der Schaltfläche **New Selection Layer** unten im Ebenenbedienfeld erstellen Sie eine leere Auswahlebene, in die Sie direkt malen können.
