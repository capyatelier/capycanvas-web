## Bauen Sie Ihre Schichten auf

Wählen Sie unten im **Layers**-Bedienfeld **New layer** aus, um eine Ebene über der aktuellen hinzuzufügen. Doppelklicken Sie auf den Namen einer Ebene, um sie umzubenennen. Klare Namen wie *Sketch* oder *Line Art* erleichtern die Orientierung in einer geschäftigen Zeichnung erheblich. Ebenen weiter oben in der Liste liegen vor den Ebenen darunter. Platzieren Sie also Strichzeichnungen über den Farben, die Sie darunter malen.

Klicken Sie auf die Miniaturansicht einer Ebene, um sie auszuwählen. Die ausgewählte Ebene ist die Ebene, auf der Ihre Pinsel malen, und sie wird in der Liste hervorgehoben. Wenn eine Ebene über eine Maske verfügt, wird eine zweite Miniaturansicht angezeigt. Wenn Sie darauf klicken, können Sie die Maske anstelle der Farbe bearbeiten, was [Masken und Ausschnitt](/de/docs/layers/masks/) erklärt.

## Ausblenden, neu anordnen und ausblenden

Klicken Sie auf das Auge neben einer Ebene, um sie auszublenden. Durch das Ausblenden bleibt alles auf der Ebene, sodass Sie es jederzeit wieder wiederherstellen können. Ziehen Sie eine Ebene nach oben oder unten, um ihre Position im Stapel zu ändern. Mit der Maus können Sie sofort ziehen; Halten Sie die Ebene zunächst mit einem Stift oder Finger einen Moment lang gedrückt oder ziehen Sie sie am Griff. Wischen Sie auf einem Touchscreen über eine Ebene nach links, um sie zu löschen.

Der Schieberegler über der Liste legt die Deckkraft der gesamten Ebene fest, wodurch alles, was bereits darauf gemalt wurde, ausgeblendet wird. Das Menü daneben legt den Mischmodus fest, der ändert, wie sich die Farben der Ebene mit den darunter liegenden Ebenen mischen. **Normal** ist für die meisten Schichten die richtige Wahl. [Gruppen und Überblendung](/de/docs/layers/groups/) zeigt einige nützliche Überblendungsmodi.

## Schützen und organisieren

Öffnen Sie das Menü einer Ebene mit einem Rechtsklick oder halten Sie die Maustaste gedrückt, um weitere Optionen anzuzeigen. **Organize** beinhaltet **Duplicate**, was eine gute Angewohnheit vor einer großen Veränderung ist. **Layer Settings** enthält **Lock editing**, das verhindert, dass eine Ebene versehentlich geändert wird, und **Alpha lock**, mit dem Sie vorhandene Striche neu zeichnen können, ohne außerhalb davon zu malen.

Mit den Schaltflächen am unteren Rand des Bedienfelds können Sie außerdem Gruppen, Masken und Auswahlebenen hinzufügen und ein Bild aus einer Datei importieren. [Schnellmaske und Auswahlebenen](/de/docs/selections/quick-mask/) erklärt, wozu Auswahlebenen dienen.
