## Apri un disegno o una foto

Scegli **File → Open…** per aprire un file `.capy`. Puoi aprire foto e altre immagini allo stesso modo, inclusi i file JPEG, PNG, TIFF, WebP, HEIC, AVIF e OpenEXR. Una foto si apre come un nuovo disegno nelle sue dimensioni originali e i suoi colori vengono mantenuti esattamente come sono stati catturati.

Per portare un'immagine nel disegno che hai già aperto, scegli invece **File → Import Image as Layer…** o trascina il file immagine sulla tela. Puoi anche copiare un'immagine in un'altra app e incollarla con **Ctrl+V**, utile per le immagini di riferimento. [Modifica una foto](/it/docs/filters/image-editing/) mostra entrambe le direzioni in modo più dettagliato.

## Lavora con diversi disegni

In Paint e Photo, ogni disegno che apri o crei ha la propria scheda nella parte superiore della finestra. Fai clic su una scheda per passare a quel disegno oppure trascina le schede per modificarne l'ordine. Un punto accanto al nome indica che il disegno presenta modifiche che non sono state ancora salvate. **File → Drawings…** elenca tutti i disegni aperti, in qualsiasi area di lavoro.

Chiudi un disegno con il pulsante sulla sua scheda o con **File → Close**. Se presenta modifiche non salvate, Capy Canvas ti chiede se desideri salvarlo prima.

## Salva e recupera il tuo lavoro

Scegliere **File → Save As…** la prima volta che si salva un disegno e successivamente **File → Save** per aggiornare lo stesso file. Quando salvi una foto aperta, Capy Canvas chiede dove salvare un nuovo file `.capy` e lascia intatta la foto originale.

Se il browser si chiude prima di aver salvato, Capy Canvas propone di recuperare il disegno la prossima volta che lo apri. Questa è solo una rete di sicurezza, quindi salva regolarmente i tuoi file `.capy` e conserva copie di quelli importanti.

Per creare un'immagine da condividere o stampare, vedere [Esportare un'immagine](/it/docs/output/export/).
